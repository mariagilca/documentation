### What is SlickEdit?

**SlickEdit** is a popular cross-platform, multi-language source code and text editor. It is a commercial product from **SlickEdit, Inc.** that provides a wide array of coding tools and time-saving features. SlickEdit is known for its ability to handle over 60 programming languages and run on multiple platforms, including Windows, macOS, and Linux.

The usage of the SlickEdit editor is managed by a **proprietary license manager**. OpenLM provides an interface to this license manager, allowing you to monitor license usage and obtain usage statistics.

OpenLM provides the following functionality for monitoring SlickEdit licenses:

* **Denials Reporting**: No
* **Report resolution**: By Minute
* **Borrowed License reporting**: Yes
* **Expiration Date reporting**: No
* **Multiple Server Redundancy Support**: No
* **Token License Support**: No

SlickEdit is one of over 69 license managers that OpenLM can manage.
