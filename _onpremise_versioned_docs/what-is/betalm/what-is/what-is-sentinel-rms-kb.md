### What is Sentinel RMS?

**Sentinel RMS**, from **Gemalto**, is a flexible and scalable license manager that allows software vendors to offer a wide variety of business models for any environment, from on-premise to in the cloud. It supports concurrent use, node-locked, pay-per-use, and other license models at the suite, application, or feature level. As a leader in cybersecurity, RMS offers multiple security options, including biometrics, hardware keys, and cloud-based security. Vendors can choose between 128-bit AES encryption or RSA-2048 signing to secure licenses. The system is designed for high reliability, with features like server redundancy and grace periods to ensure uninterrupted user access. RMS is widely adopted, with a significant share of the global software license management market.

* **Denials Reporting**: Yes

* **Expiration Date reporting**: Yes
* **Multiple Server Redundancy Support**: No

Sentinel RMS is one of over 69 license managers that OpenLM can manage.

Sentinel RMS is a mature, API-based platform for implementing various license models, ensuring customer compliance and reducing software piracy.

***

### Flexibility

The API interface enables RMS to support various business models, including software evaluation, standalone node-locked, feature-based, pay-per-use, and network (floating) licenses. Features can also be bundled and deployed as packages.

RMS allows you to bind a license to an out-of-the-box machine fingerprint, a **SafeNet Software Licensing Hardware Key**, or a custom lock code.

### Flavors

Sentinel RMS comes in several versions:
* **Vanilla**: The standard installation.
* **Lightweight version**: For embedded applications.
* **Sentinel RMS on the Cloud**: A cloud-based version.
