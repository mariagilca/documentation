<h2><b>What is Adobe Creative Cloud (Adobe CC)?</b></h2>
<span style="font-weight: 400;">Adobe Creative Cloud (CC) is a SaaS offering that bundles all of Adobe’s graphics software into a single cloud offering, which is hosted on Microsoft Azure. Adobe is notorious for being the first major software vendor to offer a subscription-based software model, replacing their perpetual licensing model, and starting the trend among other vendors, such as Autodesk.</span>

<span style="font-weight: 400;">There are various forms of Creative Cloud, targeted at individual, business, and enterprise customers. Some of the over 30 products bundled in CC include Acrobat Pro, Photoshop, InDesign, and Dreamweaver. For customers who do not need access to graphics, but require the document management capability of Acrobat, there is a Document Cloud option. There is also a marketing/customer experience offering, called Experience Cloud.</span>

<span style="font-weight: 400;">OpenLM previously enabled customers to manage Adobe licensing by using the Applications Manager to access the licenses using the custom license functionality. <h2><b>What is Adobe Document Cloud (Adobe DC)?</b></h2>

<h2><b>What is Adobe Experience Cloud?</b></h2>
<span style="font-weight: 400;">Adobe Experience Cloud was announced in 2017 and combines the products formerly known as Adobe Marketing Cloud, Advertising Cloud, and Analytics Cloud to provide a comprehensive software bundle for managing and measuring the customer experience. It integrates with Creative Cloud and Document Cloud. Some of the products included in the Experience bouquet include Audience Manager, Campaign, and Target. </span>
