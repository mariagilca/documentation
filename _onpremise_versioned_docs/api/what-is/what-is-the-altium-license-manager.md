<h2><b>What is the Altium License Manager?</b></h2>
<span style="font-weight: 400;">As one of the premier providers of EDA software for designing printed circuit boards (PCBs), Altium have their own proprietary license manager for on-premise sites. It is a two-tier licensing system, consisting of a license for the server, which controls a pool of user licenses. When the maximum number of concurrent users are reached, users will be denied until a license is freed up.</span>

<span style="font-weight: 400;">OpenLM provides the following functionality for monitoring Altium Licenses:-</span>
<ul>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Denials Reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">Yes</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Report resolution</span> <span style="color: #000080;"><em><span style="font-weight: 400;">By Minute</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Borrowed License reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Expiration Date reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">Yes</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Multiple Server Redundancy Support</span> <span style="color: #000080;"><em><span style="font-weight: 400;">One backup</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Token License Support</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
</ul>
<span style="font-weight: 400;">Altium is only one of over 70 license managers that OpenLM can manage. </span><a href="https://www.openlm.com/license-manager-capabilities/"><span style="font-weight: 400;">Check the list</span></a><span style="font-weight: 400;">.</span>
