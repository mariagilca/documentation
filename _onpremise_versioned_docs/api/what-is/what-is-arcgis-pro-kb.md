ESRI has released the 10.3 ArcGIS version at the 2nd half of 2014. As a side dish it offered the ArcGIS Pro.
<h2><b>What is ArcGIS Pro</b></h2>
ArcGIS Pro is designed to be the premier application for visualizing, editing, and performing analysis using local or online ArcGIS content. It holds 2D and 3D display capabilities, and is  64-bit, speed optimized for improved user experience. The ESRI user now controls a contextual interface with tools that appear only when needed, in a surrounding that is highly integrated with other ESRI tools.
<h2><b>Main features</b></h2>
ArcGIS Pro introduces many benefits for ArcMap users. among these are:
<ul>
 <li>Project based workflows: The same Data files, i.e. Maps (.mxd), Scenes (.sxd) and Globes (.3DD) can all be imported into ArcGIS Pro. Once in ArcGIS Pro these can be saved and processed as Projects (.aprx).</li>
</ul>
<ul>
 <li>Multiple maps, multiple layout view: ArcGIS Pro introduces a multiple layout approach, enabling data from multiple views to be synchronized and presented together, combining visual information. One such alternative is the combination of 2D and 3D views. <a href="http://video.esri.com/watch/2533/unveiling-the-new-arcgis-professional-application-with-jim-mckinney-and-jack-dangermond">See this ESRI presentation </a>for elaboration.</li>
</ul>
<ul>
 <li>Simplification: A predominant motivation in the development of the ArcGIS Pro application has been the simplification of the interface. Much thought has been spent on the optimization and context of menus and functionality. Such is the creation of multiple features by applying “Grouped Feature Templates”.</li>
</ul>
<ul>
 <li>3D presentation and editing has become more interactive; ArcGIS Pro uses direct feedback and handles for quick and intuitive 3D mapping.</li>
</ul>
<ul>
 <li>Even though it is to be released with the ArcGIS 10.3 version, ArcGIS Pro will be backward compatible with older versions of ArcGIS for desktop versions.</li>
</ul>
<h2><b>The OpenLM point</b></h2>
<a href="https://www.openlm.com/" target="_blank" rel="noopener">OpenLM</a> is a general purpose application for monitoring floating license usage. As it was originated by ESRI veterans, it provides specific benefits for ESRI users. OpenLM will continue supporting ArcGIS license monitoring into the upcoming version.
