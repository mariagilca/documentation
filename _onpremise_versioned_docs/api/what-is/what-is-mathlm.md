<h2>What is MathLM?</h2>
<span style="font-weight: 400;">MathLM is Wolfram’s custom license manager for its products, which include Mathematica and Wolfram One. Where the customer is running multiple instances of the Wolfram system, MathLM is installed as a network license manager, which will manage all access and retrieval of its products, specifically Mathematica. The number of concurrent processes that can run is shown on the network license certificate.</span>

<span style="font-weight: 400;">OpenLM provides the following functionality for monitoring MathLM Licenses:-</span>
<ul>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Denials Reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Report resolution</span> <span style="color: #000080;"><em><span style="font-weight: 400;">By Minute</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Borrowed License reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Expiration Date reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Multiple Server Redundancy Support</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>

<h3>Who is Wolfram?</h3>
<span style="font-weight: 400;">Wolfram Research was founded in 1987 by Stephen Wolfram, and was one of the pioneers in mathematical computation, developing the Wolfram Language to support their computational products. Their flagship product is Mathematica, which is used by millions worldwide. Ten years ago Wolfram|Alpha was designed from the foundation of Wolfram Language. MathLM is Wolfram’s proprietary license manager. The corporate headquarters are based in Champaign Illinois, with offices on every continent.</span>
