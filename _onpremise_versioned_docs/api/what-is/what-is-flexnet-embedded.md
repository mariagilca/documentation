<h2>What is FlexNet Embedded (FNE)?</h2>
FlexNet Embedded is a small-footprint SDK for license management that can be used to protect software on all platforms, although it was primarily designed for IoT devices.

Embedded software licenses are not a new concept, but <a href="https://www.openlm.com/knowledge-base/flexera-flexlm-flexnet-publisher/">Flexera</a>® has revisited the concept and produced a solution in system development kit (SDK) format with a very small footprint of approximately 50k. The vendor who purchases the solution can tailor the license to fit their particular offering to achieve a number of benefits for themselves and their licensees. The embedded licenses are part of Flexera®’s Software Monetization Suite, formerly called the FlexNet Producer Suite, which was originally launched about a decade ago. The embedded licenses are the mechanisms for managing the software and gathering licensing information.

<a href="https://www.openlm.com/download/">OpenLM versions 4.5 and higher</a> support Flexnet Embedded (FNE) that has XML API enabled such as <strong>Avid</strong> or <strong>Nvidia</strong>.

OpenLM provides the following functionality for monitoring FlexNet Embedded:-
<ul>
 <li>Denials Reporting <span style="color: #000080;"><em>No</em></span></li>
 <li>Report resolution<span style="color: #000080;"> <em>By Second</em></span></li>
 <li>Borrowed License reporting <span style="color: #000080;"><em>Yes</em></span></li>
 <li>Expiration Date reporting <span style="color: #000080;"><em>Yes</em></span></li>
 <li>Multiple Server Redundancy Support <span style="color: #000080;"><em>No</em></span></li>
 <li>Token License Support <span style="color: #000080;"><em>Yes</em></span></li>
</ul>
FlexNet Embedded (FNE) is only one of over 70 license managers that OpenLM can manage. <a href="https://www.openlm.com/license-manager-capabilities/">Check the list</a>.
