<h2>What is Sentinel RMS?</h2>
 

<span style="font-weight: 400;">Sentinel RMS, from </span><span style="font-weight: 400;">Gemalto</span><span style="font-weight: 400;">, is a flexible and extensive license manager that allows the software vendor to offer a wide variety of business models for any environment from on-premise to in the cloud. Concurrent use, node-locked licenses, pay-per-use, and permutations of these models can be set up, either per suite, per application, or down to feature level. As a recognized leader in cybersecurity, there are several options for additional securing of the license, including biometrics (fingerprints), the addition of a </span><span style="font-weight: 400;">hardware key,</span><span style="font-weight: 400;"> or cloud-based security. The vendor can choose between 128-bit AES encryption or RSA-2048 signing to secure the RMS licenses. Monitoring includes virtual machines.</span>

<span style="font-weight: 400;">Reliability of connectivity is assured via server redundancy and grace periods when the user’s network goes down. Under normal operating conditions, the license manager operates in real-time mode.</span>

<span style="font-weight: 400;">RMS is second only to Flexera FlexNet in global adoption and has over 35% of the market for software license management.</span>

Sentinel RMS is Safenet’s mature license management system. It provides a flexible API-based platform for implementing various types of license models, thus ensuring customer compliance with licensing terms and conditions and reducing software piracy.

 
<h2>Flexibility</h2>
The API interface enables RMS to support various licensing business models, thus increasing license revenue. Software evaluation licenses, Standalone node-locked, Feature-based licensing, Pay-per-use and Network (‘Floating’)  licenses are all available for implementation. Licensed features can also be aggregated and deployed as packages.

RMS allows you to bind a license to either an out-of-the-box machine fingerprint, a SafeNet Software Licensing Hardware Key, or a custom-defined lock code.
