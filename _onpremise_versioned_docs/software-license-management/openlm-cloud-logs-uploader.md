The logs uploader is what we call the “Manual” method of interfacing with a Flexlm license manager. The license manager files must be uploaded manually to the EasyAdmin User interface.
Make sure to have the necessary admin roles for this procedure.
<h2><a id="post-85568-_v1imufdv32l6"></a>Configuration</h2>
<ol>
 <li>Navigate to the EasyAdmin User Interface:
<ul>
 <li>Go to Start → Administration → License Manager Servers → Add LM.</li>
</ul>
</li>
 <li>Set Up License Manager Details:
<ul>
 <li>Unique Name: Enter a unique name to identify the License Manager. (1)</li>
 <li>License File: Drag and drop the license file into the designated area. (2)</li>
</ul>
</li>
 <li>Submit the License File:
<ul>
 <li>Click [<strong>Submit</strong>]. (3)</li>
</ul>
</li>
 <li>Configure Connection Settings:
<ul>
 <li>Port Number: Define the port number for the License Manager. (4)</li>
 <li>Time Zone: Select the appropriate time zone for the License Manager. (5)</li>
</ul>
</li>
 <li>Click [<strong>Save</strong>] to finalize the setup.
<img class="wp-image-85569" src="https://cdn.openlm.com/wp-content/uploads/2024/05/add-a-new-license-server-window-manually.png" alt="Add a new License Server window (manually)" />

[caption id="attachment_85570" align="alignnone" width="1644"]<img class="wp-image-85570" src="https://cdn.openlm.com/wp-content/uploads/2024/05/word-image-85568-2.png" alt="Figure 1: Add a new License Server window (manually)" width="1644" height="159" /> Figure 1: Add a new License Server window (manually)[/caption]</li>
 <li>The next step is to upload the debug log. To do so, click on the Cloud Icon on the upper right side:

[caption id="attachment_85571" align="alignnone" width="1360"]<img class="wp-image-85571" src="https://cdn.openlm.com/wp-content/uploads/2024/05/debug-log-upload-icon.png" alt="Debug log upload icon" width="1360" height="483" /> Figure 2: Debug log upload icon[/caption]</li>
 <li>Drag and drop the debug log, then click [<strong><strong>Upload].
</strong></strong>

[caption id="attachment_85572" align="alignnone" width="1611"]<img class="wp-image-85572" src="https://cdn.openlm.com/wp-content/uploads/2024/05/drag-and-drop-the-debug-log-prompt.png" alt="Drag and drop the debug log prompt" width="1611" height="578" /> Figure 3: Drag and drop the debug log prompt[/caption]</li>
 <li>Then, the licensing data will be displayed in various OpenLM reports, such as License Activity.

[caption id="attachment_85573" align="alignnone" width="1538"]<img class="wp-image-85573" src="https://cdn.openlm.com/wp-content/uploads/2024/05/license-activity-window.png" alt="License activity window" width="1538" height="753" /> Figure 4: License activity window[/caption]</li>
</ol>
