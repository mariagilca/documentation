<strong>OpenLM features are optional extra software modules</strong> that add enhanced functionality to OpenLM SLM. They are available to all OpenLM SLM customers and may be purchased if and when needed. If you are not certain what features you require for your organization, please <a href="https://www.openlm.com/contact-us/">contact </a>our sales team who will be happy to explain further. And, we will give you a 30-day trial to test it out before you decide!

 

<strong>The OpenLM features are described briefly below:</strong>

<h2 dir="ltr"><strong>Alerts Management</strong></h2>
<p dir="ltr">Define alerts and have them sent to the license administrator. Get notifications when certain criteria are met such as license about to expire, license used to 90% capacity, and more.</p>

<h2 dir="ltr"><strong>Roles and Permissions</strong></h2>
<p dir="ltr">This lets you allocate OpenLM functionality to different administrators. First, define administration roles with different OpenLM capabilities and then grant roles to appropriate administrators as necessary.</p>

<h2 dir="ltr"><strong>Directory Sync </strong></h2>
<p dir="ltr">This lets you import user details from Windows Active Directory, including host and user names, OUs, and groups. Synchronized according to the frequency you specify (doesn’t require anything else) and works with multiple corporate AD domains.</p>

<h2 dir="ltr"><strong>Group Usage </strong></h2>
<p dir="ltr">Gives you a usage reporting option by the group. Groups can be custom-defined in OpenLM or based on imported (synchronized) Active Directory OU’s and work groups</p>

<h2 dir="ltr"><strong>Actual Usage </strong></h2>
<p dir="ltr">This lets you report how much time a license was consumed by a specific user for a specific session. Parameters user idle time, CPU, and data IO. Lets you report how much time a license was idle while in the hands of a user.</p>

<h2 dir="ltr"><strong>License Allocation Manager </strong></h2>
<p dir="ltr">This gives you an easy way to configure FlexNet Publisher and other license manager options files.</p>

<h2 dir="ltr"><strong>Project Usage </strong></h2>
<p dir="ltr">Gives you a usage reporting option by project. Projects are defined in OpenLM and users of engineering software can be forced to select the appropriate project when pulling a license.</p>

<h2 dir="ltr"><strong>Custom Commands </strong></h2>
<p dir="ltr">Admins to run scripts for managing specialized situations on the end-user workstation for licenses and permissions that occur with changing usage status.</p>

<h2 dir="ltr"><strong>Unmanaged Processes </strong></h2>
<p dir="ltr">Monitoring applications that are not managed by a license manager.</p>
