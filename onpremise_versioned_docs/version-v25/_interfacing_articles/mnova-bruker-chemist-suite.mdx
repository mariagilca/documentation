# Mnova

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Mnova Bruker Chemist Suite License Manager.

## Requirements

Before starting, install:

1. OpenLM SLM v2.x on a machine in your organization or have an SLMC account
2. OpenLM Broker v24.8 or higher on the same machine as the Mnova License Manager

## Monitoring capabilities

| LM Type in the Broker | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- |
| MlicAdmin | No | No | No | No | Yes (if the license file for the feature is provided) | No | Seconds |

Using the Broker also enables buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

:::note
OpenLM Broker must be installed and configured to report to OpenLM before proceeding.

### Steps

1. Open the Broker web UI at `http://localhost:5090`.  
   If the default port is in use, try `5091` or `5092`.
2. Go to **License Managers** → **Add License Manager**.
3. Select **MlicAdmin** from the drop-down list, enter the port number (e.g., `888`), and click **Add**.

   ![](https://www.openlm.com/wp-content/uploads/2024/09/word-image-90727-2.png)

4. In **Settings**, configure license files:  
   - Select **Detect license file automatically**, or  
   - Select **Set license file path manually** for each feature.  
     ![](https://www.openlm.com/wp-content/uploads/2024/09/word-image-90727-4.png)
5. If adding manually, click **Add license file path** and browse to each feature’s license file.
6. Ensure **Allow license file sorting** and **Watch license file** are turned **off**.
7. In **Vendors**, click **Add Vendor**, enter `Mnova`, and click **Continue**.

   ![](https://www.openlm.com/wp-content/uploads/2024/09/word-image-90727-5.png)

8. In **Log Files**, click **Add Log File**, ensure **Watch file by pattern** is off, then click **Continue**.

   ![](https://www.openlm.com/wp-content/uploads/2024/09/word-image-90727-6.png)

9. Click **Save**.

## OpenLM Server configuration

Once the Broker is configured, approve the license manager in EasyAdmin:

1. Open EasyAdmin.
2. In **License Servers**, click the **There are Servers Pending Approval** icon.
3. Double-click the pending license manager (displayed as **OpenLM Generic**).
4. Verify details and click **Approve**.

   ![](https://www.openlm.com/wp-content/uploads/2024/09/word-image-90727-8.png)

After approval, the Mnova License Manager will be monitored. A green circle icon indicates an active connection.

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Servers**.
3. Ensure the Mnova entry appears in the list with a green circle status.

   ![](https://www.openlm.com/wp-content/uploads/2024/09/word-image-90727-9.png)

:::note
For new connections, it may take up to 3 minutes for the status to update.
:::
