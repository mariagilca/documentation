## How to use this report

1. **Orphans**: Run through section 2; delete each file unless you can match it to a renamed English file. If you find a rename, move/rename the JA file to match the new EN path.
2. **Missing**: Decide a translation policy. Options:
   - Translate everything in one sprint (engage a translator).
   - Apply a "translate-on-major-release-only" policy, document it in `CONTRIBUTING.md`, and accept that some EN pages render in English when viewed under `/ja/`.
   - Prioritize a subset (e.g. only top-level `getting-started/`, `understanding-openlm/`, `api/`) and leave the rest as English fallbacks.

Docusaurus already falls back to the English source when a Japanese file is missing, so this is a content-quality issue, not a build failure.
