# Token Usage

The Token Usage Report provides insights into how users consume software tokens across dates, users, and features. Tokens represent license usage credits for various software features, and this report helps track peak usage, identify top consumers, and monitor usage patterns to support resource planning.

![Token Usage](/img/reporting/token-usage.png)
*Token Usage*

A detailed report visualizing token consumption trends across dates, users, and features for efficient license resource management.

## Visualizations

- **Token Usage by Date Bar Chart:** Displays the maximum number of tokens that users consume on each day of the selected period, helping you track daily peak loads.

**Values displayed:**

- Date
- Maximum number of Tokens

- **Token Usage by User Bar Chart:** Highlights how many tokens each user consumes, showing top token consumers.

**Values displayed:**

- Username
- Maximum number of Tokens

- **Token Usage by Feature Bar Chart:** Shows the number of tokens users consume for each feature or application, allowing analysis of feature-specific usage.

**Values displayed:**

- Feature Name
- Maximum number of Tokens

- **Filters:**

- **Date Duration:** Users can select any date range between 2023/01/12 to 2025/02/13 to analyze token usage trends.
- **Feature Name:** Users can filter the data based on specific feature names.
- **Username:** Users can select particular users to check their token usage activity.
- **Server Name:** Users can select specific servers to analyze where the token requests originated.
- **Token Type:** Users can filter by different token types if multiple token schemes are in place.
- **Product Name:** Users can narrow down usage by specific products linked to the tokens.
