A report that shows the current usage of each licensed feature. It helps in tracking utilization trends and making licensing decisions.

![Feature Usage Status](/img/reporting/feature-usage-status.png)
*Feature Usage Status*

Feature Usage Summary - Displays current license usage percentages, borrowed counts, and feature-level licensing details.

## Visualizations

- **Feature Usage Status Table:** This table shows how each licensed feature performs. It lists usage percentage, total licenses, how many licenses remain in use, whether users borrow the license, the feature name, vendor, server, version, product name, and any additional key.

**Values displayed:**

- **Usage %:** Percentage of used licenses relative to the total available quantity.
- **Quantity:** Total number of licenses available for the feature.
- **Used:** Number of licenses currently in use.
- **Borrowed:** Shows whether users borrow the license.
- **Feature Name:** Name of the software feature.
- **Vendor:** Vendor supplying the license.
- **Server:** License server name.
- **License Type:** Type of license.
- **Version:** Feature version.
- **Product Name:** Product to which the feature belongs.
- **Additional Key:** Any extra licensing or configuration key associated with the feature.

- **Filters:**

- **Date Duration:** Users can select any date range within a rolling 10-year window - from 1st January 2015 to 17th July 2025 - using this filter.
- **Server Name:** Users can select any server name from this filter.
- **Vendor:** Users can select any vendor from this filter.
- **Feature Name:** Users can select any feature name from this filter.
- **Group Name:** Users can select any group name from this filter.
- **License Type:** Users can select any license type from this filter.
- **Version:** Users can select any version from this filter.
- **Product Name:** Users can select any product name from this filter.
- **Additional Key:** Users can select any additional key from this filter.
- **Project Name:** Users can select any project name from this filter.
