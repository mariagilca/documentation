The Executive overview report gives a high-level, at-a-glance summary of your organization's AI usage and financial metrics. It surfaces headline indicators — total cost, token consumption, and user adoption — alongside breakdowns of cost and token consumption by model and by top users.

## Visualizations

- **Total cost consumption KPI:** The overall cost incurred by AI usage across the organization.

**Values displayed:**

- Total cost (sum of raw cost)

- **Total token consumption KPI:** The combined total of input and output tokens consumed.

**Values displayed:**

- Total tokens (sum of total tokens)

- **Users with allocated licenses KPI:** The distinct count of employees provisioned an AI license through the procurement system.

**Values displayed:**

- Licensed user count (distinct count of email)

- **Users with usage KPI:** The distinct count of users who actively consumed tokens, excluding dormant seats.

**Values displayed:**

- Active user count (distinct count of email, excluding inactive seats)

- **Top user by cost KPI:** The single highest-spending user, with their total cost.

**Values displayed:**

- Highest cost (sum of raw cost)
- User name

- **Total cost by model stacked bar chart:** Cost broken down by model family, for example Opus, Sonnet, and Haiku, with color segments for the specific model versions driving the cost.

**Values displayed:**

- Y-axis: model family
- X-axis: total cost (sum of raw cost)
- Color: specific model name

- **Total tokens by model donut chart:** The proportional distribution of tokens consumed across models, for quick identification of the most-used models.

**Values displayed:**

- Color: model display name
- Value: total tokens (sum of total tokens)

- **Top 5 users by cost bar chart:** The five highest-spending users, ranked by total cost.

**Values displayed:**

- Y-axis: user name
- X-axis: total cost (sum of raw cost)
