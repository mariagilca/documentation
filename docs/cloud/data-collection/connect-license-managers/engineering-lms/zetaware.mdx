# Zetaware

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from ZetaWare License Manager.

## Requirements

Before you query the license manager, install:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Zataware, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Item | Value |
| --- | --- |
| LM Type in the Broker | ZetaWare |
| Commands | No |
| Logs | Yes |
| Quantity | No |
| Expiration date | No |
| Denied | No |
| Borrowing | No |
| Allocations | No |
| Report resolution | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the ZetaWare License Manager](/img/engineering-lms/zetaware/image27.png)
*Diagram of how OpenLM interfaces with the ZetaWare License Manager*

OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.

## Configuring through the Broker UI

1. Open the Broker web UI at http://localhost:5090. If the default port is in use, try 5091 or 5092.

1. Go to License Managers -> Add License Manager.

1. From the LM Type drop-down list, select ZetaWare.

1. Enter the port number (for example, 888) and click Add.

    ![Adding ZetaWare license manager in OpenLM Broker](/img/engineering-lms/zetaware/image20.png)
*Adding ZetaWare license manager in OpenLM Broker*

1. Go to the Vendors tab. Click Add Vendor, enter ZetaWare, and click Continue.

    ![Adding ZetaWare vendor in OpenLM Broker](/img/engineering-lms/zetaware/image108.png)
*Adding ZetaWare vendor in OpenLM Broker*

1. Go to the Log Files tab. Click Add Log File. Turn off Watch file by pattern. You can add multiple logs for different applications. Click Continue.

    ![Adding log files for ZetaWare in OpenLM Broker](/img/engineering-lms/zetaware/image168.png)
*Adding log files for ZetaWare in OpenLM Broker*

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/zetaware/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the ZetaWare license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/zetaware/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Zetaware appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
