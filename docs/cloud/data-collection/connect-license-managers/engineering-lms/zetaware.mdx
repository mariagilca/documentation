Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from ZetaWare License Manager.

## Before you begin

Before you query the license manager, install:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Zataware, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ZetaWare | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the ZetaWare License Manager](/img/engineering-lms/zetaware/image27.png)
*Diagram of how OpenLM interfaces with the ZetaWare License Manager*

OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding.

### Add manually
1. Open the Broker web UI at http://localhost:5090. If the default port is in use, try 5091 or 5092.

1. Go to License Managers → Add License Manager.

1. From the LM Type drop-down list, select ZetaWare.

1. Enter the port number (for example, 888) and select Add.

    ![Adding ZetaWare license manager in OpenLM Broker](/img/engineering-lms/zetaware/image20.png)
*Adding ZetaWare license manager in OpenLM Broker*

1. Go to the Vendors tab. Select Add Vendor, enter ZetaWare, and select Continue.

    ![Adding ZetaWare vendor in OpenLM Broker](/img/engineering-lms/zetaware/image108.png)
*Adding ZetaWare vendor in OpenLM Broker*

1. Go to the Log Files tab. Select Add Log File. Turn off Watch file by pattern. You can add multiple logs for different applications. Select Continue.

    ![Adding log files for ZetaWare in OpenLM Broker](/img/engineering-lms/zetaware/image168.png)
*Adding log files for ZetaWare in OpenLM Broker*

1. Select Save.

## Approve Zetaware in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Zetaware license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Zetaware appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
