Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Oracle Enterprise Manager.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Oracle Enterprise Manager, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

    Monitoring capabilities

    | Item | Value |
    | --- | --- |
    | LM Type in the Broker | Oracle Enterprise Manager |
    | License totals | No |
    | License usage | Yes |
    | Denials | No |
    | Borrowing | No |
    | Expiration date | No |
    | Redundancy | No |
    | Report resolution | Seconds |

    Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

    ![Diagram of how OpenLM interfaces with the Oracle Enterprise Manager](/img/engineering-lms/oracle-enterprise-manager/image27.png)
*Diagram of how OpenLM interfaces with the Oracle Enterprise Manager*

    OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding

## Configure OpenLM Broker

1. Open the Broker web UI at http://localhost:5090. If the default port is in use, try 5091 or 5092.

1. Go to License Managers → Add License Manager.

1. Select Oracle Enterprise Manager from the drop-down list, enter the port number, and select Add.

    ![In Commands, set the Executable path to the folder containing the Oracle Enterprise Manager SQL file in lmsettings and select Execute.](/img/engineering-lms/oracle-enterprise-manager/image74.png)
*In Commands, set the Executable path to the folder containing the Oracle Enterprise Manager SQL file in lmsettings and select Execute.*

    ![In Vendors, select Add Vendor, enter Oracle, and select Continue.](/img/engineering-lms/oracle-enterprise-manager/image11.png)
*In Vendors, select Add Vendor, enter Oracle, and select Continue.*

    ![Select Save.](/img/engineering-lms/oracle-enterprise-manager/image135.png)
*Select Save.*

## Approve Oracle Enterprise Manager in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Oracle Enterprise Manager license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Oracle Enterprise Manager appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
