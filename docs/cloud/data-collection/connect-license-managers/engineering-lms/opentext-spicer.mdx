OpenLM can interface with OpenText to monitor license usage and obtain statistics. This guide is based on integration with OpenLM Broker v4.8.8 or higher. For older Broker versions using the EventLog Monitor tool, see this KB.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as OpenText, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | No | Yes | No |

Using Broker also allows buffered communication and remote start/stop of the license manager service.

## Configure OpenLM Broker

![How OpenLM interfaces with OpenText](/img/engineering-lms/opentext-spicer/image27.png)
*How OpenLM interfaces with OpenText*

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

1. In License Manager Type, select OpenText. Select Apply.

1. In Vendors, enter the name you want shown in reports (for example, OpenText).

1. In Log Files, select Add Log File and browse to the OpenText log file path (for example, C:\OpenText\ImgLM_##_##_##.txt).

1. Select Advanced and activate Watch Files by Pattern.

1. Select Apply.

1. Open the opentext@PORT.properties file in the Broker installation folder and adjust settings:

    - monitored.log.next: newest (default) or newer for testing.

    - date.format: default MM/dd/yyyy HH:mm:ss.

    - opentext.feature.name: feature to monitor (for example, OpenText Desktop Viewer).

    - `total.<FeatureName>`: total licenses for that feature (for example, total. OpenText Desktop Viewer=10).

1. Save changes and Restart Broker.

## Approve OpenText (Spicer) in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the OpenText (Spicer) license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm OpenText (Spicer) appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
