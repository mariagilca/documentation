This document describes how to interface OpenLM with Siemens SIMATIC to monitor license usage and obtain statistics.

## Before you begin

To query Siemens SIMATIC, install:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as SIMATIC, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

Current monitoring capabilities through OpenLM Broker:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | No | No |

## Configure OpenLM Broker

![Diagram of OpenLM interface with Siemens SIMATIC](/img/engineering-lms/siemens-simatic/image27.png)
*Diagram of OpenLM interface with Siemens SIMATIC*

Broker reads the Siemens SIMATIC log file. Once read, data is compiled and sent to OpenLM Server.

### Add manually
OpenLM Broker must be installed and configured to report to OpenLM Server before continuing:

1. Open a browser and go to http://localhost:5090/.

1. Click License Managers, then Add License Manager.

    ![In the pop-up, select the license manager type, enter any port number (for example, 888), then click Add.](/img/engineering-lms/siemens-simatic/image12.png)
*In the pop-up, select the license manager type, enter any port number (for example, 888), then click Add.*

    ![Go to Vendors. Click Add Vendor, enter the name, then click Confirm.](/img/engineering-lms/siemens-simatic/image21.png)
*Go to Vendors. Click Add Vendor, enter the name, then click Confirm.*

    ![Go to Log Files.](/img/engineering-lms/siemens-simatic/image33.png)
*Go to Log Files.*

    ![Click Add Log File, then either enter the path manually or browse for it using the magnifying glass icon.](/img/engineering-lms/siemens-simatic/image46.png)
*Click Add Log File, then either enter the path manually or browse for it using the magnifying glass icon.*

1. Select the log file, then click Open.

1. From the drop-down, select vendor Siemens SIMATIC.

1. Click Continue.

    ![Click Save.](/img/engineering-lms/siemens-simatic/image86.png)
*Click Save.*

    ![Configure OpenLM Platform](/img/engineering-lms/siemens-simatic/image59.png)
*Configure OpenLM Platform*

## Approve Siemens SIMATIC in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Siemens SIMATIC license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Siemens SIMATIC appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
