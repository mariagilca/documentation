# Razorcat

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Razorcat license manager.

## Requirements

Before starting, make sure you have:

- OpenLM Platform

- OpenLM Broker v25.x or higher installed on the same machine as Razorcart, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The current monitoring capabilities for Razorcat through OpenLM Broker are:

| Item | Value |
| --- | --- |
| Report resolution | By minute |
| License totals | Yes |
| License usage | Yes |
| Denials reporting | No |
| Borrowed license reporting | No |
| Expiration date reporting | No |
| Multiple server redundancy | No |

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the Razorcat license manager](/img/engineering-lms/razorcat/image27.png)
*Diagram of how OpenLM interfaces with the Razorcat license manager*

Install and configure OpenLM Broker before starting these steps.

## Configuring through the Broker UI

1. Open a browser and go to http://localhost:5090/.

1. Go to License Managers -> Add License Manager.

    ![Select Razorcat from the type dropdown, enter the port number, and click Add. IMAGE 1](/img/engineering-lms/razorcat/image70.png)
*Select Razorcat from the type dropdown, enter the port number, and click Add. IMAGE 1*

1. Select Razorcat from the type dropdown, enter the port number, and click Add.

    ![In the Commands tab, set the Executable Path to the folder containing flsutil.exe (or browse with the magnifier icon).](/img/engineering-lms/razorcat/image1.png)
*In the Commands tab, set the Executable Path to the folder containing flsutil.exe (or browse with the magnifier icon).*

1. In the Commands tab, set the Executable Path to the folder containing flsutil.exe (or browse with the magnifier icon).

1. Enter the Service Name (for example, Razorcat).

    ![Go to the Vendors tab -> Add Vendor, enter Razorcat, and click Continue. IMAGE 140](/img/engineering-lms/razorcat/image160.png)
*Go to the Vendors tab -> Add Vendor, enter Razorcat, and click Continue. IMAGE 140*

1. Go to the Vendors tab -> Add Vendor, enter Razorcat, and click Continue.

    ![Click Save.](/img/engineering-lms/razorcat/image140.png)
*Click Save.*

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/razorcat/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Razorcart license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/razorcat/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Razorcart appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
