# Razorcat

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Razorcat license manager.

## Before you begin

Before starting, make sure you have:

- OpenLM Platform

- OpenLM Broker v25.x or higher installed on the same machine as Razorcat, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The current monitoring capabilities for Razorcat through OpenLM Broker are:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | No | No |

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the Razorcat license manager](/img/engineering-lms/razorcat/image27.png)
*Diagram of how OpenLM interfaces with the Razorcat license manager*

Install and configure OpenLM Broker before starting these steps.

### Add manually
- Open a browser and go to http://localhost:5090/.

1. Go to License Managers → Add License Manager.

    ![Select Razorcat from the type dropdown, enter the port number, and click Add.](/img/engineering-lms/razorcat/image70.png)
*Select Razorcat from the type dropdown, enter the port number, and click Add.*

    ![In the Commands tab, set the Executable Path to the folder containing flsutil.exe (or browse with the magnifier icon).](/img/engineering-lms/razorcat/image1.png)
*In the Commands tab, set the Executable Path to the folder containing flsutil.exe (or browse with the magnifier icon).*

1. Enter the Service Name (for example, Razorcat).

    ![Go to the Vendors tab → Add Vendor, enter Razorcat, and click Continue.](/img/engineering-lms/razorcat/image160.png)
*Go to the Vendors tab → Add Vendor, enter Razorcat, and click Continue.*

    ![Click Save.](/img/engineering-lms/razorcat/image140.png)
*Click Save.*

## Approve Razorcat in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Razorcat license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Razorcat appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
