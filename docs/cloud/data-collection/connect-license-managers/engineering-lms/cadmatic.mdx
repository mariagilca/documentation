OpenLM monitors the CADMATIC License Server through OpenLM Broker. Once a data inquiry is configured, the Broker reports **Quantity, Usage, Usernames, and Procurement** data to OpenLM Server. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- OpenLM Platform.
- OpenLM Broker v26.x or later, able to reach the CADMATIC License Server, and approved in [Broker Hub](/cloud/data-collection/broker-hub).

:::note[Documentation in progress]
The full step-by-step configuration guide for CADMATIC is being finalized. If you need to configure CADMATIC today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page.
:::
