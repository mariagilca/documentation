OLicense is one of the license managers supported by OpenLM. This guide explains how to configure OpenLM to interface with OLicense-Server to monitor license usage and obtain license statistics.

Broker method: OpenLM Broker is installed on the OLicense-Server machine, queries locally, and sends data to OpenLM Server.

## Query using OpenLM Server only (direct method)

![Direct query between OpenLM Server and OLicense](/img/engineering-lms/olicense/image96.png)
*Direct query between OpenLM Server and OLicense*

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as OLicense, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

    OpenLM Broker queries OLicense locally and sends data to OpenLM Server, ensuring buffered communication during network outages

    ![OpenLM Broker setup with OLicense](/img/engineering-lms/olicense/image26.png)
*OpenLM Broker setup with OLicense*

## Configure OpenLM Broker

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers.
    - If OLicense is detected automatically, confirm and save.
    - If not, select Add License Manager → Select OLicense → Enter port (default: 80) → Select ADD.

    ![Adding OLicense manually in Broker](/img/engineering-lms/olicense/image169.png)
*Adding OLicense manually in Broker*

1. In Commands, set the path to olixtool.exe. Execute to confirm output.

    ![Defining command path in Broker Web UI](/img/engineering-lms/olicense/image170.png)
*Defining command path in Broker Web UI*

1. In Vendors, select Add Vendor → Enter "OLicense" → Continue.

1. Select SAVE.

1. Configure OpenLM Server as described earlier.

## Approve OLicense in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the OLicense license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm OLicense appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
