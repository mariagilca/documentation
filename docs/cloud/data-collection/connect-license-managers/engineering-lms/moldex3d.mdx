This guide explains how to monitor the Moldex3D License Manager with OpenLM to obtain license usage and statistics.

## Before you begin

Install the following:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Moldex3D, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The following table shows the monitoring capabilities available through OpenLM Broker:

| Report resolution | License totals | License usage | Denials | Borrowed licenses | Expiration dates | Redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | Yes | Yes | No |

Using Broker also allows:

- Buffered communication with OpenLM Server

- Remote start/stop of the license manager service

## Configure OpenLM Broker

![Broker queries Moldex3D License Manager locally using the MDX3DLMUtil utility. Data is then sent to OpenLM Server for processing.](/img/engineering-lms/moldex3d/image121.png)
*Broker queries Moldex3D License Manager locally using the MDX3DLMUtil utility. Data is then sent to OpenLM Server for processing.*

:::note
Ensure Broker is installed and configured to report to OpenLM Server before proceeding.
:::
### Option 1 — Detect automatically
1. In Broker, select Detect.

    ![If the Moldex3D service (for example, Moldex3D-LM Service) is running, Broker detects and configures it automatically.](/img/engineering-lms/moldex3d/image107.png)
*If the Moldex3D service (for example, Moldex3D-LM Service) is running, Broker detects and configures it automatically.*

1. After configuration, select Restart Broker.

1. Also run data_inquiry → Execute to confirm valid output.

### Option 2 — Add manually
1. Install the latest Broker.

1. Open http://localhost:5090/.

1. Go to License Managers.
    - If the Moldex3D service is running, select Detect.
    - If autodetect fails, select Add License Manager. From Type, select Moldex3D. Enter the port and select Add.

    ![In Commands, set the path to MDX3DLMUtil.exe. Select Execute to confirm.](/img/engineering-lms/moldex3d/image124.png)
*In Commands, set the path to MDX3DLMUtil.exe. Select Execute to confirm.*

1. In Vendors, select Add Vendor, enter Moldex3D, and select Continue.

    ![Select Save.](/img/engineering-lms/moldex3d/image82.png)
*Select Save.*

## Approve Moldex3D in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Moldex3D license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Moldex3D appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
