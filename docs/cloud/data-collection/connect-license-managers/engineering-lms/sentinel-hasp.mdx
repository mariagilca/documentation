# Sentinel HASP

OpenLM supports monitoring for a wide and growing variety of license managers. This guide describes how to configure OpenLM to interface with Sentinel HASP, monitor license usage, and obtain license statistics.

OpenLM supports Sentinel HASP versions 5.0 and higher. Versions 4 and below are not supported.

## Before you begin

To query Sentinel HASP, ensure:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Sentinel HASP, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The following monitoring capabilities are available for Sentinel HASP through OpenLM Broker:

- Denials reporting: Yes

- Report resolution: By minute

- Borrowed license reporting: No

- Expiration date reporting: No

- Multiple server redundancy support: No

- Token license support: No

## Configure OpenLM Broker

![Diagram: OpenLM Broker querying Sentinel HASP locally](/img/engineering-lms/sentinel-hasp/image26.png)
*Diagram: OpenLM Broker querying Sentinel HASP locally*

This method uses OpenLM Broker installed on the HASP server to query through command-line utilities and usage logs.

Recommended: Provides full monitoring, including denials and log-based data.

### Configuring Broker (manual setup)

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

1. In Broker, click Add Port and enter the HASP server port (default: 5093).

1. Set LM Type to Sentinel HASP License Manager.

1. Under Commands, browse to the folder containing Sentinel HASP command-line utilities. Click Update.

1. (Windows only) If HASP runs as a service, activate Use Service and enter Sentinel HASP License Manager.

1. Click Apply.

1. Under data_inquiry, click Execute and confirm valid output.

1. Right-click Log Files → Add Log File.

1. Set Type = Other, then browse to the HASP usage log file.

1. Click Apply and Restart Broker.

## Approve Sentinel HASP in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Sentinel HASP license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Sentinel HASP appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
