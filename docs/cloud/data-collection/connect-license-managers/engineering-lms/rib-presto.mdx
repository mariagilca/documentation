Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the RIB Presto License Manager.

## Before you begin

Before starting, make sure you have:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as RIB Presto, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

RIB Presto is monitored through log file parsing. The Broker reads the log file, compiles the data, and sends it to OpenLM Server for processing.

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the RIB Presto License Manager](/img/engineering-lms/rib-presto/image27.png)
*Diagram of how OpenLM interfaces with the RIB Presto License Manager*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

### Add manually
1. Open the Broker web UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

    ![From the drop-down, select Presto and enter any port number (for example, 888) since only log file reading is used. Select Add.](/img/engineering-lms/rib-presto/image48.png)
*From the drop-down, select Presto and enter any port number (for example, 888) since only log file reading is used. Select Add.*

    ![In the Vendors tab, select Add Vendor, enter RIB Presto, and select Continue.](/img/engineering-lms/rib-presto/image54.png)
*In the Vendors tab, select Add Vendor, enter RIB Presto, and select Continue.*

    ![Go to the Log Files tab.](/img/engineering-lms/rib-presto/image61.png)
*Go to the Log Files tab.*

    ![Select Add Log File.](/img/engineering-lms/rib-presto/image83.png)
*Select Add Log File.*

1. Browse to or manually enter the path to the RIB Presto log file.

1. From the vendor list, select RIB Presto.

1. Select Save.

## Approve Rib Presto in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Rib Presto license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Rib Presto appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
