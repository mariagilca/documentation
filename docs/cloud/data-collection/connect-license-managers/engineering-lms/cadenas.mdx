# CADENAS

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from CADENAS Server.

## Requirements

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as CADENAS, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Item | Value |
| --- | --- |
| LM Type in the Broker | Cadenas |
| Commands | No |
| Logs | Yes |
| Quantity | Yes |
| Expiration date | No |
| Denied | No |
| Borrowing | No |
| Allocations | No |
| Report resolution | Seconds |

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the CADENAS Server License Manager](/img/engineering-lms/cadenas/image27.png)
*Diagram of how OpenLM interfaces with the CADENAS Server License Manager*

note

OpenLM Broker must be installed and configured to report to OpenLM before proceeding.

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers -> Add License Manager.

1. Select CADENAS, enter the port number, and click Add.

    ![Adding a CADENAS Server license manager in OpenLM Broker](/img/engineering-lms/cadenas/image110.png)
*Adding a CADENAS Server license manager in OpenLM Broker*


    Adding a CADENAS Server license manager in OpenLM Broker

1. Go to the Vendors tab. Click Add Vendor, enter CADENAS Server, and click Continue.

    ![Adding CADENAS Server vendor in OpenLM Broker](/img/engineering-lms/cadenas/image164.png)
*Adding CADENAS Server vendor in OpenLM Broker*

1. Go to the Log Files tab. Click Add Log File. Turn off Watch file by pattern. Add the log path, then click Continue. Adding a log file for CADENAS Server in OpenLM Broker

1. Click Save.

    Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/cadenas/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Cadenas license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/cadenas/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Cadenas appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
