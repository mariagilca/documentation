Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the L3Harris License Manager.

## Before you begin

Before starting, make sure you have:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as L3Harris, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Report resolution | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | No | No | No | No | No |

The Broker allows buffered communication and allows remote start/stop of the license manager service.

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with L3Harris](/img/engineering-lms/l3harris-geospatial/image27.png)
*Diagram of how OpenLM interfaces with L3Harris*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

1. Open the Broker web UI at http://localhost:5090 (or 5091, 5092 if the default port is in use).

1. Go to License Managers → Add License Manager.

1. From the drop-down, select L3Harris and enter a port number. The port number is not used for data capture but is required for licensing purposes.

1. Select Add.

    ![In the Commands tab, browse to the folder containing the L3Harris log file and select Apply.](/img/engineering-lms/l3harris-geospatial/image65.png)
*In the Commands tab, browse to the folder containing the L3Harris log file and select Apply.*

1. In the Executable path field, specify the executable path on the L3Harris license server.

1. Go to Vendors and set the vendor name.

1. Go to Log Files → Add Log File and configure:
    - Log type - Usage Log
    - Log name (descriptive) - any name to identify the log
    - Log path - browse to the L3Harris logs folder
    - Vendor - vendor defined in the Vendors tab
    - Set data size limit (KB) - default 100
    - Read file every (sec) - default 10
    - Watch file by pattern - Off
    - Encoding - windows-1252

    ![Select Continue and then Save.](/img/engineering-lms/l3harris-geospatial/image112.png)
*Select Continue and then Save.*

## Approve L3Harris Geospatial in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the L3Harris Geospatial license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm L3Harris Geospatial appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
