# L3Harris Geospatial

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the L3Harris License Manager.

## Requirements

Before starting, make sure you have:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as L3Harris, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Item | Value |
| --- | --- |
| Report resolution | By second |
| License totals | Yes |
| License usage | No |
| Denials | No |
| Borrowing | No |
| Expiration date | No |
| Redundancy | No |

The Broker allows buffered communication and allows remote start/stop of the license manager service.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with L3Harris](/img/engineering-lms/l3harris-geospatial/image27.png)
*Diagram of how OpenLM interfaces with L3Harris*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

1. Open the Broker web UI at http://localhost:5090 (or 5091, 5092 if the default port is in use).

1. Go to License Managers -> Add License Manager.

1. From the drop-down, select L3Harris and enter a port number. The port number is not used for data capture but is required for licensing purposes.

1. Click Add.

    ![In the Commands tab, browse to the folder containing the L3Harris log file and click Apply.](/img/engineering-lms/l3harris-geospatial/image65.png)
*In the Commands tab, browse to the folder containing the L3Harris log file and click Apply.*

1. In the Commands tab, browse to the folder containing the L3Harris log file and click Apply.

1. In the Executable path field, specify the executable path on the L3Harris license server.

1. Go to Vendors and set the vendor name.

1. Go to Log Files -> Add Log File and configure:
    - Log type - Usage Log
    - Log name (descriptive) - any name to identify the log
    - Log path - browse to the L3Harris logs folder
    - Vendor - vendor defined in the Vendors tab
    - Set data size limit (KB) - default 100
    - Read file every (sec) - default 10
    - Watch file by pattern - Off
    - Encoding - windows-1252

    ![Click Continue and then Save.](/img/engineering-lms/l3harris-geospatial/image112.png)
*Click Continue and then Save.*

1. Click Continue and then Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/l3harris-geospatial/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the L3Harris license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/l3harris-geospatial/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure L3Harris appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
