Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Kisters VSLM License Manager.

## Before you begin

Before starting, install:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as VSLM, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| LM Type in the Broker | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- |
| VSLM | No | No | No | Yes | Yes | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the VSLM License Manager](/img/engineering-lms/kisters-vslm/image27.png)
*Diagram of how OpenLM interfaces with the VSLM License Manager*

OpenLM Broker must be installed and configured to report to OpenLM before proceeding.

### Add manually
1. Open the Broker web UI at http://localhost:5090. If the default port is in use, try 5091 or 5092. You can also select Detect to automatically detect the license manager.

1. Go to License Managers → Add License Manager.

1. Select VSLM from the drop-down list, enter the port number (for example, 888), and select Add.

    ![In Commands, confirm settings or adjust as needed.](/img/engineering-lms/kisters-vslm/image113.png)
*In Commands, confirm settings or adjust as needed.*

    ![In Vendors, select Add Vendor, enter VSLM, and select Continue.](/img/engineering-lms/kisters-vslm/image154.png)
*In Vendors, select Add Vendor, enter VSLM, and select Continue.*

    ![In Log Files, select Add Log File, browse to the VSLM log location, and ensure Watch file by pattern is off.](/img/engineering-lms/kisters-vslm/image171.png)
*In Log Files, select Add Log File, browse to the VSLM log location, and ensure Watch file by pattern is off.*

    ![Select Save.](/img/engineering-lms/kisters-vslm/image73.png)
*Select Save.*

## Approve Kisters VSLM in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Kisters VSLM license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Kisters VSLM appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
