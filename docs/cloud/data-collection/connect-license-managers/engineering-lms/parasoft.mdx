Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Parasoft.

## Before you begin

Before you query the license manager, install:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Parasoft, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Parasoft | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the Parasoft License Manager](/img/engineering-lms/parasoft/image27.png)
*Diagram of how OpenLM interfaces with the Parasoft License Manager*

OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding.

### Add manually
1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

1. From the LM Type drop-down list, select Parasoft.

1. Enter the port number (for example, 889) and click Add.

    ![Adding Parasoft license manager in OpenLM Broker](/img/engineering-lms/parasoft/image16.png)
*Adding Parasoft license manager in OpenLM Broker*

1. Go to the Vendors tab. Click Add Vendor, enter Parasoft, and click Continue.

    ![Adding Parasoft vendor in OpenLM Broker](/img/engineering-lms/parasoft/image7.png)
*Adding Parasoft vendor in OpenLM Broker*

1. Go to the Log Files tab. Click Add Log File. Turn off Watch file by pattern. You can add multiple logs. Click Continue.

1. Click Save.

## Approve Parasoft in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Parasoft license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Parasoft appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
