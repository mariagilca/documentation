# Parasoft

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Parasoft.

## Requirements

Before you query the license manager, install:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Parasoft, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Item | Value |
| --- | --- |
| LM Type in the Broker | Parasoft |
| Commands | No |
| Logs | Yes |
| Quantity | No |
| Expiration date | No |
| Denied | No |
| Borrowing | No |
| Allocations | No |
| Report resolution | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the Parasoft License Manager](/img/engineering-lms/parasoft/image27.png)
*Diagram of how OpenLM interfaces with the Parasoft License Manager*

OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.

## Configuring through the Broker UI

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers -> Add License Manager.

1. From the LM Type drop-down list, select Parasoft.

1. Enter the port number (for example, 889) and click Add.

    ![Adding Parasoft license manager in OpenLM Broker](/img/engineering-lms/parasoft/image16.png)
*Adding Parasoft license manager in OpenLM Broker*

1. Go to the Vendors tab. Click Add Vendor, enter Parasoft, and click Continue.

    ![Adding Parasoft vendor in OpenLM Broker](/img/engineering-lms/parasoft/image7.png)
*Adding Parasoft vendor in OpenLM Broker*

1. Go to the Log Files tab. Click Add Log File. Turn off Watch file by pattern. You can add multiple logs. Click Continue.

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/parasoft/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Parasoft license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/parasoft/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Parasoft appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
