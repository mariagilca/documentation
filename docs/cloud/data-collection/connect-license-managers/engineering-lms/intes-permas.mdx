This integration allows OpenLM to monitor INTES PERMAS for license usage and availability.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as INTES PERMAS, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute/second | Yes | Yes | No | No | No | No |

## Configure OpenLM Broker

OpenLM Broker communicates with INTES PERMAS to collect license data and send it to OpenLM Server.

You must have OpenLM Broker installed and reporting to OpenLM Server before starting this configuration.

### Manual configuration

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

1. Set License Manager Type to INTES.

1. In the Commands tab → status tab, enter the path to INTES_OpenLM.exe, for example:C:\Program Files (x86)\AMPORTAK\INTES_OpenLM.exe

1. In the Commands tab → data_inquiry tab, enter the path to AMP_OpenLM.exe, for example:C:\Program Files (x86)\AMP\AMP_OpenLM.exe

1. Select Apply.

1. In the Vendors tab, select Add Vendor if none exists.

1. Select the vendor and set Name to INTES PERMAS.

1. Select Apply.

1. Select Restart Broker → select OK → close the tool.

## Approve INTES PERMAS in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the INTES PERMAS license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm INTES PERMAS appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
