# Infograph

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Infograph License Manager.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as InfoGraph, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| InfoGraph | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## Approve Infograph in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Infograph license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Infograph appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
