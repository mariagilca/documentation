# Comos

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Comos license manager.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Comos, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

    | Item | Value |
    | --- | --- |
    | Report resolution | By second |
    | License totals | Yes |
    | License usage | Yes |
    | Denials reporting | Yes |
    | Borrowed license reporting | No |
    | Expiration date reporting | Yes |
    | Multiple server redundancy | No |

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the Comos license manager](/img/engineering-lms/comos/image27.png)
*Diagram of how OpenLM interfaces with the Comos license manager*

:::note
Install and configure OpenLM Broker before starting these steps.
:::
### Option 1 — Detect automatically
1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Detect

1. Comos appears

1. Validate and save

### Option 2 — Add manually
1. Open a browser and go to http://localhost:5090/.

1. Go to License Managers → Add License Manager.

    ![Select Comos from the type dropdown, enter the port number, and click Add.](/img/engineering-lms/comos/image70.png)
*Select Comos from the type dropdown, enter the port number, and click Add.*

    ![In the Commands tab, set the Comos installation path and click Execute to check for errors.](/img/engineering-lms/comos/image62.png)
*In the Commands tab, set the Comos installation path and click Execute to check for errors.*

    ![Go to the Vendors tab → Add Vendor, enter Comos, and click Continue.](/img/engineering-lms/comos/image104.png)
*Go to the Vendors tab → Add Vendor, enter Comos, and click Continue.*

    ![Go to the Log Files tab → Add Log File, browse to the Comos log file, enable Watch file by pattern, and click Continue.](/img/engineering-lms/comos/image56.png)
*Go to the Log Files tab → Add Log File, browse to the Comos log file, enable Watch file by pattern, and click Continue.*

1. Go to the Log Files tab → Add Log File, browse to the Comos log file, activate Watch file by pattern, and click Continue.

    ![Click Save.](/img/engineering-lms/comos/image79.png)
*Click Save.*

## Approve Comos in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Comos license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Comos appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
