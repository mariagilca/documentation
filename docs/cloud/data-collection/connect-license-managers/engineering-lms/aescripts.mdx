OpenLM can monitor AEScripts License Manager through OpenLM Broker to track license statistics.

## Before you begin

Before you begin, make sure you have:

- OpenLM Platform.
- OpenLM Broker v25.x or higher installed on the same machine as AEScripts, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | No | No | No |

Using Broker also allows buffered communication and the ability to remotely start or stop the license manager service.

## Configure OpenLM Broker

![How OpenLM interfaces with AEScripts License Manager](/img/engineering-lms/aescripts/image157.png)
*How OpenLM interfaces with AEScripts License Manager*

### Configuring through the Broker UI
1. Open Broker UI at [http://localhost:5090](http://localhost:5090).
2. Go to Menu: License Managers → Add License Manager.
3. Select AEScripts, enter the port number, and click Add.
4. In Commands, set the executable path and adjust start/stop toggles if needed.
5. In Log Files, click Add Log File, then fill in:
   - Type: AEScripts Log
   - Log name: descriptive name
   - Log Path: path to AEScripts logs folder
   - Vendor: AEScripts
   - Encoding: UTF-16
6. Click Continue, then Save.

## Approve AEScripts in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the AEScripts license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm AEScripts appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
