# Siemens Polarion

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Siemens Polarion License Manager.

## Before you begin

Before starting, make sure you have:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Siemens Polarion, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

Siemens Polarion is monitored through log file parsing. The Broker reads the log file, compiles the data, and sends it to OpenLM Server for processing.

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the Siemens Polarion License Manager](/img/engineering-lms/siemens-polarion/image27.png)
*Diagram of how OpenLM interfaces with the Siemens Polarion License Manager*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

### Add manually
1. Open the Broker web UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

    ![From the drop-down, select Siemens Polarion and enter any port number (for example, 888) since only log file reading is used. Click Add.](/img/engineering-lms/siemens-polarion/image48.png)
*From the drop-down, select Siemens Polarion and enter any port number (for example, 888) since only log file reading is used. Click Add.*

    ![In the Vendors tab, click Add Vendor, enter Siemens Polarion, and click Continue.](/img/engineering-lms/siemens-polarion/image13.png)
*In the Vendors tab, click Add Vendor, enter Siemens Polarion, and click Continue.*

    ![Go to the Log Files tab.](/img/engineering-lms/siemens-polarion/image156.png)
*Go to the Log Files tab.*

    ![Click Add Log File.](/img/engineering-lms/siemens-polarion/image30.png)
*Click Add Log File.*

1. Browse to or manually enter the path to the Siemens Polarion log file.

1. From the vendor list, select Siemens Polarion.

1. Click Save.

## Approve Siemens Polarion in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Siemens Polarion license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Siemens Polarion appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
