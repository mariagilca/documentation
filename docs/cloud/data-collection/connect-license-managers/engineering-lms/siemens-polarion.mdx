# Siemens Polarion

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Siemens Polarion License Manager.

## Requirements

Before starting, make sure you have:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Siemens Polarion, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

Siemens Polarion is monitored via log file parsing. The Broker reads the log file, compiles the data, and sends it to OpenLM Server for processing.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the Siemens Polarion License Manager](/img/engineering-lms/siemens-polarion/image27.png)
*Diagram of how OpenLM interfaces with the Siemens Polarion License Manager*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

## Configuring via Broker UI

1. Open the Broker web UI at http://localhost:5090/.

1. Go to License Managers -> Add License Manager.

    ![From the drop-down, select Siemens Polarion and enter any port number (e.g., 888) since only log file reading is used. Click Add. IMAGE 13](/img/engineering-lms/siemens-polarion/image48.png)
*From the drop-down, select Siemens Polarion and enter any port number (e.g., 888) since only log file reading is used. Click Add. IMAGE 13*

1. From the drop-down, select Siemens Polarion and enter any port number (e.g., 888) since only log file reading is used. Click Add.

    ![In the Vendors tab, click Add Vendor, enter Siemens Polarion, and click Continue. IMAGE 156](/img/engineering-lms/siemens-polarion/image13.png)
*In the Vendors tab, click Add Vendor, enter Siemens Polarion, and click Continue. IMAGE 156*

1. In the Vendors tab, click Add Vendor, enter Siemens Polarion, and click Continue.

    ![Go to the Log Files tab. IMAGE 30](/img/engineering-lms/siemens-polarion/image156.png)
*Go to the Log Files tab. IMAGE 30*

1. Go to the Log Files tab.

    ![Click Add Log File.](/img/engineering-lms/siemens-polarion/image30.png)
*Click Add Log File.*

1. Click Add Log File.

1. Browse to or manually enter the path to the Siemens Polarion log file.

1. From the vendor list, select Siemens Polarion.

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/siemens-polarion/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Siemens Polarion license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/siemens-polarion/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Siemens Polarion appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
