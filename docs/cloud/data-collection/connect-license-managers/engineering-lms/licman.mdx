# Licman

OpenLM can interface with Licman to monitor license usage and obtain statistics. The Licman server is queried locally by OpenLM Broker, which sends the data to OpenLM Server for monitoring and reporting.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Licman, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Licman | Yes | No | Yes | Yes | No | No | No | Seconds |


Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

![Configuring through the Broker UI](/img/engineering-lms/licman/image34.png)
*Configuring through the Broker UI*

1. Open a browser and go to http://localhost:5090/.

1. Go to License Managers → Add License Manager.

1. Select Licman, enter a port, and click Add.

1. In Commands, set the path to licman20_appl.exe.

1. In Vendors, enter the Licman vendor name.

1. Click Save.

    ![Configure OpenLM Platform](/img/engineering-lms/licman/image37.png)
*Configure OpenLM Platform*

## Approve Licman in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Licman license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Licman appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
