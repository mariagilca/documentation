OpenLM can interface with the TASKING License Management System (TLM) through OpenLM Broker to monitor license usage, denials, and other statistics.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Tasking, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | Yes | Yes | No | No |

Broker also provides buffered communication, remote start/stop of the license service, and denials monitoring.

## Configure OpenLM Broker

![How OpenLM interfaces with TASKING](/img/engineering-lms/tasking-license-manager-tlm/image40.png)
*How OpenLM interfaces with TASKING*

Broker runs on the same machine as TLM and queries the license manager using the licdstat tool, then sends the data to OpenLM Server.

## Automatic Broker configuration

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Detect

1. If the TASKING service is running, Broker will detect and configure it automatically.

    ![Configuring through the Broker UI](/img/engineering-lms/tasking-license-manager-tlm/image71.png)
*Configuring through the Broker UI*

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

1. Enter the TLM port number (default: 9090). Select TASKING from the License Manager Type list and click Add.

    ![In the Commands tab, set the executable path to licdstat.exe (usually in C:\Program Files (x86)\TASKING\taskinglm) and click Update, then Apply.](/img/engineering-lms/tasking-license-manager-tlm/image158.png)
*In the Commands tab, set the executable path to licdstat.exe (usually in C:\Program Files (x86)\TASKING\taskinglm) and click Update, then Apply.*

    ![Click Save, then Execute to verify no errors appear.](/img/engineering-lms/tasking-license-manager-tlm/image75.png)
*Click Save, then Execute to verify no errors appear.*

1. In the Vendors tab, click Add Vendor, enter the vendor name, and click Continue.

    ![In Log Files, navigate to the TLM log file to capture denials, then click Continue and Save.](/img/engineering-lms/tasking-license-manager-tlm/image114.png)
*In Log Files, navigate to the TLM log file to capture denials, then click Continue and Save.*

    ![Configure OpenLM Platform](/img/engineering-lms/tasking-license-manager-tlm/image163.png)
*Configure OpenLM Platform*

## Approve TASKING License Manager (TLM) in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the TASKING License Manager (TLM) license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm TASKING License Manager (TLM) appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
