# pure::variants

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the pure::variants License Manager.

## Before you begin

Before starting, make sure you have:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Pure::variants, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | No | No |

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the pure::variants License Manager](/img/engineering-lms/purevariants/image27.png)
*Diagram of how OpenLM interfaces with the pure::variants License Manager*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

### Add manually
1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

    ![From the drop-down, select Pure Variants and enter the port number (for example, 888). Click Add.](/img/engineering-lms/purevariants/image12.png)
*From the drop-down, select Pure Variants and enter the port number (for example, 888). Click Add.*

1. In the Settings tab, make sure Watch License File is off.

1. Go to the Commands tab and enter the executable path for pure::variants.

    ![Go to the Vendors tab → Add Vendor, enter pure::variants, and click Continue.](/img/engineering-lms/purevariants/image134.png)
*Go to the Vendors tab → Add Vendor, enter pure::variants, and click Continue.*

    ![Go to the Advanced tab and enter the pure::variants login and password.](/img/engineering-lms/purevariants/image105.png)
*Go to the Advanced tab and enter the pure::variants login and password.*

1. Click Save.

## Approve pure::variants in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the pure::variants license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm pure::variants appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
