# BetaLM

## Before you begin

Before you begin, make sure you have:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as BetaLM, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Configure through the Broker UI

Follow these steps on the machine where BetaLM is installed:

1. Open the Broker UI at http://localhost:5090/
2. Navigate to License Managers → Add License Manager
3. Enter a descriptive Display name
4. From Type, select BetaLM
5. Enter the Hostname and Port (default: 6007)
6. Select the correct Time Zone for the license server
7. (Optional) Activate Triad Configuration if using a redundant setup (only if supported)
8. Set "Use Broker" to On
9. Click Save

## Approve BetaLM in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the BetaLM license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm BetaLM appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
