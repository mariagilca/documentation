This document describes the steps required to interface OpenLM with Canvas, allowing you to monitor license usage and obtain statistics.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Canvas, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The current monitoring capabilities for Canvas through OpenLM Broker are:

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Canvas | No | Yes | No | No | No | No | No | Per second |

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the Canvas License Manager](/img/engineering-lms/canvas-x-geo/image27.png)
*Diagram of how OpenLM interfaces with the Canvas License Manager*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

1. Select Canvas, enter the port number, and select Add.

    ![Adding a Canvas license manager in OpenLM Broker](/img/engineering-lms/canvas-x-geo/image138.png)
*Adding a Canvas license manager in OpenLM Broker*

1. Select the Vendors tab. Select Add Vendor. In the pop-up, enter Canvas as the vendor name and select Continue.

    ![Adding Canvas vendor in OpenLM Broker](/img/engineering-lms/canvas-x-geo/image125.png)
*Adding Canvas vendor in OpenLM Broker*

1. Switch to the Log Files tab. Select Add Log File. Make sure Watch file by pattern is turned off. You can add multiple logs. Browse to the location of the activity log, then select Continue.

    ![Adding a log file for Canvas in OpenLM Broker](/img/engineering-lms/canvas-x-geo/image99.png)
*Adding a log file for Canvas in OpenLM Broker*

1. Select Save.

## Approve canvas x geo in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the canvas x geo license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm canvas x geo appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
