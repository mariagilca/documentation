# Altium License Manager

This integration enables OpenLM to monitor Altium License Manager for license usage, expirations, and denials.

## Requirements

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Altium, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities and features

| Item | Value |
| --- | --- |
| Report resolution | By minute |
| License totals | Yes |
| License usage | Yes |
| Denials reporting | No |
| Borrowed license reporting | No |
| Expiration date reporting | Yes |
| Multiple server redundancy | No |

## OpenLM Broker configuration

1. Open a web browser and go to http://localhost:5090 (or another configured port such as 5091, 5092).
2. Go to the License Managers tab and click Add License Manager.
3. In the pop-up:
    - Select Altium from the drop-down.
    - Enter the port number (e.g., 9780).
    - Click Add.

    ![Commands tab](/img/engineering-lms/altium-license-manager/image36.png)
*Commands tab*

4. In the Commands tab:
    - Verify Data Inquiry is correctly set for your Altium instance.
    - Edit the `altium@<port>` file in C:\Program Files\OpenLM\OpenLM Broker\ and add the Altium username and password.
    - Save the file and return to the Broker interface.
    - Click Execute to confirm valid data output.

5. In the Vendors tab:
    - Click Add Vendor.
    - Enter Altium as the vendor name.
    - Click Continue.

    ![Save action to complete Broker configuration](/img/engineering-lms/altium-license-manager/image81.png)
*Save action to complete Broker configuration*

6. Click Save to complete the Broker configuration.

## Configure OpenLM Platform

1. Open the OpenLM Platform.
2. From the menu, go to License Servers.

    ![Select Pending Server in the left menu](/img/engineering-lms/altium-license-manager/image10.png)
*Select Pending Server in the left menu*

3. In the left menu, select Pending Server.
4. In the list, select the Altium license manager and click Approve and Merge.

    ![Verifying the configuration](/img/engineering-lms/altium-license-manager/image3.png)
*Verifying the configuration*

5. Navigate to Menu > License Servers Live > Server Statistics.
6. Ensure Altium appears in the list with a green status indicator.

> Note: It can take up to 3 minutes for the status to update for new connections.
