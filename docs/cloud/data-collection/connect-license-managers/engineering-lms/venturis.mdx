# Venturis

This document describes how to configure OpenLM to monitor Venturis License Manager and obtain license statistics.

## Requirements

To query Venturis License Manager, install:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Venturis, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities and features

Current monitoring capabilities through OpenLM Broker:

| Item | Value |
| --- | --- |
| Report resolution | By second |
| License totals | Yes |
| License usage | Yes |
| Denials reporting | No |
| Borrowed license reporting | No |
| Expiration date reporting | No |
| Multiple server redundancy | No |

## OpenLM Broker configuration

OpenLM Broker reads the Venturis log file. Data is compiled and sent to OpenLM Server. License files are configured manually in Broker. Broker reads the log file and tracks session changes. The license file and options file are monitored for updates based on the configured Watch interval.

## Configuring through the Broker UI

1. Open a browser and go to http://localhost:5090/.

1. Go to License Managers -> Add license manager.

1. Select Venturis as the license manager type, enter the port (for example, 2679), and click Add.

1. In Settings, choose one of:
    - Detect license file path automatically
    - Set license file manually
    - Allow license file sorting
    - Watch license file

1. In Commands, set Executable path to the i4blt executable on the IBM LUM license server.

1. In Vendors, enter the correct vendor name.

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/venturis/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Venturis license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/venturis/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Venturis appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
