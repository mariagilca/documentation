This document describes how to configure OpenLM to monitor Venturis License Manager and obtain license statistics.

## Before you begin

To query Venturis License Manager, install:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Venturis, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

Current monitoring capabilities through OpenLM Broker:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | No | No |

## Configure OpenLM Broker

OpenLM Broker reads the Venturis log file. Data is compiled and sent to OpenLM Server. License files are configured manually in Broker. Broker reads the log file and tracks session changes. The license file and options file are monitored for updates based on the configured Watch interval.

### Add manually
1. Open a browser and go to http://localhost:5090/.

1. Go to License Managers → Add license manager.

1. Select Venturis as the license manager type, enter the port (for example, 2679), and click Add.

1. In Settings, choose one of:
    - Detect license file path automatically
    - Set license file manually
    - Allow license file sorting
    - Watch license file

1. In Commands, set Executable path to the i4blt executable on the IBM LUM license server.

1. In Vendors, enter the correct vendor name.

1. Click Save.

## Approve Venturis in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Venturis license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Venturis appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
