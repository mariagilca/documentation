OpenLM monitors NI Volume License Manager (NI VLM) through OpenLM Broker. The NI VLM server is monitored as FLEXlm; in addition, when the NIVLM port is configured, OpenLM Broker reports **disconnected (home) licenses as borrowed licenses**. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- OpenLM Platform.
- OpenLM Broker **v26.6.1 or later**, installed on the NI VLM server machine and approved in [Broker Hub](/cloud/data-collection/broker-hub).

:::note[Documentation in progress]
The full step-by-step configuration guide for NI VLM is being finalized. If you need to configure NI VLM today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page.
:::
