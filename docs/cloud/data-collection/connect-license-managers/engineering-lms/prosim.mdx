Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the ProSim License Manager.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as ProSim, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| LM Type in the Broker | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ProSim | Yes | No | No | No | Yes | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

![Diagram of how OpenLM interfaces with the ProSim License Manager](/img/engineering-lms/prosim/image27.png)
*Diagram of how OpenLM interfaces with the ProSim License Manager*

OpenLM Broker must be installed and configured to report to OpenLM before proceeding.

## Configure OpenLM Broker

1. Open the Broker web UI at http://localhost:5090. If the default port is in use, try 5091 or 5092.

1. Go to License Managers → Add License Manager.

1. Select ProSim from the drop-down list, enter the port number (for example, 888), and click Add.

    ![In Vendors, click Add Vendor, enter ProSim, and click Continue.](/img/engineering-lms/prosim/image53.png)
*In Vendors, click Add Vendor, enter ProSim, and click Continue.*

    ![In Log Files, click Add Log File, browse to the log location, and ensure Watch file by pattern is off.](/img/engineering-lms/prosim/image68.png)
*In Log Files, click Add Log File, browse to the log location, and ensure Watch file by pattern is off.*

    ![Click Save.](/img/engineering-lms/prosim/image162.png)
*Click Save.*

## Approve ProSim in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the ProSim license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm ProSim appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
