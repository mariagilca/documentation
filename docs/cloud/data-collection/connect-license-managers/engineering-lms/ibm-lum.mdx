# IBM LUM

OpenLM supports monitoring a wide and growing variety of license managers, such as FlexLM and DSLS. This guide describes how to configure OpenLM with IBM LUM to monitor license usage, denials, and statistics.

## Requirements

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as IBM LUM, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Automatic Broker configuration

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers -> Detect

1. IBM LUM should appears

## Use OpenLM Broker

The Broker queries license usage locally and forwards data to OpenLM Server. It requires Java JRE and can run on both Windows and UNIX/Linux servers.

## Configuring via Broker UI

1. Open Broker web UI: http://localhost:5090/.

1. Go to License Managers -> Add License Manager.

1. Select LUM, enter the port (default: 1515), and click Add.

    ![Configure Cluster toggle:](/img/engineering-lms/ibm-lum/image129.png)
*Configure Cluster toggle:*

1. Configure Cluster toggle:

    - Off: Single server.

    - On: For HAL (see above).

1. In Commands, set the path to i4blt.exe.

1. In Vendors, set the correct name.

1. Click Save.

    ![Configure OpenLM Platform](/img/engineering-lms/ibm-lum/image45.png)
*Configure OpenLM Platform*

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/ibm-lum/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the IBM LUM license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/ibm-lum/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure IBM LUM appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
