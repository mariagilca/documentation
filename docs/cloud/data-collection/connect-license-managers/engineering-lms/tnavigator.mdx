# tNavigator

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the tNavigator License Manager.

## Before you begin

Before starting, make sure you have:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as tNavigator, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Report resolution | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | Yes | No |

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the tNavigator License Manager](/img/engineering-lms/tnavigator/image27.png)
*Diagram of how OpenLM interfaces with the tNavigator License Manager*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

### Add manually
1. On the tNavigator license manager machine, open the Broker web UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

    ![Select tNavigator from the drop-down list and enter the port number. Click Add.](/img/engineering-lms/tnavigator/image159.png)
*Select tNavigator from the drop-down list and enter the port number. Click Add.*

1. In the Commands tab, browse to or type the installation path of the tNavigator License Manager.

1. Click Execute to verify there are no errors.

1. Go to Vendors → Add Vendor. Enter tNavigator and click Continue.

1. Go to Log Files → Add Log File. Browse to the tNavigator log file location, turn Watch File by Pattern on, and click Continue.

1. Click Save.

## Approve tNavigator in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the tNavigator license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm tNavigator appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
