# Mnova Bruker Chemist Suite

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Mnova Bruker Chemist Suite License Manager.

## Requirements

Before starting, install:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Mnova, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Item | Value |
| --- | --- |
| LM Type in the Broker | MlicAdmin |
| License totals | No |
| License usage | No |
| Denials | No |
| Borrowing | No |
| Expiration date | Yes (if the license file for the feature is provided) |
| Redundancy | No |
| Report resolution | Seconds |

Using the Broker also enables buffered communication and allows remote start and stop of the license manager service.

OpenLM Broker must be installed and configured to report to OpenLM before proceeding.

## Configuring via Broker UI

1. Open the Broker web UI at http://localhost:5090. If the default port is in use, try 5091 or 5092.

1. Go to License Managers -> Add License Manager.

1. Select MlicAdmin from the drop-down list, enter the port number (e.g., 888), and click Add.

    ![In Settings, configure license files:](/img/engineering-lms/mnova-bruker-chemist-suite/image166.png)
*In Settings, configure license files:*

1. In Settings, configure license files:
    - Select Detect license file automatically, or
    - Select Set license file path manually for each feature.

    ![If adding manually, click Add license file path and browse to each feature's license file.](/img/engineering-lms/mnova-bruker-chemist-suite/image49.png)
*If adding manually, click Add license file path and browse to each feature's license file.*

1. If adding manually, click Add license file path and browse to each feature's license file.

1. Ensure Allow license file sorting and Watch license file are turned off.

1. In Vendors, click Add Vendor, enter Mnova, and click Continue.

    ![In Log Files, click Add Log File, ensure Watch file by pattern is off, then click Continue. IMAGE 149](/img/engineering-lms/mnova-bruker-chemist-suite/image5.png)
*In Log Files, click Add Log File, ensure Watch file by pattern is off, then click Continue. IMAGE 149*

1. In Log Files, click Add Log File, ensure Watch file by pattern is off, then click Continue.

    ![Click Save.](/img/engineering-lms/mnova-bruker-chemist-suite/image149.png)
*Click Save.*

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/mnova-bruker-chemist-suite/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Mnova license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/mnova-bruker-chemist-suite/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Mnova appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
