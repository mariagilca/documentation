OpenLM monitors LimeLM (TurboFloat Server) through OpenLM Broker. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- OpenLM Platform.
- OpenLM Broker v25.x or later, installed on the same machine as LimeLM (TurboFloat Server) and approved in [Broker Hub](/cloud/data-collection/broker-hub).

:::note[Documentation in progress]
If you need to configure LimeLM (TurboFloat Server) today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. We will share the current procedure directly while the doc is finalized.
:::
