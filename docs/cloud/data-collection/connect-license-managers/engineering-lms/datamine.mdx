# Datamine

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Datamine license manager.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Datamine, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The current monitoring capabilities for Datamine through OpenLM Broker are:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | No | No |

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the Datamine license manager](/img/engineering-lms/datamine/image27.png)
*Diagram of how OpenLM interfaces with the Datamine license manager*

:::note
The OpenLM Broker reads the Datamine .csv log file and sends the processed data to OpenLM Server.
:::
### Manual configuration (Broker web UI)

1. Open a browser and go to http://localhost:5090/.

1. Go to License Managers → Add License Manager.

    ![Select Datamine, enter any port number (for example, 888), and click Add.](/img/engineering-lms/datamine/image70.png)
*Select Datamine, enter any port number (for example, 888), and click Add.*

    ![In Log Files, click Add Log File.](/img/engineering-lms/datamine/image141.png)
*In Log Files, click Add Log File.*

1. Enter or browse to the .csv log file location.

    ![Click Continue, then Save.](/img/engineering-lms/datamine/image109.png)
*Click Continue, then Save.*

## Approve Datamine in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Datamine license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Datamine appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
