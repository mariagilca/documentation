# ASH WARE

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from ASH WARE.

## Requirements

1. OpenLM Platform.
2. OpenLM Broker v25.x or higher installed on the same machine as ASH WARE, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Item | Value |
| --- | --- |
| LM Type in the Broker | ASH WARE |
| Commands | Yes |
| Logs | No |
| Quantity | Yes |
| Expiration date | Yes |
| Denied | No |
| Borrowing | No |
| Allocations | No |
| Report resolution | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Open Broker UI at http://localhost:5090/.](/img/engineering-lms/ash-ware/image57.png)
*Open Broker UI at http://localhost:5090/.*

1. Open Broker UI at http://localhost:5090/.
2. Go to License Managers > Add License Manager.
3. From the LM Type drop-down list, select ASH WARE.
4. Enter the port number (default: 6333) and click Add.
![Setting executable path for ASH WARE in OpenLM Broker](/img/engineering-lms/ash-ware/image161.png)
*Setting executable path for ASH WARE in OpenLM Broker*
5. In the Executable Path field, browse to the installation directory of the ASH WARE .exe file.
6. Click Save.
7. To verify the configuration, click Execute in the Commands tab.
![Example of a successful execution result](/img/engineering-lms/ash-ware/image64.png)
*Example of a successful execution result*
8. Go to the Vendors tab. Click Add Vendor, enter ASH WARE, and click Continue.
![Adding ASH WARE vendor in OpenLM Broker](/img/engineering-lms/ash-ware/image87.png)
*Adding ASH WARE vendor in OpenLM Broker*
9. Click Save.

### Configure OpenLM Platform
1. Log in to OpenLM Platform.
2. From the Menu, go to License Servers.
![On left menu, select Pending Server](/img/engineering-lms/ash-ware/image10.png)
*On left menu, select Pending Server*
3. In the left menu, select Pending Server.
4. In the list, select the ASH WARE license manager and click Approve and Merge.
![Verifying the configuration](/img/engineering-lms/ash-ware/image3.png)
*Verifying the configuration*
5. Navigate to Menu > License Servers Live > Server Statistics.
6. Ensure ASH WARE appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
