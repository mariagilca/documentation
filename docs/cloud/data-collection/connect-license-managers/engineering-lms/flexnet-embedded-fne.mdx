# Flexnet Embedded (FNE)

This guide explains how to configure OpenLM to monitor a FlexNet Embedded license manager and collect usage statistics.

## How it works

OpenLM Server queries the FlexNet Embedded server's XML API to retrieve license usage and statistics. The data is aggregated and displayed in OpenLM Web Interface reports. For more details, see What is FlexNet Embedded?.

![Diagram of how OpenLM Server interfaces with a FlexNet Embedded server](/img/engineering-lms/flexnet-embedded-fne/image145.png)
*Diagram of how OpenLM Server interfaces with a FlexNet Embedded server*

## Requirements

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Flexnet Embedded, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Configuring through the Broker UI

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers -> Add License Manager.

1. Select Flexnet Embedded, enter the port number, and click Add.

1. Fill in the fields:
    - Type: FlexNet Embedded
    - Description: recognizable name (for example, FlexNet Embedded server)
    - Time zone: match the license server's location
    - Hostname: server hostname or IP
    - Port: see the following instructions
    - Vendor name: for example, Avid, NVIDIA

1. Click Test to verify.

1. Click Apply, then Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/flexnet-embedded-fne/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the FlexLM license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/flexnet-embedded-fne/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure AEScripts appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
