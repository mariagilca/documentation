This document describes how to interface OpenLM with UniSim License Manager to monitor license usage and obtain statistics.

## Before you begin

To query UniSim license manager, install:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as UniSim, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

Current monitoring capabilities through OpenLM Broker:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | No | Yes | Yes | No | No | No |

Using Broker also allows buffered communication and the ability to start or stop the license manager service remotely.

## Configure OpenLM Broker

![Diagram of OpenLM interface with UniSim](/img/engineering-lms/unisim/image27.png)
*Diagram of OpenLM interface with UniSim*

### Option 1 — Detect automatically
1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Detect

1. UniSim appears

1. Validate and save

### Option 2 — Add manually
If auto-detect does not work, add and configure the license manager manually:

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers → Add License Manager.

1. Enter the UniSim LM port number (for example, 6607).

1. Select UniSim from the License Manager Type list. Select Apply.

1. Go to Commands. In Update path for commands, enter or browse to the UniSim installation root folder. Select Update, then Apply.

1. Broker automatically adds vendor name and log file path.

1. Select Apply.

1. Select Restart Broker.

## Approve UniSim in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the UniSim license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm UniSim appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
