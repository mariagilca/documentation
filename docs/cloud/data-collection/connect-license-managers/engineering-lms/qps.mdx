Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from QPS License Manager.

## Before you begin

Before you query the license manager, install:

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as QPS, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| QPS | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the QPS License Manager](/img/engineering-lms/qps/image27.png)
*Diagram of how OpenLM interfaces with the QPS License Manager*

OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding.

### Add manually
1. Open the Broker web UI at http://localhost:5090. If the default port is in use, try 5091 or 5092.

1. Go to License Managers → Add License Manager.

1. From the LM Type drop-down list, select QPS.

1. Enter the port number (for example, 1234) and click Add.

    ![Adding QPS license manager in OpenLM Broker](/img/engineering-lms/qps/image93.png)
*Adding QPS license manager in OpenLM Broker*

1. In the Commands tab, set the path to the QPS installation folder.

    ![Configuring command path for QPS in OpenLM Broker](/img/engineering-lms/qps/image136.png)
*Configuring command path for QPS in OpenLM Broker*

1. Go to the Vendors tab. Click Add Vendor, enter QPS, and click Continue.

    ![Adding QPS vendor in OpenLM Broker](/img/engineering-lms/qps/image133.png)
*Adding QPS vendor in OpenLM Broker*

1. Go to the Log Files tab. Click Add Log File. Turn off Watch file by pattern. You can add multiple logs for different applications. Click Continue.

    ![Adding log files for QPS in OpenLM Broker](/img/engineering-lms/qps/image19.png)
*Adding log files for QPS in OpenLM Broker*

1. Click Save.

## Approve QPS in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the QPS license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm QPS appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
