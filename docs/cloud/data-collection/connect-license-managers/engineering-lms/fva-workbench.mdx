# FVA-Workbench

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics.

## Requirements

- OpenLM Platform

- OpenLM Broker v25.x or higher installed on the same machine as FVA-Workbench, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The current monitoring capabilities for FVA-Workbench through the OpenLM Broker are:

| Item | Value |
| --- | --- |
| Commands | Yes |
| Logs | No |
| Quantity | Yes |
| Expiration date | Yes |
| Denied | No |
| Borrowing | No |
| Report resolution | By minute |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## Configuring through the Broker UI

1. In the Broker web UI, click License Managers.

1. Click Add license manager.

1. In the Add license manager dialog, enter the FVA-Workbench LM port number.

1. From the LM type drop-down, select FVA.

1. Click Add.

    ![Select the Commands tab. Under Data Inquiry, click Execute to verify that the output is correct. IMAGE 76](/img/engineering-lms/fva-workbench/image47.png)
*Select the Commands tab. Under Data Inquiry, click Execute to verify that the output is correct. IMAGE 76*

1. Select the Commands tab. Under Data Inquiry, click Execute to verify that the output is correct.

    ![Switch to the Vendors tab. Click Add Vendor, enter FVA-Workbench in the Vendor Name field, and click Continue.](/img/engineering-lms/fva-workbench/image76.png)
*Switch to the Vendors tab. Click Add Vendor, enter FVA-Workbench in the Vendor Name field, and click Continue.*

1. Switch to the Vendors tab. Click Add Vendor, enter FVA-Workbench in the Vendor Name field, and click Continue.

1. Select the Advanced tab and enter the FVA-Workbench login and password.

    ![Alternatively, navigate to C:\Program Files\OpenLM\OpenLM Broker\lmsettings\fva.properties and enter the credentials manually. Restart the Broker service if you use this method.](/img/engineering-lms/fva-workbench/image128.png)

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/fva-workbench/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the FVA-Workbench license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/fva-workbench/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure FVA-Workbench appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
