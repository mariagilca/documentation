Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics.

## Before you begin

- OpenLM Platform

- OpenLM Broker v25.x or higher installed on the same machine as FVA-Workbench, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The current monitoring capabilities for FVA-Workbench through the OpenLM Broker are:

| Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Report resolution |
| --- | --- | --- | --- | --- | --- | --- |
| Yes | No | Yes | Yes | No | No | By minute |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## Configure OpenLM Broker

![OpenLM Broker queries the license manager locally. Once collected, the data is sent to OpenLM Server for processing.](/img/engineering-lms/fva-workbench/image27.png)
*OpenLM Broker queries the license manager locally. Once collected, the data is sent to OpenLM Server for processing.*

Note: OpenLM Broker must already be installed and configured to report to OpenLM Server before proceeding.

### Add manually
- In the Broker web UI, select License Managers.

1. Select Add license manager.

1. In the Add license manager dialog, enter the FVA-Workbench LM port number.

1. From the LM type drop-down, select FVA.

1. Select Add.

    ![Select the Commands tab. Under Data Inquiry, select Execute to verify that the output is correct.](/img/engineering-lms/fva-workbench/image47.png)
*Select the Commands tab. Under Data Inquiry, select Execute to verify that the output is correct.*

    ![Switch to the Vendors tab. Select Add Vendor, enter FVA-Workbench in the Vendor Name field, and select Continue.](/img/engineering-lms/fva-workbench/image76.png)
*Switch to the Vendors tab. Select Add Vendor, enter FVA-Workbench in the Vendor Name field, and select Continue.*

1. Select the Advanced tab and enter the FVA-Workbench login and password.

    ![Alternatively, navigate to C:\Program Files\OpenLM\OpenLM Broker\lmsettings\fva.properties and enter the credentials manually. Restart the Broker service if you use this method.](/img/engineering-lms/fva-workbench/image128.png)
*Alternatively, navigate to C:\Program Files\OpenLM\OpenLM Broker\lmsettings\fva.properties and enter the credentials manually. Restart the Broker service if you use this method.*

## Approve FVA-Workbench in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the FVA-Workbench license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm FVA-Workbench appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
