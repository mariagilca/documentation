Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Chaos V-Ray License Manager.

## Before you begin

- OpenLM Platform
- OpenLM Broker v25.x or higher installed on the same machine as Chaos, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

The Broker reads the Chaos V-Ray License Manager log file, compiles the data, and sends it to OpenLM for processing.

| Report resolution | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | No | No | No | No | No |

## Configure OpenLM Broker

![Diagram of how OpenLM interfaces with the Chaos V-Ray License Manager](/img/engineering-lms/chaos-v-ray/image27.png)
*Diagram of how OpenLM interfaces with the Chaos V-Ray License Manager*

1. Open the Broker web UI at http://localhost:5090 (or 5091, 5092 if the default port is in use).

1. Go to License Managers → Add License Manager.

    ![From the drop-down list, select Chaos and enter the port (for example, 35033).](/img/engineering-lms/chaos-v-ray/image48.png)
*From the drop-down list, select Chaos and enter the port (for example, 35033).*

1. Click Add.

    ![Go to Vendors → Add Vendor and enter the name Chaos V-Ray. Click Continue.](/img/engineering-lms/chaos-v-ray/image6.png)
*Go to Vendors → Add Vendor and enter the name Chaos V-Ray. Click Continue.*

1. Go to Log Files → Add Log File.

1. Specify the log file path manually or use the magnifier icon to browse.

1. Select Chaos V-Ray as the vendor and click Save.

## Approve Chaos V-Ray in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Chaos V-Ray license manager, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **License Servers Live** → **Server Statistics**.
2. Confirm Chaos V-Ray appears with a green status indicator.

:::note
It can take up to 3 minutes for the status to update for a new connection.
:::
