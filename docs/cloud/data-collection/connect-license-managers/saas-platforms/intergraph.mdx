# Intergraph
Intergraph Usage Monitoring

## About Intergraph

Intergraph, now part of Hexagon, provides engineering and geospatial software used in various industries, including plant design, shipbuilding, and public safety. Its products are often used for complex, high-value projects. Monitoring Intergraph usage is crucial for cost optimization and ensuring that expensive licenses are utilized effectively. This is similar to monitoring other engineering and design platforms like Bentley or Autodesk Cloud.

## Prerequisites

To begin monitoring Intergraph, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Intergraph license server or a central management portal to generate the necessary API keys or configuration files.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Intergraph in OpenLM Cloud Broker:

1. Activate API Access: In the Intergraph admin portal, create an API key with read access for license and user data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Intergraph integration and enter the API credentials.
3. Verify Connection: Test the connection to confirm successful data retrieval.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: You can now view usage data for Intergraph products in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: Identify which projects and users are consuming the most licenses, helping with license re-allocation.
- Expired/Unused License Reports: Pinpoint and reclaim licenses from inactive users to save on costs.
