# Intergraph

Intergraph, now part of Hexagon, provides engineering and geospatial software used in various industries, including plant design, shipbuilding, and public safety. Its products are often used for complex, high-value projects.

## Before you begin

To begin monitoring Intergraph, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Intergraph license server or a central management portal to generate the necessary API keys or configuration files.

## Configure data collection

1. Activate API Access: In the Intergraph admin portal, create an API key with read access for license and user data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Intergraph integration and enter the API credentials.

## Approve Intergraph in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Intergraph data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Intergraph usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **Expired or unused licenses** — identify inactive users and reclaim their seats.
