# Apollo.io

OpenLM monitors Apollo.io through OpenLM Cloud Broker. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- An active OpenLM Platform tenant.
- OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).

:::note[Documentation in progress]
If you need to configure Apollo.io today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. We will share the current procedure directly while the doc is finalized.
:::
