# Personio

Personio is an all-in-one HR software platform for small and medium-sized businesses. It helps with everything from recruiting and onboarding to payroll and performance management.

## Before you begin

To begin monitoring Personio, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Personio account to generate an API key and client ID with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your Personio settings, create new API credentials with read access to employee and user data.

1. Go to Marketplace → Connected Integrations.
2. Click Create custom integration at the top right of the screen.
3. Configure the setup.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Personio integration and enter the API key and client ID.

![Personio credential configuration in Cloud Broker](/img/saas-platforms/personio/image33.png)
*Personio credential configuration in Cloud Broker*

## Approve Personio in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Personio data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Personio usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
