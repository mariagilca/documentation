Cursor AI is an AI-powered code editor used by development teams. OpenLM monitors Cursor license usage through OpenLM Cloud Broker. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- An active OpenLM Platform tenant.
- OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Administrative access to your Cursor organization, so you can authorize access to user and license data.

:::note[Documentation in progress]
If you need to configure Cursor AI today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. We will share the current procedure directly while the doc is finalized.
:::
