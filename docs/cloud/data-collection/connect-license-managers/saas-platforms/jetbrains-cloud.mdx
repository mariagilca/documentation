# JetBrains Cloud

JetBrains Cloud is a suite of development tools and collaboration platforms for software developers and teams. It includes products like YouTrack, TeamCity, and Space.

## Before you begin

To begin monitoring JetBrains Cloud, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your JetBrains Cloud instance to generate a permanent token with the necessary read permissions.

## Configure data collection

1. From the main navigation menu, select Administration → Access Management → Users.
2. Select the user for whom you want to generate a permanent token.
3. Switch to the Account Security tab.
4. In the Tokens section of the page, click the New token button.
5. In the New Permanent Token dialog, specify a name for the new token and the access scope for it. The scope for the token is a list of services that the user is allowed to access with this new token.
6. Click the Create token button.

1. A dialog window with the new token is displayed.

7. Copy the token and store it in a secure location. Use either of these two actions to copy the token:
8. Add Credentials: In the OpenLM Cloud Broker dashboard, find the JetBrains Cloud integration and enter the token and Company ID.
  ![JetBrains Cloud credential configuration in Cloud Broker](/img/saas-platforms/jetbrains-cloud/image32.png)
  *JetBrains Cloud credential configuration in Cloud Broker*

## Approve JetBrains Cloud in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the JetBrains Cloud data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm JetBrains Cloud usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
