Atlassian Confluence Cloud is a team workspace where organizations create, organize, and collaborate on documentation and knowledge-base content. OpenLM monitors Confluence Cloud license usage through OpenLM Cloud Broker. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- An active OpenLM Platform tenant.
- OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Administrative access to your Atlassian organization, so you can authorize access to Confluence user and license data.

:::note[Documentation in progress]
If you need to configure Atlassian Confluence Cloud today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. We will share the current procedure directly while the doc is finalized.
:::
