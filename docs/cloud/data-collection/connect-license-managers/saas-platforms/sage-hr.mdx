# Sage HR
Sage HR Usage Monitoring

## About Sage HR

Sage HR is a human resources management platform that helps businesses with everything from onboarding and performance management to time tracking and payroll. Monitoring Sage HR usage is important for ensuring that licenses are used effectively and for optimizing costs. This is similar to monitoring other HR platforms like BambooHR or Personio.

## Prerequisites

To begin monitoring Sage HR, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Sage HR account to generate an API key with the necessary read permissions.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Sage HR in OpenLM Cloud Broker:

1. Activate API Access: In your Sage HR admin panel, create a new API key with read access to user and employee data.

1. Click on your name on the top right, then click Settings.
2. On the settings menu, click INTEGRATIONS, then click API.
3. Click ENABLE API ACCESS to activate access to API and provide you with your unique API key.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Sage HR integration and enter the API key.

![Sage HR credential configuration in Cloud Broker](/img/saas-platforms/sage-hr/image29.png)

3. Verify Connection: Test the connection to ensure that OpenLM can successfully retrieve data.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for Sage HR will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which HR professionals are most active in the platform, helping you manage resource allocation.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users.
