Sage HR is a human resources management platform that helps businesses with everything from onboarding and performance management to time tracking and payroll.

## Before you begin

To begin monitoring Sage HR, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Sage HR account to generate an API key with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your Sage HR admin panel, create a new API key with read access to user and employee data.

1. Select your name in the top right, then select **Settings**.
2. On the settings menu, select INTEGRATIONS, then select API.
3. Select ENABLE API ACCESS to activate access to API and provide you with your unique API key.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Sage HR integration and enter the API key.

![Sage HR credential configuration in Cloud Broker](/img/saas-platforms/sage-hr/image29.png)
*Sage HR credential configuration in Cloud Broker*

## Approve Sage HR in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Sage HR data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Sage HR usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
