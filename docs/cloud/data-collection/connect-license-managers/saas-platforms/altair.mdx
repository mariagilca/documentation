# Altair
Altair Usage Monitoring

## About Altair

Altair provides simulation, high-performance computing, and data analytics software used across various industries, particularly in engineering and manufacturing. Its products like HyperWorks and solidThinking help companies with design, modeling, and simulation. Monitoring Altair usage is crucial for cost control and license optimization, similar to managing other engineering platforms like Intergraph or Bentley.

## Prerequisites

To begin monitoring Altair, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Altair license server and any associated management portals to retrieve the necessary API keys or configuration files.

## Configuring data collection

1. Contact our support team [support@openlm.com](mailto:support@openlm.com) to setup Altair integration.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: Identify peak usage times and understand which teams are using which Altair modules.
- Expired/Unused License Reports: Pinpoint unused licenses to reassign or remove them, saving on costs.
