Pipedrive is a sales CRM and pipeline management tool that helps sales teams visualize their sales process and focus on the right deals.

## Before you begin

To begin monitoring Pipedrive, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Pipedrive account to generate a personal API token with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your Pipedrive account settings, generate a personal API token.

1. How can I find my personal API key?
2. If you ever need your personal API key, it can be found under Settings → Personal preferences → API.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Pipedrive integration and enter the API token.

![Pipedrive credential configuration in Cloud Broker](/img/saas-platforms/pipedrive/image35.png)
*Pipedrive credential configuration in Cloud Broker*

## Approve Pipedrive in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Pipedrive data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Pipedrive usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
