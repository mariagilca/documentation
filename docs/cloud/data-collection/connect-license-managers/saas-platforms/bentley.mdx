# Bentley

Bentley provides software solutions for civil engineering, architecture, construction, and infrastructure. Products like MicroStation and OpenRoads are widely used for designing and managing large-scale projects.

## Before you begin

To begin monitoring Bentley, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Bentley license management system (for example, SELECTserver or CONNECT Licensing) to generate API keys or tokens with permissions to access usage data.

## Configure data collection

1. Activate API Access: In the Bentley administrator portal, create an API key with read access for license and user data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Bentley integration and enter user name and password.

![Bentley credential configuration in Cloud Broker](/img/saas-platforms/bentley/image11.png)
*Bentley credential configuration in Cloud Broker*

## Approve Bentley in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Bentley data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Bentley usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
