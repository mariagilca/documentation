Insightful is a workforce analytics and productivity management platform. It provides insights into employee activity and helps teams improve efficiency.

## Before you begin

To begin monitoring Insightful, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Insightful account to generate an API key with the necessary read permissions.

## Configure data collection

Insightful's API is using Bearer Token for authorization. Here is how you can obtain yours:

1. Login as an Admin to your organization's account

2. Go to the API page

3. Create a new Token

4. Name your token

5. Generate new token and keep in mind that this will be the only time that we will provide you with your token

6. Copy the token and make sure you are storing it safely

7. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Insightful integration and enter the API key.

## Approve Insightful in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Insightful data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Insightful usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
