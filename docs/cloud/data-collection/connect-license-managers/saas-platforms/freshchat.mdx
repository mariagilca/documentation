Freshchat is a customer messaging software for sales and customer engagement. It allows businesses to communicate with their customers through a unified chat platform.

## Before you begin

To begin monitoring Freshchat, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Freshchat account to generate an API key with the necessary read permissions.

## Configure data collection

1. To obtain the API key, navigate to Admin → CONFIGURE → API Tokens page and click the Generate Token button. The authentication server returns the access token (specified in the page as API KEY). You should use the API key in the authorization header parameter to make a valid API call.
2. Retrieve the account URL

For stand-alone Freshchat accounts, the URL to access the product resources through API requests is in the following format:

`https://<account-name>.freshchat.com/v2/<resource-name>`

3. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Freshchat integration and enter your URL and API token.

![Freshchat credential configuration in Cloud Broker](/img/saas-platforms/freshchat/image4.png)
*Freshchat credential configuration in Cloud Broker*

## Approve Freshchat in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Freshchat data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Freshchat usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
