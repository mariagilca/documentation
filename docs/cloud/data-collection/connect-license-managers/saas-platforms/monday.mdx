monday.com is a work operating system (Work OS) that helps teams manage projects, workflows, and everyday tasks. It's a highly visual and collaborative platform used by a wide range of industries.com usage is crucial for optimizing subscription costs and ensuring that licenses are used by active team members.

## Before you begin

To begin monitoring monday.com, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your monday.com account to generate an API v2 token with the necessary read permissions.

## Configure data collection

1. If you are an admin user on your [monday.com](https://monday.com/) account, follow these steps to access your API token:

1. Log into your [monday.com](https://monday.com/) account.
2. Select your avatar in the top-right corner.
3. Select Administration → Connections → API.
4. Copy your personal token and paste it into the 'API V2 Token' field.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the monday.com integration and enter the API token.

![monday.com credential configuration in Cloud Broker](/img/saas-platforms/monday/image36.png)
*monday.com credential configuration in Cloud Broker*

## Approve Monday in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Monday data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Monday usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
