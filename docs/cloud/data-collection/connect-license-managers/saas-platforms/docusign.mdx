DocuSign is a leading e-signature platform that allows businesses to send, sign, and manage agreements digitally. It streamlines document workflows and improves efficiency.

## Before you begin

To begin monitoring DocuSign, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your DocuSign account to generate an API key and obtain the necessary user ID and account ID.

## Configure data collection

1. Activate API Access: In your DocuSign admin console, create an integration key and generate a user ID with read-only access to user and envelope data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the DocuSign integration and enter user ID, Account ID, Organization ID, Private Key and Integration Key.

![DocuSign credential configuration in Cloud Broker](/img/saas-platforms/docusign/image1.png)
*DocuSign credential configuration in Cloud Broker*

## Approve DocuSign in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the DocuSign data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm DocuSign usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
