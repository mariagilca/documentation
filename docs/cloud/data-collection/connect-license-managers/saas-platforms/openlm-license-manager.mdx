# OpenLM License Manager

OpenLM License Manager is a software license management tool that helps organizations track, manage, and optimize the use of their software licenses. It provides real-time monitoring and reporting for various license types. This is a core component of the OpenLM suite.

## Before you begin

To begin monitoring OpenLM License Manager, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need a user with administrative rights within your OpenLM Server to access the necessary API endpoints.

## Configure data collection

1. Activate API Access: Ensure your OpenLM Server has the API activated and a user with the necessary read permissions is available.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the OpenLM License Manager integration and enter the server URL and user credentials.

## Approve OpenLM License Manager in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the OpenLM License Manager data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm OpenLM License Manager usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
