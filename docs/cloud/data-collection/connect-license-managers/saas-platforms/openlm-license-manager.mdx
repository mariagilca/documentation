# OpenLM License Manager
OpenLM License Manager Usage Monitoring

## About OpenLM License Manager

OpenLM License Manager is a software license management tool that helps organizations track, manage, and optimize the use of their software licenses. It provides real-time monitoring and reporting for various license types. Monitoring OpenLM License Manager is important for ensuring the tool itself is used effectively to manage your entire software portfolio. This is a core component of the OpenLM suite.

## Prerequisites

To begin monitoring OpenLM License Manager, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need a user with administrative rights within your OpenLM Server to access the necessary API endpoints.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for OpenLM License Manager in OpenLM Cloud Broker:

1. Activate API Access: Ensure your OpenLM Server has the API activated and a user with the necessary read permissions is available.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the OpenLM License Manager integration and enter the server URL and user credentials.
3. Verify Connection: Test the connection to ensure that OpenLM Cloud Broker can successfully communicate with the OpenLM Server API.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for your OpenLM-managed licenses will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See how often users are checking out licenses.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users.
