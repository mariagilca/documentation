Grammarly is a writing assistant used across teams for grammar, tone, and style. OpenLM monitors Grammarly license usage through the OpenLM SaaS Agent. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- An active OpenLM Platform tenant.
- OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Administrative access to your Grammarly Business account, so you can authorize access to user and license data.

:::note[Documentation in progress]
If you need to configure Grammarly today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. We will share the current procedure directly while the doc is finalized.
:::
