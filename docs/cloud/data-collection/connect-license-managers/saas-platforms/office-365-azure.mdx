# Office 365 / Azure

Office 365 is a cloud-based productivity suite that includes Word, Excel, Teams, and more. Azure is a comprehensive cloud computing platform for building, deploying, and managing applications and services. Companies monitor these platforms to reduce license waste, ensure compliance, and align subscriptions with actual usage.

## Before you begin

To begin monitoring Office 365 / Azure, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You need a global administrator role in your Microsoft 365 tenant to grant permissions for the Microsoft Graph API.

## Configure data collection

1. Activate API Access: Register OpenLM Cloud Broker as an application in Azure Active Directory (now Microsoft Entra ID) and grant it read permissions for user and reports data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Office 365 / Azure integration and enter Client ID, Client Secret, Tenant ID and Service ID.

![Office 365 / Azure credential configuration in Cloud Broker](/img/saas-platforms/office-365-azure/image18.png)
*Office 365 / Azure credential configuration in Cloud Broker*

## Approve Office 365 / Azure in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Office 365 / Azure data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Office 365 / Azure usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
