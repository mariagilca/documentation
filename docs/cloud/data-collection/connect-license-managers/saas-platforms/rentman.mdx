# Rentman

Rentman is a rental management software solution for the event and production industry. It helps businesses manage their equipment, staff, and projects.

## Before you begin

To begin monitoring Rentman, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Rentman account to generate an API key with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your Rentman account settings, create a new API key with read access to user and project data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Rentman integration and enter the API key.

![Rentman credential configuration in Cloud Broker](/img/saas-platforms/rentman/image17.png)
*Rentman credential configuration in Cloud Broker*

## Approve Rentman in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Rentman data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Rentman usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
