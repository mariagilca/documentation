Google Analytics is a web analytics service that tracks and reports website traffic. It provides insights into user behavior, traffic sources, and conversion metrics.

## Before you begin

To begin monitoring Google Analytics, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Google Analytics account to create a Service Account with the necessary API access and permissions.

## Configure data collection

1. Sign in to your Google Analytics account.
2. Select **Admin** in the lower-left corner.
3. In the Property column, select Data Streams.
4. Select the relevant data stream for your website.
5. Look for the Measurement ID, which starts with "G-" followed by a series of letters and numbers. This is your Google tag ID.

6. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Google Analytics integration and type your Account ID.

![Google Analytics credential configuration in Cloud Broker](/img/saas-platforms/google-analytics/image12.png)
*Google Analytics credential configuration in Cloud Broker*

## Approve Google Analytics in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Google Analytics data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Google Analytics usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::
