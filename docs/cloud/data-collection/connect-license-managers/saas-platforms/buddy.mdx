# Buddy

Buddy is a continuous integration and continuous deployment (CI/CD) platform that helps developers build, test, and deploy software quickly. It automates development workflows and integrates with various code repositories.

## Before you begin

To begin monitoring Buddy, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Buddy workspace to generate an API key with the necessary read permissions.

## Configure data collection

1. Log in to Buddy.
2. Select your avatar in the top-right corner and go to the **Security** tab.

3. In the Security view, scroll down to the Personal Access Tokens section and click the + icon.

4. Provide the token description and [select proper scopes](https://buddy.works/docs/api/getting-started/oauth2/personal-access-token#personal-access-token-settings-in-buddy).
5. A window with the token will appear. Copy the token and put it in a safe place

1. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Buddy integration and enter the domain and personal token.

![Buddy credential configuration in Cloud Broker](/img/saas-platforms/buddy/image31.png)
*Buddy credential configuration in Cloud Broker*

## Approve Buddy in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Buddy data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Buddy usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
