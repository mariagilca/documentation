# YouTrack

YouTrack is a project management and issue-tracking system from JetBrains. It is used by development teams to plan projects, track tasks, and manage bug reports.

## Before you begin

To begin monitoring YouTrack, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your YouTrack instance to generate a permanent token with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your YouTrack admin panel, create a new permanent token with read access to user and project data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the YouTrack integration and enter the token.

## Approve YouTrack in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the YouTrack data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm YouTrack usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
