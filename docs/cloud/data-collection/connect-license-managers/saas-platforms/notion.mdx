# Notion

Notion is a versatile workspace for notes, project management, and knowledge bases. It allows teams to create and collaborate on documents, databases, and more.

## Before you begin

To begin monitoring Notion, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Notion workspace to create an integration and generate an API key with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your Notion workspace settings, create a new integration and generate an internal integration token.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Notion integration and enter the API token.

![Notion credential configuration in Cloud Broker](/img/saas-platforms/notion/image21.png)
*Notion credential configuration in Cloud Broker*

## Approve Notion in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Notion data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Notion usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
