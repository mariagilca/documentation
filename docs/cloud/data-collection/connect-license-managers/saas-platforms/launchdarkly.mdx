LaunchDarkly is a feature management platform that allows development teams to deliver software features to specific user segments without deploying new code. It's used for A/B testing, phased rollouts, and kill switches.

## Before you begin

To begin monitoring LaunchDarkly, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your LaunchDarkly account to generate a personal access token with the necessary read permissions.

## Configure data collection

1. Follow these step-by-step instructions to set up data collection for LaunchDarkly in OpenLM Cloud Broker:

To create an access token:

1. Select the gear icon in the left sidenav to view Organization settings.
2. Select Authorization.
3. In the "Access tokens" section, select Create token. The "Create an access token" panel appears.
4. Give your token a human-readable Name.
5. Assign a Role to the token by selecting one from the menu.

- Select Reader, Writer, Admin, or Owner if you want to use a base role.
- Select Custom to select another role, either one you've created or one provided by LaunchDarkly. This option is available only if your LaunchDarkly subscription includes custom roles.
- Select Inline policy to create a role policy in-line, specific to this token. To learn more, read [Create policies for roles](https://launchdarkly.com/docs/home/account/roles/role-create#create-policies-for-roles). This option is available only if your LaunchDarkly subscription includes custom roles.

6. Select the API version to assign to your token. By default, API requests you send using this token will use this API version. To learn more, read [Versioning](https://launchdarkly.com/docs/api#versioning).
7. (Optional) Select the This is a service token checkbox if you wish to create a service token. This feature is only available to customers on Enterprise plans:
8. Select Save token. The new token appears in the Authorization page.
9. Copy and save the token somewhere secure. After you leave this page, the token is obscured:

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the LaunchDarkly integration and enter the access token.

## Approve LaunchDarkly in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the LaunchDarkly data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm LaunchDarkly usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::
