GitHub Copilot is an AI pair programmer licensed per seat through GitHub organizations and enterprises. OpenLM monitors Copilot license usage through OpenLM Cloud Broker. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- An active OpenLM Platform tenant.
- OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Administrative access to your GitHub organization or enterprise, so you can authorize access to user and license data.

:::note[Documentation in progress]
If you need to configure GitHub Copilot today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. We will share the current procedure directly while the doc is finalized.
:::
