Claude AI is Anthropic's AI assistant used by teams for writing, analysis, and coding. OpenLM monitors Claude license usage through the OpenLM SaaS Agent, and can track actual usage through the OpenLM AI Proxy. Detailed configuration steps are being prepared and will be published in the next documentation release.

## Before you begin

- An active OpenLM Platform tenant.
- OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Administrative access to your Anthropic organization, so you can authorize access to user and license data.

:::note[Documentation in progress]
If you need to configure Claude AI today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. We will share the current procedure directly while the doc is finalized.
:::
