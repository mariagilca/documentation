Really Simple Systems is a cloud-based CRM system designed for small and medium-sized businesses. It helps companies manage sales, marketing, and customer service.

## Before you begin

To begin monitoring Really Simple Systems, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Really Simple Systems account to generate an API key with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your Really Simple Systems admin settings, create a new API key with read access to user and company data.

Step 1: Log into Really Simple Systems and navigate to “API V4”. This can be found in your settings under "Integrations".

Step 2: Create a new API key. Select **Manage your API keys and alerts** → **Generate new key**, choose a user, then select **Generate**. Really Simple Systems generates the API key.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Really Simple Systems integration and enter the API key.

![Really Simple Systems credential configuration in Cloud Broker](/img/saas-platforms/really-simple-systems/image9.png)
*Really Simple Systems credential configuration in Cloud Broker*

## Approve Really Simple Systems in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Really Simple Systems data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Really Simple Systems usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
