Google Workspace (formerly G Suite) is a cloud-based productivity and collaboration suite that includes Gmail, Docs, Drive, and Meet. It's used by organizations for communication, collaboration, and document management.

## Before you begin

To begin monitoring Google Workspace, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need a Google Cloud Project with a Service Account and permissions to access the Google Workspace Admin SDK and Reports API.

## Configure data collection

1. Activate API Access: In your Google Cloud Console, create a Service Account and grant it API permissions for your Google Workspace domain.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Google Workspace integration and enter the Service Account credentials.

## Approve Google Workspace in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Google Workspace data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Google Workspace usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
