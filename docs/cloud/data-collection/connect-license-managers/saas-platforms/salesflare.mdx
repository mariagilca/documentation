# Salesflare

Salesflare is an intelligent CRM and sales automation platform for small and medium-sized businesses. It automates data collection and helps sales teams focus on building relationships.

## Before you begin

To begin monitoring Salesflare, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Salesflare account to generate an API key with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your Salesflare account settings, create a new API key with read access to user and sales data.

You can make an API key in[ ](https://app.salesflare.com/#/settings/apikeys)"Settings" → "API keys".

Select the large orange **+** button in the bottom-right of the screen to create an API key.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Salesflare integration and enter the API key.

![Salesflare credential configuration in Cloud Broker](/img/saas-platforms/salesflare/image5.png)
*Salesflare credential configuration in Cloud Broker*

## Approve Salesflare in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Salesflare data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Salesflare usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
