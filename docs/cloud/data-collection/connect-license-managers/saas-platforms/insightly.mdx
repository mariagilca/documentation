Insightly is a customer relationship management (CRM) platform that helps businesses with sales, marketing, and project management. It's a versatile tool for managing customer relationships and automating business processes.

## Before you begin

To begin monitoring Insightly, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Insightly account to generate an API key and secret with the necessary read permissions.

## Configure data collection

1. To find your API Key and URL in Insightly, simply navigate to the top right user icon in your CRM navigation and select User Settings.
2. From here you'll see your API key and URL.
3. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Insightly integration and enter the API Key.

![Insightly credential configuration in Cloud Broker](/img/saas-platforms/insightly/image39.png)
*Insightly credential configuration in Cloud Broker*

## Approve Insightly in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Insightly data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Insightly usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
