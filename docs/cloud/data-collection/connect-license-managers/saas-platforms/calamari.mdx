# Calamari

Calamari is an HR platform that helps with leave and attendance management. It simplifies time-off requests, tracking, and payroll integration.

## Before you begin

To begin monitoring Calamari, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your Calamari account to generate an API token with the necessary read permissions.

## Configure data collection

1. Activate API Access: In your Calamari account settings, create a new API token with read access to user and attendance data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Calamari integration and enter the base URL and API Key.

![Calamari credential configuration in Cloud Broker](/img/saas-platforms/calamari/image15.png)
*Calamari credential configuration in Cloud Broker*

## Approve Calamari in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the Calamari data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm Calamari usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
