# ActiveCampaign

ActiveCampaign is an all-in-one marketing and customer relationship management (CRM) platform used for email marketing, sales automation, and lead management. It helps businesses automate marketing workflows and enhance customer engagement.

## Before you begin

To begin monitoring ActiveCampaign, ensure you have the following components and permissions in place:

- OpenLM components: OpenLM Cloud Broker, approved in [Broker Hub](/cloud/data-collection/broker-hub).
- Platform-specific Requirements: You'll need administrative access to your ActiveCampaign account to generate an API key and API URL. For instructions, see the official [ActiveCampaign authentication documentation](https://developers.activecampaign.com/reference/authentication).

## Configure data collection

1. Follow these step-by-step instructions to set up data collection for ActiveCampaign in OpenLM Cloud Broker:

Your ActiveCampaign API URL and Key are located on the Developer Settings page in your account:

1. Click "Settings" (gear icon).
2. The Account Settings menu will appear. Click the "Developer" option.
3. Copy and paste your API URL and Key into your 3rd party application.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, select **Add a Service**, choose **ActiveCampaign**, then enter the API URL and key.

![ActiveCampaign credential configuration in Cloud Broker](/img/saas-platforms/activecampaign/image10.png)
*ActiveCampaign credential configuration in Cloud Broker*

## Approve ActiveCampaign in OpenLM Platform

1. Sign in to OpenLM Platform.
2. From the menu, go to **License Servers** → **Pending Server**.
3. Select the ActiveCampaign data source, then select **Approve and Merge**.

## Verify the integration

1. In OpenLM Platform, go to **Allocation**.
2. Confirm ActiveCampaign usage data appears.

:::note
It can take up to 3 minutes for data to appear after approval.
:::

## Viewing reports

- **User activity trends** — see which users are most active in the platform; reallocate seats accordingly.
- **Expired or unused licenses** — identify inactive users and reclaim their seats.
