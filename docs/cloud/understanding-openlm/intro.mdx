# What is OpenLM?

Welcome to OpenLM documentation.

OpenLM is a specialized software license management and software asset management (SAM) solution for engineering, scientific, and other technical environments. It helps you monitor, optimize, and control software license usage across on-premises, hybrid, and cloud infrastructures.

OpenLM supports more than 100 license managers, including FlexNet, DSLS, Sentinel RMS, Reprise, and LM-X. It also includes purpose-built tools for managing cloud-based licensing platforms such as Autodesk Cloud.

## Key capabilities

- Compliance and audit readiness  
  Generate vendor-compliant reports, enforce usage policies, and detect unauthorized activity to stay prepared for audits.

- Cloud license management  
  Monitor and control SaaS and token-based licensing models with dedicated tools.

- Advanced usage analytics  
  View real-time and historical usage data by user, feature, or workstation to identify trends and idle consumption.

- Policy enforcement and access control  
  Automate license release, apply access restrictions, and reduce denials with configurable allocation rules.

- Enterprise integration  
  Connect to LDAP, SAML, ITSM platforms, reporting tools, and internal systems.

- Multi-environment coverage  
  Manage licenses across distributed, virtualized, and cloud-hosted environments from a unified interface.
