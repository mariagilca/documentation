# License File Management (LFM) 

The License File Management (LFM) allows you to manage license files for your license servers. This guide explains how to use LFM to retrieve, update, and deploy license files.

## Overview

LFM integrates with the Broker Hub to automatically retrieve license files from license servers. You can also create and deploy drafts of license files through the GraphQL API.

## Main workflows

### Get license files from Broker Hub

LFM automatically retrieves license files from the Broker Hub via Kafka messages. Here's how it works:

1. The Broker Hub sends a `BrokerLicenseFilesRequest` message to the `broker-messages` topic.
2. LFM processes each license file in the message.
3. If the CRC is not 0 and the license text is empty, LFM requests the full license text.
4. LFM checks the license server in the database and adds it if it doesn't exist.
5. LFM analyzes the license file and determines its status: new, updated, same, or deleted.

#### New file
- A new license file is added to the database.

#### Updated file
- The current version is archived in history.
- The license file is updated.
- If there's a matching submitted draft, it's published.

#### Same file
- No changes if the file is identical.
- Handles drafts similarly to updated files.

#### Deleted file
- The file is archived in history and removed from active files.

### Update license files using drafts

You can create and manage drafts of license files before deploying them.

#### Create a new draft
Use the GraphQL API to create a draft for an existing license file.

#### Save a draft
Update the draft text as needed.

#### Deploy a draft
Push the draft to the license server. LFM sends a command to the Broker Hub and tracks the deployment.

## Using the GraphQL API

LFM provides a GraphQL API for managing license files and drafts.

### Get license files

Retrieve a list of license files.

**Request:**
```graphql
query getLicenseFiles {
  getLicenseFiles(first: 25) {
    nodes {
      licenseFileId 
      licenseServerId 
      draft {
        draftText
        draftCreatedDate
        recentlySavedDate
        pushDate
        draftStatus
      }
      licenseServerName 
      licenseServerType 
      receiveDate
      path
    }
    pageInfo {
      startCursor endCursor
    }
    totalCount
  }
}
```

**Response:**
```json
{
  "Files": [
    {
      "LicenseFileId": "string",
      "LicenseServerId": "string",
      "Draft": {
        "draftText": "string",
        "draftCreatedDate": "2024-05-06T04:42:00.665Z",
        "recentlySavedDate": "2024-05-06T04:42:00.665Z",
        "pushDate": "2024-05-06T04:42:00.665Z",
        "draftStatus": "string"
      },
      "LicenseServerName": "string",
      "LicenseServerType": "string",
      "ReceiveDate": "2024-05-06T04:40:08.843Z",
      "Path": "string"
    }
  ]
}
```
