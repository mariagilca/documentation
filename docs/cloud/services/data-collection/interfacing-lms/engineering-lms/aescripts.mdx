# AEScripts

OpenLM can monitor AEScripts License Manager via OpenLM Broker to track license statistics.

## Requirements
1. OpenLM Platform.
2. OpenLM Broker v25.x or higher installed on the same machine as AEScripts, and approve it in [Broker Hub](/cloud/services/data-collection/broker-hub).

## Monitoring capabilities and features

| Item | Value |
| --- | --- |
| Report resolution | By second |
| License totals | Yes |
| License usage | Yes |
| Denials reporting | Yes |
| Borrowed license reporting | No |
| Expiration date reporting | No |
| Multiple server redundancy | No |

Using Broker also enables buffered communication and the ability to remotely start or stop the license manager service.

## OpenLM Broker configuration

![How OpenLM interfaces with AEScripts License Manager](/img/engineering-lms/aescripts/image157.png)

### Configuring via Broker UI
1. Open Broker UI at [http://localhost:5090](http://localhost:5090).
2. Go to Menu: License Managers -> Add License Manager.
3. Select AEScripts, enter the port number, and click Add.
4. In Commands, set the executable path and adjust start/stop toggles if needed.
5. In Log Files, click Add Log File, then fill in:
   - Type: AEScripts Log
   - Log name: descriptive name
   - Log Path: path to AEScripts logs folder
   - Vendor: AEScripts
   - Encoding: UTF-16
6. Click Continue, then Save.

## Configure OpenLM Platform
1. Log into the OpenLM Platform.
2. From the Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/aescripts/image10.png)
3. In the left menu, select Pending Server.
4. In the list, select the AEScripts License Manager and click Approve and Merge.

    ![Verifying the configuration](/img/engineering-lms/aescripts/image3.png)
5. Navigate to Menu -> License Servers Live -> Server Statistics.
6. Ensure AEScripts appears in the list with a green status indicator.

> Note: It can take up to 3 minutes for the status to update for new connections.
