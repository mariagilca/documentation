# Chaos V-Ray

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Chaos V-Ray License Manager.

## Requirements

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Chaos, and approve it in [Broker Hub](/cloud/services/data-collection/broker-hub).

## Monitoring capabilities

The Broker reads the Chaos V-Ray License Manager log file, compiles the data, and sends it to OpenLM for processing.

| Item | Value |
| --- | --- |
| Report resolution | By second |
| License totals | Yes |
| License usage | No |
| Denials | No |
| Borrowing | No |
| Expiration date | No |
| Redundancy | No |

## Configuring via Broker UI

![Diagram of how OpenLM interfaces with the Chaos V-Ray License Manager](/img/engineering-lms/chaos-v-ray/image27.png)

1. Open the Broker web UI at http://localhost:5090 (or 5091, 5092 if the default port is in use).

1. Go to License Managers -> Add License Manager.

    ![From the drop-down list, select Chaos and enter the port (e.g., 35033).](/img/engineering-lms/chaos-v-ray/image48.png)

1. From the drop-down list, select Chaos and enter the port (e.g., 35033).

1. Click Add.

    ![Go to Vendors -> Add Vendor and enter the name Chaos V-Ray. Click Continue.](/img/engineering-lms/chaos-v-ray/image6.png)

1. Go to Vendors -> Add Vendor and enter the name Chaos V-Ray. Click Continue.

1. Go to Log Files -> Add Log File.

1. Specify the log file path manually or use the magnifier icon to browse.

1. Select Chaos V-Ray as the vendor and click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/chaos-v-ray/image10.png)

1. On left menu, select Pending Server

1. On the list, select the Chaos license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/chaos-v-ray/image3.png)

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Chaos appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
