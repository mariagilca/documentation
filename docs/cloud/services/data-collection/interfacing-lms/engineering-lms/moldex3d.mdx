# Moldex3D

This guide explains how to monitor the Moldex3D License Manager with OpenLM to obtain license usage and statistics.

## Requirements

Install the following:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Moldex3D, and approve it in [Broker Hub](/cloud/services/data-collection/broker-hub).

## Monitoring capabilities

The table below shows the monitoring capabilities available through OpenLM Broker:

| Item | Value |
| --- | --- |
| Report resolution | By second |
| License totals | Yes |
| License usage | Yes |
| Denials | Yes |
| Borrowed licenses | Yes |
| Expiration dates | Yes |
| Redundancy | No |

Using Broker also enables:

- Buffered communication with OpenLM Server

- Remote start/stop of the license manager service

## Automatic Broker configuration

1. In Broker, click Detect.

    ![If the Moldex3D service (for example, Moldex3D-LM Service) is running, Broker detects and configures it automatically.](/img/engineering-lms/moldex3d/image107.png)

1. If the Moldex3D service (for example, Moldex3D-LM Service) is running, Broker detects and configures it automatically.

1. After configuration, select Restart Broker.

1. It is recommended to also run data_inquiry -> Execute to confirm valid output.

## Configuring via Broker UI

1. Install the latest Broker.

1. Open http://localhost:5090/.

1. Go to License Managers.
    - If the Moldex3D service is running, click Detect.
    - If autodetect fails, click Add License Manager. From Type, select Moldex3D. Enter the port and click Add.

    ![In Commands, set the path to MDX3DLMUtil.exe. Click Execute to confirm.](/img/engineering-lms/moldex3d/image124.png)

1. In Commands, set the path to MDX3DLMUtil.exe. Click Execute to confirm.

1. In Vendors, click Add Vendor, enter Moldex3D, and click Continue.

    ![Click Save.](/img/engineering-lms/moldex3d/image82.png)

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/moldex3d/image10.png)

1. On left menu, select Pending Server

1. On the list, select the Modelex3D license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/moldex3d/image3.png)

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Modelex3D appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
