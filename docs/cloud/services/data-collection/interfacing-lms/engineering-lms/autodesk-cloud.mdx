# Autodesk Cloud

OpenLM can integrate with Autodesk Cloud to collect license usage data and account statistics.

:::info Support assistance required
This implementation requires assistance from the OpenLM Support Team. Please open a support ticket to have the Autodesk Cloud integration configured for your environment.
:::
