# Monday
Monday.com Usage Monitoring

## About Monday.com

Monday.com is a work operating system (Work OS) that helps teams manage projects, workflows, and everyday tasks. It's a highly visual and collaborative platform used by a wide range of industries. Monitoring Monday.com usage is crucial for optimizing subscription costs and ensuring that licenses are used by active team members. This is similar to monitoring other project management platforms like Jira or Asana.

## Prerequisites

To begin monitoring Monday.com, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Monday.com account to generate an API v2 token with the necessary read permissions.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Monday.com in OpenLM Cloud Broker:

1. If you are an admin user on your [monday.com](https://www.google.com/url?q=http://monday.com/&sa=D&source=editors&ust=1760366848058557&usg=AOvVaw09EbIvnHIN_MqDJxRMR558) account, follow these steps to access your API token:

1. Log into your [monday.com](https://www.google.com/url?q=http://monday.com/&sa=D&source=editors&ust=1760366848058772&usg=AOvVaw1NAQmPGYR1iGynN4m1EygO) account.
2. Click on your avatar/profile picture in the top right corner.
3. Select Administration &gt; Connections &gt; API.
4. Copy your personal token and paste it into the 'API V2 Token' field.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Monday.com integration and enter the API token.

![](/img/saas-platforms/monday/image36.png)

3. Verify Connection: Test the connection to ensure that OpenLM can successfully communicate with the Monday.com API.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for Monday.com will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which users are most active, which helps in reallocating licenses.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users to save on costs.
