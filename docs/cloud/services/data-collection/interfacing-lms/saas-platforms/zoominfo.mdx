# ZoomInfo
ZoomInfo Usage Monitoring

## About ZoomInfo

ZoomInfo is a go-to-market intelligence platform that provides sales and marketing teams with business contact and company data. It helps users find, engage, and close deals. Monitoring ZoomInfo usage is crucial for ensuring that licenses are used effectively and for optimizing subscription costs. This is similar to monitoring other sales tools like Salesflare or Pipedrive.

## Prerequisites

To begin monitoring ZoomInfo, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your ZoomInfo account to generate an API key with the necessary read permissions.
