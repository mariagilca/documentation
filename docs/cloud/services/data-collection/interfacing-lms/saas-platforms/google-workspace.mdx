# Google Workspace
Google Workspace Usage Monitoring

## About Google Workspace

Google Workspace (formerly G Suite) is a cloud-based productivity and collaboration suite that includes Gmail, Docs, Drive, and Meet. It's used by organizations for communication, collaboration, and document management. Monitoring Google Workspace is essential for optimizing costs, ensuring compliance, and understanding license utilization. This is similar to monitoring Office 365 or Microsoft 365.

## Prerequisites

To begin monitoring Google Workspace, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required. For automation, consider OpenLM OneDirectorySync or License Allocation Control.
- Platform-specific Requirements: You'll need a Google Cloud Project with a Service Account and permissions to access the Google Workspace Admin SDK and Reports API.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Google Workspace in OpenLM Cloud Broker:

1. Enable API Access: In your Google Cloud Console, create a Service Account and grant it API permissions for your Google Workspace domain.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Google Workspace integration and enter the Service Account credentials.
3. Verify Connection: Test the connection to ensure that OpenLM can successfully communicate with the Google APIs.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for Google Workspace will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which users are most active across different Google Workspace applications.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users to save on costs.
