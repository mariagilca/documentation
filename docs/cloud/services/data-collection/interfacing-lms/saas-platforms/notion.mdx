# Notion
Notion Usage Monitoring

## About Notion

Notion is a versatile workspace for notes, project management, and knowledge bases. It allows teams to create and collaborate on documents, databases, and more. Monitoring Notion usage is important for understanding how teams are using the platform and for optimizing subscription costs. This is similar to monitoring other collaboration tools like Google Workspace or Confluence.

## Prerequisites

To begin monitoring Notion, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required. For automation, consider OpenLM OneDirectorySync or License Allocation Control.
- Platform-specific Requirements: You'll need administrative access to your Notion workspace to create an integration and generate an API key with the necessary read permissions.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Notion in OpenLM Cloud Broker:

1. Enable API Access: In your Notion workspace settings, create a new integration and generate an internal integration token.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Notion integration and enter the API token.

![](/img/saas-platforms/notion/image21.png)

3. Verify Connection: Test the connection to ensure that OpenLM can successfully communicate with the Notion API.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for Notion will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which users are most active, which helps you reallocate licenses.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users to save on costs.
