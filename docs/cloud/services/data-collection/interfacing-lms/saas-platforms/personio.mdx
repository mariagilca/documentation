# Personio
Personio Usage Monitoring

## About Personio

Personio is an all-in-one HR software platform for small and medium-sized businesses. It helps with everything from recruiting and onboarding to payroll and performance management. Monitoring Personio usage is important for ensuring that HR licenses are being used effectively and for optimizing costs. This is similar to monitoring other HR platforms like BambooHR or Sage HR.

## Prerequisites

To begin monitoring Personio, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Personio account to generate an API key and client ID with the necessary read permissions.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Personio in OpenLM Cloud Broker:

1. Enable API Access: In your Personio settings, create new API credentials with read access to employee and user data.

1. Go to Marketplace &gt; Connected Integrations.
2. Click Create custom integration at the top right of the screen.
3. Configure the setup.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Personio integration and enter the API key and client ID.

![](/img/saas-platforms/personio/image33.png)

3. Verify Connection: Test the connection to ensure that OpenLM can successfully retrieve data.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for Personio will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which HR professionals are most active in the platform, helping you manage resource allocation.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users.
