# Really Simple Systems
Really Simple Systems Usage Monitoring

## About Really Simple Systems

Really Simple Systems is a cloud-based CRM system designed for small and medium-sized businesses. It helps companies manage sales, marketing, and customer service. Monitoring Really Simple Systems usage is important for ensuring that licenses are used effectively and for optimizing subscription costs. This is similar to monitoring other sales tools like Salesflare or Pipedrive.

## Prerequisites

To begin monitoring Really Simple Systems, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Really Simple Systems account to generate an API key with the necessary read permissions.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Really Simple Systems in OpenLM Cloud Broker:

1. Enable API Access: In your Really Simple Systems admin settings, create a new API key with read access to user and company data.

Step 1: Log into Really Simple Systems and navigate to “API V4”. This can be found in your settings under "Integrations".

Step 2: From here, you can create a new API Key by clicking on "Manage your API keys and alerts &gt; Generate new key". Select a user and click on "Generate". Really Simple Systems will now generate an API Key.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Really Simple Systems integration and enter the API key.

![](/img/saas-platforms/really-simple-systems/image9.png)

3. Verify Connection: Test the connection to ensure that OpenLM can successfully retrieve data.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for Really Simple Systems will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which users are most active in the platform, helping you manage resource allocation.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users.
