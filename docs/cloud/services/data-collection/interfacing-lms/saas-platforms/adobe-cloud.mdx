# Adobe Cloud
Adobe Cloud Usage Monitoring

## About Adobe Cloud

Adobe Creative Cloud is a suite of applications and services for graphic design, video editing, web development, and photography. It includes industry-standard tools like Photoshop, Illustrator, and Premiere Pro. Organizations monitor its usage to optimize subscription costs, ensure license compliance, and understand which creative teams are using which tools. Monitoring Adobe Cloud with OpenLM Cloud Broker is similar to monitoring other design and creative platforms like Figma or Sketch.

## Prerequisites

To begin monitoring Adobe Cloud, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker is required for data collection. You'll also need OpenLM SLM (Software License Manager) for basic monitoring, and may need OpenLM OneDirectorySync or License Allocation Control for automated license management.
- Platform-specific Requirements: You need administrative access to your Adobe Admin Console. This allows you to generate the necessary API keys, client IDs, and client secrets with permissions to access user and product usage data.

## Configuring data collection

1. Please contact our support team [support@openlm.com](mailto:support@openlm.com) to setup Adobe Cloud integration.

## Viewing reports

After data collection is configured, you can access comprehensive reports to analyze your Adobe Cloud usage.

- User Activity Trends: These reports show how often and for how long users are active on the platform, allowing you to identify active and inactive users.
- Expired/Unused License Reports: This report identifies licenses that are no longer in use, which is critical for cost optimization.
