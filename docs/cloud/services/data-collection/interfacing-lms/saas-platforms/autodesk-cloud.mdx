# Autodesk Cloud
Autodesk Cloud Usage Monitoring

## About Autodesk Cloud

Autodesk Cloud offers a suite of cloud-based design and make software for the architecture, engineering, construction, and manufacturing industries. It includes tools like Revit, AutoCAD, and Fusion 360. Monitoring Autodesk Cloud is critical for cost optimization due to the high cost of licenses, ensuring that licenses are used efficiently and by the right people. This is similar to managing other engineering and design platforms like Bentley or Intergraph.

## Prerequisites

To begin monitoring Autodesk Cloud, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required. For automation, License Access Control (LAC) is optional; fully available for FlexLM and experimental for DSLS, RLM, Autodesk Cloud, and LinkedIn.
- Platform-specific Requirements: You'll need administrative access to your Autodesk Account Management portal to retrieve the necessary API keys or tokens with permissions to access usage data.

## Configuring data collection

Please contact our support team [support@openlm.com](mailto:support@openlm.com) to setup Autodesk Cloud integration.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: Identify which projects and users are consuming the most licenses, helping with license re-allocation.
- Expired/Unused License Reports: Pinpoint and reclaim licenses from inactive users to save on costs.
