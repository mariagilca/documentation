# Syncfusion
Syncfusion Usage Monitoring

## About Syncfusion

Syncfusion provides a comprehensive suite of software components and frameworks for building modern web, mobile, and desktop applications. It's used by developers to create user interfaces and other features. Monitoring Syncfusion usage is important for ensuring that licenses are used effectively and for optimizing costs. This is similar to monitoring other development platforms like JetBrains Cloud or GitLab.

## Prerequisites

To begin monitoring Syncfusion, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required. For automation, consider OpenLM OneDirectorySync or License Allocation Control.
- Platform-specific Requirements: You'll need administrative access to your Syncfusion account to generate an API key with the necessary read permissions.
