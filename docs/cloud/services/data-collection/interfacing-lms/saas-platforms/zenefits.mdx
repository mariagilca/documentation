# Zenefits
Zenefits Usage Monitoring

## About Zenefits

Zenefits is an all-in-one HR platform that helps businesses with payroll, benefits, and HR administration. It simplifies complex HR processes and ensures compliance. Monitoring Zenefits usage is important for ensuring that licenses are used effectively and for optimizing costs. This is similar to monitoring other HR platforms like BambooHR or Sage HR.

## Prerequisites

To begin monitoring Zenefits, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Zenefits account to generate an API key and client secret with the necessary read permissions.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which HR professionals are most active in the platform, helping you manage resource allocation.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users.
