# Bentley
Bentley Usage Monitoring

## About Bentley

Bentley provides software solutions for civil engineering, architecture, construction, and infrastructure. Products like MicroStation and OpenRoads are widely used for designing and managing large-scale projects. Monitoring Bentley usage is critical for cost optimization and ensuring that expensive licenses are utilized efficiently. This is similar to managing other engineering and design platforms like Autodesk Cloud or Intergraph.

## Prerequisites

To begin monitoring Bentley, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required. For automation, consider OpenLM OneDirectorySync or License Allocation Control.
- Platform-specific Requirements: You'll need administrative access to your Bentley license management system (e.g., SELECTserver or CONNECT Licensing) to generate API keys or tokens with permissions to access usage data.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Bentley in OpenLM Cloud Broker:

1. Enable API Access: In the Bentley administrator portal, create an API key with read access for license and user data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Bentley integration and enter user name and password.

![](/img/saas-platforms/bentley/image11.png)

3. Verify Connection: Test the connection to confirm successful data retrieval.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: You can now view usage data for Bentley products in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: Identify which projects and users are consuming the most licenses, helping with license re-allocation.
- Expired/Unused License Reports: Pinpoint and reclaim licenses from inactive users to save on costs.
