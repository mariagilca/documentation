# License Parser

License Parser turns cryptic FlexLM license files into human-readable reports. Use it to inspect a license file before it reaches a license server, validate that it contains the features you expect, and share a clean summary with stakeholders who do not work with raw license text.

## What you can do with License Parser

- Upload or point at a FlexLM license file.
- View a structured breakdown of vendors, features, expiration dates, quantities, and host or user constraints.
- Share the parsed report with non-technical stakeholders who need to verify what was purchased.

## Where to find it in the platform

Open the OpenLM Cloud app launcher, then select **Licenses and Features → License Parser**.

## Prerequisites

- An active OpenLM Platform account with **License Parser** activated in [Products](./openlm-administration/products).
- Access to the FlexLM license file you want to inspect.
