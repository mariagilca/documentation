# Figma
Figma Usage Monitoring

## About Figma

Figma is a collaborative interface design tool used by designers, product managers, and developers. It allows teams to create, prototype, and share designs in a single, cloud-based platform. Monitoring Figma usage is critical for optimizing subscription costs and ensuring that design licenses are used efficiently. This is similar to monitoring other creative and design tools like Adobe Cloud or Sketch.

## Prerequisites

To begin monitoring Figma, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Figma organization or team account to generate a personal access token with the necessary read permissions.
