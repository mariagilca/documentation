# Odoo
Odoo Usage Monitoring

## About Odoo

Odoo is an open-source suite of business management software, including tools for CRM, e-commerce, accounting, and project management. It's used by businesses of all sizes to manage their operations. Monitoring Odoo usage is important for ensuring that licenses are used effectively and for optimizing costs. This is similar to monitoring other all-in-one business solutions like Salesforce or HubSpot.

## Prerequisites

To begin monitoring Odoo, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Odoo instance to generate an API key with the necessary read permissions.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Odoo in OpenLM Cloud Broker:

1. Enable API Access: In your Odoo admin panel, create a new API key with read access to user and subscription data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Odoo integration and enter the company URL, database name, user name and password.

![Odoo credential configuration in Cloud Broker](/img/saas-platforms/odoo/image25.png)

3. Verify Connection: Test the connection to ensure that OpenLM can successfully retrieve data.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for Odoo will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which users are most active, which helps you reallocate licenses.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users to save on costs.
