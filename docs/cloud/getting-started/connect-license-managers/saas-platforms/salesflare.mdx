# Salesflare
Salesflare Usage Monitoring

## About Salesflare

Salesflare is an intelligent CRM and sales automation platform for small and medium-sized businesses. It automates data collection and helps sales teams focus on building relationships. Monitoring Salesflare usage is important for ensuring that licenses are used effectively and for optimizing costs. This is similar to monitoring other sales tools like Pipedrive or HubSpot.

## Prerequisites

To begin monitoring Salesflare, ensure you have the following components and permissions in place:

- OpenLM Components: OpenLM Cloud Broker and OpenLM SLM are required.
- Platform-specific Requirements: You'll need administrative access to your Salesflare account to generate an API key with the necessary read permissions.

## Configuring data collection

Follow these step-by-step instructions to set up data collection for Salesflare in OpenLM Cloud Broker:

1. Enable API Access: In your Salesflare account settings, create a new API key with read access to user and sales data.

You can make an API key in[ ](https://www.google.com/url?q=https://app.salesflare.com/%23/settings/apikeys&sa=D&source=editors&ust=1760366848116787&usg=AOvVaw01dRy5uAnzH8sETe6i18mt)"Settings" &gt; "API keys".

Click on the large orange "+" button on the bottom right of the screen to create an API key.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Salesflare integration and enter the API key.

![Salesflare credential configuration in Cloud Broker](/img/saas-platforms/salesflare/image5.png)

3. Verify Connection: Test the connection to ensure that OpenLM can successfully retrieve data.
4. Approve in OpenLM: Approve the new data source within the License Servers section.
5. See Data: Usage data for Salesflare will now be visible in the OpenLM Allocation service.

## Viewing reports

Access your reports to analyze usage patterns.

- User Activity Trends: See which sales professionals are most active in the platform, helping you manage resource allocation.
- Expired/Unused License Reports: Identify and reclaim licenses from inactive users.
