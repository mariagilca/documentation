# LS-DYNA

## General

LS-DYNA is a finite element simulation tool developed by Livermore Software Technology Corporation (LSTC). LS-DYNA includes peripheral tools such as LS-OPT, LS_PREPOST, LS_TASC, and THUMS. Together they cover a wide range of physics simulation topics, from fluid dynamics to car safety.

LS-DYNA uses a proprietary license manager to control deployment of network licenses. OpenLM enables you to view license utilization, analyze usage statistics and patterns, and manage idle licenses.

OpenLM supports multiple license managers such as Flexera FLEXnet Publisher (FLEXlm) and Sentinel RMS. This document explains how to configure OpenLM to monitor LS-DYNA licenses.

Query the license server locally using OpenLM Broker and forward the information to OpenLM Server.

## Requirements

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as LM-DYNA, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Configuring via Broker UI

![How Broker interfaces with OpenLM Server.](/img/engineering-lms/ls-dyna/image26.png)
*How Broker interfaces with OpenLM Server.*

Install and configure OpenLM Broker on the LS-DYNA license server machine. Broker queries the license server locally and forwards data to OpenLM Server. It also provides buffered communication to overcome network failures and security restrictions.

1. Open Broker UI at http://localhost:5090/.

1. Go to License Managers -> Add License Manager.

1. In the Commands node, enter the full path to lstc_qrun.exe.

1. Click Apply.

1. Go to the Vendors node and enter the vendor name.

1. Click Restart Broker.

    ![LS-DYNA configuration in Broker web UI.](/img/engineering-lms/ls-dyna/image165.png)
*LS-DYNA configuration in Broker web UI.*


### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/ls-dyna/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the LS-DYNA license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/ls-dyna/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure LS-DYNA appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
