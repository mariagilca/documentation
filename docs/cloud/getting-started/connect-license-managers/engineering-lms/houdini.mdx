# Houdini

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Houdini.

## Requirements

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Houdini, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Item | Value |
| --- | --- |
| LM Type in the Broker | Houdini |
| Commands | Yes |
| Logs | No |
| Quantity | Yes |
| Expiration date | Yes |
| Denied | No |
| Borrowing | No |
| Allocations | N/A |
| Report resolution | By minute |

Using the Broker also enables buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with Houdini License Manager](/img/engineering-lms/houdini/image27.png)
*Diagram of how OpenLM interfaces with Houdini License Manager*

## note

OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.

OpenLM Broker queries the Houdini license manager locally using the Network License Manager (sesinetd). It executes commands such as sesictrl.exe -i periodically to capture:

- Total licenses

- Licenses in use

- License expiration dates

- Usernames and hostnames

- License IDs and versions

## Automatic Broker configuration

1. Open the Broker web UI.

1. Go to License Managers and click Detect.

    ![Automatic detection in OpenLM Broker](/img/engineering-lms/houdini/image67.png)
*Automatic detection in OpenLM Broker*

1. If the Houdini service is running, Broker will detect it and create a port node with all required settings.

1. Click Apply to save.

1. Verify the setup by going to Commands -> data_query and clicking Execute.

## Configuring via Broker UI

If auto-detect fails:

1. Go to License Managers -> Add License Manager.

    ![Manually adding a Houdini license manager in OpenLM Broker](/img/engineering-lms/houdini/image25.png)
*Manually adding a Houdini license manager in OpenLM Broker*

1. Select Houdini from the LM Type drop-down list.

1. Enter the port number (default: 1075) and click Add.

1. In the Executable Path field, browse to the root folder where Houdini (sesinetd) is installed, then click Save.

    ![Setting executable path for Houdini in OpenLM Broker](/img/engineering-lms/houdini/image85.png)
*Setting executable path for Houdini in OpenLM Broker*

1. Go to the Vendors tab. Enter Houdini as the vendor name and click Continue.

    ![Adding Houdini vendor in OpenLM Broker](/img/engineering-lms/houdini/image103.png)
*Adding Houdini vendor in OpenLM Broker*

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/houdini/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Houdini license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/houdini/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Houdini appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
