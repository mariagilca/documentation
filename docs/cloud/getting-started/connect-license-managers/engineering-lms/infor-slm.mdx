# INFOR SLM

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Infor SLM License Manager.

## Requirements

Before you query the license manager, install:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Infor SLM, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## OpenLM Broker configuration

![Adding Infor SLM License Manager in OpenLM Broker](/img/engineering-lms/infor-slm/image9.png)
*Adding Infor SLM License Manager in OpenLM Broker*

## note

OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.

1. Open the Broker web UI at http://localhost:5090. If the default port is in use, try 5091 or 5092.

1. Go to License Managers -> Add License Manager.

1. From the LM Type drop-down list, select Infor SLM.

1. Enter the port number (e.g., 4325) and click Add.

1. Go to the Settings tab.
    - The Broker may auto-detect the license file path.
    - If not, select Set license file path manually and navigate to the license.xml file.

    ![Setting license file path for Infor SLM in OpenLM Broker](/img/engineering-lms/infor-slm/image92.png)
*Setting license file path for Infor SLM in OpenLM Broker*

1. Go to the Commands tab. Enter the Infor SLM host and port in the Data Inquiry field.

    ![Configuring data inquiry for Infor SLM in OpenLM Broker](/img/engineering-lms/infor-slm/image63.png)
*Configuring data inquiry for Infor SLM in OpenLM Broker*

1. Click Save, then click Execute to test the configuration.

    ![Successful execution output for Infor SLM license manager](/img/engineering-lms/infor-slm/image35.png)
*Successful execution output for Infor SLM license manager*

1. Go to the Vendors tab. Click Add Vendor, enter Infor SLM, and click Continue.

1. Click Save.

## OpenLM configuration

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/infor-slm/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the InforSML license manager and click on Approve and Merge

    ![At this point, Infor SLM is added to OpenLM SLM.](/img/engineering-lms/infor-slm/image3.png)
*At this point, Infor SLM is added to OpenLM SLM.*


    At this point, Infor SLM is added to OpenLM SLM.

### Verifying the configuration

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure AEScripts appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
