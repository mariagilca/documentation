# Rib Presto

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the RIB Presto License Manager.

## Requirements

Before starting, make sure you have:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as RIB Presto, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

RIB Presto is monitored via log file parsing. The Broker reads the log file, compiles the data, and sends it to OpenLM Server for processing.

## OpenLM Broker configuration

*Diagram of how OpenLM interfaces with the RIB Presto License Manager*

OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.

## Configuring via Broker UI

1. Open the Broker web UI at http://localhost:5090/.

1. Go to License Managers -> Add License Manager.

    ![From the drop-down, select Presto and enter any port number (e.g., 888) since only log file reading is used. Click Add. IMAGE 54](/img/engineering-lms/rib-presto/image48.png)
*From the drop-down, select Presto and enter any port number (e.g., 888) since only log file reading is used. Click Add. IMAGE 54*

1. From the drop-down, select Presto and enter any port number (e.g., 888) since only log file reading is used. Click Add.

    ![In the Vendors tab, click Add Vendor, enter RIB Presto, and click Continue. IMAGE 42](/img/engineering-lms/rib-presto/image54.png)
*In the Vendors tab, click Add Vendor, enter RIB Presto, and click Continue. IMAGE 42*

1. In the Vendors tab, click Add Vendor, enter RIB Presto, and click Continue.

    ![IMAGE 61](/img/engineering-lms/rib-presto/image42.png)
*IMAGE 61*

    ![Go to the Log Files tab. IMAGE 83](/img/engineering-lms/rib-presto/image61.png)
*Go to the Log Files tab. IMAGE 83*

1. Go to the Log Files tab.

    ![Click Add Log File.](/img/engineering-lms/rib-presto/image83.png)
*Click Add Log File.*

1. Click Add Log File.

1. Browse to or manually enter the path to the RIB Presto log file.

1. From the vendor list, select RIB Presto.

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/rib-presto/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the RIB Presto license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/rib-presto/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure RIB Presto appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
