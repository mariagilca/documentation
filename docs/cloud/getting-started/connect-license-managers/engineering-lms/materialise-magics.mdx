# Materialise Magics

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Materialise Magics.

## Requirements

Before you query the license manager, install:

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as Materialise Magics, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities

| Item | Value |
| --- | --- |
| LM Type in the Broker | Materialise Magics |
| Commands | Yes |
| Logs | No |
| Quantity | Yes |
| Expiration date | Yes |
| Denied | No |
| Borrowing | No |
| Allocations | No |
| Report resolution | Seconds |

Using the Broker also enables buffered communication and allows remote start and stop of the license manager service.

## Configuring via Broker UI

![OpenLM Broker configured to connect to the Materialise Magics license manager](/img/engineering-lms/materialise-magics/image28.png)
*OpenLM Broker configured to connect to the Materialise Magics license manager*

OpenLM Broker configured to connect to the Materialise Magics license manager

note

OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.

1. Open the Broker web UI at http://localhost:5090. If you want to access it from another machine on the same network, generate a token by visiting:http://localhost:5090/api/new-token

1. Go to License Managers -> Add License Manager.

1. From the LM Type drop-down list, select Materialise Magics.

1. Enter the port number (default: 7010) and click Add.

1. In the Executable Path field, browse to the installation directory of the Materialise Magics .exe file.

    ![Setting executable path for Materialise Magics in OpenLM Broker](/img/engineering-lms/materialise-magics/image147.png)
*Setting executable path for Materialise Magics in OpenLM Broker*

1. Click Save.

1. To verify the configuration, go to the Commands tab and click Execute.

    ![Verifying Materialise Magics license manager connection](/img/engineering-lms/materialise-magics/image84.png)
*Verifying Materialise Magics license manager connection*


    Verifying Materialise Magics license manager connection

1. If successful, the output will resemble the example below:

    ![Successful connection output](/img/engineering-lms/materialise-magics/image130.png)
*Successful connection output*

1. Go to the Vendors tab. Click Add Vendor, enter Materialise, and click Continue.

    ![Adding Materialise vendor in OpenLM Broker](/img/engineering-lms/materialise-magics/image66.png)
*Adding Materialise vendor in OpenLM Broker*


    Adding Materialise vendor in OpenLM Broker

1. Click Save.

### Configure OpenLM Platform

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/materialise-magics/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Materialise Magic license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/materialise-magics/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Materialise Magic appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
