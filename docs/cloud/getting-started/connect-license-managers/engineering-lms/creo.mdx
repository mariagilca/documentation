# CREO

This document outlines the steps required to integrate Creo License Manager with OpenLM. By completing the configuration, you can monitor license usage, gather statistics, and ensure optimized license management.

## Requirements

1. OpenLM Platform
2. OpenLM Broker v25.x or higher installed on the same machine as AEScripts, and approve it in [Broker Hub](/cloud/data-collection/broker-hub).

## Monitoring capabilities and Features

The current monitoring capabilities available for CREO through OpenLM Broker are as follows:

| Item | Value |
| --- | --- |
| Denials | Yes |
| Expiration Date Reporting | Yes |
| Logs | Yes |

## Configuring via Broker UI

Step 1: Access the OpenLM Broker Interface

• Open a web browser and access the Broker interface using the URL:

http://localhost:5090 (adjust the port number if it's not the default, e.g., 5091 or 5092).

Step 2: Add a License Manager

1. Navigate to the License Managers tab.

1. Click Add License Manager.

1. In the pop-up window:

    • Select Creo from the drop-down list.

    • Enter the Creo port number (e.g., 25).

    • Click Add.

    ![Step 3: Configure License File Settings](/img/engineering-lms/creo/image17.png)
*Step 3: Configure License File Settings*

    Step 3: Configure License File Settings

    • Go to the Settings tab. The Broker can auto-detect the license file.

    • Verify the detected file path, or select Set license file path manually to navigate to the license.xml file.

    •Click Save.

    ![Step 4: Commands tab](/img/engineering-lms/creo/image94.png)
*Step 4: Commands tab*

    Step 4: Commands tab

1. Switch to the Commands tab.

1. Click Save, then click Execute. A positive execute command result will look like this:

    ![Configure OpenLM Platform](/img/engineering-lms/creo/image35.png)
*Configure OpenLM Platform*

1. Log in to OpenLM Platform.

1. From Menu, go to License Servers.

    ![On left menu, select Pending Server](/img/engineering-lms/creo/image10.png)
*On left menu, select Pending Server*

1. On left menu, select Pending Server

1. On the list, select the Creo license manager and click on Approve and Merge

    ![Verifying the configuration](/img/engineering-lms/creo/image3.png)
*Verifying the configuration*

1. In OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics.

1. Ensure Creo appears in the list with a green status indicator.

Note: It can take up to 3 minutes for the status to update for new connections.
