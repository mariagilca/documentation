Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the pure::variants License Manager.

## Requirements

Before starting, make sure you have:

1. OpenLM Server v2x installed on a machine in your organization or an OpenLM Cloud (SLMC) account  
2. OpenLM Broker v22.3 or higher installed on the same machine as pure::variants License Manager

## Monitoring capabilities

| Feature | Resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Support | By minute | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the pure::variants License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit.png)  
*Diagram of how OpenLM interfaces with the pure::variants License Manager*

:::note
OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.
:::

1. Open the Broker web UI at `http://localhost:5090/` (or an incremented port if 5090 is occupied).  
2. Go to **License Managers** → **Add License Manager**.  
   ![Screenshot: OpenLM Broker configuration](/img/legacy/word-image-54772-2.png)  
3. From the drop-down, select **Pure Variants** and enter the port number (for example, 888). Click **Add**.  
4. In the **Settings** tab, make sure **Watch License File** is off.  
5. Go to the **Commands** tab and enter the executable path for pure::variants.  
   ![Screenshot 2: OpenLM Broker configuration](/img/legacy/word-image-54772-3.png)  
6. Go to the **Vendors** tab → **Add Vendor**, enter `pure::variants`, and click **Continue**.  
   ![Screenshot 3: OpenLM Broker configuration](/img/legacy/word-image-54772-4.png)  
7. Go to the **Advanced** tab and enter the pure::variants login and password.  
8. Click **Save**.

## OpenLM Server configuration

### Automatic configuration through EasyAdmin

1. Open EasyAdmin and go to **Start → Widgets → License Manager Servers**.  
2. Click the **Servers pending approval** icon.  
   ![Screenshot: Automatic configuration through EasyAdmin](/img/legacy/word-image-54772-5.png)  
3. Select the pure::variants entry (displayed as **OpenLM Generic**) and verify settings.  
4. Click **Approve**.  
   ![Screenshot 2: Automatic configuration through EasyAdmin](/img/legacy/word-image-54772-6.png)  

The pure::variants License Manager will be added automatically and begin reporting shortly.

## Verify your configuration

1. Open EasyAdmin.  
2. Go to **Start → Widgets → License Servers**.  
3. Confirm the pure::variants License Manager appears with a green status circle.

:::note
It may take up to 3 minutes for a new connection to show as active.
:::
