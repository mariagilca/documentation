# ETAP

## Interfacing ETAP License Manager with OpenLM

This document outlines the steps required to integrate ETAP License Manager with OpenLM. By completing the configuration, you can monitor license usage, gather statistics, and ensure optimized license management.

## Requirements

To set up ETAP integration with OpenLM, the following components are necessary:

OpenLM SLM:
- Version 2.x installed on a local machine within your organization.
- Alternatively, an SLMC account.

OpenLM Broker:
- Version 26.1 or higher installed on the same machine as the ETAP License Manager.

## Monitoring Capabilities and Features

The current monitoring capabilities available for ETAP through OpenLM Broker are as follows:

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ETAP | Log through Event Viewer command | Yes (Log-based) | Not Available (Usage) | N/A | N/A | N/A | N/A | seconds |

The **Commands** integration reads from a log file generated by Broker. Broker runs a command that pulls log lines from Windows Event Viewer and writes them into the log file it then parses.

## Configuration Steps

### OpenLM Broker Configuration

1. Navigate to your Broker instance. Select **License Managers** from the sidebar.
   ![OpenLM Broker sidebar with License Managers selected](/img/legacy/etap/image4.jpg)
2. Click **Add License Manager** to register a new license manager on the selected host.
   ![Add License Manager button in OpenLM Broker](/img/legacy/etap/image21.jpg)
3. Open the **LM Type** dropdown and browse the available license manager types.
   ![LM Type dropdown list in OpenLM Broker](/img/legacy/etap/image10.jpg)
4. Pick **ETAP** as the LM Type.
   ![ETAP selected as LM Type](/img/legacy/etap/image9.jpg)
5. Click the **Port** field to confirm or change the port the license service listens on.
   ![Port field for the ETAP license manager](/img/legacy/etap/image3.jpg)
6. Update the port to match your ETAP configuration. (Port does not play a role, as this is a log-based integration).
   ![Updated port value for ETAP license manager](/img/legacy/etap/image18.jpg)
7. Click **Add** to create the license manager entry in OpenLM Broker.
   ![Add button to create the license manager entry](/img/legacy/etap/image16.jpg)
8. Switch to the **Vendors** tab to verify the vendor definition tied to this license manager.
   ![Vendors tab showing the vendor definition](/img/legacy/etap/image1.jpg)
9. Click **Save** to apply the license manager configuration and send it for approval.
   ![Save button to submit the license manager for approval](/img/legacy/etap/image19.jpg)
10. Use the **Edit** action to reopen the license manager and fine-tune its settings if required.
    ![Edit action for the license manager entry](/img/legacy/etap/image5.jpg)
11. Click **Execute** to test the **Data Inquiry** command and confirm it returns valid results.
    ![Executing the Data Inquiry command](/img/legacy/etap/image17.jpg)
12. Close the **Execution Result** window after validating the command output.
    ![Execution Result window for Data Inquiry](/img/legacy/etap/image15.jpg)

### OpenLM SLM Configuration

Once the OpenLM Broker is set up, proceed to configure OpenLM through the EasyAdmin User Interface:

1. Navigate to EasyAdmin User Interface. Open the Start menu.
   ![Windows Start menu with EasyAdmin shortcut](/img/legacy/etap/image14.jpg)
2. Navigate to **Start -> Widgets -> License Manager Servers** to review broker servers awaiting approval.
   ![EasyAdmin widgets with License Manager Servers](/img/legacy/etap/image13.jpg)
3. Double-click the pending-approval banner to jump directly to servers that need approval (displayed as OpenLM Generic).
   ![Pending approval banner in EasyAdmin](/img/legacy/etap/image7.jpg)
4. Click **Edit** on the pending server to review its details before approving it.
   ![Edit button for the pending license server](/img/legacy/etap/image12.jpg)
5. Confirm the **Display name** so the server is easy to identify after approval.
   ![Display name field in license server details](/img/legacy/etap/image11.jpg)
6. Open **Custom fields** to fill in any required metadata for this server.
   ![Custom fields section in license server details](/img/legacy/etap/image6.jpg)
7. Use the **Custom Fields** to add relevant details, such as country, usage scope, or description.
   ![Custom fields populated with metadata](/img/legacy/etap/image8.jpg)
8. Click **APPROVE** to activate the broker-added license manager in Administration.
   ![Approve button for the pending license server](/img/legacy/etap/image2.jpg)
9. Verify the configuration details and click **Approve**.

The ETAP License Manager will now be added to the OpenLM SLM. After a brief period (up to 3 minutes), the system will parse the data and display its status with a green circle, indicating an active connection.

## Verifying the ETAP Configuration

To confirm that the ETAP License Manager is correctly configured:

1. Open EasyAdmin in your browser.
2. Navigate to **EasyAdmin Start -> Widgets -> License Servers**.
3. Verify that the configured license manager appears in the server list.

A green circle node indicates an active connection to the license server.

> Note: For new connections, it may take up to 3 minutes for the status indicator to change.

![License server list showing active green status indicator](/img/legacy/etap/image20.jpg)
