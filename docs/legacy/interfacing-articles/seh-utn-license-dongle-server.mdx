This integration allows OpenLM to monitor SEH-UTN license dongle servers for license usage and availability.

## Requirements

1. OpenLM Server installed on a central network server.
2. OpenLM Broker installed on a machine that can access both the OpenLM Server and the SEH Control Center web interface.

## SEH Control Center

The SEH Control Center is a web interface for configuring the SEH-UTN dongle server.

![Screenshot: SEH Control Center](/img/legacy/word-image-42287-1.jpeg)

In the Control Center, note:
- License dongle server IP address (for example, `192.168.0.140`) and server name.
- UTN port number (for example, `9200`).
- Device names in the **Attached devices** window.

Use these details when configuring OpenLM.

## OpenLM Broker configuration

:::note
Do not install OpenLM Broker on a workstation that consumes dongle licenses, as `utnm.exe` does not report host/user details on consuming machines.
:::

1. Install OpenLM Broker on a server or workstation with access to the SEH Control Center and the `utnm.exe` file.
2. In **OpenLM Broker Configuration**:
   - Select the license manager node.
   - Select **Add Port** if Auto-Detect fails.
   - Enter the UTN port number (for example, `9200`).
   - Set **License Manager Type** to **SEH-UTN**.
   - Select **Apply** → **OK**.
3. Go to the **Commands** node and set the path to `utnm.exe` on the SEH dongle host.
4. Ensure **status** and **data_inquiry** commands are configured.
   ![Screenshot: OpenLM Broker configuration](/img/legacy/word-image-42287-3.png)
5. In **Vendors**, enter the vendor name.
6. Select **Restart Broker**.
7. (Optional) Configure through the [Broker web UI](https://www.openlm.com/knowledge-base/openlm-broker-webui/).  
   ![Screenshot 2: OpenLM Broker configuration](/img/legacy/word-image-42287-4.png)

At this point, OpenLM should start collecting SEH licensing information.

## OpenLM Server configuration

### Manual configuration in EasyAdmin

1. In EasyAdmin, go to **Start → Administration → License Manager Servers**.
2. Select the **LM Servers** tab and select **Add**.
3. From **Type**, select **OpenLM_Generic**.
4. Enter a display name (for example, `My SEH server`).
5. Set the server's time zone.
6. Enter the hostname and port (for example, `my_seh_server`, `9200`).
7. **Is Triad Configuration**: off.
8. **Use Broker**: checked.
9. Select **Approve**.

![Screenshot: Manual configuration in EasyAdmin](/img/legacy/word-image-42287-5.png)

## How to verify configuration

1. In EasyAdmin, select the **Pending Approval** link and approve SEH-UTN.
2. Check that SEH-UTN appears in the list with a green status indicator.
