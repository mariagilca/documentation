This guide explains how to configure OpenLM to monitor a FlexNet Embedded license manager and collect usage statistics.

## How it works

OpenLM SLM queries the FlexNet Embedded server's XML API to retrieve license usage and statistics. The data is aggregated and displayed in EasyAdmin reports.  
For more details, see [What is FlexNet Embedded?](https://www.openlm.com/Knowledgebase%20and%20articles/what-is-flexnet-embedded/).

## OpenLM SLM configuration

1. In EasyAdmin, go to **Administration → License Manager servers**.
2. Select the **LM Servers** tab.
3. Select **+ Add LM**.
4. Fill in the fields:

   - **Type**: FlexNet Embedded  
   - **Description**: recognizable name (for example, *FlexNet Embedded server*)  
   - **Time zone**: match the license server's location  
   - **Hostname**: server hostname or IP  
   - **Port**: see the following instructions  
   - **Vendor name**: for example, *Avid*, *NVIDIA*

5. Select **Test** to verify.
6. Select **Apply**, then **Save**.

### Find the FlexNet Embedded port number

1. Open the web UI (for example, `http://win10:8888/FneServer/`).  
2. Select **Properties and status**.  
3. Locate **Listen port**.  

![Finding the FlexNet Embedded server's port](/img/legacy/finding-the-flexnet-embedded-servers-listening-po.png)  
*Locate the listening port in the web UI.*

### Nvidia customers

If the XML API cannot be queried remotely:

1. Edit `translator-config.properties` (for example, `C:\Program Files (x86)\NVIDIA\License Server\Tomcat\webapps\fne\WEB-INF\classes\translator-config.properties`).  
2. Change:  
   ```text
   RESTRICT_TO_LOCALHOST=false
   ```
3. Save and restart the FlexNet Embedded server.

## Verify configuration

1. Open EasyAdmin (`http://<OpenLM Server FQDN>:5015` or `https://cloud.openlm.com`).  
2. Go to **Start → Widgets → License Manager servers**.  
3. Confirm the FlexNet Embedded server appears with a **green** status.

## Known limitations

- License denials not monitored  
- No support for multiple server redundancy
