This guide explains how to monitor the Moldex3D License Manager with OpenLM to obtain license usage and statistics.

## Requirements

Install the following:

1. **OpenLM SLM v5.6 or higher**, or an OpenLM Platform account  
2. **OpenLM Broker v4.12 or higher** on the same machine as the Moldex3D License Manager  

## Monitoring capabilities

The following table shows the monitoring capabilities available through OpenLM Broker:

| Feature                  | Resolution | License totals | License usage | Denials | Borrowed licenses | Expiration dates | Redundancy |
|---------------------------|------------|----------------|---------------|---------|-------------------|------------------|-------------|
| **Supported**             | By second  | ✔              | ✔             | ✔       | ✔                 | ✔                | ❌          |

Using Broker also allows:

- Buffered communication with OpenLM SLM  
- Remote start/stop of the license manager service  

## OpenLM Broker configuration

![Diagram: OpenLM interfacing with Moldex3D License Manager](/img/legacy/openlm-interfacing-with-moldex3d-license-manager-d.png)

Broker queries Moldex3D License Manager locally using the `MDX3DLMUtil` utility. Data is then sent to OpenLM SLM for processing.  

:::note
Ensure Broker is [installed](../openlm-broker) and [configured](../openlm-broker/openlm-broker-configuration) to report to OpenLM SLM before proceeding.
:::

### Automatic Broker configuration

1. In Broker, select **Detect**.  
   ![Broker auto-detect for Moldex3D](/img/legacy/openlm-broker-auto-detect-for-moldex3d-lm.png)  
2. If the Moldex3D service (for example, *Moldex3D-LM Service*) is running, Broker detects and configures it automatically.  
3. After configuration, select **Restart Broker**.  
4. Also run **data_inquiry → Execute** to confirm valid output.  

### Manual Broker configuration

If autodetect fails:

1. Select **Add Port**.  
2. Enter the Moldex3D port (default: 2556).  
3. From **Type**, select **Moldex3D**. Select **Apply**.  
4. In **Commands**, browse to the folder containing `MDX3DLMUtil.exe` (for example: `C:\Moldex3D\LMSR\Tools\MDX3DLMUtil`). Select **Update → Apply**.  
5. Under **data_inquiry**, select **Execute**. Confirm valid output (no errors).  
6. Select **Restart Broker**.  

![Manual Broker configuration for Moldex3D](/img/legacy/openlm-broker-configuration-for-moldex3d-license-m.png)

### Broker web UI configuration

1. Install the latest Broker.  
2. Open **http://localhost:5090/**.  
3. Go to **License Managers**.  
   - If the Moldex3D service is running, select **Detect**.  
   - If autodetect fails, select **Add License Manager**. From **Type**, select **Moldex3D**. Enter the port and select **Add**.  
   ![Add Moldex3D LM in Broker Web UI](/img/legacy/Screenshot-2023-03-17-at-11.57.23-1.png)  
4. In **Commands**, set the path to `MDX3DLMUtil.exe`. Select **Execute** to confirm.  
5. In **Vendors**, select **Add Vendor**, enter `Moldex3D`, and select **Continue**.  
   ![Vendors tab in Broker UI](/img/legacy/Screenshot-2023-03-17-at-12.10.24.png)  
6. Select **Save**.

## OpenLM SLM configuration

### Automatic through EasyAdmin

If Broker is configured correctly, it will send data to Server. Approve the new server in EasyAdmin:

1. Open **EasyAdmin** (`http://<OpenLM Server>:5015` or through Windows Start → OpenLM → EasyAdmin).  
2. In **License Manager Servers**, select **There are # servers pending approval**.  
   ![Pending approval in EasyAdmin](/img/legacy/word-image-42310-4.png)  
3. Edit the pending LM entry (double-click or use the pencil icon).  
   ![Edit pending LM](/img/legacy/word-image-42310-5.png)  
4. Update the **Display name** if desired.  
5. Select **Approve**.  
   ![Approve Moldex3D in EasyAdmin](/img/legacy/word-image-42310-6.png)  
6. The Moldex3D License Manager is now added.  
   ![Approved Moldex3D LM in EasyAdmin](/img/legacy/word-image-42310-7.png)

### Manual configuration

If automatic approval fails:

1. In EasyAdmin, go to **Start → Administration → License Manager Servers**.  
2. Select **Add LM**.  
3. From **Type**, select **Moldex3D**.  
4. Enter a **Description** (for example, `Moldex3D License Manager`).  
5. Set the correct **Time Zone**.  
6. Enter the **Hostname** and **Port** (must match Broker configuration).  
7. Leave **Is Triad Configuration** unchecked.  
8. Check **Use Broker**.  
9. Select **Save**.  

![Manual server configuration for Moldex3D](/img/legacy/word-image-42310-8.png)

## Verify the configuration

1. Open **EasyAdmin** at `http://<OpenLM Server hostname>:5015`.  
2. Go to **Start → Widgets → License Manager Servers**.  
3. Verify Moldex3D appears in the list.  
4. A **green Up to date** icon indicates an active connection.  

![Verify Moldex3D in EasyAdmin](/img/legacy/word-image-42310-9.png)

:::note
It may take up to **3 minutes** for the status indicator to update after a new connection is added.
:::
