## Scope

OpenLM supports monitoring a wide and growing variety of license managers.  
This document explains how to configure OpenLM to monitor the **Solidworks EPDM database** and track license usage and reporting.

## Configure OpenLM SLM for EPDM

1. Ensure you have a single OpenLM SLMon a central network server.  
2. From the Windows **Start** menu, go to **OpenLM → OpenLM SLM**.  
3. Select the **LM Tools** tab → **EPDM**.  
4. Enter the EPDM connection string fields:  
   - **Server Name** → EPDM server hostname or IP  
   - **Database Name** → EPDM database name  
   - **SQL Username** → database username  
   - **Password** → password for the username  
5. Select **Test** to validate the connection.  
6. Go to **License Servers → Add** and configure:  
   - **Type** → **EPDM**  
   - **Description** → descriptive server name  
   - **Time Zone** → license server time zone  
   - **Hostname** and **Port** → any text (not significant for EPDM)  
   - **Is Triad Configuration** → select if applicable  
   - Clear the checkboxes for **Use Broker** and **Use License File**  
7. Select **Apply**.  
8. For added functionality, consider:  
   - Installing the OpenLM Workstation Agent  
   - Evaluating Features 
9. Review results in OpenLM Reports.
