This topic explains how to monitor the Office 365 Cloud license manager with OpenLM, including setup for environments behind a proxy server.

## Requirements

To query the Office 365 Cloud license manager, you need:

- OpenLM SLM v22.2 or later installed on a machine in your organization.
- Workstation Agent and Applications Manager for usage data.
- Azure account with one of these roles:
  - Global administrator
  - Privileged role administrator
  - Cloud application administrator
  - Application administrator  
  *(Or a custom directory role with permission to grant permissions to applications.)*
- Two-factor authentication turned off.

## Permissions required by OpenLM

- **Read all users' basic profiles** – Reads display name, first and last name, email, and photo.
- **Read all users' full profiles** – Reads user profiles without a signed-in user.
- **Read all usage reports** – Reads usage reports for Office 365 and Azure Active Directory without a signed-in user.
- **Read directory data** – Reads directory data such as users, groups, and apps without a signed-in user.

## Configure OpenLM for Office 365 Cloud

Connect OpenLM SLM to the Office 365 Cloud admin portal to get license allocation information. License usage is gathered by Workstation Agent through the Applications Manager.

### Steps

1. In **EasyAdmin**, go to **Start → Administration → License Manager Servers → Add LM**.
2. Enter a descriptive **Display name**.
3. From the **License manager type** list, select **Office365Cloud**. The LM address is populated automatically.
4. Select **Set access permission**.  
   You are redirected to the Microsoft Azure portal to grant permissions. Review the permissions and select **Accept**.
5. In the [Microsoft 365 Admin portal – Domains](https://portal.office.com/adminportal#/Domains), find the domain ending in `.onmicrosoft.com` (for example, `openlmsoftware.onmicrosoft.com`) and copy it.
6. In EasyAdmin, paste the copied domain into the **Tenant/Domain** field.
7. Select **Save**.
8. Open the OpenLM User interface to view the new license server and its data.

## Behind a proxy

If OpenLM SLM connects to Office 365 Cloud through a proxy, update the `appsettings.json` file.

### Proxy with username and password


```json
"Proxy": {
  "UseProxy": true,
  "ProxyUrl": "http://10.0.0.140:3128",
  "ByPassProxyOnLocal": false,
  "UseCredentials": true,
  "UseDefaultCredentials": false,
  "UseDefaultWebProxy": false,
  "UserName": "openlm",
  "Password": "b3Blbmxt" // Base64-encoded password
}

```
### Proxy without username and password


```json
"Proxy": {
  "UseProxy": true,
  "ProxyUrl": "http://10.0.0.140:3128",
  "ByPassProxyOnLocal": false,
  "UseCredentials": true,
  "UseDefaultCredentials": false,
  "UseDefaultWebProxy": false,
  "UserName": "",
  "Password": ""
}
```
### Proxy that does not require credentials


```json
"Proxy": {
  "UseProxy": true,
  "ProxyUrl": "http://10.0.0.140:3128",
  "ByPassProxyOnLocal": false,
  "UseCredentials": false,
  "UseDefaultCredentials": false,
  "UseDefaultWebProxy": false,
  "UserName": "openlm",
  "Password": "password"
}
```

### Deactivate proxy


```json
"Proxy": {
  "UseProxy": false,
  "ProxyUrl": "http://10.0.0.140:3128",
  "ByPassProxyOnLocal": false,
  "UseCredentials": true,
  "UseDefaultCredentials": false,
  "UseDefaultWebProxy": false,
  "UserName": "openlm",
  "Password": "password"
}
```


## Add the Office 365 license manager server

To add the Office 365 license manager in the **License Manager Servers** tab in the OpenLM EasyAdmin user interface:

1. Select **Start → Administration → License Manager Servers**.  
   ![Opening License Manager Servers from the Start menu in OpenLM EasyAdmin.](/img/legacy/word-image-30-1.png)
2. Select **LM Servers**, and select **Add LM**.  
   ![Selecting Add LM on the LM Servers tab in EasyAdmin.](/img/legacy/word-image-31-1.png)
3. In **Display name**, enter a unique name to identify the license manager server.
4. In **LM address**, enter the Office 365 license manager URL or address.
5. In **Username**, enter the username.
6. In **Password**, enter the password.
7. In **Timezone**, select the time zone of the license manager server.
8. Toggle **Enabled** to turn license server monitoring on or off.
9. Select **Save**.

(Optional) To configure access permissions, select **Set access permission**.  
![Set access permission option for the Office 365 license manager server in EasyAdmin.](/img/legacy/word-image-32-1.png)

## Verify the Office 365 configuration

To verify that the configured Office 365 license manager server appears in the list and is active:

1. In EasyAdmin, go to **Start → Widgets → License Manager - Servers**.  
   ![Opening the License Manager - Servers widget in EasyAdmin.](/img/legacy/word-image-33-1.png)
2. Confirm the Office 365 license manager server appears in the list with a green checkmark.  
   ![Office 365 license manager server listed with a green checkmark in EasyAdmin.](/img/legacy/word-image-34-1.png)
3. If the server does not appear, select the **Refresh** icon. The added license manager server should now display.  
   ![Refreshing the license manager server list in EasyAdmin.](/img/legacy/word-image-35-1.png)

> It can take up to 3 minutes for a new connection to display as active.
