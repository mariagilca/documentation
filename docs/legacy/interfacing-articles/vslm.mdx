Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Kisters VSLM License Manager.

## Requirements

Before starting, install:

1. OpenLM SLM v2.x on a machine in your organization or have an SLMC account  
2. OpenLM Broker v24.8 or higher on the same machine as the Kisters VSLM License Manager

## Monitoring capabilities

| LM Type in the Broker | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- |
| VSLM | No | No | No | Yes | Yes | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with VSLM](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit-1.png)  
*Diagram of how OpenLM interfaces with the VSLM License Manager*

:::note
OpenLM Broker must be installed and configured to report to OpenLM before proceeding.
:::

### Steps

1. Open the Broker web UI at `http://localhost:5090`.  
   If the default port is in use, try `5091` or `5092`.  
   You can also select **Detect** to automatically detect the license manager.
2. Go to **License Managers** → **Add License Manager**.
3. Select **VSLM** from the drop-down list, enter the port number (for example, `888`), and select **Add**.

   ![Screenshot: Steps](/img/legacy/word-image-90713-2.png)

4. In **Commands**, confirm settings or adjust as needed.

   ![Screenshot 2: Steps](/img/legacy/word-image-90713-3.png)

5. In **Vendors**, select **Add Vendor**, enter `VSLM`, and select **Continue**.

   ![Screenshot 3: Steps](/img/legacy/word-image-90713-4.png)

6. In **Log Files**, select **Add Log File**, browse to the VSLM log location, and ensure **Watch file by pattern** is off.

   ![Screenshot 4: Steps](/img/legacy/word-image-90713-5.png)

7. Select **Save**.

## OpenLM Server configuration

Once the Broker is configured, approve the license manager in EasyAdmin:

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Select the **There are Servers Pending Approval** icon.
4. Double-click the pending license manager (displayed as **OpenLM Generic**), verify details, and select **Approve**.

   ![Screenshot: OpenLM Server configuration](/img/legacy/word-image-90713-6.png)

After approval, the VSLM License Manager will be monitored. A green circle icon indicates an active connection.

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Servers**.
3. Ensure the VSLM entry appears in the list with a green circle status.

:::note
For new connections, it may take up to 3 minutes for the status to update.
:::
