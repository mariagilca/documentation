Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from CADENAS Server.

## Requirements

Before you query the license manager, install:

1. OpenLM SLM v2.x on your premises (or an SLMC account)
2. OpenLM Broker v25.5 or higher on the same machine as the CADENAS Server LicenseMonitor

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Cadenas | No | Yes | Yes | No | No | No | No | Seconds |

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the CADENAS Server License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit.png)  
*Diagram of how OpenLM interfaces with the CADENAS Server License Manager*

:::note
OpenLM Broker must be installed and configured to report to OpenLM before proceeding.
:::

1. Open the Broker web UI.
2. Go to **License Managers** → **Add License Manager**.
3. From the **LM Type** drop-down list, select **CADENAS Server**.
4. Enter the CADENAS Server port number (for example, `2004`) and click **Add**.

   ![Screenshot: OpenLM Broker configuration](/img/legacy/word-image-98685-2.png)  
   *Adding a CADENAS Server license manager in OpenLM Broker*

5. Go to the **Vendors** tab. Click **Add Vendor**, enter `CADENAS Server`, and click **Continue**.

   ![Screenshot 2: OpenLM Broker configuration](/img/legacy/word-image-98685-3.png)  
   *Adding CADENAS Server vendor in OpenLM Broker*

6. Go to the **Log Files** tab. Click **Add Log File**.  
   Turn off **Watch file by pattern**. Add the log path, then click **Continue**.

   ![Screenshot 3: OpenLM Broker configuration](/img/legacy/word-image-98685-4.png)  
   *Adding a log file for CADENAS Server in OpenLM Broker*

7. Click **Save**.

## OpenLM configuration

If the preceding steps are complete, Broker should be transmitting data to OpenLM SLM.  
Approve the configuration in the EasyAdmin UI:

1. Go to **Start → Widgets → License Manager Servers**.
2. Click **Servers Pending Approval**.

   ![Screenshot: OpenLM configuration](/img/legacy/word-image-98685-5.png)  
   *Pending license managers in EasyAdmin*

3. Double-click the pending license manager. It will display as **OpenLM Generic**.

   ![Screenshot 2: OpenLM configuration](/img/legacy/word-image-98685-6.png)  
   *Pending CADENAS Server license manager in EasyAdmin*

4. (Optional) Modify the display name. Verify the configuration, then click **Approve**.

   ![Screenshot 3: OpenLM configuration](/img/legacy/word-image-98685-7.png)  
   *Approving a CADENAS Server license manager in EasyAdmin*

5. (Optional) Add details such as country, usage scope, and description in **Custom Fields**.

   ![Screenshot 4: OpenLM configuration](/img/legacy/word-image-98685-8.png)  
   *Custom fields in EasyAdmin*

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Confirm that the CADENAS Server license manager appears in the list with a green circle icon.

:::note
It may take up to 3 minutes for the status to update after a new connection.
:::
