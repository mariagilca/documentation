OpenLM can connect to ArcGIS Online to retrieve license quantities and usage data.  
> **Note:** ArcGIS Online accounts with two-factor authentication (2FA) cannot be monitored. Deactivate 2FA before proceeding.

## Adding ArcGIS Online to OpenLM

1. In **EasyAdmin**, go to **Start → Administration → License Manager Servers**.  
2. Select **Add LM**.  
   ![Selecting Add LM on the License Manager Servers page in EasyAdmin.](/img/legacy/adding-a-new-lm-1.png)  
3. Enter a descriptive **Display Name**.  
4. In **Type**, select **ArcGIS Online**.  
5. In **LM Address**, enter:  
   ```text
   https://www.arcgis.com
   ```
   6. Enter your ArcGIS Online **admin username** and **password**.  
7. Select the license manager's **time zone**.  
8. Select **Test Connection**. A successful connection will look like:  
![Successful ArcGIS Online connection test result in EasyAdmin.](/img/legacy/test-results-2.png)  
9. Select **Save**.  

Within a few minutes, license usage and allocation data will appear in OpenLM reports.  

![ArcGIS Online license usage and allocation data shown in OpenLM reports.](/img/legacy/test-results-3.png)
