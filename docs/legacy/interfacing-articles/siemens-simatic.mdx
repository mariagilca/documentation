This document describes how to interface OpenLM with Siemens SIMATIC to monitor license usage and obtain statistics.

## Requirements

To query Siemens SIMATIC, install:

1. OpenLM Server v2.x on a machine in your organization.
2. OpenLM Broker v22.5 or higher on the same machine as Siemens SIMATIC.

## Monitoring capabilities and features

Current monitoring capabilities through OpenLM Broker:

| Feature | Resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Support | By minute | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with Siemens SIMATIC License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit-1.png)
*Diagram of OpenLM interface with Siemens SIMATIC*

Broker reads the Siemens SIMATIC log file. Once read, data is compiled and sent to OpenLM Server.

OpenLM Broker must be [installed](https://www.openlm.com/application-notes-v3-0/installing-openlm-v3-0/broker-comprehensive-installation-guide-an4004b/) and [configured](https://www.openlm.com/Knowledgebase%20and%20articles/openlm-broker-configuration/) to report to OpenLM Server before continuing:

1. Select **Add Port**.
2. Since Broker reads only the log file, enter any port number (for example, 888).
3. Select **Siemens SIMATIC** from the **License Manager Type** list. Select **Apply**.
4. Select **Vendor Name to Be Filled** under **Vendors**. Enter `Siemens SIMATIC` in **Vendor Name**. Select **Apply**.
5. Select **Log Files**, then select **Add Log File**.
6. Select the new **log** node. Select **[…]** and browse to the path of the Siemens SIMATIC License Manager `.log` file.
7. Select **Apply**.
8. Select **Restart Broker**.

### Alternative: Configuration through Broker web UI

1. Open a browser and go to [http://localhost:5090/](http://localhost:5090/).
2. Select **License Managers**, then **Add License Manager**.

   ![Add license manager in Broker Web UI](/img/legacy/word-image-41986-2.png)

3. In the pop-up, select the license manager type, enter any port number (for example, 888), then select **Add**.

   ![License manager type selection](/img/legacy/word-image-41986-3.png)

4. Go to **Vendors**. Select **Add Vendor**, enter the name, then select **Confirm**.

   ![Add vendor in Broker Web UI](/img/legacy/word-image-41986-4.png)

5. Go to **Log Files**.

   ![Log files tab in Broker Web UI](/img/legacy/word-image-41986-5.png)

6. Select **Add Log File**, then either enter the path manually or browse for it using the magnifying glass icon.
7. Select the log file, then select **Open**.
8. From the drop-down, select vendor `Siemens SIMATIC`.
9. Select **Continue**.

   ![File explorer pop-up window](/img/legacy/word-image-41986-6.png)

10. Select **Save**.

    ![Save log file path in Broker Web UI](/img/legacy/word-image-41986-7.png)

## OpenLM Server configuration

### Automatic configuration through EasyAdmin

If you followed the steps above, OpenLM Broker should now send data to OpenLM Server. Approve the configuration in EasyAdmin:

1. Open EasyAdmin (**Windows Start → OpenLM → OpenLM EasyAdmin User Interface**).
2. In **License Servers**, find the row for the new Siemens SIMATIC License Manager server (unapproved rows are highlighted red) and double-click it.

   ![Pending Siemens SIMATIC license manager in EasyAdmin](/img/legacy/word-image-41986-8.png)

3. Give the connection a descriptive name or keep the default. Keep **Type** as **OpenLM Generic**. Select **Approve**.

   ![Approve Siemens SIMATIC license manager in EasyAdmin](/img/legacy/word-image-41986-9.png)

Once added, data appears after parsing. A green circle confirms status.

![Green circle indicates active monitoring](/img/legacy/word-image-41986-10.png)

### Manual configuration

If automatic configuration fails, manually connect OpenLM Server to the OpenLM Broker on the Siemens SIMATIC License Manager machine.

The hostname and port must match the Broker configuration.

1. Go to **Start → Administration → License Manager Servers**.
2. Select **Add LM**.
3. Select **OpenLM Generic** from **Type**.
4. Enter a description (for example, `Siemens SIMATIC`).
5. Set **Time Zone** to the license server location.
6. Enter **Hostname** and **Port**.
7. Clear **Is Triad Configuration**.
8. Select **Use Broker**.
9. Select **Save**.

![Manual Siemens SIMATIC license manager configuration](/img/legacy/word-image-41986-11.png)

## How to verify configuration

1. Open EasyAdmin in a browser.
2. Go to **Start → Widgets → License Servers**.
3. Verify Siemens SIMATIC appears in the list. A green circle indicates an active connection.

![Siemens SIMATIC with active connection](/img/legacy/word-image-41986-12.png)

If new, the status indicator may take up to three minutes to update.
