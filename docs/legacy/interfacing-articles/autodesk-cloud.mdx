:::

For monitoring Autodesk Cloud, OpenLM connects directly to the Autodesk Cloud admin portal.  

There are two ways to gather license usage:

- **With Workstation Agent or AutoCAD Plugin**: These communicate with OpenLM Applications Manager, which transmits usage data to OpenLM Server. This method provides detailed *usage data*.  
- **Without Applications Manager**: Only license *quantity data* is gathered. To capture usage details, see the [Applications Manager documentation](../openlm-applications-manager/configure-applications-manager-to-track-actual-usage.md).  

## Configure Autodesk Cloud in OpenLM

1. Open **EasyAdmin**.  
2. Go to **Start → Administration → License Manager Servers → Add LM**.  
   ![Monitoring the Autodesk Cloud license manager with OpenLM](/img/legacy/word-image-42313-1.png)  
   *Adding Autodesk Cloud license manager in EasyAdmin*  
3. Enter a descriptive name in **Display name**.  
4. From the **Type** drop-down, select **Autodesk Cloud**. The LM address is filled automatically.  
5. Enter **Autodesk Cloud Account admin credentials** (username and password).  
6. Select the **time zone** of the license manager server.  
7. Click **TEST Connection**. A successful test looks like this:  
   ![Test connection to Autodesk Cloud](/img/legacy/word-image-42313-2.png)  
   *Successful Autodesk Cloud connection test*  
8. Click **SAVE**.  
9. Within minutes, usage and/or allocation data from Autodesk Cloud will appear in reports.
