OpenLM can monitor Flexera FlexNet (TokenFlex) for license usage and token consumption.

## Requirements

1. One OpenLM SLM installation on a central network server.
2. (Recommended) OpenLM Broker installed on the FlexNet server for enhanced capabilities such as file monitoring, data buffering, and remote control.
3. OpenLM Workstation Agent installed on client machines to monitor token usage.

## Broker configuration

:::note
Install and connect OpenLM Broker to OpenLM SLM before starting this configuration.
:::

1. Open **OpenLM Broker Configuration**.
2. Select **OpenLM SLM instances** → **Add** → select **localhost**.
3. Set **OpenLM SLM hostname**.
4. Select **Check connectivity to OpenLM SLM** → **Apply**.
5. Select **Detect** to find FlexLM license servers.
6. Select the license server hostname tab.
7. If the port is not listed, select **Add Port**.
8. Under **License Servers**, configure:
   - **License Manager Type**: FlexLM
   - **License file path**: vendor license file path (if available)
   - If no license file is listed, select **Set Path Manually** → **Add** → select the file.
   - Check **Watch License File**.
9. Select **Apply**.
10. In **Commands**, set the path to the vendor's `lmutil.exe`, select **Update**, then **Apply**.
11. In **Vendors**:
    - Select **Add Vendor** if none exists.
    - Set **Name** exactly as provided by the vendor (for example, `adskflex`, `ptc_d`, `MLM`, `ugslmd`).
    - **Option File Description**: descriptive name for the options file.
    - **Option File Path**: path to the options file.
    - Check **Watch Options File**.
12. In **Log Files**:
    - Select **Add Log** if none exists.
    - Set:
      - **Type**: log file type
      - **Name**: descriptive name
      - **Path**: vendor debug log file path
      - **Vendor**: vendor name
13. Select **Apply**.
14. Select **Restart Broker** → **OK** → close the tool.
15. In EasyAdmin, go to **Widgets → License Servers** and select **Approve** on the red-line entry.
16. In **OpenLM SLM Configuration**, enable **Token Support** for the license server.
17. Select **Apply**.

## Direct server configuration (without Broker)

1. Open **OpenLM SLM Configuration** (**Windows Start → OpenLM → OpenLM SLM**).
2. Go to **LM Tools** → **FlexLM**.
3. Copy `lmutil.exe` from the license server to:  
   `C:\Program Files\OpenLM\OpenLM Server\LM\`
4. In **LM Tools**, type the full path to `lmutil.exe`.
5. Go to **License Servers** → **Add** and configure:
   - **Type**: FlexLM
   - **Description**: server name
   - **Time Zone**: license server time zone
   - **Hostname** and **Port**: server details
   - **Is Triad Configuration**: check if applicable
   - **Use Broker**: unchecked
   - **Read license file**: unchecked
   - **Enable Token Support**: checked
6. Select **Apply**.

## Verifying configuration

1. Open EasyAdmin.
2. Go to **Widgets → License Servers**.
3. Confirm the FlexNet (TokenFlex) server appears with a green status.

:::note
It may take up to 3 minutes for the license manager to appear as active in EasyAdmin.
:::
