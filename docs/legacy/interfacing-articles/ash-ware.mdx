Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from ASH WARE.

## Requirements

Before you query the license manager, install:

1. OpenLM SLM on your premises (or an OpenLM Cloud account)
2. OpenLM Broker v25.5 or higher on the same machine as the ASH WARE license manager

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ASH WARE | Yes | No | Yes | Yes | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Diagram of OpenLM Broker connection to ASH WARE license manager](/img/legacy/word-image-97945-1.png)  
*OpenLM Broker configured to connect to the ASH WARE license manager*

:::note
OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.
:::

1. Open the Broker web UI at `http://localhost:5090`.  
   If you want to access it from another machine on the same network, generate a token by visiting:  
   `http://localhost:5090/api/new-token`
2. Go to **License Managers** → **Add License Manager**.
3. From the **LM Type** drop-down list, select **ASH WARE**.
4. Enter the port number (default: `6333`) and click **Add**.

   ![Screenshot: OpenLM Broker configuration](/img/legacy/word-image-97945-2.png)  
   *Setting executable path for ASH WARE in OpenLM Broker*

5. In the **Executable Path** field, browse to the installation directory of the ASH WARE `.exe` file.
6. Click **Save**.
7. To verify the configuration, click **Execute** in the **Commands** tab.

   ![Screenshot 2: OpenLM Broker configuration](/img/legacy/word-image-97945-3.png)  
   *Example of a successful execution result*

8. Go to the **Vendors** tab. Click **Add Vendor**, enter `ASH WARE`, and click **Continue**.

   ![Screenshot 3: OpenLM Broker configuration](/img/legacy/word-image-97945-4.png)  
   *Adding ASH WARE vendor in OpenLM Broker*

9. Click **Save**.

## OpenLM configuration

If the preceding steps are complete, Broker should be transmitting data to OpenLM SLM.  
Approve the configuration in the EasyAdmin UI:

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Click the **Servers Pending Approval** link.

   ![Screenshot: OpenLM configuration](/img/legacy/word-image-97945-5.png)  
   *Pending license managers in EasyAdmin*

4. Click the edit icon for the ASH WARE entry.  
   In the **Display Name** field, enter a preferred name (for example, `ASH WARE`).

   ![Screenshot 2: OpenLM configuration](/img/legacy/word-image-97945-6.png)  
   *Editing display name for ASH WARE license manager*

5. (Optional) Go to the **Custom Fields** tab to add details such as country, usage scope, and description.

   ![Screenshot 3: OpenLM configuration](/img/legacy/word-image-97945-7.png)  
   *Adding custom fields for ASH WARE license manager*

6. Click **Approve**.

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Confirm that the ASH WARE license manager appears in the list with a green circle icon.

:::note
It may take up to 3 minutes for the status to update after a new connection.
:::
