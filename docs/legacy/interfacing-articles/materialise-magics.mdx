Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Materialise Magics.

## Requirements

Before you query the license manager, install:

1. OpenLM SLM on your premises (or an OpenLM Platform account)
2. OpenLM Broker v25.4 or higher on the same machine as the Materialise Magics license manager

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Materialise Magics | Yes | No | Yes | Yes | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Diagram of OpenLM Broker connection to Materialise Magics license manager](/img/legacy/word-image-97860-1.png)  
*OpenLM Broker configured to connect to the Materialise Magics license manager*

:::note
OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.
:::

1. Open the Broker web UI at `http://localhost:5090`.  
   If you want to access it from another machine on the same network, generate a token by visiting:  
   `http://localhost:5090/api/new-token`
2. Go to **License Managers** → **Add License Manager**.
3. From the **LM Type** drop-down list, select **Materialise Magics**.
4. Enter the port number (default: `7010`) and select **Add**.
5. In the **Executable Path** field, browse to the installation directory of the Materialise Magics `.exe` file.

   ![Setting the executable path for Materialise Magics in OpenLM Broker.](/img/legacy/word-image-97860-2.png)  
   *Setting executable path for Materialise Magics in OpenLM Broker*

6. Select **Save**.
7. To verify the configuration, go to the **Commands** tab and select **Execute**.

   ![Verifying the Materialise Magics license manager connection in OpenLM Broker.](/img/legacy/word-image-97860-3.png)  
   *Verifying Materialise Magics license manager connection*

8. If successful, the output will resemble the following example:

   ![Successful Materialise Magics connection output in OpenLM Broker.](/img/legacy/word-image-97860-4.png)  
   *Successful connection output*

9. Go to the **Vendors** tab. Select **Add Vendor**, enter `Materialise`, and select **Continue**.

   ![Adding the Materialise vendor in OpenLM Broker.](/img/legacy/word-image-97860-5.png)  
   *Adding Materialise vendor in OpenLM Broker*

10. Select **Save**.

## OpenLM configuration

If the preceding steps are complete, Broker should be transmitting data to OpenLM SLM.  
Approve the configuration in the EasyAdmin UI:

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Select the **Servers Pending Approval** link.

   ![Pending license managers in EasyAdmin.](/img/legacy/word-image-97860-6.png)  
   *Pending license managers in EasyAdmin*

4. Select the edit icon for the Materialise Magics entry.  
   In the **Display Name** field, enter a preferred name (for example, `Materialise Magics`).

   ![Editing the display name for the Materialise Magics license manager in EasyAdmin.](/img/legacy/word-image-97860-7.png)  
   *Editing display name for Materialise Magics license manager*

5. (Optional) Go to the **Custom Fields** tab to add details such as country, usage scope, and description.

   ![Adding custom fields for the Materialise Magics license manager in EasyAdmin.](/img/legacy/word-image-97860-8.png)  
   *Adding custom fields for Materialise Magics license manager*

6. Select **Save**.

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Confirm that the Materialise Magics license manager appears in the list with a green circle icon.

   ![Green circle indicating an active Materialise Magics connection in EasyAdmin.](/img/legacy/word-image-97860-9.png)  
   *Green circle indicating an active connection in EasyAdmin*

:::note
It may take up to 3 minutes for the status to update after a new connection.
:::
