# INTES PERMAS

This integration allows OpenLM to monitor INTES PERMAS for license usage and availability.

## Requirements

1. OpenLM Broker installed on the INTES PERMAS host machine.
2. A single OpenLM Server installation on a central network server.

## Monitoring capabilities and features

| Feature | Resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Support | By minute/second | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker configuration

OpenLM Broker communicates with INTES PERMAS to collect license data and send it to OpenLM Server.

:::note
You must have OpenLM Broker installed and reporting to OpenLM Server before starting this configuration.
:::

### Manual configuration

1. Open the **OpenLM Broker Configuration** tool.
2. Select the **OpenLM Servers** directory icon → **Add** → select **localhost**.
3. Configure the **OpenLM Server hostname**.
4. Click **Check connectivity to OpenLM Server** → click **Apply**.
5. Select the license server hostname tab.
6. Click **Add port** if the port is not already listed.
7. Select the vendor **port** under the **License Servers** directory icon.
8. Set **License Manager Type** to **INTES**.
9. In the **Commands** tab → **status** tab, enter the path to `INTES_OpenLM.exe`, for example:  
   `C:\Program Files (x86)\AMPORTAK\INTES_OpenLM.exe`
10. In the **Commands** tab → **data_inquiry** tab, enter the path to `AMP_OpenLM.exe`, for example:  
    `C:\Program Files (x86)\AMP\AMP_OpenLM.exe`
11. Click **Apply**.
12. In the **Vendors** tab, click **Add Vendor** if none exists.
13. Select the vendor and set **Name** to **INTES PERMAS**.
14. Click **Apply**.
15. Click **Restart Broker** → click **OK** → close the tool.

## OpenLM Server configuration

### Automatic configuration through EasyAdmin

1. On the OpenLM Server host, open **EasyAdmin** (**Windows Start → OpenLM → OpenLM EasyAdmin User Interface**).
2. Go to **Widgets → License Servers**.
3. Click **Approve** on the red-line entry for the license manager you configured.
4. Restart the **OpenLM Server** service in **Windows Services**.

### Manual configuration

If automatic detection fails, manually add the license server in EasyAdmin with the correct hostname and port.

## How to verify configuration

1. Open EasyAdmin.
2. Go to **Widgets → License Servers**.
3. Confirm that INTES PERMAS appears with a green status indicator.

:::note
It may take up to 3 minutes for the license manager to appear as active in OpenLM after configuration.
:::
