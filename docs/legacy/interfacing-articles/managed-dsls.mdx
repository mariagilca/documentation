Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the Managed DSLS license manager.

## Requirements

Before starting, make sure you have:

- OpenLM Server v2.x installed on a machine in your organization or an OpenLM Cloud (SLMC) account  
- OpenLM Broker v22.6 or higher installed on a machine with access to the `dslsstat` utility

## Monitoring capabilities

Monitoring capabilities depend on the query method:

1. **Querying remotely** through OpenLM Server:
   - License totals
   - License usage
2. **Querying locally** through OpenLM Broker:
   - All of the preceding, plus:
     - Buffered communication to overcome temporary network failures
     - Ability to start/stop the license manager service remotely
     - License denial reporting
     - 1-minute resolution for license usage reports
     - Reading Managed DSLS license and log files
     - Viewing license file content in EasyAdmin

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the Managed DSLS license manager](/img/legacy/external-bb4a7f98a1ea390c.png)  
*Diagram of how OpenLM interfaces with the Managed DSLS license manager*

:::note
Install and configure OpenLM Broker on the same machine as Managed DSLS before proceeding.
:::

### Automatic configuration

1. Access the Broker web UI on the Managed DSLS machine.  
2. Go to **License Managers** and select **Detect**.  
   ![Screenshot: Automatic configuration](/img/legacy/external-ae0e44f03cab0f35.png)  

If the service is running, Broker will auto-configure all required settings.  
For accuracy, review the following **Manual configuration** section.

### Manual configuration

1. Open Broker and go to **License Managers → Add License Manager**.  
2. From **LM Type**, select **DSLS Cloud**, enter the port number, and select **Add**.  
3. Go to the **Commands** tab and set the executable path to the Managed DSLS utility.  
4. If running as a service, turn **Use operating system start/stop commands file** on and set the service name.  
5. Turn **Data Inquiry** on and select **Execute** to test the connection.  
6. Go to the **Vendors** tab → **Add Vendor**, enter the vendor name, and select **Continue**.  
7. Go to the **Log Files** tab → **Add Log File**, select the latest Managed DSLS log file, select the vendor, and select **Continue**.  
8. Select **Save**.

## OpenLM Server configuration

### Automatic configuration through EasyAdmin

1. Open EasyAdmin in your browser or from **Windows Start → OpenLM → EasyAdmin User Interface**.  
2. In **License Servers**, select the "servers pending approval" message.  
3. Select the Managed DSLS entry and select **Approve**.

## Verify your configuration

1. Open EasyAdmin.  
2. Go to **Start → Widgets → License Servers**.  
3. Confirm the Managed DSLS license manager appears in the list with a green status circle.

:::note
A new connection may take up to 3 minutes to display an active status.
:::
