OpenLM monitors OGI Systems license servers through OpenLM Broker. Detailed configuration steps are being prepared and will be published in an upcoming documentation release.

## Before you begin

- OpenLM Server v25.x or later.
- OpenLM Broker, installed on the same machine as the OGI Systems license server.

:::note[Documentation in progress]
If you need to configure OGI Systems today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. OpenLM Support shares the current procedure while the guide is finalized.
:::
