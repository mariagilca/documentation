:::info
ESPRIT is one of the license managers supported by OpenLM. This guide explains how to configure OpenLM to monitor the DPTC ESPRIT License Manager and track license usage and statistics.
:::

![How OpenLM interfaces with ESPRIT License Manager](/img/legacy/how-openlm-interfaces-with-the-esprit-license-mana.png)
*Diagram of how OpenLM Broker interfaces with ESPRIT License Manager and OpenLM SLM*

## Requirements

- OpenLM Broker v4.10 or later installed and configured on the ESPRIT license manager machine.  
- OpenLM SLM v4.6 or later installed and configured on a network computer.  

## Print license mapping details

Broker requires license mapping details from the ESPRIT license printout file.

1. Launch **DP Technology Server Security Manager**.  
2. In the left panel, locate the license under the *LocalHost* node (for example, `E1009703_872223`). Right-click → **Print**.  
   ![Print the license output from ESPRIT DP Technology Server](/img/legacy/print-the-license-output-from-esprit-dp-technology.png)  
3. Select either *Microsoft Print to PDF* or *Generic / Text Only Printer* (recommended).  
4. Save the file. If using PDF, copy contents into a text file (`.txt`).  
5. Repeat for each license.

## Install Generic / Text Only Printer (Windows)

Using a *Generic / Text Only Printer* saves the output directly as a `.txt` file.  

1. Search Windows for **add printer**.  
2. Select **Add printer or scanner**.  
3. In the window, select **Add a printer or scanner**.  
   ![Add printer or scanner button](/img/legacy/add-printer-or-scanner-button.png)  
4. Wait, then select **The printer that I want isn't listed**.  
   ![Select to install the Generic Text Only Printer](/img/legacy/select-to-install-the-generic-text-only-printer.png)  
5. Select **Add a local printer with manual settings** → Next.  
6. Use existing port: `FILE: (Print to File)`.  
7. Select **Generic → Generic / Text Only** driver → Next.  
8. Keep **Use the driver that is currently installed** → Next.  
9. Name the printer → Next.  
10. Select **Do not share this printer** → Next.  
11. Finish setup.  

Whenever you print with this device, Windows will prompt you to save the output as a file.

## OpenLM Broker configuration

1. Open **OpenLM Broker Web UI** → *License Managers* tab (`http://localhost:5090/#/license-managers`).  
2. Select **Add License Manager**.  
3. Enter any port number and select **ESPRIT** as the license manager type.  
   ![Adding the ESPRIT license manager in the OpenLM Broker web UI.](/img/legacy/word-image-42311-6.png)  
4. In the **Settings** tab, set the license file path:  
   - Auto-detect  
   - Or set manually → **Continue**  
   :::warning  
   Make sure **Watch License File** remains unchecked.  
   :::  
   ![Setting the ESPRIT license file path on the Settings tab in OpenLM Broker.](/img/legacy/word-image-42311-7.png)  
5. Go to **Commands** tab and set the ESPRIT executable path.  
   ![Setting the ESPRIT executable path on the Commands tab in OpenLM Broker.](/img/legacy/word-image-42311-8.png)  
6. Go to **Vendors** tab → **Add Vendor**. Enter a descriptive name.  
   ![Adding the ESPRIT vendor on the Vendors tab in OpenLM Broker.](/img/legacy/word-image-42311-9.png)  
7. Go to **Log File** tab → **Add Log File**. Configure:  
   - **Type**: ESPRIT Server Usage  
   - **Log (Descriptive)**: name to identify the log  
   - **Path**: `DptSecLogServerUsage.txt` (in ESPRIT logs folder)  
   - **Vendor**: select vendor from previous step  
   ![Configuring the ESPRIT log file on the Log File tab in OpenLM Broker.](/img/legacy/word-image-42311-10.png)  
8. Save configuration.  
9. Open **EasyAdmin** (`http://<Server IP>:5015`).  
10. Approve the ESPRIT License Manager entry in *License Managers Pending Approval*.  

## Verify ESPRIT License Manager configuration

1. Open **EasyAdmin** (`http://<Server IP>:5015`).  
2. Go to *EasyAdmin Start → Widgets → License Servers*.  
3. Confirm that ESPRIT appears in the list.  
   - A green circle indicates an active connection.  

## Known limitations

- License denials are not currently monitored.  
- The number of licenses cannot be read, so it displays as *Unlimited*.
