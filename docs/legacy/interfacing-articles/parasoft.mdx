Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Parasoft.

## Requirements

Before you query the license manager, install:

1. OpenLM SLM v2.x on your premises (or an OpenLM Platform account)
2. OpenLM Broker v24.11 or higher on the same machine as the Parasoft license manager

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Parasoft | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the Parasoft License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit.png)  
*Diagram of how OpenLM interfaces with the Parasoft License Manager*

:::note
OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.
:::

1. Open the Broker web UI at `http://localhost:5090`.  
   If the default port is in use, try `5091` or `5092`.
2. Go to **License Managers** → **Add License Manager**.
3. From the **LM Type** drop-down list, select **Parasoft**.
4. Enter the port number (for example, `889`) and select **Add**.

   ![Adding the Parasoft license manager in the OpenLM Broker web UI.](/img/legacy/word-image-94553-2.png)  
   *Adding Parasoft license manager in OpenLM Broker*

5. Go to the **Vendors** tab. Select **Add Vendor**, enter `Parasoft`, and select **Continue**.

   ![Adding the Parasoft vendor on the Vendors tab in OpenLM Broker.](/img/legacy/word-image-94553-3.png)  
   *Adding Parasoft vendor in OpenLM Broker*

6. Go to the **Log Files** tab. Select **Add Log File**.  
   Turn off **Watch file by pattern**. You can add multiple logs. Select **Continue**.

7. Select **Save**.

## OpenLM configuration

If the preceding steps are complete, Broker should be transmitting data to OpenLM SLM.  
Approve the configuration in the EasyAdmin UI:

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Select the **Servers Pending Approval** link.

   ![Servers Pending Approval link in the EasyAdmin License Manager Servers widget.](/img/legacy/word-image-94553-4.png)  
   *Pending license managers in EasyAdmin*

4. Double-click the pending Parasoft entry. It will be displayed as **OpenLM Generic**.
5. Verify the configuration details and select **Approve**.

At this point, Parasoft is added to OpenLM SLM.  
It may take a few moments for the data to be parsed and displayed.  
A green circle icon indicates an active connection.

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Confirm that the Parasoft license manager appears in the list with a green circle icon.

:::note
It may take up to 3 minutes for the status to update after a new connection.
:::
