# InfoGraph

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Infograph License Manager.

## Requirements

Before you query the license manager, install:

1. OpenLM SLM v2.x on your premises (or an OpenLM Cloud account)  
2. OpenLM Broker v24.11 or higher on the same machine as the InfoGraph License Manager

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| InfoGraph | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also enables buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Adding InfoGraph License Manager in OpenLM Broker](/img/legacy/word-image-92953-1.png)  
*Adding InfoGraph License Manager in OpenLM Broker*

:::note
OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.
:::

1. Open the Broker web UI at `http://localhost:5090`.  
   If the default port is in use, try `5091` or `5092`.
2. Go to **License Managers** → **Add License Manager**.
3. From the **LM Type** drop-down list, select **InfoGraph**.
4. Enter the port number (e.g., `888`) and click **Add**.
5. Go to the **Settings** tab.  
   - The Broker may auto-detect the license file path.  
   - If not, select **Set license file path manually** and navigate to the `lgraph.xml` file.

   ![](/img/legacy/word-image-92953-2.png)  
   *Setting license file path for InfoGraph in OpenLM Broker*

6. Go to the **Vendors** tab. Click **Add Vendor**, enter `InfoGraph`, and click **Continue**.

   ![](/img/legacy/word-image-92953-3.png)  
   *Adding InfoGraph vendor in OpenLM Broker*

7. Go to the **Log Files** tab. Click **Add Log File**.  
   Turn off **Watch file by pattern**. You can add multiple log files if needed. Click **Continue** and then **Save**.

   ![](/img/legacy/word-image-92953-4.png)  
   *Adding a log file for InfoGraph in OpenLM Broker*

## OpenLM configuration

If the above steps are complete, Broker should be transmitting data to OpenLM SLM.  
Approve the configuration in the EasyAdmin UI:

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Click the **Servers Pending Approval** link.

   ![](/img/legacy/word-image-92953-5.png)  
   *Pending license managers in EasyAdmin*

4. Double-click the pending InfoGraph entry. It will be displayed as **OpenLM Generic**.

   ![](/img/legacy/word-image-92953-6.png)  
   *Pending InfoGraph license manager in EasyAdmin*

5. In the **Display Name** field, enter a preferred name (for example, `InfoGraph`).

   ![](/img/legacy/word-image-92953-7.png)  
   *Editing display name for InfoGraph license manager*

6. (Optional) Go to the **Custom Fields** tab to add details such as country, usage scope, and description.

   ![](/img/legacy/word-image-92953-8.png)  
   *Adding custom fields for InfoGraph license manager*

7. Verify the configuration and click **Approve**.

At this point, InfoGraph is added to OpenLM SLM. It may take up to 3 minutes for the status to update.  
A green circle icon indicates an active connection.

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Confirm that the InfoGraph license manager appears in the list with a green circle icon.

   ![](/img/legacy/word-image-92953-9.png)  
   *Green circle indicating an active connection in EasyAdmin*

:::note
It may take up to 3 minutes for the status to update after a new connection.
:::
