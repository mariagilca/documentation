OpenLM monitors Squish license servers through OpenLM Broker. Detailed configuration steps are being prepared and will be published in an upcoming documentation release.

## Before you begin

- OpenLM SLM v25.x or later.
- OpenLM Broker, installed on the same machine as the Squish license server.

:::note[Documentation in progress]
If you need to configure Squish today, open a ticket from the [Customer Portal](https://customer.openlm.com) and reference this page. OpenLM Support shares the current procedure while the guide is finalized.
:::
