OpenLM can interface with the TASKING License Management System (TLM) through OpenLM Broker to monitor license usage, denials, and other statistics.

## Requirements

1. **OpenLM SLM** — on-premises or cloud account.  
2. **OpenLM Broker** v4.8.8 or higher installed on the same machine as TLM.

## Monitoring capabilities and features

| Feature | Resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Support | By minute | ✔ | ✔ | ✔  | ✔ | ❌ | ❌ |

Broker also provides buffered communication, remote start/stop of the license service, and denials monitoring.

## OpenLM Broker configuration

![Diagram: how OpenLM interfaces with TASKING.](/img/legacy/word-image-42284-1-1.png)  
*How OpenLM interfaces with TASKING*

Broker runs on the same machine as TLM and queries the license manager using the `licdstat` tool, then sends the data to OpenLM SLM.

### Automatic configuration

1. Open OpenLM Broker on the TLM license server.  
2. Go to the **License Managers** tab and select **Detect**.  
   ![Detecting the TASKING license manager automatically in OpenLM Broker.](/img/legacy/word-image-42284-2-1.png)  
   If the TASKING service is running, Broker will detect and configure it automatically.

### Manual configuration

1. In **License Managers**, select **Add License Manager**.  
2. Enter the TLM port number (default: `9090`).  
3. Select **TASKING** from the License Manager Type list and select **Add**.  
   ![Adding the TASKING license manager manually in OpenLM Broker.](/img/legacy/word-image-42284-3-1.png)  
4. In the **Commands** tab, set the executable path to `licdstat.exe` (usually in `C:\Program Files (x86)\TASKING\taskinglm`) and select **Update**, then **Apply**.  
   ![Setting the licdstat.exe executable path on the Commands tab in OpenLM Broker.](/img/legacy/word-image-42284-5-1.png)  
5. Select **Save**, then **Execute** to verify no errors appear.  
6. In the **Vendors** tab, select **Add Vendor**, enter the vendor name, and select **Continue**.  
   ![Adding the TASKING vendor on the Vendors tab in OpenLM Broker.](/img/legacy/word-image-42284-6.png)  
7. In **Log Files**, navigate to the TLM log file to capture denials, then select **Continue** and **Save**.  
   ![Adding the TLM log file on the Log Files tab in OpenLM Broker.](/img/legacy/word-image-42284-7.png)

## OpenLM SLM configuration

### Automatic through EasyAdmin

1. Open EasyAdmin (**Start → Widgets → License Manager Servers**).  
2. Select the **Servers pending approval** icon.  
3. Double-click the TASKING entry and approve it.  

![Approving the pending TASKING license server in EasyAdmin.](/img/legacy/word-image-42284-8.png)

## Verifying the configuration

1. In EasyAdmin, go to **Start → Widgets → License Servers**.  
2. Confirm TASKING appears in the list with a green status indicator.  

*Note: Status updates for new connections may take up to 3 minutes.*
