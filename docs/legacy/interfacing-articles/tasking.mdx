# TASKING

OpenLM can interface with the TASKING License Management System (TLM) via OpenLM Broker to monitor license usage, denials, and other statistics.

## Requirements

1. **OpenLM SLM** — on-premises or cloud account.  
2. **OpenLM Broker** v4.8.8 or higher installed on the same machine as TLM.

## Monitoring capabilities and features

| Feature | Resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Support | By minute | ✔ | ✔ | ✔ | ✔ | ❌ | ❌ |

Broker also provides buffered communication, remote start/stop of the license service, and denials monitoring.

## OpenLM Broker configuration

![](/img/legacy/word-image-42284-1-1.png)  
*How OpenLM interfaces with TASKING*

Broker runs on the same machine as TLM and queries the license manager using the `licdstat` tool, then sends the data to OpenLM SLM.

### Automatic configuration

1. Open OpenLM Broker on the TLM license server.  
2. Go to the **License Managers** tab and click **Detect**.  
   ![](/img/legacy/word-image-42284-2-1.png)  
   If the TASKING service is running, Broker will detect and configure it automatically.

### Manual configuration

1. In **License Managers**, click **Add License Manager**.  
2. Enter the TLM port number (default: `9090`).  
3. Select **TASKING** from the License Manager Type list and click **Add**.  
   ![](/img/legacy/word-image-42284-3-1.png)  
4. In the **Commands** tab, set the executable path to `licdstat.exe` (usually in `C:\Program Files (x86)\TASKING\taskinglm`) and click **Update**, then **Apply**.  
   ![](/img/legacy/word-image-42284-5-1.png)  
5. Click **Save**, then **Execute** to verify no errors appear.  
6. In the **Vendors** tab, click **Add Vendor**, enter the vendor name, and click **Continue**.  
   ![](/img/legacy/word-image-42284-6.png)  
7. In **Log Files**, navigate to the TLM log file to capture denials, then click **Continue** and **Save**.  
   ![](/img/legacy/word-image-42284-7.png)

## OpenLM SLM configuration

### Automatic via EasyAdmin

1. Open EasyAdmin (**Start → Widgets → License Manager Servers**).  
2. Click the **Servers pending approval** icon.  
3. Double-click the TASKING entry and approve it.  

![](/img/legacy/word-image-42284-8.png)

## Verifying the configuration

1. In EasyAdmin, go to **Start → Widgets → License Servers**.  
2. Confirm TASKING appears in the list with a green status indicator.  

*Note: Status updates for new connections may take up to 3 minutes.*
