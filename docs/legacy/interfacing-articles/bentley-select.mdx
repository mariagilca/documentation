# Bentley

:::info Monitoring note
OpenLM integrates with Bentley SELECT (on-premises and cloud). Monitoring capabilities depend on configuration and the Bentley license model.
:::

## About Bentley

[Bentley Systems](https://www.bentley.com/en-US/) is a U.S.-based software company specializing in solutions for civil engineering and infrastructure construction. The company has offices in over 50 countries worldwide.  

Bentley was founded by Keith and Barry Bentley, both former Intergraph engineers. Their first product enhanced Intergraph’s graphic display capabilities, later evolving into CAD tools compatible with Intergraph systems.  

[Bentley’s product portfolio](https://www.bentley.com/en-US/Products/) covers:  
- Geospatial and mapping in preliminary design.  
- Conceptual design of plants and structures.  
- Operational analysis of engineered systems.  

## Licensing model

Bentley licensing is based on **SELECT Server**, which can be deployed either:  
- **On-premises**, or  
- **Cloud-based**.  

Both versions provide a web-based interface for administration and reporting.  

## Supported features

OpenLM supports monitoring for the following Bentley products:  
- **MicroStation**  
- **STAAD**  
- **AutoPIPE**  

Partial support is available for MicroStation-based products such as:  
- **RailRoads**  
- **InTracks**  

## Benefits of monitoring Bentley with OpenLM

Using OpenLM with Bentley SELECT Server provides:  
1. **Cost optimization** – prevent overspending on Bentley licenses and manage the “bucket” system efficiently.  
2. **Granular control** – manage license checkouts by time, group, application, and version.  
3. **Idle license recovery** – OpenLM can release a license when a workstation hibernates, preventing unnecessary bucket consumption.  

## Applications Manager

For advanced monitoring and control, OpenLM Applications Manager extends capabilities within the Bentley environment.
