# Infor SLM

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from Infor SLM License Manager.

## Requirements

Before you query the license manager, install:

1. OpenLM SLM v2.x on your premises (or an OpenLM Cloud account)  
2. OpenLM Broker v24.11 or higher on the same machine as the Infor SLM License Manager

## OpenLM Broker configuration

![Adding Infor SLM License Manager in OpenLM Broker](/img/legacy/word-image-94537-1.png)  
*Adding Infor SLM License Manager in OpenLM Broker*

:::note
OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.
:::

1. Open the Broker web UI at `http://localhost:5090`.  
   If the default port is in use, try `5091` or `5092`.
2. Go to **License Managers** → **Add License Manager**.
3. From the **LM Type** drop-down list, select **Infor SLM**.
4. Enter the port number (e.g., `4325`) and click **Add**.
5. Go to the **Settings** tab.  
   - The Broker may auto-detect the license file path.  
   - If not, select **Set license file path manually** and navigate to the `license.xml` file.

   ![](/img/legacy/word-image-94537-2.png)  
   *Setting license file path for Infor SLM in OpenLM Broker*

6. Go to the **Commands** tab. Enter the Infor SLM host and port in the **Data Inquiry** field.

   ![](/img/legacy/infor.png)  
   *Configuring data inquiry for Infor SLM in OpenLM Broker*

7. Click **Save**, then click **Execute** to test the configuration.

   ![](/img/legacy/word-image-94537-4.png)  
   *Successful execution output for Infor SLM license manager*

8. Go to the **Vendors** tab. Click **Add Vendor**, enter `Infor SLM`, and click **Continue**.
9. Click **Save**.

## OpenLM configuration

If the above steps are complete, Broker should be transmitting data to OpenLM SLM.  
Approve the configuration in the EasyAdmin UI:

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Click the **Servers Pending Approval** link.

   ![](/img/legacy/word-image-94537-6.png)  
   *Pending license managers in EasyAdmin*

4. Double-click the pending Infor SLM entry. It will be displayed as **OpenLM Generic**.

   ![](/img/legacy/word-image-94537-7.png)  
   *Pending Infor SLM license manager in EasyAdmin*

5. In the **Display Name** field, enter a preferred name (for example, `Infor SLM`).
6. (Optional) Go to the **Custom Fields** tab to add details such as country, usage scope, and description.

   ![](/img/legacy/word-image-94537-9.png)  
   *Adding custom fields for Infor SLM license manager*

7. Verify the configuration and click **Approve**.

At this point, Infor SLM is added to OpenLM SLM. It may take up to 3 minutes for the status to update.  
A green circle icon indicates an active connection.

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Confirm that the Infor SLM license manager appears in the list with a green circle icon.

:::note
It may take up to 3 minutes for the status to update after a new connection.
:::
