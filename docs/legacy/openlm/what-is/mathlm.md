## What is MathLM?

MathLM is Wolfram's custom license manager for its products, which include Mathematica and Wolfram One. Where the customer is running multiple instances of the Wolfram system, MathLM is installed as a network license manager, which will manage all access and retrieval of its products, specifically Mathematica. The number of concurrent processes that can run is shown on the network license certificate.

OpenLM provides the following functionality for monitoring MathLM licenses:

- Denials reporting *No*
- Report resolution *By minute*
- Borrowed license reporting *No*
- Expiration date reporting *No*
- Multiple server redundancy support *No*
- Token license support *No*

MathLM is only one of over 70 license managers that OpenLM can manage. [Check the list](https://www.openlm.com/license-manager-capabilities/).

### Who is Wolfram?

Wolfram Research was founded in 1987 by Stephen Wolfram, and was one of the pioneers in mathematical computation, developing the Wolfram Language to support their computational products. Their flagship product is Mathematica, which is used by millions worldwide. Ten years ago Wolfram|Alpha was designed from the foundation of Wolfram Language. MathLM is Wolfram's proprietary license manager. The corporate headquarters are based in Champaign Illinois, with offices on every continent.
