## What is Altium?

As one of the premier providers of EDA software for designing printed circuit boards (PCBs), Altium have their own proprietary license manager for on-premises sites. It is a 2-tier licensing system, consisting of a license for the server, which controls a pool of user licenses. When the maximum number of concurrent users are reached, users will be denied until a license is freed up.

OpenLM provides the following functionality for monitoring Altium licenses:

| Capability | Support |
|-----------|---------|
| Denials reporting | Yes |
| Report resolution | Per minute |
| Borrowed license reporting | No |
| Expiration date reporting | Yes |
| Multiple server redundancy support | One backup |
| Token license support | No |
Altium is only one of over 90 license managers that OpenLM can manage. 
## What is Altium 365?

Altium 365 is Altium’s cloud offering currently (August 2019) in beta test mode, and available to registered users of Altium.
