## What is BetaLM?

BetaLM is a proprietary license manager from Beta Computer Aided Engineering Systems for its computer‑aided engineering (CAE) products. These include Automatic Net Generation for Structural Analysis (ANSA) as a pre-processor and Multidomain Post-processing Environment (META) as a post-processor. This simulation software often runs in batch mode.

OpenLM provides the following monitoring capabilities for BetaLM licenses:

| Capability | Support |
|------------|---------|
| Denials reporting | Yes |
| Report resolution | Per second |
| Borrowed license reporting | Not applicable |
| Expiration date reporting | Yes |
| Multiple server redundancy support | Triad |
| Token license support | No |

BetaLM is among more than 90 license managers OpenLM monitors. See the full [list](https://www.openlm.com/license-manager-capabilities/).

### About Beta CAE Systems

Founded in Lucerne about 25 years ago, Swiss computer‑aided engineering (CAE) software company Beta Computer Aided Engineering Systems operates worldwide with locations in the United States, India, Japan, and across Europe. Products include Automatic Net Generation for Structural Analysis (ANSA) and Multidomain Post-processing Environment (META), used in automotive, aerospace, and petrochemical industries. The company also developed the proprietary license manager BetaLM. Beta CAE simulation software runs on NVIDIA and Advanced Micro Devices (AMD) graphics processing units (GPUs). ANSA ingests a wide range of data formats from other CAE vendors such as Dassault and Siemens.
