## What is EPLAN LM?

EPLAN has its own proprietary license manager, which is issued via a dongle for installation on a license server. The EPLAN License Manager monitors all EPLAN software products. An optional Standby server capability can be purchased.

OpenLM provides the following functionality for monitoring EPLAN licenses:

- Denials reporting *Yes*
- Report resolution *By second*
- Borrowed license reporting *Yes*
- Expiration date reporting *No*
- Multiple server redundancy support *Eplan does have a Standby server option as well as a primary server.*
- Token license support *No*

EPLAN is only one of over 70license managers that OpenLM can manage. [Check the list](https://www.openlm.com/license-manager-capabilities/).

### Who is EPLAN?

EPLAN is one of the companies in the German family-owned Friedhelm Loh Group and was established in 1984. Their software supports process engineering in a number of engineering disciplines, especially electrical, automation, and mechatronics. EPLAN's range of software products helps customers standardize and optimize the many disparate software products and artifacts used in a PLM or PDM environment. Apart from the EPLAN Platform and Engineering configuration, which help companies streamline their engineering process flows, EPLAN offers applications tailored to particular engineering challenges, such as Electric P8 for electrical engineering flows, Harness ProD for the design and management of cable harnesses and Fluid, which assists in fluid power engineering.

EPLAN employs 1000 employees and has 55,000 users globally.
