## What is Intergraph SPLM?

Intergraph SPLM is a license manager for SmartPlant® installations. It was developed in-house by Intergraph CAS. It is designed for concurrent usage of the plant design suite. Most users of SmartPlant are still using older versions of the license manager, such as v.11.00.17. It runs as a background controller service and startup can be delayed through the service manager. The main program executable is license.exe. The software installer includes 5 files and is usually about 3.92 MB (4,114,597 bytes).

OpenLM provides the following functionality for monitoring SPLM licenses:

- Denials reporting *No*
- Report resolution *By minute*
- Borrowed license reporting *No*
- Expiration date reporting *No*
- Multiple server redundancy support *No*
- Token license support *No*

SmartPlant LM is only one of over 70 license managers that OpenLM can manage. [Check the list](https://www.openlm.com/license-manager-capabilities/).

### Who is Intergraph?

Intergraph is a company that specializes in plant management software, especially in the oil and gas industries. It was acquired by Hexagon in 2010 and is now known as Hexagon PPM (Process, Power, and Marine). It was founded in 1969 as M & S Computing, specializing in graphics software and soon became known worldwide for its CAD system IGDS, becoming the largest graphics systems vendor towards the end of the 80s. Having exited the hardware industry towards the end of the century, Intergraph focused on software and developed SmartPlant® 3D, which provides graphics for the design, build, and maintenance of a plant. SmartPlant has a dedicated license manager, SmartPlant LM or Intergraph SPLM, which was developed by Intergraph CAS.
