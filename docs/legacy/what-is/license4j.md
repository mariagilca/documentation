## What is License4J?

License4j is a license manager for Java Applications, produced by the company of the same name, which is based in Ankara in Turkey, and is relatively new, having incorporated in 2010. License4j can support node-locked and floating licenses, as well as some other permutations.

OpenLM provides the following functionality for monitoring License4J:-

- Denials reporting *No*
- Report resolution *By minute*
- Borrowed license reporting *Yes*
- Expiration date reporting *Yes*
- Multiple server redundancy support *No*
- Token license support *No*

License 4J is only one of the over 70 license managers that OpenLM can manage. [Check the list](https://www.openlm.com/license-manager-capabilities/).
