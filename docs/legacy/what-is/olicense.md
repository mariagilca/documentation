## What is Olicense?

Olicense is a license manager produced by Optimum GMBH, which also have other software products such as SmartKlaus, which uses optical recognition for supply-chain monitoring. Some Olicense users include Cosin, Ensoft, JCMWave, and Math2Market.

OpenLM provides the following functionality for monitoring Olicense licenses:

- Denials reporting *No*
- Report resolution *By second*
- Borrowed license reporting *No*
- Expiration date reporting *Yes*
- Multiple server redundancy support *No*
- Token license support *No*

Olicense is only one of over 70 license managers that OpenLM can manage. [Check the list](https://www.openlm.com/license-manager-capabilities/).
