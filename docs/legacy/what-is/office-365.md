## What is Office 365?

Office 365 is Microsoft's SaaS offering. While it is still possible to purchase a perpetual license, such as Office 2019 Professional, Microsoft is trying to attract customers to the Office 365 portal by offering additional products, such as Microsoft Teams for collaboration and Microsoft Bookings for customers to schedule meetings. The product range varies from individual licenses to business (up to 250 employees) and enterprise licenses, which include Teams and Bookings.

With Release 4.5, OpenLM has added the capability to manage Microsoft 365 licenses in the cloud.

OpenLM provides the following functionality for monitoring Office 365 licenses:

- Denials reporting *No*
- Report resolution *By minute*
- Borrowed license reporting *Not applicable*
- Expiration date reporting *Yes*
- Multiple server redundancy support *Not applicable*
- Token license support *No*

There are over 30 license managers that OpenLM can now monitor with Release 4.5. For more details, check this [list](https://www.openlm.com/license-manager-capabilities/).
