## OpenLM SLM features
OpenLM features are optional software modules that add enhanced functionality to OpenLM SLM. They are available to all OpenLM SLM customers and may be purchased as needed. If you are unsure which features you require for your organization, contact our sales team for a 30-day trial.

The OpenLM features are described below:

## Applications Manager:
A system for monitoring and controlling the use of any software in your organization, regardless of the licensing scheme. You can use it to implement your enterprise software allocation policy.

## Alerts Management:
Define alerts to be sent to the license administrator when certain criteria are met, such as a license about to expire, license usage reaching 90% capacity, and more.

## Roles and Permissions:
Allows you to grant different OpenLM capabilities to different administrators. You can define custom administration roles and then assign them to the appropriate administrators.

## Directory Sync:
Import user details from Windows Active Directory, including host and user names, organizational units (OUs), and groups. The synchronization frequency is customizable and works with multiple corporate AD domains.

## Group Usage:
Provides a usage reporting option by group. Groups can be custom-defined in OpenLM or based on synchronized Active Directory OUs and workgroups.

## Actual Usage:
Reports how much time a license was consumed by a specific user during a session. It uses parameters like user idle time, CPU, and data I/O to report how much time a license was idle while a user held it.

## License Allocation Manager: 
Provides an easy way to configure FlexNet Publisher and other license manager options files.

## Project Usage:
Gives you a usage reporting option by project. Projects are defined in OpenLM, and users can be prompted to select the appropriate project when pulling a license.

## Custom Commands: 
Allows administrators to run scripts on end-user workstations to manage specialized situations for licenses and permissions that occur with changing usage status.

## Unmanaged Processes:
Monitors applications that are not managed by a license manager.

## Report Scheduler:
Enables the automatic generation of predefined reports and their submission to predefined recipients on a set schedule.
