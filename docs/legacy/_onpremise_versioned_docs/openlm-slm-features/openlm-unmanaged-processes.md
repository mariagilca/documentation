## How to monitor unmanaged licenses
Unmanaged licenses are those not monitored by a license manager. You can still monitor them by configuring OpenLM to track their processes on a PC. Here's how to monitor unmanaged licenses step-by-step:

First, make sure the application you want to monitor is running.

Next, identify the process that the application uses and note down the process name.

In the EasyAdmin user interface, click Start → Administration → "Unmanaged Processes".

In the Unmanaged Processes window, click the "Add Vendor" icon to add the vendor to the list of monitored vendors.

The "Add Vendor" pop-up will open. .

Finally, fill in the following fields:

Type in the software vendor name: The vendor's name.

Feature Name: A free text field.

Process Name: The exact process name you noted down earlier.

Description: A free text field for a description.

You can add additional features to the monitored vendor using the Add button. After the process is configured, it will appear on all relevant EasyAdmin user interface windows and in the License Usage Information window.
