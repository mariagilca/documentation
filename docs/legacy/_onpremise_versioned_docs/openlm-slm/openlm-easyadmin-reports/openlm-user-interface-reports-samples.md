## License servers

**Path:** `Start → Widgets → License Servers`

A live widget showing license usage and availability in real time, meaning how many licenses are used and how many are currently free.

## License usage

**Path:** `Start → Reports → License Usage`

The license usage report accounts for the consumption of single or multiple feature licenses relative to the total number of licenses. It presents license consumption patterns over configurable periods and resolutions.  

This information helps identify bottlenecks and redundancies in the license inventory.  

The report is available in three formats, according to the display pane tabs:  

- Table  
- Chart  
- Heatmap  

---

## Denials

**Path:** `Start → Reports → Denials`

Displays historic license denial occurrences, which can be aggregated by any dimension available in OpenLM (user, group, feature, etc.).

---

## License utilization

**Path:** `Start → Management → License Utilization`

This chart indicates license usage efficiency. Each column `x` answers: *What is the percentage of usage time that at least x licenses have been in use?*  

This form of presentation ignores momentary peaks and depicts true license consumption patterns. It also shows how many licenses are required in the organization.  

The QoS line indicates the number of licenses required to support a certain percentage of license requests.  

Example: Only 7 licenses (out of 12 available) are required to support 96% of license requests.

## License activity

**Path:** `Start → Reports → License Activity`

Enables administrators to produce detailed reports and track license activity of individual users.  

The **Group by** tab supports license statistics by:  

- Workstations  
- Features  
- Users  
- Groups  
- Projects  

Green lines mark currently active sessions.

---

## Active users

**Path:** `Start → Management → Active Users Report`

Displays which users have been active and checked out a license in the selected time frame.

---

## Project usage report

**Path:** `Start → Reports → Project Usage`

Provides license usage time according to the active project, as reported by the end user.

---

## Group usage report

**Path:** `Start → Reports → Group Usage`

Provides license usage statistics grouped by user groups.

---

## Feature usage per group

**Path:** `Start → Reports → Feature Usage Per Group`

Displays the usage (in hours) of selected features by user groups in a stacked vertical bar chart.  

Hover over the chart to see detailed usage per section of the bars.

---

## Feature usage per user

**Path:** `Start → Reports → Feature Usage Per User`

Displays the usage (in hours) of selected features by users in a stacked vertical bar chart.  

Hover over the chart to see detailed usage per section of the bars.

---

## Licenses

**Path:** `Start → Management → Licenses`

Shows a full list of licenses of the selected license manager.

## License procurement

**Path:** `Start → Management → License Procurement`

Displays full procurement information found in the vendor file, such as expiration date and packages.

## Currently consumed licenses

**Path:** `Start → Operational → Currently Consumed Licenses`

A live widget showing current running sessions, including:  

- Start time  
- Feature  
- Group  
- License server  
- Username
