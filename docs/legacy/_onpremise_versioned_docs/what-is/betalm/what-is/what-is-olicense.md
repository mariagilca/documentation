### What is Olicense?

**Olicense** is a license manager produced by **Optimum GmbH**, a company that also develops other software products like SmartKlaus, which uses optical recognition for supply-chain monitoring. Olicense is used by a number of companies, including Cosin, Ensoft, JCMWave, and Math2Market.

OpenLM provides the following functionality for monitoring Olicense licenses:

* **Denials Reporting**: No
* **Report resolution**: By Second
* **Borrowed License reporting**: No
* **Expiration Date reporting**: Yes
* **Multiple Server Redundancy Support**: No
* **Token License Support**: No

Olicense is one of over 70 license managers that OpenLM can manage.
