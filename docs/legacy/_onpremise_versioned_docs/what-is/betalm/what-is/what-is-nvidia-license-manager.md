### What is NVIDIA License Manager?

The **NVIDIA GRID® License Manager** is a tool used to monitor and manage NVIDIA's virtual computing software. This software is essential for running virtual desktops and applications, as well as for compute-intensive workloads like AI and machine learning.

NVIDIA offers two license models: an annual subscription and a concurrent usage version with an annual maintenance fee. The licensing can also vary depending on the workload; for a **virtual Compute Server (vCS)** used for AI or high-performance computing, the license is per GPU rather than per user.

The concurrent license is not restrictive and will not deny users access even without a valid license. This allows for uninterrupted workflows but places the responsibility on the customer to track usage and ensure compliance. Customers are not limited to the NVIDIA GRID license manager and can use other reliable license tracking methods.

***

### Key Features of NVIDIA's License Manager

OpenLM provides the following functionality for monitoring NVIDIA licenses:

* **Denials Reporting**: No
* **Report resolution**: By Minute
* **Borrowed License reporting**: No
* **Expiration Date reporting**: Yes
* **Multiple Server Redundancy Support**: No
* **Token License Support**: No

### Who is NVIDIA?

NVIDIA is a technology company that has become a global leader in accelerated computing. Although it started by developing graphics accelerator boards for gaming, its **Graphics Processing Units (GPUs)** are now critical hardware for a wide range of industries. These include engineering, research, and IT, where GPUs are used for simulation software, virtual machine setups, AI, and high-performance computing.

The **NVIDIA GRID® license manager** is used to monitor the company's four main software editions:

* **GRID vPC (Virtual PC)**: Provides a full-performance virtual desktop experience for general business applications.
* **Quadro vDWS (Virtual Data Center Workstation)**: Tailored for designers and engineers who use demanding software like CATIA, SOLIDWORKS, and PTC Creo.
* **GRID vApps (Virtual Applications)**: Suited for customers using application streaming solutions.
* **NVIDIA vCS (Virtual ComputeServer)**: Designed for AI, machine learning, and high-performance computing, with licensing based on GPU usage rather than per user.

As of OpenLM Server v4.5, the NVIDIA License Manager has been replaced by **FlexNet Embedded**.
