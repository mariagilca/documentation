### What is SEH-UTN Manager?

**UTN Manager** is a license manager developed by **SEH Computertechnik** for its line of dongle and UTN servers. These servers can host up to 20 dongles, such as those from **Gemalto Sentinel HASP** or **Wibu Codemeter**, and provide network-wide access to the licenses they control.

This setup offers several benefits:
* Dongles are stored in a secure, central location, reducing the risk of loss or theft.
* Any user with access rights can use the licensed software across the network.
* Licenses are more readily available, as the dongle is not tied to a single user's workstation or laptop.
* The system supports virtual machines, providing a flexible solution for modern IT environments.

OpenLM can access these dongle servers to analyze the usage of various vendors' licenses. It provides the following functionality for monitoring UTN Manager licenses:

* **Denials Reporting**: No
* **Report resolution**: By Minute
* **Borrowed License reporting**: No
* **Expiration Date reporting**: No
* **Multiple Server Redundancy Support**: No
* **Token License Support**: No

UTN Manager is one of over 70 license managers that OpenLM can manage.

### Who is SEH?

**SEH Computertechnik GmbH** is a German company founded in 1986. Originally focused on networking and printer solutions, SEH developed the **UTN (USB to Network)** protocols to address the growing use of USB devices. This led to the creation of their **MyUTN** product line, which includes the **MyUTN-800 Dongleserver**. This device can host up to 20 dongles, making hardware-protected licenses accessible across a network.

The **UTN Manager** software tool provides management and control of access to these dongles. SEH provides cost-effective and controlled networking solutions for large corporations, with a customer list that includes IKEA, Motorola, and the US Air Force.
