### What is License4J?

**License4J** is a license manager produced by a company of the same name, founded in 2010 and based in Ankara, Turkey. It's designed specifically for **Java applications** and supports various licensing models, including **node-locked and floating licenses**.

OpenLM provides the following functionality for monitoring License4J licenses:

* **Denials Reporting**: No
* **Report resolution**: By Minute
* **Borrowed License reporting**: Yes
* **Expiration Date reporting**: Yes
* **Multiple Server Redundancy Support**: No
* **Token License Support**: No

License4J is one of more than 70 license managers that OpenLM can manage.
