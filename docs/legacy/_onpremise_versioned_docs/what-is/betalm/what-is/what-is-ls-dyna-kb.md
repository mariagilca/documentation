### What is LS-DYNA?

**LS-DYNA** is a powerful finite element analysis (FEA) software developed by **Livermore Software Technology Corporation (LSTC)**. It's used across various industries for simulation and modeling. The software has its own proprietary license manager, also called **LS-DYNA**.

Unlike conventional license managers that count concurrent users, LS-DYNA's licensing is structured around the **number of cores being used and the number of simultaneous jobs**. The license is available for both node-locked and networked usage.

OpenLM provides the following functionality for monitoring LS-DYNA licenses:

* **Denials Reporting**: Yes
* **Report resolution**: By minute
* **Borrowed License reporting**: No
* **Expiration Date reporting**: Yes
* **Multiple Server Redundancy Support**: No
* **Token License Support**: No

### Who is Livermore Technologies?

**Livermore Software Technology Corporation (LSTC)** was founded in 1987 in Livermore, California. The company's goal was to commercialize the **DYNA3D** software, renaming it **LS-DYNA**. LSTC is known for its FEA tools and complementary software like **LS-OPT** and **THUMS** (Total Human Model for Safety), which was developed for Toyota. LSTC's solver software is used in diverse fields, including aerospace, bioengineering, and manufacturing. The company's proprietary license manager is also known as **LS-DYNA**.
