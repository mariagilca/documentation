### What is FlexNet Embedded (FNE)?

**FlexNet Embedded (FNE)** is a small-footprint **System Development Kit (SDK)** for license management, designed by **Flexera**. While it can protect software on all platforms, it was primarily developed for **IoT (Internet of Things)** devices. With a footprint of approximately 50k, it allows vendors to tailor licensing to their specific products.

The embedded licenses are a key part of Flexera's **Software Monetization Suite**, which provides the mechanisms for managing software and collecting valuable licensing information.

**OpenLM versions 4.5 and higher** support FlexNet Embedded servers that have an **XML API** enabled, such as those used by Avid and Nvidia.

OpenLM provides the following functionality for monitoring FlexNet Embedded:

* **Denials Reporting**: No
* **Report resolution**: By Second
* **Borrowed License reporting**: Yes
* **Expiration Date reporting**: Yes
* **Multiple Server Redundancy Support**: No
* **Token License Support**: Yes

FlexNet Embedded (FNE) is one of over 70 license managers that OpenLM can manage. For step-by-step instructions on how to monitor FlexNet Embedded servers with OpenLM, consult [HT907](https://www.openlm.com/knowledge-base/interfacing-the-flexnet-embedded-license-manager-ht907/).
