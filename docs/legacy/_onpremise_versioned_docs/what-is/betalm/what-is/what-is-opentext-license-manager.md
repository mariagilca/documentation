OpenText License Manager is a tool for monitoring the usage of OpenText's enterprise content and documentation (ECD) solutions. These solutions, which can be cloud-based or on-premise, are available in various versions, from free single-user to enterprise-level. OpenText's license models are diverse and can be based on several metrics, including:

* Named user
* Concurrent user
* Number of dual-core CPUs
* Document pages processed per year
* Number of ECD instances
* ECD Managed Entity (any entity using the software)

OpenLM provides the following functionality for monitoring OpenText licenses:

* **Denials Reporting**: No
* **Report Resolution**: By Second
* **Borrowed License Reporting**: No
* **Expiration Date Reporting**: No
* **Multiple Server Redundancy Support**: No
* **Token License Support**: No

### Who is OpenText?

OpenText is a Canadian company specializing in enterprise content and document management solutions. It was founded in 1991, stemming from a research project at the University of Waterloo that developed an early search engine technology. The company grew rapidly through acquisitions and product development, with its Livelink and OpenText products becoming market leaders. Today, OpenText is a publicly traded company that serves over 120,000 customers globally with solutions that integrate with major platforms like Salesforce, Oracle, and SAP.
