## What is the Altium License Manager?

As a leading provider of EDA software for designing printed circuit boards (PCBs), Altium has its own proprietary license manager for on-premise sites. It operates as a two-tier licensing system, where a single server license controls a pool of user licenses. When the maximum number of concurrent users is reached, new users are denied access until a license becomes available.

OpenLM offers the following functionality for monitoring Altium Licenses:

* **Denials Reporting:** Yes
* **Report resolution:** By Minute
* **Borrowed License reporting:** No
* **Expiration Date reporting:** Yes
* **Multiple Server Redundancy Support:** One backup
* **Token License Support:** No

Altium is just one of over 70 license managers that OpenLM can manage.

### What is Altium 365?

Altium 365 is Altium's cloud offering, which was in beta testing as of August 2019 and is available to registered Altium users.
