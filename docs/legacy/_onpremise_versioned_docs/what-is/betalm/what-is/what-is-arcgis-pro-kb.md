ESRI released ArcGIS Pro with the 10.3 version of ArcGIS in the second half of 2014. It was designed to be the premier application for GIS professionals.

### What is ArcGIS Pro?

ArcGIS Pro is a GIS application for visualizing, editing, and performing analysis using local or online ArcGIS content. It is a **64-bit application** with 2D and 3D display capabilities, optimized for improved speed and user experience. The interface is contextual, providing tools only when needed, and is highly integrated with other Esri tools.

### Main features

ArcGIS Pro introduces many benefits for users, including:

* **Project-based workflows**: Data files from older versions, such as maps (`.mxd`), scenes (`.sxd`), and globes (`.3DD`), can be imported and saved as projects (`.aprx`).
* **Multiple maps, multiple layouts**: The application allows you to work with multiple displays and layouts simultaneously. You can synchronize data between different views, such as a 2D map and a 3D scene, to combine visual information.
* **Simplified interface**: The interface is optimized for a better user experience, with contextual menus and functionality. For example, it simplifies the creation of multiple features using "Grouped Feature Templates."
* **Interactive 3D**: 3D visualization and editing are more interactive, with direct feedback and handles for quick and intuitive 3D mapping.
* **Backward compatibility**: While it was released with ArcGIS 10.3, ArcGIS Pro is backward compatible with older versions of ArcGIS for desktop.

### The OpenLM point

OpenLM is a general-purpose application for monitoring floating license usage, with specific benefits for ESRI users due to its origins. OpenLM continues to support ArcGIS license monitoring, including for ArcGIS Pro.
