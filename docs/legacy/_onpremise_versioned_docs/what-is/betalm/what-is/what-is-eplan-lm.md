### What is EPLAN LM?

**EPLAN LM** is the proprietary license manager developed by **EPLAN** for all of its software products. The license manager is typically issued via a dongle that is installed on a license server. An optional standby server capability can be purchased to provide redundancy.

OpenLM provides the following functionality for monitoring EPLAN licenses:

* **Denials Reporting**: Yes
* **Report resolution**: By Second
* **Borrowed License reporting**: Yes
* **Expiration Date reporting**: No
* **Multiple Server Redundancy Support**: EPLAN offers a Standby server option, in addition to a primary server.
* **Token License Support**: No

EPLAN is one of over 70 license managers that OpenLM can manage.

### Who is EPLAN?

**EPLAN** is a German software company founded in 1984. It is part of the family-owned Friedhelm Loh Group. EPLAN specializes in software that supports process engineering for electrical, automation, and mechatronics disciplines. The company's products help customers streamline and standardize their engineering workflows within a **Product Lifecycle Management (PLM)** or **Product Data Management (PDM)** environment.

EPLAN's software portfolio includes:

* **EPLAN Platform**: Provides a foundation for various engineering disciplines.
* **EPLAN Electric P8**: For electrical engineering design.
* **EPLAN Harness ProD**: For the design and management of cable harnesses.
* **EPLAN Fluid**: Assists in fluid power engineering.

EPLAN employs 1,000 people and serves 55,000 users globally.
