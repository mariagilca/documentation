<span style="font-weight: 400;">OpenText License Manager monitors the usage of the OpenText enterprise content documentation (ECD) solutions. The product is available in several versions from a free single-user to an enterprise version. Users can work via the cloud or have on-premise solutions with a concurrent user set-up. OpenText has several variants when it comes to license models:-</span>
<ul>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Named user </span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Concurrent User</span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Number of dual-core CPUs</span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Document pages processed per year</span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Number of ECD instances </span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">ECD Managed Entity (any entity using the software, e.g. an application or a user)</span></li>
</ul>
 

<span style="font-weight: 400;">OpenLM provides the following functionality for monitoring OpenText Licenses:-</span>
<ul>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Denials Reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Report resolution</span> <span style="color: #000080;"><em><span style="font-weight: 400;">By Second</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Borrowed License reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Expiration Date reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Multiple Server Redundancy Support</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>

<h1><b>Who is OpenText?</b></h1>
 

<span style="font-weight: 400;">OpenText is a Canadian company that has enterprise content and document management solutions that can interface with most leading vendor software from Salesforce to Oracle and SAP. Its origins were at the Canadian University of Waterloo in Ontario, which resulted in a marketable search engine product in 1991. The company was quick to realize the potential of the Internet and the Intranet, and during the years 1995-1998 they grew rapidly, both organically and by acquisitions. The products, Livelink and OpenText were recognized as market leaders during this phase, and the company has grown steadily with a current base of 120,000 customers globally.</span>
