<h2>What is SlickEdit?</h2>
<a href="https://www.slickedit.com/products/slickedit"><span style="font-weight: 400;">SlickEdit</span></a> <span style="font-weight: 400;">is a popular cross-platform, multi-language source code and text editor. It provides various coding tools and time-saving programming features. SlickEdit 2014 facilitates coding in over 40 languages on 9 different platforms.</span>

<span style="font-weight: 400;">Usage of the SlickEdit editor is licensed and managed by a proprietary license manager. Here is an explanation of how to</span><a href="https://www.openlm.com/knowledge-base/interfacing-the-slickedit-license-manager-kb4001o/"><span style="font-weight: 400;"> interface</span></a><span style="font-weight: 400;"> SlickEdit to OpenLM in order to monitor license usage and obtain license usage statistics.</span>

<span style="font-weight: 400;">OpenLM provides the following functionality for monitoring SlickEdit Licenses:-</span>
<ul>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Denials Reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Report resolution</span> <span style="color: #000080;"><em><span style="font-weight: 400;">By Minute</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Borrowed License reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">Yes</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Expiration Date reporting</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Multiple Server Redundancy Support</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
 <li style="font-weight: 400;"><span style="font-weight: 400;">Token License Support</span> <span style="color: #000080;"><em><span style="font-weight: 400;">No</span></em></span></li>
</ul>
