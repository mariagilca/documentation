This is a short guide on configuring OKTA SSO and OpenLM integration.

Requirements:
An existing OKTA account

OpenLM SLM & Identity Service v21 and higher configured with SSL or an OpenLM SLMC

Adding an OpenLM application in the Okta admin interface
In the left-side menu, click Applications.

Click Create App Integration.

In the pop-up window, select OIDC - OpenID Connect for the Sign-in method and Web Application for the Application Type. Click Next.

Name the application and check the following boxes:

Client Credentials

Authorization Code

Implicit (Hybrid)

Leave the URIs unchanged. The correct URIs will be provided by OpenLM later. Scroll down and click Save. After saving, note the Client ID and Client Secret. Leave this window open.

OpenLM on-premise configuration
Go to the OpenLM Identity Service → External Providers tab.

Click Add Provider. From the dropdown list, select Okta.

Fill in the following fields with information from your Okta account:

Client ID: The Client ID you noted in step 5 above.

Client Secret: The Client Secret you noted in step 5.

Account ID: Enter none (case-sensitive).

Authority: Your Okta ID.

Click Save.

After the import is complete, OpenLM Identity Service will generate the correct URIs tied to your account.

Go back to your Okta account. Click Edit on the General setting section.

Scroll down to the Login section. Input the sign-in and sign-out redirect URLs generated by OpenLM. Click Save.

Go to the Identity Service webpage and log out. You can now log in with the Okta button.

OpenLM SLMC
If you are an OpenLM SLMC user, follow these steps to configure Okta as an external Identity provider:

Navigate to your Cloud Portal instance → Identity & Access Management (IAM) → External Providers → Add Provider.

Input the following details from your Okta account:

Client ID

Client Secret

Authority (e.g., dev-12345678.okta.com).

Provide a public button name (e.g., Okta).

Switch to the Products and Roles tab. For the following products, choose either an Admin or Manager role:

Virtual License Manager

Software License Management Cloud

Dongle Monitoring

OneDirectorySync

Click Save. The correct URIs will be generated.

Go back to your Okta account. Click Edit on the General setting section.

Scroll down to the Login section. Input the sign-in and sign-out redirect URLs from the OpenLM Cloud Portal. Click Save.

Go back to your Cloud Portal and sign out. You can now sign in using this pattern, replacing the account ID with your own: https://cloud.openlm.com/portal?loginAccountId=123456789. You can find your OpenLM Account ID by clicking the dropdown arrow next to your username in the top right corner.
