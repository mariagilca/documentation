# OpenLM Documentation

Source for the OpenLM documentation site at https://www.openlm.com/documentation/, built with [Docusaurus 3](https://docusaurus.io/).

## Documentation sets

Two doc sets are wired into the site (see `docusaurus.config.js`):

| Set | Path | Route | Sidebar | Label in UI |
| --- | --- | --- | --- | --- |
| OpenLM Platform (cloud) | `docs/cloud/` | `/cloud` | `sidebars-cloud.js` (curated) | OpenLM Platform |
| Legacy (Version 25) | `docs/legacy/` | `/legacy` | `sidebars-default.js` (autogenerated) | Version 25 |

The site is served under `baseUrl: /documentation/`, so local dev runs at `http://localhost:3000/documentation/`.

## Quick start

```bash
npm install
npm run start            # English at /documentation/
npm run start -- --locale ja
```

## Common commands

| Command | What it does |
| --- | --- |
| `npm run start` | Dev server with hot reload (English). |
| `npm run start -- --locale ja` | Dev server in Japanese. |
| `npm run build` | Production build into `build/`. |
| `npm run serve` | Serve the `build/` output for smoke testing. |
| `npm run clear` | Clear `.docusaurus/` cache when builds get stale. |
| `npm run write-translations -- --locale ja` | Extract strings to `i18n/ja/` for translation. |
| `npm run vale` | Run Vale prose linter on `docs/`. |

Node 18+ required (`engines.node` in `package.json`).

## Repository layout

```
docs/                     Authored Markdown/MDX, grouped by doc set
  cloud/                  OpenLM Platform (current product)
  legacy/                 Version 25 (legacy)
i18n/ja/                  Japanese translations + theme strings
src/
  components/             MDX-embeddable React components
  theme/                  Swizzled Docusaurus theme overrides
  plugins/                Custom Docusaurus plugins (reading-time, last-updated)
  pages/                  Standalone routes (homepage, changelog, etc.)
  css/custom.css          Global styles
static/                   Assets copied verbatim into the build
sidebars-cloud.js         Curated sidebar for the cloud set
sidebars-default.js       Autogenerated fallback (used by legacy)
docusaurus.config.js      Site config: plugins, redirects, navbar, search
azure-pipelines.yml       CI: a11y checks → build → axe scan → rsync deploy
Dockerfile                Multi-stage image (base / dev / prod / serve)
project-guides/           Deeper guides for contributors and maintainers
scripts/                  Python a11y and SaaS-doc-population helpers
generate-analysis.js      One-off script that exports docs to Word (.docx)
```

## Deployment

Pushes to `master` trigger `azure-pipelines.yml`, which:

1. Runs Python a11y checks (`scripts/check-a11y-*.py`).
2. Builds the static site (`npm run build`).
3. Runs an axe-core WCAG 2.1 AA scan against the built site (warnings only, doesn't block).
4. Rsyncs `build/` to `docs_deploy@openlm.com:/var/www/www/openlm.com/documentation/` over SSH.

The Dockerfile is for local containerised dev (`dev` stage) and reproducible serving (`prod`/`serve` stages).

## Environment setup

### macOS

```bash
# Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install git node
```

### Windows (WSL)

```powershell
wsl --install
```

Then in the WSL shell:

```bash
sudo apt update && sudo apt install -y git curl
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt install -y nodejs
```

### Ubuntu

sudo apt update && sudo apt install -y git curl
