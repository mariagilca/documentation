# RIB Presto

Follow these steps to configure OpenLM to monitor license usage and retrieve statistics from the RIB Presto License Manager.

## Requirements

Before starting, make sure you have:

1. OpenLM Server v2x installed on a machine in your organization or an OpenLM Cloud (SLMC) account  
2. OpenLM Broker v23.6 or higher installed on the same machine as RIB Presto

## Monitoring capabilities

RIB Presto is monitored via log file parsing. The Broker reads the log file, compiles the data, and sends it to OpenLM Server for processing.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the RIB Presto License Manager](https://www.openlm.com/wp-content/uploads/2023/07/how-openlm-interfaces-with-the-coscom-licensemonit-1.png)  
*Diagram of how OpenLM interfaces with the RIB Presto License Manager*

:::note
OpenLM Broker must already be installed and configured to report to OpenLM before proceeding.
:::

1. Open the Broker web UI at `http://localhost:5090/`.  
2. Go to **License Managers** → **Add License Manager**.  
   ![](https://www.openlm.com/wp-content/uploads/2023/07/word-image-59543-2.png)  
3. From the drop-down, select **Presto** and enter any port number (e.g., 888) since only log file reading is used. Click **Add**.  
   ![](https://www.openlm.com/wp-content/uploads/2023/07/word-image-59543-3.png)  
4. In the **Vendors** tab, click **Add Vendor**, enter `RIB Presto`, and click **Continue**.  
   ![](https://www.openlm.com/wp-content/uploads/2023/07/word-image-59543-4.png)  
5. Go to the **Log Files** tab.  
   ![](https://www.openlm.com/wp-content/uploads/2023/07/word-image-59543-5.png)  
6. Click **Add Log File**.  
7. Browse to or manually enter the path to the RIB Presto log file.  
8. From the vendor list, select **RIB Presto**.  
9. Click **Save**.

## OpenLM Server configuration

### Automatic configuration via EasyAdmin

1. Open EasyAdmin at **Windows Start → OpenLM → OpenLM EasyAdmin User Interface**.  
2. Click the **Servers pending approval** icon.  
   ![](https://www.openlm.com/wp-content/uploads/2023/07/word-image-59543-6.png)  
3. Select the RIB Presto entry (displayed as **OpenLM Generic**).  
4. Optionally, enter a descriptive name and confirm the time zone.  
5. Click **Approve**.

The RIB Presto License Manager will be added automatically and begin reporting shortly.

### Manual configuration (if automatic fails)

1. In EasyAdmin, go to **Start → Administration → License Manager Servers**.  
2. Click **Add LM**.  
3. Set **Type** to **OpenLM Generic**.  
4. Enter a description (e.g., `RIB Presto`).  
5. Set the license server's time zone.  
6. Enter the **Hostname** and **Port** configured in the Broker.  
7. Turn **Use Broker** on.  
8. Click **Save**.

## Verify your configuration

1. Open EasyAdmin.  
2. Go to **Start → Widgets → License Servers**.  
3. Confirm the RIB Presto License Manager appears with a green status circle.

:::note
It may take up to 3 minutes for a new connection to show as active.
:::
