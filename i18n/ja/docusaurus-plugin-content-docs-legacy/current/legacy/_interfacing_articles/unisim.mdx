# UniSim

This document describes how to interface OpenLM with UniSim License Manager to monitor license usage and obtain statistics.

## Requirements

To query UniSim license manager, install:

1. OpenLM Server v5 or higher on a machine in your organization.
2. OpenLM Broker v4.14 or higher on the same machine as UniSim license manager.

## Monitoring capabilities and features

Current monitoring capabilities through OpenLM Broker:

| Feature | Resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Support | By minute | ❌ | ✔ | ✔ | ❌ | ❌ | ❌ |

Using Broker also enables buffered communication and the ability to start or stop the license manager service remotely.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with UniSim](https://www.openlm.com/wp-content/uploads/2022/01/word-image-71.png)
*Diagram of OpenLM interface with UniSim*

Broker queries UniSim locally via the **NetworkLicenceManager** tool and the UniSim log file. Once collected, data is sent to OpenLM Server.

Broker must be [installed](https://www.openlm.com/application-notes-v3-0/installing-openlm-v3-0/broker-comprehensive-installation-guide-an4004b/) and [configured](https://www.openlm.com/knowledge-base/openlm-broker-configuration/) to report to OpenLM Server before continuing.

### Manual configuration

If auto-detect does not work, add and configure the license manager manually:

1. Click **Add Port**.
2. Enter the UniSim LM port number (for example, 6607).
3. Select **UniSim** from the **License Manager Type** list. Click **Apply**.
4. Go to **Commands**. In **Update path for commands**, enter or browse to the UniSim installation root folder. Click **Update**, then **Apply**.
5. Broker automatically adds vendor name and log file path.
6. Click **Apply**.
7. Click **Restart Broker**.

![Broker UniSim manual configuration](https://www.openlm.com/wp-content/uploads/2022/01/word-image-72.png)

## OpenLM Server configuration

### Automatic configuration via EasyAdmin

If Broker is transmitting data, approve the configuration in EasyAdmin:

1. Open EasyAdmin in your browser or via **Windows Start → OpenLM → OpenLM EasyAdmin User Interface**.
2. Go to **Start → Administration → License Manager Servers**.
3. Double-click the UniSim License Manager entry that requires approval.

   ![Pending UniSim license manager in EasyAdmin](https://www.openlm.com/wp-content/uploads/2022/01/word-image-73.png)

4. Enter a display name.
5. Enable the license server.
6. Select **OpenLM Generic** as **Type**.
7. Verify hostname and port. Adjust if needed.
8. Set the **Timezone**.
9. Click **Approve**.

![Approved UniSim license manager in EasyAdmin](https://www.openlm.com/wp-content/uploads/2022/01/word-image-74.png)

At this point, UniSim License Manager is added and configuration is complete.

## How to verify configuration

1. Open EasyAdmin in a browser.
2. Go to **Start → Widgets → License Servers**.
3. Verify UniSim License Manager appears in the list. A green circle indicates an active connection.

![UniSim license manager with active connection](https://www.openlm.com/wp-content/uploads/2022/01/word-image-75.png)

If new, status may take up to three minutes to update.
