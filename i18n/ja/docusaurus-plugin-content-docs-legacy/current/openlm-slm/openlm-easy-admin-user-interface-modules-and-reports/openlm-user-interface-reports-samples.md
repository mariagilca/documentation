## **License Servers**

'Start' → 'Widgets' → "License Servers"

リアルタイムでライセンス使用状況と空き数（使用中のライセンス数と現在空いている数）を表示するライブウィジェットです。詳しくは [リンク](https://vimeo.com/263134338) を参照してください。

## **License Usage**

'Start' → 'Reports' → "License Usage"

強力な License usage レポートウィンドウは、総ライセンス数に対する単一または複数フィーチャーライセンスの消費状況を集計します。設定可能な期間とサンプル解像度でライセンス消費パターンを表示し、ライセンス在庫のボトルネックや冗長性の特定に役立ちます。このレポートは、表、チャート、ヒートマップの 3 つの形式で表示できます（表示ペインのタブで切り替え）。

## **Denials**

'Start' → 'Reports' → "Denials"

履歴のライセンス拒否イベントを表示します。OpenLM で利用可能な任意のディメンション（User、Group、Feature など）で集計できます。

## **License Utilization**

'Start' → 'Management' → "License Utilization"

このチャートはライセンス使用効率を示します。各列 'x' は "少なくとも x 本のライセンスが同時に使用されていた時間の割合" を示します。この表示は瞬間的なピークを無視し、実際のライセンス消費パターンを直感的に把握できます。組織に必要なライセンス数を示します。QoS ラインは、一定割合のライセンス要求を満たすために必要なライセンス数を示します。以下の例では、12 本中 7 本のライセンスがあれば 96% の要求を満たせることを示しています。詳細は [こちら](https://vimeo.com/263134354) を参照してください。

## **Licenses not in use**

'Start' → 'Management' → "Licenses not in use"

選択した期間における未使用のフィーチャーとライセンスの一覧を表示します。詳しくは [こちら](https://vimeo.com/263134369) を参照してください。

## **License Activity**

'Start' → 'Reports' → "License Activity"

License Activity ウィンドウは、システム管理者が高度なレポートを作成し、個々のユーザーのライセンス活動を追跡できる機能です。このウィンドウの "Group by" タブでは、Workstations、Features、Users、Groups、Projects によるライセンス統計レポートを生成できます。緑色で表示される線は現在アクティブなセッションを示します。

## **Active Users**

'Start' → 'Management' → "Active Users Report"

選択した期間内にライセンスをチェックアウトしてアクティブだったユーザーを表示します。

## **Project Usage Report**

'Start' → 'Reports' → "Project Usage"

プロジェクト指向の企業が、エンドユーザーが報告したアクティブプロジェクトに基づいてライセンス使用時間を取得できます。

## **Group Usage Report**

'Start' → 'Reports' → "Group Usage"

グループ別のライセンス使用統計を取得できます。

## **Feature Usage Per Group**

'Start' → 'Reports' → "Feature Usage Per Group"

選択したユーザーグループ（またはすべてのアクティブグループ）ごとの選択フィーチャー使用時間を、積み上げ縦棒グラフで表示します。チャートにカーソルを合わせると、バー各セクションの具体的な使用情報が表示されます。

## **Feature Usage Per User**

'Start' → 'Reports' → "Feature Usage Per User"

選択したユーザー（またはすべてのアクティブユーザー）ごとの選択フィーチャー使用時間を、積み上げ縦棒グラフで表示します。チャートにカーソルを合わせると、バー各セクションの具体的な使用情報が表示されます。

## **Licenses**

'Start' → 'Management' → "Licenses"

選択したライセンスマネージャーのライセンス一覧を表示します。

## **License Procurement**

'Start' → 'Management' → "License Procurement"

ベンダーファイル内の有効期限、パッケージなどの調達情報一覧を表示します。

## **Currently Consumed Licenses**

'Start' → 'Operational' → "Currently Consumed Licenses"

現在実行中のセッションを表示するライブウィジェットです。開始時刻、フィーチャー、グループ、ライセンスサーバー、ユーザー名などの関連情報が含まれます。

## **Dashboard**

'Start' → 'Dashboard'

最も使用されているフィーチャー、最長セッションなどの重要 KPI を含むダッシュボードです。
