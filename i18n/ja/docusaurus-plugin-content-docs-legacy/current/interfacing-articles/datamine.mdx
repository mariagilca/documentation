# Datamine

以下の手順で OpenLM を設定し、Datamine ライセンスマネージャーのライセンス使用状況を監視して統計情報を取得します。

## 要件

ライセンスマネージャーを問い合わせる前に、次を用意してください:

- 組織内のマシンに OpenLM Server v2.x をインストール済み  
- Datamine と同じマシンに OpenLM Broker v22.5 以降

## 監視機能

OpenLM Broker 経由で Datamine に対して利用できる監視機能は次のとおりです:

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 秒 | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Datamine license manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit-1.png)  
*OpenLM と Datamine ライセンスマネージャーの連携図*

:::note
OpenLM Broker は Datamine の `.csv` ログファイルを読み取り、処理したデータを OpenLM Server に送信します。
:::

### 手動設定（Broker デスクトップ UI）

1. **Add Port** をクリックします。  
2. Broker はログファイルのみを読み取るため、任意のポート番号（例: `888`）を入力します。  
3. **License Manager Type** から **Datamine** を選択し、**Apply** をクリックします。  
4. **Log Files** ノード → **Add Log File** に進みます。  
5. `LicenseServicesXXXXXXXX.csv` ログファイルのパスを指定します。  
6. 新しい **log** ノードを選択し、**[…]** をクリックして `.csv` ログファイルの場所を参照します。  
7. **Apply** をクリックします。  
8. **Restart Broker** をクリックします。

### 手動設定（Broker Web UI）

1. ブラウザで [http://localhost:5090/](http://localhost:5090/) を開きます。  
2. **License Managers → Add License Manager** に移動します。  
   ![](/img/legacy/word-image-74-2.png)  
3. **Datamine** を選択し、任意のポート番号（例: `888`）を入力して **Add** をクリックします。  
   ![](/img/legacy/word-image-75-2.png)  
4. **Log Files** で **Add Log File** をクリックします。  
5. `.csv` ログファイルの場所を入力するか参照します。  
   ![](/img/legacy/word-image-76-1.png)  
6. **Continue** をクリックし、続けて **Save** をクリックします。

## OpenLM Server の設定

### EasyAdmin による自動設定

1. EasyAdmin を開きます（**Start → Widgets → License Manager - Servers**）。  
2. Datamine のエントリをダブルクリックします。  
   ![](/img/legacy/word-image-78-1.png)  
3. （任意）接続名を変更し、種別は **OpenLM Generic** のまま **Approve** をクリックします。  
   ![](/img/legacy/word-image-79-1.png)

### EasyAdmin による手動設定

自動設定が失敗した場合:

1. **Start → Administration → License Manager Servers** に移動します。  
2. **Add LM** をクリックします。  
3. **Type** から **OpenLM Generic** を選択します。  
4. 説明（例: `Datamine`）を入力します。  
5. ライセンスサーバーの場所のタイムゾーンを設定します。  
6. Broker で設定した **Hostname** と **Port** を入力します。  
7. **Allow server fallback to denied license** のチェックを外します。  
8. **Use Broker** をオンにします。  
9. **Save** をクリックします。

## 設定の確認

1. ブラウザで EasyAdmin を開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に Datamine が表示され、緑色の丸アイコンになっていることを確認します。  

:::note
新しい接続の後、アクティブ表示まで最大 3 分かかることがあります。
:::
