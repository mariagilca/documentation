# Parasoft

以下の手順で OpenLM を設定し、Parasoft のライセンス使用状況を監視して統計情報を取得します。

## 要件

ライセンスマネージャーを問い合わせる前に、次を用意してください:

1. オンプレミスの OpenLM SLM v2.x（または OpenLM Cloud アカウント）
2. Parasoft ライセンスマネージャーと同じマシンに OpenLM Broker v24.11 以降

## 監視機能

| Broker の LM タイプ | コマンド | ログ | 数量 | 有効期限 | 拒否 | 借用 | 割り当て | レポート粒度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Parasoft | いいえ | はい | いいえ | いいえ | いいえ | いいえ | いいえ | 秒 |

Broker を使用すると、バッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Parasoft License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit.png)  
*OpenLM と Parasoft License Manager の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM SLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を `http://localhost:5090` で開きます。  
   既定ポートが使用中の場合は `5091` または `5092` を試してください。
2. **License Managers** → **Add License Manager** に移動します。
3. **LM Type** のドロップダウンから **Parasoft** を選択します。
4. ポート番号（例: `889`）を入力して **Add** をクリックします。

   ![](/img/legacy/word-image-94553-2.png)  
   *Adding Parasoft license manager in OpenLM Broker*

5. **Vendors** タブで **Add Vendor** をクリックし、`Parasoft` を入力して **Continue** をクリックします。

   ![](/img/legacy/word-image-94553-3.png)  
   *Adding Parasoft vendor in OpenLM Broker*

6. **Log Files** タブで **Add Log File** をクリックします。  
   **Watch file by pattern** をオフにします。複数のログを追加できます。**Continue** をクリックします。

7. **Save** をクリックします。

## OpenLM の設定

上記手順が完了すると、Broker は OpenLM SLM にデータを送信しているはずです。  
EasyAdmin UI で設定を承認します:

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. **Servers Pending Approval** のリンクをクリックします。

   ![](/img/legacy/word-image-94553-4.png)  
   *Pending license managers in EasyAdmin*

4. 保留中の Parasoft エントリをダブルクリックします（**OpenLM Generic** と表示されます）。
5. 設定内容を確認し、**Approve** をクリックします。

これで Parasoft が OpenLM SLM に追加されます。  
データの解析と表示まで少し時間がかかる場合があります。  
緑色の丸は接続がアクティブであることを示します。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. 一覧に Parasoft ライセンスマネージャーが表示され、緑色の丸のステータスになっていることを確認します。

:::note
新しい接続の後、ステータス更新まで最大 3 分かかることがあります。
:::
