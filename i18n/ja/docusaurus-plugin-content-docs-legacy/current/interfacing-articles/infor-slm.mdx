以下の手順で OpenLM を設定し、Infor SLM License Manager のライセンス使用状況を監視して統計情報を取得します。

## 要件

ライセンスマネージャーを問い合わせる前に、次を用意してください:

1. オンプレミスの OpenLM SLM v2.x（または OpenLM Platform アカウント）  
2. Infor SLM License Manager と同じマシンに OpenLM Broker v24.11 以降

## OpenLM Broker の設定

![Adding Infor SLM License Manager in OpenLM Broker](/img/legacy/word-image-94537-1.png)  
*OpenLM Broker で Infor SLM License Manager を追加*

:::note
OpenLM Broker は事前にインストールし、OpenLM SLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を `http://localhost:5090` で開きます。  
   既定ポートが使用中の場合は `5091` または `5092` を試してください。
2. **License Managers** → **Add License Manager** に移動します。
3. **LM Type** のドロップダウンから **Infor SLM** を選択します。
4. ポート番号（例: `4325`）を入力して **Add** をクリックします。
5. **Settings** タブに移動します。  
   - Broker がライセンスファイルのパスを自動検出する場合があります。  
   - 検出できない場合は **Set license file path manually** を選択し、`license.xml` を指定します。

   ![OpenLM Broker で Infor SLM のライセンスファイルのパスを設定。](/img/legacy/word-image-94537-2.png)  
   *OpenLM Broker で Infor SLM のライセンスファイルパスを設定*

6. **Commands** タブに移動し、**Data Inquiry** フィールドに Infor SLM のホストとポートを入力します。

   ![OpenLM Broker で Infor SLM のデータインクワイアリを設定。](/img/legacy/infor.png)  
   *OpenLM Broker で Infor SLM の Data Inquiry を設定*

7. **Save** をクリックし、続いて **Execute** をクリックして設定をテストします。

   ![OpenLM Broker での Infor SLM ライセンスマネージャーの実行成功出力。](/img/legacy/word-image-94537-4.png)  
   *Infor SLM ライセンスマネージャーの実行結果（成功）*

8. **Vendors** タブに移動し、**Add Vendor** をクリックして `Infor SLM` を入力し、**Continue** をクリックします。
9. **Save** をクリックします。

## OpenLM の設定

上記手順が完了すると、Broker は OpenLM SLM にデータを送信しているはずです。  
EasyAdmin UI で設定を承認します:

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. **Servers Pending Approval** のリンクをクリックします。

   ![EasyAdmin の承認待ちライセンスマネージャー。](/img/legacy/word-image-94537-6.png)  
   *EasyAdmin の承認待ちライセンスマネージャー*

4. 保留中の Infor SLM エントリをダブルクリックします（**OpenLM Generic** と表示されます）。

   ![EasyAdmin で OpenLM Generic として表示される承認待ちの Infor SLM ライセンスマネージャー。](/img/legacy/word-image-94537-7.png)  
   *EasyAdmin の承認待ち Infor SLM ライセンスマネージャー*

5. **Display Name** に任意の名前を入力します（例: `Infor SLM`）。
6. （任意）**Custom Fields** タブで国、使用範囲、説明などを追加します。

   ![EasyAdmin で Infor SLM ライセンスマネージャーのカスタムフィールドを追加。](/img/legacy/word-image-94537-9.png)  
   *Infor SLM ライセンスマネージャーにカスタム項目を追加*

7. 設定を確認して **Approve** をクリックします。

これで Infor SLM が OpenLM SLM に追加されます。ステータス更新には最大 3 分かかる場合があります。  
緑色の丸は接続がアクティブであることを示します。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. 一覧に Infor SLM ライセンスマネージャーが表示され、緑色の丸のステータスになっていることを確認します。

:::note
新しい接続の後、ステータス更新まで最大 3 分かかることがあります。
:::
