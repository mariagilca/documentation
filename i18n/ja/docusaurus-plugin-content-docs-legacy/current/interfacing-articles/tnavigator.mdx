以下の手順で OpenLM を設定し、tNavigator License Manager のライセンス使用状況を監視して統計情報を取得します。

## 要件

開始前に、以下を満たしていることを確認してください:

1. 組織内のマシンに OpenLM SLM v2x をインストール済み  
2. tNavigator License Manager と同じマシンに OpenLM Broker v23.8 以降をインストール

## 監視機能

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否 | 借用 | 有効期限 | 冗長 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 秒単位 | ✔ | ✔ | ❌ | ❌ | ✔ | ❌ |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the tNavigator License Manager](/img/legacy/how-openlm-interfaces-with-the-razorcatlicensemoni.png)  
*OpenLM と tNavigator License Manager の連携図*

:::note
OpenLM Broker は事前に [インストール](https://www.openlm.com/application-notes-v3-0/installing-openlm-v3-0/broker-comprehensive-installation-guide-an4004b/) し、OpenLM にレポートするよう [設定](https://www.openlm.com/Knowledgebase%20and%20articles/openlm-broker-configuration/) しておく必要があります。
:::

1. tNavigator ライセンスマネージャーのマシンで、`http://localhost:5090/` から Broker Web UI を開きます。  
2. **License Managers** → **Add License Manager** に移動します。  
   ![OpenLM Broker の Web UI で Add License Manager を開く。](/img/legacy/word-image-62604-2.png)  
3. ドロップダウンから **tNavigator** を選択し、ポート番号を入力して **Add** をクリックします。  
4. **Commands** タブで tNavigator License Manager のインストールパスを入力または参照します。  
5. **Execute** をクリックしてエラーがないことを確認します。  
6. **Vendors** → **Add Vendor** に移動し、`tNavigator` を入力して **Continue** をクリックします。  
7. **Log Files** → **Add Log File** に移動し、tNavigator のログファイルの場所を指定して **Watch File by Pattern** をオンにし、**Continue** をクリックします。  
8. **Save** をクリックします。

## OpenLM SLM の設定

### EasyAdmin による自動設定

1. **Windows Start → OpenLM → OpenLM EasyAdmin User Interface → Start → Widgets → License Manager Servers** で EasyAdmin を開きます。  
2. **Servers pending approval** のアイコンをクリックします。  
3. tNavigator のエントリ（**OpenLM Generic** と表示）を選択します。  
4. 必要に応じて表示名（例: `tNavigator`）を入力し、**Enabled** がオンであることを確認します。  
5. **Approve** をクリックします。

tNavigator License Manager は自動で追加され、しばらくするとレポートが開始されます。

## 設定の確認

1. EasyAdmin を開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に tNavigator License Manager が表示され、緑色の丸のステータスになっていることを確認します。

:::note
新しい接続がアクティブとして表示されるまで最大 3 分かかることがあります。
:::
