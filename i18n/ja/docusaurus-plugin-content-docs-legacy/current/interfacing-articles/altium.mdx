この連携により、OpenLM は Altium License Manager のライセンス使用状況、有効期限、拒否を監視できます。

## 要件

1. **OpenLM SLM**:
   - オンプレミスに Version 2.x をインストール、または  
   - **SLMC** アカウント。
2. **OpenLM Broker**:
   - Altium License Manager と同じマシンに Version 24.8 以降をインストール。

## 監視機能と特長

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスレポート | 有効期限レポート | 複数サーバー冗長 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 分単位 | ✔ | ✔ | ❌ | ❌ | ✔ | ❌ |

## OpenLM Broker の設定

1. ブラウザーで `http://localhost:5090`（または 5091、5092 などの設定済みポート）を開きます。
2. **License Managers** タブで **Add License Manager** をクリックします。
3. ポップアップで次を設定します:
   - ドロップダウンから **Altium** を選択  
   - ポート番号を入力（例: `9780`）  
   - **Add** をクリック  
   ![スクリーンショット: OpenLM Broker configuration](/img/legacy/word-image-42160-1-1.png)
4. **Commands** タブで次を行います:
   - **Data Inquiry** が Altium インスタンスに正しく設定されていることを確認します。  
   - `C:\Program Files\OpenLM\OpenLM Broker\` の `altium@<port>` ファイルを編集し、Altium のユーザー名とパスワードを追加します。  
   - 保存して Broker 画面に戻ります。  
   - **Execute** をクリックして正しいデータ出力を確認します。  
5. **Vendors** タブで次を行います:
   - **Add Vendor** をクリック  
   - ベンダー名に **Altium** を入力  
   - **Continue** をクリック  
     ![スクリーンショット 2: OpenLM Broker configuration](/img/legacy/word-image-42160-2-1.png)
6. **Save** をクリックして Broker の設定を完了します。

## OpenLM Server の設定

### EasyAdmin による自動設定

1. **EasyAdmin** を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. **Pending Approval** のアイコンをクリックします。
4. 保留中の Altium サーバー（**OpenLM Generic** と表示）をダブルクリックします。
5. 設定を確認して **Approve** をクリックします。  
   ![スクリーンショット: Automatic configuration through EasyAdmin](/img/legacy/word-image-42160-3.png)

緑色の丸は接続がアクティブであることを示します。新しい接続のステータス更新には最大 3 分かかる場合があります。

### リモートサンプリングによる手動設定

自動設定が失敗した場合:

1. EasyAdmin で **Start → Administration → License Manager server** に移動します。
2. **Add LM** をクリックします。
3. 説明を入力します（例: “Altium License Server”）。
4. **Type** のドロップダウンから **Altium** を選択します。
5. 次を入力します:
   - **LM Address**（Altium をホストするサーバーアドレス）
   - Altium Infrastructure Server の **Username** と **Password**
6. **Time Zone** を Altium サーバーに合わせます。
7. **TEST CONNECTION** をクリックし、成功のポップアップが表示されることを確認します。  
   ![スクリーンショット: Manual configuration through remote sampling](/img/legacy/word-image-42160-4.png)
8. **Save** をクリックします。  
   ![スクリーンショット 2: Manual configuration through remote sampling](/img/legacy/word-image-42160-5.png)

Altium サーバーは OpenLM と連携できる状態になりました。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Servers** に移動します。
3. Altium が一覧に表示され、ステータスが緑であることを確認します。
