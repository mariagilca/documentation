OLicense は [OpenLM がサポートするライセンスマネージャー](https://www.openlm.com/license-manager-capabilities/) の 1 つです。  
本ガイドでは、OpenLM を OLicense-Server と連携し、ライセンス使用状況を監視して統計情報を取得する方法を説明します。

OLicense-Server を問い合わせる方法は 2 通りあります:

- **直接方式**: OpenLM SLM がライセンスサーバーをリモートで問い合わせます。  
- **Broker 方式**: OLicense-Server マシンに OpenLM Broker をインストールし、ローカルで問い合わせて OpenLM SLM に送信します。  

## OpenLM SLM のみで問い合わせ（直接方式）

![OpenLM Server interfacing directly with the license manager](/img/legacy/openlm-server-interfacing-directly-with-the-lm-2.png)  
*OpenLM SLM と OLicense の直接連携*

### EasyAdmin の設定

1. OpenLM SLM をインストールします。  
2. **EasyAdmin** → **Start → Administration → License Manager Servers** を開きます。  
3. **LM Tools** で LM type から **OLicense** を選択します。  
4. OLicense をインストールしているマシンから `olixtool.exe` をコピーします。  
   - 既定パス: `C:\Program Files\optimum\olicense`  
   - コピー先: `C:\Program Files\OpenLM\OpenLM Server\LM`  
5. EasyAdmin で **Full path to the OLicense executable** にコピーした `olixtool.exe` のパスを設定します。  
6. **SAVE** をクリックします。  

![Configure OLicense in EasyAdmin](/img/legacy/word-image-42315-2.png)  
*EasyAdmin の OLicense 設定*

### OLicense サーバーの追加

1. **EasyAdmin** で **Start → Administration → License Manager Servers** に移動します。  
2. **Add LM** をクリックします。  
3. **Display name** にわかりやすい名前（例: *OLicense central*）を入力します。  
4. **Type** から **OLicense** を選択します。  
5. トグルを設定します:  
   - **Use Broker**:  
     - *Off*（既定）: OpenLM SLM が OLicense を直接問い合わせます。  
     - *On*: OpenLM Broker が使用状況情報を提供します。  
   - **Is Triad Configuration**: *Off* のままにします。  
6. OLicense-Server の **Hostname** と **Port** を入力します（既定ポート: **80**）。  
7. **Time Zone** を選択します。  
8. **SAVE** をクリックします。  

![Adding OLicense server](/img/legacy/word-image-42315-3.png)  
*EasyAdmin で OLicense サーバーを追加*

## OpenLM Broker で問い合わせ

OpenLM Broker は任意ですが推奨です。OLicense をローカルで問い合わせて OpenLM SLM に送信し、ネットワーク障害時のバッファ付き通信を確保します。

![Broker interface with log and license files](/img/legacy/broker-interface-with-log-and-license-files-3.png)  
*OLicense に対する OpenLM Broker 設定*

### OpenLM SLM の設定（Broker 利用）

上記のサーバー設定手順を繰り返し、**Use Broker = On** にします。  

![Server setup with Broker](/img/legacy/word-image-42315-5.png)  
*Broker 有効時の EasyAdmin 設定*

### OpenLM Broker の設定

1. [ダウンロード](https://www.openlm.com/downloads/) して最新の OpenLM Broker をインストールします。  
2. 正しいポート（既定: **80**）で OLicense を監視するよう Broker を設定します。  
   ![OLicense port setup](/img/legacy/word-image-42315-6.png)  
   *Broker で OLicense のポートを設定*  
3. Broker の各フィールドを EasyAdmin の設定に合わせます。  
4. **Commands** ノードで `olixtool.exe` のパスを設定します。  
   ![Command path setup](/img/legacy/word-image-42315-7.png)  
   *Broker でコマンドパスを設定*  
5. **status** と **data_inquiry** で **Execute** をクリックしてテストします。  
6. **Apply** をクリックし、Broker を再起動します。  
   ![Broker restart](/img/legacy/word-image-42315-8.png)  
   *設定後に Broker を再起動*

## 代替: Broker Web UI の手動設定

1. 最新の OpenLM Broker をインストールします。  
2. [Broker Web UI](http://localhost:5090/) を開きます。  
3. **License Managers** に移動します。  
   - OLicense が自動検出された場合は確認して保存します。  
   - 検出されない場合は **Add License Manager** → **OLicense** を選択 → ポート（既定: 80）を入力 → **ADD**。  
   ![Add OLicense manually](/img/legacy/word-image-42315-9.png)  
   *Broker で OLicense を手動追加*  
4. **Commands** で `olixtool.exe` のパスを設定し、**Execute** で出力を確認します。  
   ![Executable path](/img/legacy/word-image-42315-10.png)  
   *Broker Web UI でコマンドパスを設定*  
5. **Vendors** で **Add Vendor** → “OLicense” を入力 → **Continue**。  
6. **SAVE** をクリックします。  
7. OpenLM SLM を上記手順で設定します。  

## EasyAdmin での確認

1. **EasyAdmin** を開きます（`http://<OpenLM Server>:5015`）。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に OLicense が表示されることを確認します。  
   - **緑色の丸アイコン** は接続が有効であることを示します。
