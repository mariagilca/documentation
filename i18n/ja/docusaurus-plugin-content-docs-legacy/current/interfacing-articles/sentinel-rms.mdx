本ガイドでは、OpenLM を Sentinel RMS と連携し、ライセンス使用状況を監視して統計情報を生成する方法を説明します。

## 要件

Sentinel RMS を問い合わせるには:

- 組織内のマシンに OpenLM Server v4.3 以降をインストール済み（または Cloud アカウントを使用）。  
- （任意）Sentinel RMS マシンに OpenLM Broker v4.x 以降をインストールし、高度な監視機能を有効化。  

## 監視機能

監視機能は OpenLM Server のみを使うか、OpenLM Broker と併用するかで異なります。

| 機能                  | 粒度   | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
|---------------------------|--------------|----------------|---------------|-------------------|----------------------------|---------------------------|----------------------------|
| 対応                   | 秒    | ✔              | ✔             | ✔                 | ✔                          | ✔                         | ❌                        |

- 黄色セル: OpenLM Server で利用可能な機能。  
- 青色セル: OpenLM Server + Broker で追加される機能。  

Broker を使用すると、バッファ付き通信とライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Server のみで監視

![Diagram of how OpenLM interfaces with Sentinel RMS using OpenLM Server only](/img/legacy/word-image-42333-6.png)
*OpenLM Server が Sentinel RMS を直接問い合わせる構成*

OpenLM Server は RMS のコマンドラインツール経由で Sentinel RMS を直接問い合わせます。この方法ではライセンス総数と使用状況のみ取得できます。

### LM Tools の設定

OpenLM Server が Sentinel RMS を問い合わせられるようにするには:

1. Sentinel RMS マシンから `lsmon.exe`、`lservnt.exe`、`lsapiw32.dll` をコピーします（例:  
   `C:\Program Files (x86)\Common Files\SafeNet Sentinel\Sentinel RMS License Manager\WinNT`）。  
   OpenLM Server のインストールフォルダに配置します（例:  
   `C:\Program Files\OpenLM\OpenLM Server\LM`）。
2. **EasyAdmin → Start → Administration → License Manager Servers** を開きます。
3. LM type を **RMS** に設定します。
4. RMS 実行ファイル（`lsmon.exe`）のフルパスを設定します。
5. **Save** をクリックします。

![LM Tools configuration in OpenLM](/img/legacy/word-image-42333-7.png)
*Sentinel RMS の LM Tools 設定*

### Sentinel RMS サーバーの追加

設定後:

1. **License Servers** タブを開きます。
2. **Add LM** をクリックします。
3. **Display Name** を入力します。
4. LM type に **RMS** を選択します。
5. **Server Host Name** と **Port**（例: 5093）を入力します。
6. 正しい **Time Zone** を設定します。
7. **Use Broker** を **off** にします。
8. **Save** をクリックします。

![Adding a new Sentinel RMS server](/img/legacy/word-image-42333-8.png)
*EasyAdmin で Sentinel RMS サーバーを追加*

## OpenLM Server + Broker で監視

![Diagram of how OpenLM interfaces with Sentinel RMS using OpenLM Broker](/img/legacy/word-image-42333-9.png)
*OpenLM Broker が Sentinel RMS をローカルで問い合わせる構成*

Broker が RMS のコマンドラインユーティリティとログファイルでローカル問い合わせを行うと、フル監視が可能になります。Broker がデータを OpenLM Server に送信します。

:::note
続行する前に OpenLM Broker をインストールして設定してください。  
[Broker インストールガイド](https://www.openlm.com/application-notes-v3-0/installing-openlm-v3-0/broker-comprehensive-installation-guide-an4004b/) と [Broker 設定ガイド](../openlm-broker/openlm-broker-configuration.md) を参照してください。
:::

### Sentinel RMS の使用状況ログを有効化

既定では RMS は使用状況ログを記録しません。`lservnt`/`lserv` の起動コマンドに `-l <usage-log-filename>` を付けるか、環境変数 `LSERVOPTS` で有効化します。  

詳細は [Sentinel RMS ドキュメント](https://docs.sentinel.gemalto.com/softwareandservices/rms/RMSDocumentation/SysAdmin/Content/Configuring_%20License_Manager.htm) を参照してください。

拒否監視にはログが必要です。

### OpenLM Broker の設定

#### 自動検出

Broker 設定ツールで:

1. **Detect** をクリックします。  
   Sentinel RMS サービスが稼働していれば、Broker がポートとユーティリティパスを自動検出します。  

:::tip
検出ではすべての設定が反映されない場合があります。必要に応じて手動設定を行ってください。
:::

![Broker auto-detection](/img/legacy/word-image-42333-10.png)
*Broker の自動検出*

#### 手動設定

検出が失敗した場合:

1. **Add Port** をクリックし、RMS ポート（例: 5093）を入力します。
2. ライセンスマネージャータイプに **RMS** を選択します。
3. **Commands** で RMS ユーティリティのパスを更新します。
4. （Windows のみ）**Use Service** をオンにし、*Sentinel RMS License Manager* を入力します。
5. **Apply** をクリックします。
6. **data_inquiry** を実行して有効な出力を確認します。
7. **Log Files** に RMS の使用状況ログを追加します。
8. Broker を再起動します。

![Manual Broker configuration](/img/legacy/word-image-42333-11.png)
*手動での Broker 設定*

### Broker UI の設定

ブラウザで Broker UI を使用する場合:

1. **License Manager** → **Add License Manager** に移動します。
2. **RMS** を選択し、ポートを入力して追加します。
3. 実行ファイルパスを確認します。
4. （Windows のみ）サービスを *Sentinel RMS License Manager* に設定します。
5. **data_inquiry** を実行して出力を確認します。
6. 必要に応じてベンダー情報を追加します。
7. RMS 使用状況ログ用に **Log Files** を設定します。
8. 変更を保存します。

![Broker UI configuration](/img/legacy/word-image-42333-16.png)
*Broker UI の RMS 設定*

### OpenLM Server の設定

Broker が正しく設定されていれば、Sentinel RMS は OpenLM Server に自動追加されます。  

自動設定が失敗した場合は手動で設定します:

1. OpenLM Server 設定で Sentinel RMS サーバーを追加します。  
2. Broker の設定に合わせてホスト名とポートを入力します。  
3. **Use Broker** をオンにします。  
4. **Save** をクリックします。  

## トークン計算の有効化（Server v24.6+）

既定ではトークン計算は無効です。有効化するには:

1. `appsettings.json` をバックアップします。
2. ファイルを開きます（既定: `C:\Program Files\OpenLM\OpenLM Server\bin`）。
3. 次のセクションを見つけます:

```json
},
"AspenTokens": {
    "AspenTechTokensFile": "../config/aspen_tokens_breakdown.json",
    "EnableTokenCalculations": false
}
```

4. `EnableTokenCalculations` を `true` に変更します:

```json
},
"AspenTokens": {
    "AspenTechTokensFile": "../config/aspen_tokens_breakdown.json",
    "EnableTokenCalculations": true
}
```

5. ファイルを保存します。
6. OpenLM Server を再起動します:

```shell
net stop "OpenLM Server"
net start "OpenLM Server"
```

7. OpenLM Server でトークン計算が有効になっていることを確認します。

## Sentinel RMS 設定の確認

監視が有効であることを確認するには:
1. EasyAdmin UI を開きます。
2. **Start → Widgets → License Servers** に移動します。
3. Sentinel RMS サーバーが一覧に表示されることを確認します。

緑色の丸アイコンは接続が有効であることを示します。  
新しい接続の場合、アクティブ表示まで最大 3 分かかることがあります。
