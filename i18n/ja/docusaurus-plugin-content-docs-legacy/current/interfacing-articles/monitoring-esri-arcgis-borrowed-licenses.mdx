# ESRI ArcGIS の借用ライセンスの監視

## 概要

ライセンスの借用 (License Borrowing) は、ライセンスプール内の単一ライセンスを特定のワークステーションに紐づける方法です。この手順により、ライセンスはライセンスマネージャー上で継続的に使用中としてマークされ、ユーザーは指定期間ライセンスを借用してライセンスマネージャーに接続せずにアプリケーションを利用できます。

## OpenLM は ESRI ライセンス借用者の身元を表示します

ESRI ライセンス管理者は、lmutil -lmstat コマンドによるライセンスサーバーの問い合わせでは借用者が特定できないことを長年認識してきました。代わりに借用者は「Activated License(s)」と表示され、今必要なライセンスを誰が使っているのか把握しづらい状態です。

## 監査ログ情報

OpenLM Server は複数の情報源を組み合わせて、ライセンス借用者の身元を特定します。使用状況はライセンスサーバーの問い合わせで取得し、借用ライセンスとユーザーの対応付けは ESRI 監査ログで行います。

## OpenLM Broker

OpenLM Broker はライセンスサーバーマシン上で動作するオプションのコンポーネントです。Broker の重要な利点の一つは、監査ログ情報を読み取り、それを OpenLM Server に伝達できることです。OpenLM Server はその情報から ESRI ライセンスの借用者を抽出します。

これは ESRI ArcGIS ライセンスの使用状況を監視・管理・最適化するための、OpenLM のユニークな機能の一つです。

## 手順

OpenLM Server と OpenLM Broker のインストール方法、および監査ログファイルの読み取り方法については、[こちらのドキュメント](./flexlm) を参照してください。
