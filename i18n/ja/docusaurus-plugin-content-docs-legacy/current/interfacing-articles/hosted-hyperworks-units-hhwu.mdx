# Hosted HyperWorks Units (HHWU)

以下の手順で OpenLM を設定し、Hosted HyperWorks Units (HHWU) License Manager のライセンス使用状況を監視して統計情報を取得します。

## 要件

開始前に次をインストールしてください:

1. 組織内のマシンに OpenLM Server v2.x
2. HHWU License Manager と同じマシンに OpenLM Broker v22.6 以降

## 監視機能

| Broker の LM タイプ | ライセンス総数 | ライセンス使用状況 | 拒否 | 借用 | 有効期限 | 冗長化 | レポート粒度 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| HHWU | はい | はい | いいえ | いいえ | はい | いいえ | 分 |

Broker を使用すると、バッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with HHWU](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit-1.png)  
*OpenLM と HHWU License Manager の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM Server へレポートするよう設定しておく必要があります。
:::

### 方法 1 — Broker デスクトップ UI

1. OpenLM Broker デスクトップアプリケーションを開きます。
2. **Add Port** をクリックします。
3. ポート番号（例: `888`）を入力します。
4. **License Manager Type** から **Hosted HyperWorks Units (HHWU)** を選択して **Apply** をクリックします。

   ![スクリーンショット: Method 1 — Broker desktop UI](/img/legacy/word-image-91877-2-1.png)

5. **Commands** ノードに移動します。**Update path for commands** で HHWU コマンドラインユーティリティのあるフォルダを参照し、**Update** をクリックします。
6. **data_inquiry** で **Execute** をクリックし、有効な出力を確認します。**Execute** を再度実行する前に **Apply** をクリックします。  
   このコマンドで問い合わせる内容:  
   - ベンダーのライセンスファイルに登録されたライセンス総数  
   - ユーザーにより現在チェックアウトされているライセンス数  
7. **Vendors** でベンダー名に `Altair` を入力し、**Apply** をクリックします。
8. Broker を再起動します。

### 方法 2 — Broker Web UI

1. Broker Web UI を `http://localhost:5090` で開きます。  
   既定ポートが使用中の場合は `5091` または `5092` を試してください。
2. **License Managers** → **Add License Manager** に移動します。
3. ドロップダウンから **Hosted HyperWorks Units (HHWU)** を選択し、ポート番号を入力して **Add** をクリックします。

   ![スクリーンショット: Method 2 — Broker web UI](/img/legacy/word-image-91877-5-1.png)

4. **Commands** で **Executable path** を HHWU コマンドラインユーティリティのあるフォルダに設定し、**Execute** をクリックします。

   ![スクリーンショット 2: Method 2 — Broker web UI](/img/legacy/word-image-91877-6-1.png)

5. **Vendors** で **Add Vendor** をクリックし、`Altair` を入力して **Continue** をクリックします。

   ![スクリーンショット 3: Method 2 — Broker web UI](/img/legacy/word-image-91877-7-1.png)

6. **Save** をクリックします。

## OpenLM Server の設定

Broker の設定後、EasyAdmin でライセンスマネージャーを承認します:

1. EasyAdmin を開きます。
2. **License Servers** で新しい HHWU エントリの赤い行をダブルクリックします。
3. わかりやすい名前を入力するか既定のままにし、**Type** を **OpenLM Generic** のまま **Approve** をクリックします。

自動設定が失敗した場合は手動で設定します:

1. **Start → Administration → License Manager Servers** に移動します。
2. **Add LM** をクリックします。
3. **Type** を **Hosted HyperWorks Units (HHWU)** に設定します。
4. 説明（例: `HHWU`）を入力します。
5. ライセンスサーバーの場所に合わせて **Time Zone** を設定します。
6. Broker 設定のホスト名とポートを入力します。
7. **Triad Configuration** をオフにし、**Use Broker** をオンにします。
8. **Save** をクリックします。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Servers** に移動します。
3. HHWU エントリが緑色の丸アイコンで表示されることを確認します。

:::note
新しい接続の後、ステータス更新まで最大 3 分かかることがあります。
:::
