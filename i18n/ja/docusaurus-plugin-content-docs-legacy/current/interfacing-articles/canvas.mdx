# Canvas

本書では、OpenLM を Canvas と連携してライセンス使用状況を監視し、統計情報を取得するための手順を説明します。

## 要件

Canvas を問い合わせるには、次のコンポーネントをインストールしてください:

1. 組織内のマシンに OpenLM SLM v2.x（または SLMC アカウント）
2. Canvas LicenseMonitor と同じマシンに OpenLM Broker v25.2 以降

## 監視機能

OpenLM Broker 経由で Canvas に対して利用できる監視機能は次のとおりです:

| Broker の LM タイプ | コマンド | ログ | 数量 | 有効期限 | 拒否 | 借用 | 割り当て | レポート粒度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Canvas | いいえ | はい | いいえ | いいえ | いいえ | いいえ | いいえ | 秒 |

Broker を使用すると、バッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Canvas License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit-1.png)  
*OpenLM と Canvas License Manager の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM へレポートするよう設定しておく必要があります。
:::

1. ブラウザで [http://localhost:5090](http://localhost:5090) を開きます。  
   5090 が使用中の場合は 5091 や 5092 などの別ポートを使用します。
2. **License Managers** タブを選択します。
3. **Add License Manager** をクリックします。  
   ポップアップが表示されます。
4. **LM Type** のドロップダウンから **Canvas** を選択します。
5. Canvas のポート番号（例: `5093`）を入力して **Add** をクリックします。

   ![スクリーンショット: OpenLM Broker configuration](/img/legacy/word-image-98722-2.png)  
   *OpenLM Broker で Canvas ライセンスマネージャーを追加*

6. **Vendors** タブを選択し、**Add Vendor** をクリックします。  
   ポップアップでベンダー名に `Canvas` を入力し、**Continue** をクリックします。

   ![スクリーンショット 2: OpenLM Broker configuration](/img/legacy/word-image-98722-3.png)  
   *OpenLM Broker で Canvas ベンダーを追加*

7. **Log Files** タブに切り替え、**Add Log File** をクリックします。  
   **Watch file by pattern** が **off** になっていることを確認します。  
   必要に応じて複数のログを追加できます。アクティビティログの場所を参照して **Continue** をクリックします。

   ![スクリーンショット 3: OpenLM Broker configuration](/img/legacy/word-image-98722-4.png)  
   *OpenLM Broker で Canvas のログファイルを追加*

8. **Save** をクリックします。

## OpenLM の設定

上記手順が完了すると、OpenLM Broker は OpenLM にデータを送信しているはずです。  
最後に EasyAdmin UI で設定を承認します:

1. EasyAdmin にアクセスし、**Start → Widgets → License Manager Servers** に移動します。
2. **Servers Pending Approval** のアイコンをクリックします。

   ![スクリーンショット: OpenLM configuration](/img/legacy/word-image-98722-5.png)  
   *EasyAdmin の保留中ライセンスマネージャー*

3. 保留中のライセンスマネージャーをダブルクリックします。  
   **OpenLM Generic** と表示されます。

   ![スクリーンショット 2: OpenLM configuration](/img/legacy/word-image-98722-6.png)  
   *EasyAdmin の保留中 Canvas ライセンスマネージャー*

4. （任意）表示名を変更し、設定を確認して **Approve** をクリックします。

   ![スクリーンショット 3: OpenLM configuration](/img/legacy/word-image-98722-7.png)  
   *EasyAdmin で Canvas ライセンスマネージャーを承認*

5. （任意）**Custom Fields** タブに切り替えて、国、使用範囲、説明などを追加します。

   ![スクリーンショット 4: OpenLM configuration](/img/legacy/word-image-98722-8.png)  
   *Canvas ライセンスマネージャーのカスタムフィールド*

これで Canvas が OpenLM SLM に追加され、設定は完了です。  
データの解析と反映には少し時間がかかる場合があります。  
緑色の丸アイコンは接続が有効であることを示します。

## Canvas の設定確認

1. ブラウザで EasyAdmin を開きます。
2. **Start → Widgets → License Servers** に移動します。
3. 設定したライセンスマネージャーが一覧に表示されることを確認します。  
   緑色の丸アイコンは接続が有効であることを示します。

   ![スクリーンショット: How to verify your Canvas configuration](/img/legacy/word-image-98722-9.png)  
   *EasyAdmin の緑色の丸アイコンは接続が有効であることを示します*

:::note
新しい接続の場合、ステータス更新まで最大 3 分かかることがあります。
:::
