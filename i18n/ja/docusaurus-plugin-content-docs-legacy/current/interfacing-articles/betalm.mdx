# BetaLM

OpenLM は、幅広い [ライセンスマネージャー](https://www.openlm.com/software-license-management/) の監視に対応しており、対応範囲は拡大し続けています。

本ガイドでは、OpenLM を BetaLM ライセンスマネージャーと連携させ、ライセンス使用状況を監視して統計情報を収集するための設定方法を説明します。

BetaLM ライセンスサーバーを問い合わせる方法は 2 通りあります:

- OpenLM Server からライセンスサーバーを直接問い合わせる。  
- ライセンスサーバーに OpenLM Broker をインストールし、ローカルで問い合わせて結果を OpenLM Server に転送する。

## オプション 1: OpenLM 直接サーバー方式 {#option-one-openlm-direct-server-method}

![OpenLM Server interfacing directly with the LM](/img/legacy/openlm-server-interfacing-directly-with-the-lm-6.png)

### OpenLM Server の設定

OpenLM が BetaLM ライセンスサーバーにアクセスできるようにするには:

1. **EasyAdmin** を開きます。  
2. **Start → Administration → License Manager Servers** に移動します。  
3. **LM Tools** をクリックします。  
4. **LM Type** から **BetaLM** を選択します。  
5. `beta_lm_stat.exe` を `C:\Program Files\OpenLM\OpenLM Server\LM\` にコピーし、フルパスを入力します。  
6. **Save** をクリックします。

![OpenLM Server BetaLM configuration](/img/legacy/word-image-42306-2.png)

### BetaLM サーバーの追加

1. **LM Servers** に切り替えます。  
2. **Add LM** をクリックします。  
3. **Display name** にわかりやすい名前を入力します。  
4. **Type** から **BetaLM** を選択します。  
5. **Hostname** と **Port** を入力します（既定: 6007）。  
6. ライセンスサーバーの **Time Zone** を正しく設定します。  
7. 冗長構成を使用する場合は **Triad Configuration** を有効にできます（すべてのライセンスマネージャーが対応しているわけではありません）。  
8. **Use Broker** を設定します:  
   - **Off**（既定）: OpenLM Server がライセンスマネージャーを直接問い合わせます。  
   - **On**: ライセンスサーバーにインストールされた Broker を使用します。  
9. **Save** をクリックします。

![Add BetaLM license server](/img/legacy/word-image-42306-3.png)

これで OpenLM Server が BetaLM を問い合わせ、EasyAdmin に結果を表示できるようになります。

## オプション 2: OpenLM Broker 経由

![Broker interface with log and license files](/img/legacy/broker-interface-with-log-and-license-files-8.png)

OpenLM Broker は任意ですが推奨です。BetaLM ライセンスサーバーにインストールすると、ローカル問い合わせと OpenLM Server へのバッファ付き通信が可能になります。これにより一時的なネットワーク障害時のデータ損失を防げます。

### OpenLM Server の設定

[オプション 1](#option-one-openlm-direct-server-method) と同じ手順で設定し、**Use Broker** をオンにします。

### OpenLM Broker の設定

1. 最新の **OpenLM Broker** をダウンロードしてインストールします。  
2. **Add Port** をクリックします。  
3. BetaLM ライセンスサーバーのポート（既定: 6007）を入力します。  
   :::note  
   ポート番号は OpenLM Server の設定と完全に一致させる必要があります。  
   :::  
4. **status** と **data_inquiry** の各ノードに `beta_lm_stat.exe` のフルパスを入力します。例:  
    ```
    C:\Program Files\OpenLM\OpenLM Server\LM\beta_lm_stat.exe
    ```
   続けて **Apply** をクリックします。

![Broker command configuration](/img/legacy/word-image-42306-5.png)

5. **Restart Broker** をクリックします。  
6. または `http://localhost:5090/` の **Broker Web UI** から設定します。

## EasyAdmin で設定を確認

BetaLM が監視されていることを確認するには:

1. ブラウザで `http://<OpenLM Server hostname>:5015` にアクセスし、**EasyAdmin** を開きます。  
2. 設定した BetaLM ライセンスサーバーが一覧に表示されていることを確認します。  
3. 緑色の丸アイコンは接続が有効であることを示します。  

有効になったら、BetaLM のライセンス使用状況データがレポートやダッシュボードで利用できます。
