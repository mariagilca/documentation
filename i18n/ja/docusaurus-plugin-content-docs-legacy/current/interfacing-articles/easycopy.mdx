## 概要

OpenLM は、[Flexera FlexNet Publisher](/supported-software) (FlexLM) や Sentinel RMS など、幅広いネットワークライセンスの監視に対応する[ライセンス管理/監視システム](https://www.openlm.com/software-license-management/)です。  

**EasyCopy** はエンジニアリング、地球科学、ライフサイエンス向けのグラフィックソリューションを提供します。  
OpenLM は [EasyCopy のビジネスパートナー](https://www.openlm.com/knowledge-base/openlm-is-an-easycopy-business-partner/) です。  

本記事では **EasyCopy License Manager** を監視し、ライセンス使用状況レポートを生成するための設定方法を説明します。この機能は EasyCopy **8.7.12 以降**で利用できます。

## 前提条件

EasyCopy のライセンス使用状況を監視するには次を用意してください:

- EasyCopy ライセンスサーバーに **OpenLM Broker** をインストール済み。  
- ネットワーク内の任意の Windows マシンに **OpenLM SLM** をインストール済み（同一マシンでも可）。  

Broker が EasyCopy ライセンスサーバーをローカルで問い合わせ、OpenLM SLM にデータを転送します。

![How Broker interfaces EasyCopy License Manager with OpenLM Server](/img/legacy/how-broker-interfaces-with-openlm-server-1.png)

## OpenLM を EasyCopy と連携する設定

### OpenLM SLM の設定

1. OpenLM SLM をダウンロードしてインストールします。  
2. EasyAdmin で **Administration → License Manager Servers → Add LM → Type** に移動します。  
   ![OpenLM Server Add LM](/img/legacy/word-image-42320-2.png)  
3. 説明（例: *My EasyCopy license server*）を入力します。  
4. **Type** のドロップダウンから **OpenLM Generic** を選択します。  
5. ライセンスサーバーの **Time Zone** を設定します。  
6. **Hostname** に EasyCopy サーバー名（例: *easycopy_server*）を入力します。  
7. **Port**: EasyCopy は特定のポートを使用しません。任意の 3 桁の番号を入力します。  
   - Broker の設定でも同じ番号を使用します。  
8. **Use Broker**: チェックをオンにします。  
   - 有効にすると、使用状況情報はサーバー上の Broker により収集されます。  
9. **Allow Server fall back to denied license**: 他の EasyCopy サーバーからライセンス取得に成功した場合に拒否を無視する場合は有効にします。  
   ![Allow Server Fallback](/img/legacy/word-image-42320-3.png)  
10. **Custom fields** タブに切り替え、**Country**、**Usage Scope**、**Description** などの詳細を入力します。  
    ![Custom fields](/img/legacy/word-image-42320-4.png)  
11. **Save** をクリックします。  

### OpenLM Broker の設定

1. [最新の OpenLM Broker をダウンロードしてインストール](../openlm-broker/index.md)します。  
2. OpenLM SLM のホスト名（例: *my_openLM_server*）を入力します。  
3. OpenLM SLM のポート（既定 **5015**）が受信通信で開いていることを確認します。  
4. 新しいポートを追加し、種別を **OpenLM Generic** に設定します。  
5. OpenLM SLM で設定したライセンスサーバー名とポート番号（例: *easycopy_server*, *123*）を入力します。  
   ![Broker license server configuration](/img/legacy/word-image-42320-5.png)  
6. **status** と **data_inquiry** のコマンド欄に EasyCopy 実行ファイルのフルパスを入力します:  

   ```bash
   eclic.exe openlm
   ```

7. **Apply** をクリックし、続けて **Restart Broker** をクリックします。

## 代替: Broker Web UI の手動設定

1. 最新の OpenLM Broker をインストールします。  
2. Broker Web UI を `http://localhost:5090/` で開きます。  
3. **License Managers** タブに移動します。  
4. **Add License Manager** をクリックします。LM type で **OpenLM Generic** を選択し、ポート（例: 123）を入力して **Add** をクリックします。  
5. **Commands** タブで `eclic.exe openlm` のパスを入力し、**Execute** をクリックして出力を確認します。  
6. **Vendors** タブで **Add Vendor** をクリックし、`EasyCopy` を入力します。  
7. **Save** をクリックします。

## 設定の確認

1. EasyAdmin Web アプリを開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に EasyCopy ライセンスサーバーが表示されることを確認します。  
   緑色の丸アイコンは接続が有効であることを示します。
