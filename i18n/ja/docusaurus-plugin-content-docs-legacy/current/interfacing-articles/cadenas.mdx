以下の手順で OpenLM を設定し、CADENAS Server のライセンス使用状況を監視して統計情報を取得します。

## 要件

ライセンスマネージャーを問い合わせる前に、次を用意してください:

1. オンプレミスの OpenLM SLM v2.x（または SLMC アカウント）
2. CADENAS Server LicenseMonitor と同じマシンに OpenLM Broker v25.5 以降

## 監視機能

| Broker の LM タイプ | コマンド | ログ | 数量 | 有効期限 | 拒否 | 借用 | 割り当て | レポート粒度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Cadenas | いいえ | はい | はい | いいえ | いいえ | いいえ | いいえ | 秒 |

## OpenLM Broker の設定

![OpenLM が CADENAS Server License Manager と連携する仕組みの図](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit.png)  
*OpenLM と CADENAS Server License Manager の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を開きます。
2. **License Managers** → **Add License Manager** に移動します。
3. **LM Type** のドロップダウンから **CADENAS Server** を選択します。
4. CADENAS Server のポート番号（例: `2004`）を入力し、**Add** をクリックします。

   ![スクリーンショット: OpenLM Broker の設定](/img/legacy/word-image-98685-2.png)  
   *OpenLM Broker での CADENAS Server ライセンスマネージャーの追加*

5. **Vendors** タブで **Add Vendor** をクリックし、`CADENAS Server` を入力して **Continue** をクリックします。

   ![スクリーンショット 2: OpenLM Broker の設定](/img/legacy/word-image-98685-3.png)  
   *OpenLM Broker での CADENAS Server ベンダーの追加*

6. **Log Files** タブで **Add Log File** をクリックします。  
   **Watch file by pattern** をオフにし、ログパスを追加して **Continue** をクリックします。

   ![スクリーンショット 3: OpenLM Broker の設定](/img/legacy/word-image-98685-4.png)  
   *OpenLM Broker での CADENAS Server 用ログファイルの追加*

7. **Save** をクリックします。

## OpenLM の設定

上記手順が完了すると、Broker は OpenLM SLM にデータを送信しているはずです。  
EasyAdmin UI で設定を承認します:

1. **Start → Widgets → License Manager Servers** に移動します。
2. **Servers Pending Approval** をクリックします。

   ![スクリーンショット: OpenLM の設定](/img/legacy/word-image-98685-5.png)  
   *EasyAdmin で承認待ちのライセンスマネージャー*

3. 保留中のライセンスマネージャーをダブルクリックします（**OpenLM Generic** と表示されます）。

   ![スクリーンショット 2: OpenLM の設定](/img/legacy/word-image-98685-6.png)  
   *EasyAdmin で承認待ちの CADENAS Server ライセンスマネージャー*

4. （任意）表示名を変更します。設定を確認して **Approve** をクリックします。

   ![スクリーンショット 3: OpenLM の設定](/img/legacy/word-image-98685-7.png)  
   *EasyAdmin での CADENAS Server ライセンスマネージャーの承認*

5. （任意）**Custom Fields** に国、使用範囲、説明などを追加します。

   ![スクリーンショット 4: OpenLM の設定](/img/legacy/word-image-98685-8.png)  
   *EasyAdmin のカスタムフィールド*

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. 一覧に CADENAS Server ライセンスマネージャーが表示され、緑色の丸のステータスになっていることを確認します。

:::note
新しい接続の後、ステータス更新まで最大 3 分かかることがあります。
:::
