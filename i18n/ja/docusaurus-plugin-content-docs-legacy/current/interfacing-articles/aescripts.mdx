OpenLM は OpenLM Broker 経由で AEScripts License Manager を監視し、ライセンス統計を取得できます。

## 要件

1. 組織内のマシンに **OpenLM SLM** v5.0.4.7 以降をインストール  
2. AEScripts と同じマシンに **OpenLM Broker** v4.11 以降をインストール

## 監視機能と特長

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスレポート | 有効期限レポート | 複数サーバー冗長 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 秒単位 | ✔ | ✔ | ✔ | ❌ | ❌ | ❌ |

Broker を使用すると、バッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動／停止も可能になります。

## OpenLM Broker の設定

![図: OpenLM が AEScripts License Manager と連携する仕組み。](/img/legacy/diagram-of-how-openlm-interfaces-with-the-aescript.png)  
*OpenLM と AEScripts License Manager の連携図*

Broker は AEScripts License Manager のログファイルを読み取り、データを集計して OpenLM SLM に送信します。

1. OpenLM Broker で **Add Port** をクリックします。  
2. AEScripts のポートを入力します（既定 `27100`）。  
3. License Manager Type の一覧から **AEScripts** を選択し、**Apply** をクリックします。  
4. **Commands** で AEScripts のログファイルがあるフォルダーを指定し、**Apply** をクリックします。  
5. **Vendors** でベンダー名を **AEScripts** に設定し、**Apply** をクリックします。  
6. **Restart Broker** をクリックします。

![OpenLM Broker で AEScripts のログファイルをアップロード。](/img/legacy/openlm-broker-log-file-upload.png)

### Broker UI での設定

1. Broker UI を `http://localhost:5090/` で開きます。  
2. **License Managers → Add License Manager** に移動します。  
3. **AEScripts** を選択し、ポート番号を入力して **Add** をクリックします。  
   ![OpenLM Broker の Web UI で AEScripts ライセンスマネージャーを追加。](/img/legacy/word-image-42282-3.png)
4. **Commands** で実行ファイルのパスを設定し、必要に応じて start/stop のトグルを調整します。  
   ![OpenLM Broker の Commands タブで AEScripts の実行ファイルのパスを設定。](/img/legacy/word-image-42282-4.png)
5. **Log Files** で **Add Log File** をクリックします:
   - **Type**: AEScripts Log  
   - **Log name**: 分かりやすい名前  
   - **Log Path**: AEScripts のログフォルダーのパス  
   - **Vendor**: AEScripts  
   - **Encoding**: windows-152  
   ![OpenLM Broker の Log Files タブで AEScripts のログファイルを追加。](/img/legacy/word-image-42282-5.png)
6. **Continue** をクリックし、続いて **Save** をクリックします。

## OpenLM SLM の設定

### EasyAdmin による自動設定

1. EasyAdmin を開きます。  
2. **License Servers** に移動します。  
3. 保留中の AEScripts サーバー（OpenLM Generic と表示）を承認します。

### EasyAdmin による手動設定

1. **Start → Administration → License Manager Servers** に移動します。  
2. **Add LM** をクリックします。  
3. Description に例: “AEScripts” を入力します。  
4. Type を **OpenLM Generic** に設定します。  
5. タイムゾーンを設定します。  
6. ホスト名とポートを入力します。  
7. **Use Broker** を有効にします。  
8. 必要に応じて **Custom Fields**（Country、Usage Scope、Description）を入力します。  
9. **Save** をクリックします。

## 設定の確認

1. EasyAdmin で **Start → Widgets → License Servers** に移動します。  
2. 一覧に AEScripts が表示され、ステータスが緑であることを確認します。  

*注: 新しい接続のステータス更新には最大 3 分かかることがあります。*

![EasyAdmin でアクティブな接続を示す AEScripts ライセンスサーバー。](/img/legacy/word-image-42282-6.png)
