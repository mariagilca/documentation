本書では、OpenLM を Siemens SIMATIC と連携してライセンス使用状況を監視し、統計情報を取得する方法を説明します。

## 要件

Siemens SIMATIC を問い合わせるには、次をインストールしてください:

1. 組織内のマシンに OpenLM SLM v2.x
2. Siemens SIMATIC と同じマシンに OpenLM Broker v22.5 以降

## 監視機能と特徴

OpenLM Broker 経由で利用できる監視機能は次のとおりです:

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 分 | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with Siemens SIMATIC License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit-1.png)
*OpenLM と Siemens SIMATIC の連携図*

Broker は Siemens SIMATIC のログファイルを読み取ります。読み取り後、データを集計して OpenLM SLM に送信します。

OpenLM Broker は事前に[インストール](https://www.openlm.com/application-notes-v3-0/installing-openlm-v3-0/broker-comprehensive-installation-guide-an4004b/)し、OpenLM SLM へレポートするよう[設定](https://www.openlm.com/Knowledgebase%20and%20articles/openlm-broker-configuration/)しておく必要があります:

1. **Add Port** をクリックします。
2. Broker はログファイルのみを読み取るため、任意のポート番号（例: 888）を入力します。
3. **License Manager Type** の一覧から **Siemens SIMATIC** を選択し、**Apply** をクリックします。
4. **Vendors** で **Vendor Name to Be Filled** を選択し、**Vendor Name** に `Siemens SIMATIC` を入力して **Apply** をクリックします。
5. **Log Files** を選択し、**Add Log File** をクリックします。
6. 新しい **log** ノードを選択し、**[…]** をクリックして Siemens SIMATIC License Manager の `.log` ファイルを参照します。
7. **Apply** をクリックします。
8. **Restart Broker** をクリックします。

### 代替: Broker Web UI での設定

1. ブラウザで [http://localhost:5090/](http://localhost:5090/) を開きます。
2. **License Managers** → **Add License Manager** をクリックします。

   ![Add license manager in Broker Web UI](/img/legacy/word-image-41986-2.png)

3. ポップアップでライセンスマネージャーの種類を選択し、任意のポート番号（例: 888）を入力して **Add** をクリックします。

   ![License manager type selection](/img/legacy/word-image-41986-3.png)

4. **Vendors** に移動し、**Add Vendor** をクリックして名前を入力し、**Confirm** をクリックします。

   ![Add vendor in Broker Web UI](/img/legacy/word-image-41986-4.png)

5. **Log Files** に移動します。

   ![Log files tab in Broker Web UI](/img/legacy/word-image-41986-5.png)

6. **Add Log File** をクリックし、パスを手入力するか拡大鏡アイコンで参照します。
7. ログファイルを選択して **Open** をクリックします。
8. ドロップダウンからベンダー `Siemens SIMATIC` を選択します。
9. **Continue** をクリックします。

   ![File explorer pop-up window](/img/legacy/word-image-41986-6.png)

10. **Save** をクリックします。

    ![Save log file path in Broker Web UI](/img/legacy/word-image-41986-7.png)

## OpenLM SLM の設定

### EasyAdmin による自動設定

上記手順を完了すると、OpenLM Broker が OpenLM SLM にデータを送信します。EasyAdmin で設定を承認します:

1. EasyAdmin を開きます（**Windows Start → OpenLM → OpenLM EasyAdmin User Interface**）。
2. **License Servers** で Siemens SIMATIC License Manager の赤い行をダブルクリックします。

   ![Pending Siemens SIMATIC license manager in EasyAdmin](/img/legacy/word-image-41986-8.png)

3. 接続名を入力するか既定のままにし、**Type** を **OpenLM Generic** のまま **Approve** をクリックします。

   ![Approve Siemens SIMATIC license manager in EasyAdmin](/img/legacy/word-image-41986-9.png)

追加後、データが解析されて表示されます。緑色の丸アイコンはステータスが有効であることを示します。

![Green circle indicates active monitoring](/img/legacy/word-image-41986-10.png)

### 手動設定

自動設定が失敗した場合は、Siemens SIMATIC License Manager マシン上の OpenLM Broker に OpenLM SLM を手動で接続します。

ホスト名とポートは Broker の設定と一致させてください。

1. **Start → Administration → License Manager Servers** に移動します。
2. **Add LM** をクリックします。
3. **Type** から **OpenLM Generic** を選択します。
4. 説明（例: `Siemens SIMATIC`）を入力します。
5. ライセンスサーバーの場所に合わせて **Time Zone** を設定します。
6. **Hostname** と **Port** を入力します。
7. **Is Triad Configuration** をオフにします。
8. **Use Broker** をオンにします。
9. **Save** をクリックします。

![Manual Siemens SIMATIC license manager configuration](/img/legacy/word-image-41986-11.png)

## 設定の確認

1. ブラウザで EasyAdmin を開きます。
2. **Start → Widgets → License Servers** に移動します。
3. 一覧に Siemens SIMATIC が表示されることを確認します。緑色の丸アイコンは接続が有効であることを示します。

![Siemens SIMATIC with active connection](/img/legacy/word-image-41986-12.png)

新しい接続の場合、ステータス更新まで最大 3 分かかることがあります。
