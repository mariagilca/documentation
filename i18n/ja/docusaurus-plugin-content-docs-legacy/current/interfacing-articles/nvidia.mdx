:::danger 非推奨の連携
OpenLM Server v4.5 以降、Nvidia License Manager は [FlexNet Embedded](./flexnet-embedded) に置き換えられました。新規導入では FlexNet Embedded 連携を使用してください。このページはレガシー向けの参考情報として残しています。
:::

## 要件

1. 中央のネットワークサーバーに OpenLM Server を 1 つインストールしていること。

## OpenLM Server の設定

1. **OpenLM Server Configuration** を開きます（**Windows Start → OpenLM → Configure OpenLM Server – Start here**）。
2. **License Servers** に移動し、**Add** をクリックします。
3. 次のように設定します:
   - **Type**: **Nvidia**
   - **Description**: サーバー名
   - **Time Zone**: ライセンスサーバーのタイムゾーン
   - **Hostname** と **Port**: サーバー情報
   - **Is Triad Configuration**: 該当する場合はチェック
   - **UserPassword**: Nvidia 管理ポータルのユーザー名とパスワード
   - **Is secure connection (https)**: 該当する場合はチェック
   - **Use Broker**: 未チェック
   - **Read license file**: 未チェック
4. **Apply** をクリックします。

## 設定の確認

1. **EasyAdmin** を開きます。
2. **Start → Widgets → License Servers** に移動します。
3. 一覧に **Nvidia** が表示され、ステータスがアクティブになっていることを確認します。

:::note
EasyAdmin で新しい接続がアクティブとして表示されるまで、最大 3 分かかることがあります。
:::
