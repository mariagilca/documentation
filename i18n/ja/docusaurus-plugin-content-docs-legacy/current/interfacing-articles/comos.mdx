# Comos

以下の手順で OpenLM を設定し、Comos ライセンスマネージャーのライセンス使用状況を監視して統計情報を取得します。

## 要件

開始前に次を用意してください:

- 組織内のマシンに OpenLM Server v2.x をインストール済み  
- Comos ライセンスマネージャーと同じマシンに OpenLM Broker v22.3 以降

## 監視機能

OpenLM Broker 経由で Comos に対して利用できる監視機能は次のとおりです:

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 秒 | ✔ | ✔ | ✔ | ❌ | ✔ | ❌ |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Comos license manager](/img/legacy/how-openlm-interfaces-with-the-razorcatlicensemoni-1.png)  
*OpenLM と Comos ライセンスマネージャーの連携図*

:::note
OpenLM Broker を事前にインストールし、設定してから開始してください。
:::

### 自動設定

1. Broker 設定ツールを開きます。  
2. 右下の **Detect** をクリックします。  
   ![Auto-detect in Broker](/img/legacy/openlm-broker-auto-detect-for-moldex3d-lm.png)  
3. Comos サービスが稼働していれば、Broker が設定を自動検出して構成します。  
4. **Data Inquiry** コマンドを実行し、出力が有効であることを確認します。

### 手動設定（Broker デスクトップ UI）

1. **Add Port** をクリックし、Comos サーバーのポート（例: `27003`）を入力します。  
2. **License Manager Type** から **Comos** を選択し、**Apply** をクリックします。  
3. **Update path for commands** フィールドで Comos のインストールパスを入力または参照します。  
4. **Commands** 配下の **Data Inquiry** を選択して **Execute** をクリックし、エラーがないことを確認します。  
5. **Vendors** ノードに移動し、ベンダー名に **Comos** を入力して **Apply** をクリックします。  
6. **Log Files** を選択し、`ComosLSLicenseWorkload` ログファイルを参照して **Watch file by pattern** をオンにします。  
7. **Apply** をクリックして Broker を再起動します。

### 手動設定（Broker Web UI）

1. ブラウザで [http://localhost:5090/](http://localhost:5090/) を開きます。  
2. **License Managers → Add License Manager** に移動します。  
   ![Broker web UI add LM](/img/legacy/word-image-40838-5.png)  
3. 種別のドロップダウンから **Comos** を選択し、ポート番号を入力して **Add** をクリックします。  
   ![スクリーンショット: Manual configuration (Broker web UI)](/img/legacy/word-image-40838-6.png)  
4. **Commands** タブで Comos のインストールパスを設定し、**Execute** をクリックしてエラーがないことを確認します。  
   ![スクリーンショット 2: Manual configuration (Broker web UI)](/img/legacy/word-image-40838-7.png)  
5. **Vendors** タブ → **Add Vendor** に進み、**Comos** を入力して **Continue** をクリックします。  
   ![スクリーンショット 3: Manual configuration (Broker web UI)](/img/legacy/word-image-40838-8.png)  
6. **Log Files** タブ → **Add Log File** に移動し、Comos のログファイルを参照し、**Watch file by pattern** をオンにして **Continue** をクリックします。  
   ![スクリーンショット 4: Manual configuration (Broker web UI)](/img/legacy/word-image-40838-9.png)  
7. **Save** をクリックします。

## OpenLM Server の設定

### EasyAdmin による自動設定

1. EasyAdmin を開きます（**Start → Widgets → License Manager - Servers**）。  
2. **Servers pending approval** アイコンをクリックします。  
3. Comos のエントリをダブルクリックします（種別は **OpenLM Generic** と表示されます）。  
4. （任意）接続名を変更し、種別は **OpenLM Generic** のまま、**Enabled** をオンにして **Approve** をクリックします。

## 設定の確認

1. ブラウザで EasyAdmin を開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に Comos が表示され、緑色の丸アイコンになっていることを確認します。

:::note
新しい接続の後、アクティブ表示まで最大 3 分かかることがあります。
:::
