OpenLM は Licman と連携してライセンス使用状況を監視し、統計情報を取得できます。  
Licman サーバーは OpenLM Broker からローカルに問い合わせられ、取得したデータが OpenLM Server に送信されて監視とレポートに利用されます。

## 要件

- **OpenLM Server**（Windows / Linux / Docker）をネットワーク内の任意の場所にインストール  
- **OpenLM Broker** を Licman サーバーと同じマシンにインストール  

インストール前に [OpenLM のシステム要件](https://www.openlm.com/openlm-system-requirements-2/) を確認してください。

## OpenLM Server の設定

1. [OpenLM Server](https://www.openlm.com/downloads/) をインストールします。  
2. **EasyAdmin** で **Start → Administration → License Manager Servers** に移動します。  
3. **Add LM** をクリックします。  
4. **Display Name** を入力します（例: `My Licman Server`）。  
5. **Type** で **Licman** を選択します。  
6. **Use Broker** を ON にします。  
7. **Is Triad Configuration** は OFF のままにします（Licman は複数サーバー冗長に対応しません）。  
8. **Hostname** を入力します（例: `my_licman_server`）。  
9. **Port** を入力します（例: `11111`）。Licman は特定のポートを必要としません。  
10. ライセンスサーバーの **Time Zone** を選択します。  
11. **Save** をクリックします。  

![スクリーンショット: OpenLM Server Configuration](/img/legacy/word-image-42286-2.png)

## OpenLM Broker の設定

1. 最新の OpenLM Broker をインストールします。  
2. **Add Port** をクリックします。  
3. License Manager Type で **Licman** を選択し、Server 設定と同じ **Port** を入力します。  
4. **Commands** で Licman サーバー上の `licman20_appl.exe` のパスを設定し、**Update** → **Apply** をクリックします。  
5. **Status** と **data_inquiry** のコマンドが表示されることを確認します。  
6. **Apply** をクリックし、**Restart Broker** を実行します。  

![スクリーンショット: OpenLM Broker Configuration](/img/legacy/word-image-42286-3.png)

### 代替手段: Broker Web UI

1. ブラウザーで `http://localhost:5090/` を開きます。  
2. **License Managers → Add License Manager** に移動します。  
3. **Licman** を選択し、ポートを入力して **Add** をクリックします。  
4. **Commands** で `licman20_appl.exe` のパスを設定します。  
5. **Vendors** に Licman のベンダー名を入力します。  
6. **Save** をクリックします。  

![スクリーンショット: Alternative: Broker Web UI](/img/legacy/Screenshot-2023-03-17-at-18.00.57.png)

## EasyAdmin での確認

1. EasyAdmin で **Start → Widgets → License Servers** に移動します。  
2. 一覧に Licman サーバーが表示されることを確認します。  
3. **緑色の丸** は接続がアクティブであることを示します。
