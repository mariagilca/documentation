このドキュメントでは、OpenLM を設定して Venturis License Manager を監視し、ライセンス統計を取得する方法を説明します。

## 要件

Venturis License Manager を問い合わせるには、次をインストールしてください:

1. 組織内のマシンに OpenLM SLM v21.x 以降。
2. Venturis License Manager と同じマシンに OpenLM Broker v21.x 以降。

## 監視機能と特徴

OpenLM Broker 経由で利用できる監視機能は次のとおりです:

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 秒 | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker の設定

OpenLM Broker は Venturis のログファイルを読み取ります。データを集計して OpenLM SLM に送信します。  
ライセンスファイルは Broker で手動設定します。Broker はログファイルを読み取り、セッションの変更を追跡します。ライセンスファイルとオプションファイルは、設定された **Watch interval** に基づいて更新を監視します。

### 手動設定

1. **Add Port** をクリックし、Venturis のポート番号（例: 27003）を入力します。
2. **License Manager Type** から **Venturis** を選択し、**Apply** をクリックします。
3. **Advanced** をクリックして **Set path manually** を有効にします。
4. **Add** をクリックして Venturis のライセンスファイルパスを選択します。
5. **Watch license file** をオフにします。
6. **Vendors** で **Vendor name** に **Venturis** を入力します。
7. **Options file path** にオプションファイルのパス（例: `venturis_lic_man.ini`）を入力します。**[…]** をクリックしてファイルを参照します。
8. **Watch options file** をオフにします。
9. **Log files** に移動し、**Add log file** をクリックします。
10. 作成された **log** ノードを選択し、**[…]** をクリックして Venturis のログファイル（例: `venturis_licman.log`）を参照します。
11. **Apply** をクリックします。
12. **Restart Broker** をクリックします。

### Broker Web UI を使った設定

1. ブラウザで `http://localhost:5090/` を開きます。
2. **License Managers** → **Add license manager** に移動します。
3. ライセンスマネージャーの種類として **Venturis** を選択し、ポート（例: 2679）を入力して **Add** をクリックします。
4. **Settings** で次のいずれかを選択します:
   - **Detect license file path automatically**
   - **Set license file manually**
   - **Allow license file sorting**
   - **Watch license file**
5. **Commands** で **Executable path** を IBM LUM ライセンスサーバー上の `i4blt` 実行ファイルに設定します。
6. **Vendors** で正しいベンダー名を入力します。
7. **Save** をクリックします。

## OpenLM SLM の設定

### EasyAdmin による自動設定

Broker がデータを送信している場合は、EasyAdmin で設定を承認します:

1. EasyAdmin を開きます。
2. **License Servers** で Venturis のエントリに対して **Approve** をクリックします。

Venturis License Manager が追加・設定されました。

### 手動設定

自動設定が失敗した場合:

1. **Start → Administration → License Manager Servers** に移動します。
2. **Add LM** をクリックします。
3. 表示名を入力します。
4. **Type** として **Venturis** を選択します。
5. 説明（例: `VenturisLM`）を入力します。
6. ライセンスサーバーの場所に合わせて **Timezone** を設定します。
7. Broker の **Hostname** と **Port** を入力します。
8. **Is triad configuration** はオフのままにします。
9. **Use Broker** をオンにします。
10. **Save** をクリックします。

OpenLM SLM は Broker からのデータ監視に設定されました。

## 設定の確認

1. ブラウザで EasyAdmin を開きます（`http://<OpenLM Server FQDN>:5015` または `https://cloud.openlm.com`）。
2. **Start → Widgets → License Manager Servers** に移動します。
3. 一覧に Venturis License Manager が表示されることを確認します。緑色の丸アイコンは接続が有効であることを示します。

新しく追加した場合、ステータス更新まで最大 3 分かかることがあります。
