:::info 監視に関する注意
OpenLM は OpenLM Broker を介して Sparx License Manager（SparxLM）と連携し、ライセンス使用状況と統計情報を収集します。
:::

## 要件

- 組織内のマシンに OpenLM SLM v21.x 以降をインストール済み。  
- Sparx License Manager と同じマシンに OpenLM Broker v21.x 以降をインストール済み。  

## OpenLM Broker の設定

1. 最新の OpenLM Broker をインストールします。[Broker 設定ガイド](https://www.openlm.com/Knowledgebase%20and%20articles/openlm-broker-configuration/)に従って構成します。  
2. Broker 設定でホスト名ノード（例: `L312MD`）を選択し、**Add Port** をクリックします。  
   ![OpenLM Broker Sparx License Manager settings](/img/legacy/openlm-broker-sparx-license-manager-settings-3.png)  
3. Sparx サーバーのポート（既定: **7770**）を入力し、License Manager Type のドロップダウンから **Sparx** を選択して **Apply** をクリックします。  
4. 新しいポートノード配下で **Log Files → Add Log File** を右クリックし、次のように設定します:  
   - **Type**: SSKS Log  
   - **Name**: わかりやすい名前（例: “Sparx log”）  
   - **Path**: Sparx のインストールログフォルダ内の `ssksLog.log` ファイル  
   - **Vendor**: Vendors ノードで定義したベンダーを選択  
   ![OpenLM Broker Sparx License Manager Log File settings](/img/legacy/openlm-broker-sparx-license-manager-log-file-setti-3.png)  
5. **Encoding**: 既定では Sparx のログは **UTF-16** です。ログファイルに BOM がない場合は、Log File Definition 画面の **Advanced** で手動設定してください（UTF-16 または UTF-16LE を選択）。  
   ![Default Encoding UTF -16 for Sparx License Manager](/img/legacy/default-encoding-utf-16-for-sparx-license-manager-3.png)  
6. **Apply** をクリックします。  
7. **Restart Broker** をクリックし、数秒待ってから「Service started successfully」メッセージで **OK** をクリックします。  
8. EasyAdmin（`http://<OpenLM Server FQDN>:5015` または `https://cloud.openlm.com`）を開き、License Servers ウィンドウで Sparx エントリの **Approve** をクリックします。  

### Broker UI で設定（代替方法）

1. Broker UI を `http://localhost:5090/` で開きます。  
2. **License Managers → Add License Manager** に移動します。  
3. LM type に **Sparx** を選択し、ポート（既定 **7770**）を入力して **Add** をクリックします。  
   ![OpenLM Broker の Web UI で Sparx ライセンスマネージャーを追加。](/img/legacy/word-image-42298-7-1.png)  
4. 必要に応じてコマンドや実行オプションを設定します（例: 起動/停止の切り替え、定期/オンデマンドの問い合わせ）。  
   ![OpenLM Broker で Sparx のコマンドおよび実行オプションを設定。](/img/legacy/word-image-42298-8.png)  
5. ログファイル設定を追加します（上記と同様）。  
   - **Type**: SSKS Log  
   - **Path**: `ssksLog.log`  
   - **Encoding**: UTF-16  
   ![OpenLM Broker で Sparx の SSKS ログファイル設定を追加。](/img/legacy/word-image-42298-9-1.png)  
6. 設定を保存します。  

## OpenLM SLM の設定

自動承認が完了しない場合は、手動で設定します:  

1. **EasyAdmin → Administration → License Manager Servers** で **Add LM** をクリックします。  
2. 次を入力します:  
   - **Display name**: 例: SparxLM  
   - **Type**: Sparx  
   - **Description**: 任意のテキスト（例: “Sparx License Manager”）  
   - **Time Zone**: ライセンスサーバーの所在地  
   - **Hostname** と **Port**: Broker の設定に合わせる（既定ポート 7770）  
   - **Use Broker**: オン  
3. **Save** をクリックします。  
   ![EasyAdmin で Use Broker を有効にして Sparx ライセンスサーバーを設定。](/img/legacy/word-image-42298-10.png)  

## 監視の確認

1. EasyAdmin（`http://<OpenLM Server FQDN>:5015` または `https://cloud.openlm.com`）を開きます。  
2. **Start → Widgets → License Manager Servers** に移動します。  
3. 一覧に SparxLM が表示され、**緑色のステータス表示**（アクティブ接続）になっていることを確認します。  
   ![EasyAdmin で緑色のステータスインジケーターとともに一覧表示された SparxLM。](/img/legacy/word-image-42298-12.png)  

## 既知の制限

- Sparx のライセンス拒否は監視されません。
