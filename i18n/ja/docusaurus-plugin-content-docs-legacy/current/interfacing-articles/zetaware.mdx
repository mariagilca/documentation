# ZetaWare

Follow these steps to configure OpenLM to monitor license usage and retrieve license statistics from ZetaWare License Manager.

## Requirements

Before you query the license manager, install:

1. OpenLM SLM v2.x on your premises (or an OpenLM Cloud account)  
2. OpenLM Broker v24.11 or higher on the same machine as the ZetaWare License Manager

## Monitoring capabilities

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ZetaWare | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also enables buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with the ZetaWare License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit-3.png)  
*Diagram of how OpenLM interfaces with the ZetaWare License Manager*

:::note
OpenLM Broker must be installed and configured to report to OpenLM SLM before proceeding.
:::

1. Open the Broker web UI at `http://localhost:5090`.  
   If the default port is in use, try `5091` or `5092`.
2. Go to **License Managers** → **Add License Manager**.
3. From the **LM Type** drop-down list, select **ZetaWare**.
4. Enter the port number (e.g., `888`) and click **Add**.

   ![](/img/legacy/word-image-92148-2.png)  
   *Adding ZetaWare license manager in OpenLM Broker*

5. Go to the **Vendors** tab. Click **Add Vendor**, enter `ZetaWare`, and click **Continue**.

   ![](/img/legacy/word-image-92148-3.png)  
   *Adding ZetaWare vendor in OpenLM Broker*

6. Go to the **Log Files** tab. Click **Add Log File**.  
   Turn off **Watch file by pattern**. You can add multiple logs for different applications. Click **Continue**.

   ![](/img/legacy/word-image-92148-4.png)  
   *Adding log files for ZetaWare in OpenLM Broker*

7. Click **Save**.

## OpenLM configuration

If the above steps are complete, Broker should be transmitting data to OpenLM SLM.  
Approve the configuration in the EasyAdmin UI:

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Click the **Servers Pending Approval** link.

   ![](/img/legacy/word-image-92148-5.png)  
   *Pending license managers in EasyAdmin*

4. Double-click the pending ZetaWare entry. It will be displayed as **OpenLM Generic**.

   ![](/img/legacy/word-image-92148-6.png)  
   *Pending ZetaWare license manager in EasyAdmin*

5. Verify the configuration details and click **Approve**.

   ![](/img/legacy/word-image-92148-7.png)  
   *Approving ZetaWare license manager in EasyAdmin*

At this point, ZetaWare is added to OpenLM SLM. It may take up to 3 minutes for the status to update.  
A green circle icon indicates an active connection.

## Verify your configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Manager Servers**.
3. Confirm that the ZetaWare license manager appears in the list with a green circle icon.

:::note
It may take up to 3 minutes for the status to update after a new connection.
:::
