:::

## 概要

[SlickEdit](http://www.slickedit.com/) はクロスプラットフォームの多言語ソースコード/テキストエディタです。さまざまなコーディングツールや時間短縮のプログラミング機能を提供します。SlickEdit 2014 は 9 つのプラットフォームで 40 以上の言語をサポートします。

SlickEdit の利用は独自のライセンスマネージャーで管理されます。本ガイドでは、OpenLM を設定して SlickEdit ライセンスマネージャーを監視し、使用状況と統計情報を収集する方法を説明します。

ライセンスサーバーを問い合わせる方法は 2 通りあります:

1. OpenLM SLM からライセンスサーバーを直接問い合わせる。
2. OpenLM Broker でローカルに問い合わせ、OpenLM SLM に情報を送信する。

## OpenLM SLM 直接方式

### OpenLM SLM で SlickEdit を有効化

OpenLM SLM を SlickEdit と連携させるには:

1. OpenLM SLM をダウンロードしてインストールします。
2. **EasyAdmin** を開きます。
3. **Start → Administration → License Manager Servers** に移動します。
4. **LM Tools** タブを選択し、**SlickEdit** を選びます。
5. SlickEdit の **selicutil.exe** 実行ファイルを次にコピー/インストールします:  
   `C:\Program Files\OpenLM\OpenLM Server\LM\`
6. **SlickEdit executable file** テキストボックスにフルパスを入力します。例:  
    ```
    C:\Program Files\OpenLM\OpenLM Server\LM\selicutil.exe
    ```
   **Apply** をクリックします。
7. Windows Services で OpenLM SLM サービスを再起動します。

![Configuring EasyAdmin to work with SlickEdit](/img/legacy/word-image-42302-1.png)  
*EasyAdmin で SlickEdit を設定*

### SlickEdit サーバーの追加

1. EasyAdmin で **Start → Administration → License Manager Servers** に移動します。
2. **LM Servers** タブを選択し、**Add License Manager** をクリックします。
3. **Type** のドロップダウンから **SlickEdit** を選択します。
4. **Display Name** にわかりやすい名称（例: *SlickEdit license server*）を入力します。
5. ライセンスサーバーの **Time zone** を設定します。
6. ライセンスサーバーの **Hostname** と **Port** を入力します。  
   *既定ポートは `27100` です。他のアプリが使用していないこと、ファイアウォールで開放されていることを確認してください。*
7. **Is Triad Configuration** はオフのままにします。SlickEdit は複数サーバー冗長化に対応していません。
8. **Use Broker** はオフのままにします。
9. **Save** をクリックします。Windows Services で OpenLM SLM サービスを再起動します。

![Adding SlickEdit server in EasyAdmin](/img/legacy/word-image-42302-2.png)  
*EasyAdmin で SlickEdit サーバーを追加*

## Broker による監視

### SlickEdit 向け OpenLM Broker の設定

OpenLM Broker は任意ですが推奨です。SlickEdit ライセンスマネージャーマシンにインストールして設定します。Broker の利点:

- より正確なライセンス統計  
- OpenLM SLM とライセンスマネージャー間の安定した通信  

Broker を設定するには:

1. [ダウンロードページ](https://www.openlm.com/downloads/)から最新の OpenLM Broker をインストールします。
2. Broker でライセンスマネージャーノードを選択します。Auto-Detect で SlickEdit が見つからない場合は **Add Port** をクリックします。
3. SlickEdit ライセンスサーバー（例: `slickedit_license_server`）のポート `27100` を監視するよう設定します。
4. ベンダー名を **SlickEdit** に設定します。
5. **Commands** ノードで `selicutil.exe` のフルパスを入力し、**Update** → **Apply** をクリックします。
6. 画像のとおり **Status** と **Data_inquiry** のコマンドを設定し、`<fullpath>` を `selicutil.exe` の実際のパスに置き換えます。

![Configuring Broker commands for SlickEdit](/img/legacy/word-image-42302-3.png)  
*Broker で SlickEdit コマンドを設定*

7. **Restart Broker** をクリックします。
8. [Broker web UI](https://www.openlm.com/knowledge-base/openlm-broker-webui/) から設定することもできます。

![Configuring SlickEdit in Broker web UI](/img/legacy/word-image-42302-4-1.png)  
*Broker Web UI で SlickEdit を設定*

## 設定の確認

SlickEdit の設定を確認するには:

1. **EasyAdmin** を開きます。
2. **Pending Approval** のリンクをクリックし、SlickEdit サーバーを承認します。
3. サーバー一覧にライセンスマネージャーが表示されることを確認します。  
   緑色の丸アイコンは接続が有効であることを示します。
