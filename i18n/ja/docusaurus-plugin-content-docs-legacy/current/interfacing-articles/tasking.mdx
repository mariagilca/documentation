OpenLM は OpenLM Broker 経由で TASKING License Management System (TLM) と連携し、ライセンス使用状況、拒否、その他の統計情報を監視できます。

## 要件

1. **OpenLM SLM** — オンプレミスまたはクラウドアカウント  
2. **OpenLM Broker** v4.8.8 以降を TLM と同じマシンにインストール

## 監視機能と特長

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスレポート | 有効期限レポート | 複数サーバー冗長 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 分単位 | ✔ | ✔ | ✔ | ✔ | ❌ | ❌ |

Broker により、バッファ付き通信、ライセンスサービスのリモート起動・停止、拒否の監視も可能です。

## OpenLM Broker の設定

![図: OpenLM が TASKING と連携する仕組み。](/img/legacy/word-image-42284-1-1.png)  
*OpenLM と TASKING の連携図*

Broker は TLM と同じマシンで動作し、`licdstat` ツールでライセンスマネージャーを問い合わせ、データを OpenLM SLM に送信します。

### 自動設定

1. TLM ライセンスサーバーで OpenLM Broker を開きます。  
2. **License Managers** タブで **Detect** をクリックします。  
   ![OpenLM Broker で TASKING ライセンスマネージャーを自動検出。](/img/legacy/word-image-42284-2-1.png)  
   TASKING サービスが稼働していれば、Broker が自動検出して設定します。

### 手動設定

1. **License Managers** で **Add License Manager** をクリックします。  
2. TLM のポート番号を入力します（既定: `9090`）。  
3. License Manager Type の一覧から **TASKING** を選択し、**Add** をクリックします。  
   ![OpenLM Broker で TASKING ライセンスマネージャーを手動で追加。](/img/legacy/word-image-42284-3-1.png)  
4. **Commands** タブで `licdstat.exe` の実行パスを設定します（通常は `C:\Program Files (x86)\TASKING\taskinglm`）。**Update** → **Apply** をクリックします。  
   ![OpenLM Broker の Commands タブで licdstat.exe の実行ファイルのパスを設定。](/img/legacy/word-image-42284-5-1.png)  
5. **Save** をクリックし、**Execute** でエラーがないことを確認します。  
6. **Vendors** タブで **Add Vendor** をクリックし、ベンダー名を入力して **Continue** をクリックします。  
   ![OpenLM Broker の Vendors タブで TASKING ベンダーを追加。](/img/legacy/word-image-42284-6.png)  
7. **Log Files** で TLM のログファイルを指定して拒否を取得し、**Continue** → **Save** をクリックします。  
   ![OpenLM Broker の Log Files タブで TLM のログファイルを追加。](/img/legacy/word-image-42284-7.png)

## OpenLM SLM の設定

### EasyAdmin による自動設定

1. EasyAdmin を開きます（**Start → Widgets → License Manager Servers**）。  
2. **Servers pending approval** のアイコンをクリックします。  
3. TASKING のエントリをダブルクリックして承認します。  

![EasyAdmin で承認待ちの TASKING ライセンスサーバーを承認。](/img/legacy/word-image-42284-8.png)

## 設定の確認

1. EasyAdmin で **Start → Widgets → License Servers** に移動します。  
2. 一覧に TASKING が表示され、ステータスが緑であることを確認します。  

*注: 新しい接続のステータス反映には最大 3 分かかることがあります。*
