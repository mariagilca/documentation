# Autodesk Cloud

:::info
接続するには 2 要素認証を無効にする必要があります。
:::

Autodesk Cloud を監視するため、OpenLM は Autodesk Cloud の管理ポータルに直接接続します。  

ライセンス使用状況の取得方法は 2 つあります:

- **Workstation Agent または AutoCAD Plugin を使用**: これらは OpenLM Applications Manager と通信し、使用状況データを OpenLM Server に送信します。この方法では詳細な *使用データ* が得られます。  
- **Applications Manager を使用しない**: 取得できるのはライセンス *数量データ* のみです。使用状況の詳細を取得するには、[Applications Manager のドキュメント](../openlm-applications-manager/configure-applications-manager-to-track-actual-usage.md) を参照してください。  

## OpenLM で Autodesk Cloud を設定

1. **EasyAdmin** を開きます。  
2. **Start → Administration → License Manager Servers → Add LM** に移動します。  
   ![Monitoring the Autodesk Cloud license manager with OpenLM](/img/legacy/word-image-42313-1.png)  
   *EasyAdmin に Autodesk Cloud ライセンスマネージャーを追加*  
3. **Display name** に分かりやすい名前を入力します。  
4. **Type** のドロップダウンから **Autodesk Cloud** を選択します。LM アドレスは自動入力されます。  
5. **Autodesk Cloud Account admin credentials**（ユーザー名とパスワード）を入力します。  
6. ライセンスマネージャーサーバーの **time zone** を選択します。  
7. **TEST Connection** をクリックします。成功すると次のように表示されます:  
   ![Test connection to Autodesk Cloud](/img/legacy/word-image-42313-2.png)  
   *Autodesk Cloud 接続テストの成功例*  
8. **SAVE** をクリックします。  
9. 数分以内に、Autodesk Cloud の使用状況や割り当てデータがレポートに表示されます。
