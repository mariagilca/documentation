# Innovyze

この連携により、OpenLM は Innovyze のライセンス使用状況、拒否、借用ライセンスのレポートを監視できます。

## 要件

1. 中央のネットワークサーバーに OpenLM Server v4.7 以降をインストール済み。
2. Innovyze と同じマシンに OpenLM Broker v4.14.0 以降をインストール済み。

## 監視機能と特徴

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 秒 | ✔ | ✔ | ✔ | ✔ | ❌ | ❌ |

さらに OpenLM Broker を使用すると、バッファ付き通信と Innovyze サービスのリモート起動・停止が可能になります。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with Innovyze](/img/legacy/word-image-9.png)
*OpenLM と Innovyze の連携図*

OpenLM Broker は Innovyze の `LicenseMonitor` ログファイルを読み取り、データを集計して OpenLM Server に送信します。

:::note
この設定を開始する前に、OpenLM Broker をインストールし、OpenLM Server にレポートするよう設定しておく必要があります。
:::

### 自動設定

1. OpenLM Broker 設定ツールの右下にある **Detect** をクリックします。
2. Innovyze のプロセスまたはサービスが稼働していれば、Broker が必要な設定でポートノードを自動作成します。
3. **Apply** をクリックします。
4. **Restart Broker** をクリックして変更を OpenLM Server に送信します。
5. 確認するには、**Commands → data_query** に移動して **Execute** をクリックします。

### 手動設定

1. **Add Port** をクリックします。
2. Innovyze のポート番号（例: `20230`）を入力します。
3. **License Manager Type** を **Innovyze** に設定し、**Apply** をクリックします。
4. **Vendors** で “Vendor Name to Be Filled” を選択し、**Innovyze** を入力して **Apply** をクリックします。
5. **Log Files** ノードを選択して **Add Log File** をクリックします。
6. 新しく作成された **log** ノードを選択し、**[…]** をクリックして CSV ログファイルの場所を参照します（通常は `C:\ProgramData\Innovyze<LM>#.#\Usage`。`#.#` はバージョン、例: `6.0`）。  
7. **Advanced** をクリックし、**Watch Files by Pattern** をチェックします。
8. **Apply** をクリックします。
9. **Restart Broker** をクリックします。

## OpenLM Server の設定

### EasyAdmin による自動設定

1. ブラウザ（`http://<OpenLM Server IP>:7019/EasyAdmin2/`）または **Windows Start → OpenLM → OpenLM EasyAdmin User Interface** から EasyAdmin を開くか、**Cloud.OpenLM.com** にログインします。
2. **License Servers** で保留中の承認メッセージをクリックします。
3. 表示名（例: Innovyze）を入力します。
4. **Approve** をクリックします。

![スクリーンショット: Automatic configuration through EasyAdmin](/img/legacy/word-image-3-2.png)
![スクリーンショット 2: Automatic configuration through EasyAdmin](/img/legacy/word-image-4-2.png)

### 手動設定

1. OpenLM Server 設定ツールを開きます（**Windows Start → OpenLM → OpenLM Server**）。
2. **License Servers** タブを選択します。
3. **Add** をクリックします。
4. **Type** から **OpenLM Generic** を選択します。
5. 説明（例: Innovyze）を入力します。
6. サーバーの **Time Zone** を正しく設定します。
7. Broker 設定と一致する **Hostname** と **Port** を入力します。
8. **Is Triad Configuration** はオフのままにします。
9. **Use Broker** をオンにします。
10. **Apply** をクリックしてツールを閉じます。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Servers** に移動します。
3. Innovyze が表示され、緑色のステータス表示になっていることを確認します。

![スクリーンショット: How to verify configuration](/img/legacy/word-image-5-1.png)

:::note
新しい接続の後、EasyAdmin にアクティブとして表示されるまで最大 3 分かかることがあります。
:::
