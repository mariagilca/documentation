# SEH-UTN

この連携により、OpenLM は SEH-UTN ライセンスドングルサーバーのライセンス使用状況と可用性を監視できます。

## 要件

1. 中央のネットワークサーバーに OpenLM Server をインストールすること。
2. OpenLM Server と SEH Control Center の Web インターフェイスの両方にアクセスできるマシンに OpenLM Broker をインストールすること。

## SEH Control Center

SEH Control Center は SEH-UTN ドングルサーバーを設定するための Web インターフェイスです。

![](/img/legacy/word-image-42287-1.jpeg)

Control Center で以下を確認します:
- ライセンスドングルサーバーの IP アドレス（例: `192.168.0.140`）とサーバー名
- UTN のポート番号（例: `9200`）
- **Attached devices** ウィンドウのデバイス名

これらの情報は OpenLM 設定時に使用します。

## OpenLM Broker の設定

:::note
`utnm.exe` はライセンスを消費するマシンではホスト／ユーザー情報を報告しないため、ドングルライセンスを使用するワークステーションには OpenLM Broker をインストールしないでください。
:::

1. SEH Control Center と `utnm.exe` にアクセスできるサーバーまたはワークステーションに OpenLM Broker をインストールします。
2. **OpenLM Broker Configuration** で次を行います:
   - ライセンスマネージャーノードを選択します。
   - Auto-Detect が失敗した場合は **Add Port** をクリックします。
   - UTN のポート番号を入力します（例: `9200`）。
   - **License Manager Type** を **SEH-UTN** に設定します。
   - **Apply** → **OK** をクリックします。
3. **Commands** ノードで、SEH ドングルホスト上の `utnm.exe` のパスを設定します。
4. **status** と **data_inquiry** のコマンドが設定されていることを確認します。
   ![](/img/legacy/word-image-42287-3.png)
5. **Vendors** にベンダー名を入力します。
6. **Restart Broker** をクリックします。
7. （任意）[Broker web UI](https://www.openlm.com/knowledge-base/openlm-broker-webui/) で設定します。  
   ![](/img/legacy/word-image-42287-4.png)

この時点で OpenLM は SEH のライセンス情報の収集を開始します。

## OpenLM Server の設定

### EasyAdmin での手動設定

1. EasyAdmin で **Start → Administration → License Manager Servers** に移動します。
2. **LM Servers** タブで **Add** をクリックします。
3. **Type** で **OpenLM_Generic** を選択します。
4. 表示名を入力します（例: `My SEH server`）。
5. サーバーのタイムゾーンを設定します。
6. ホスト名とポートを入力します（例: `my_seh_server`, `9200`）。
7. **Is Triad Configuration**: オフ。  
8. **Use Broker**: チェック。  
9. **Approve** をクリックします。

![](/img/legacy/word-image-42287-5.png)

## 設定の確認

1. EasyAdmin で **Pending Approval** をクリックし、SEH-UTN を承認します。
2. 一覧に SEH-UTN が表示され、ステータスが緑であることを確認します。
