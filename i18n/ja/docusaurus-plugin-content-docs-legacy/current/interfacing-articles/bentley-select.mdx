# Bentley

:::info 監視に関する注意
OpenLM は Bentley SELECT（オンプレミス／クラウド）と連携します。監視機能は構成と Bentley のライセンスモデルに依存します。
:::

## Bentley について

[Bentley Systems](http://www.bentley.com/en-US/) は、土木工学やインフラ構築向けのソリューションを提供する米国拠点のソフトウェア企業です。世界 50 か国以上に拠点があります。  

Bentley は Intergraph の元エンジニアである Keith Bentley と Barry Bentley によって設立されました。最初の製品は Intergraph のグラフィック表示機能を拡張し、後に Intergraph システムと互換性のある CAD ツールへ発展しました。  

[Bentley の製品ポートフォリオ](http://www.bentley.com/en-US/Products/) には、次が含まれます:  
- 予備設計における地理空間・マッピング  
- プラントや構造物の概念設計  
- エンジニアリングシステムの運用分析  

## ライセンスモデル

Bentley のライセンスは **SELECT Server** に基づいており、次のいずれかで導入できます:  
- **オンプレミス**  
- **クラウド**  

どちらも管理とレポートのための Web ベースのインターフェイスを提供します。  

## 対応機能

OpenLM は次の Bentley 製品の監視に対応しています:  
- **MicroStation**  
- **STAAD**  
- **AutoPIPE**  

MicroStation ベースの製品については、一部機能のみ対応しています:  
- **RailRoads**  
- **InTracks**  

## OpenLM で Bentley を監視するメリット

Bentley SELECT Server と OpenLM を併用すると、次の利点があります:  
1. **コスト最適化** – Bentley ライセンスの過剰支出を防ぎ、「bucket」システムを効率的に管理できます。  
2. **詳細な制御** – 時間、グループ、アプリケーション、バージョン単位でライセンスチェックアウトを管理できます。  
3. **アイドルライセンスの回収** – ワークステーションが休止状態になったときに OpenLM がライセンスを解放し、不要な bucket 消費を防ぎます。  

## Applications Manager

高度な監視と制御を行うために、OpenLM Applications Manager は Bentley 環境での機能を拡張します。
