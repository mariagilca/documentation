# Chaos V-Ray

以下の手順で OpenLM を設定し、Chaos V-Ray License Manager のライセンス使用状況を監視して統計情報を取得します。

## 要件

開始前に、以下を満たしていることを確認してください:

1. OpenLM SLMC アカウント **または** 組織内のマシンに OpenLM SLM v2x をインストール済み  
2. Chaos V-Ray License Manager と同じマシンに OpenLM Broker v23.11 以降をインストール

## 監視機能

Broker が Chaos V-Ray License Manager のログファイルを読み取り、データを集計して OpenLM に送信します。

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否 | 借用 | 有効期限 | 冗長 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 秒単位 | ✔ | ❌ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with Chaos V-Ray](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit.png)  
*OpenLM と Chaos V-Ray License Manager の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を `http://localhost:5090` で開きます（既定ポートが使用中の場合は `5091`、`5092`）。  
2. **License Managers** → **Add License Manager** に移動します。  
   ![スクリーンショット: OpenLM Broker configuration](/img/legacy/word-image-83603-2.png)  
3. ドロップダウンから **Chaos** を選択し、ポート（例: `35033`）を入力します。  
4. **Add** をクリックします。  
   ![スクリーンショット 2: OpenLM Broker configuration](/img/legacy/word-image-83603-3.png)  
5. **Vendors** → **Add Vendor** に移動し、`Chaos V-Ray` を入力して **Continue** をクリックします。  
6. **Log Files** → **Add Log File** に移動します。  
7. ログファイルのパスを手入力するか、虫眼鏡アイコンで参照します。  
8. ベンダーに `Chaos V-Ray` を選択し、**Save** をクリックします。

## OpenLM Server の設定

### EasyAdmin による自動設定

1. EasyAdmin を `http://<OpenLM-Server-IP>:5015/` で開くか、**Windows Start → OpenLM → OpenLM EasyAdmin User Interface** から起動します。  
2. **License Manager Servers** で **Servers pending approval** のアイコンをクリックします。  
   ![スクリーンショット: Automatic configuration through EasyAdmin](/img/legacy/word-image-83603-4.png)  
3. Chaos V-Ray のエントリを選択し、LM のタイムゾーンを設定して内容を確認し、**Approve** をクリックします。

Chaos V-Ray License Manager は自動で追加され、しばらくするとレポートが開始されます。

### 手動設定

自動設定が失敗した場合:

1. EasyAdmin で **Start → Administration → License Manager Servers** に移動します。  
2. **Add LM** をクリックします。  
3. **Type** で **OpenLM Generic** を選択します。  
4. 説明を追加します（例: `Chaos V-Ray`）。  
5. ライセンスサーバーのタイムゾーンを設定します。  
6. Broker 設定のホスト名とポートを入力します。  
7. **Use Broker** を **On**、**Allow SLM to fall back to denied license** を **Off** に設定します。  
8. **Save** をクリックします。

## 設定の確認

1. EasyAdmin を開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に Chaos V-Ray License Manager が表示され、緑色の丸のステータスになっていることを確認します。

:::note
新しい接続がアクティブとして表示されるまで最大 3 分かかることがあります。
:::
