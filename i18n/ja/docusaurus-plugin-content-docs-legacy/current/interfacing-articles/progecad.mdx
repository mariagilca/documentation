[ProgeCAD](http://www.progesoft.com/) は CAD とコンセプトスケッチ向けの 2D/3D 設計ソフトウェアです。AutoCAD と互換性があり、ネイティブ `.dwg` 形式で Direct Modeling をサポートします。

OpenLM は ProgeCAD Network License Manager (NLM) **13.0.18 以降**を監視できます。ライセンスサーバーが定期的に XML ファイルを生成し、OpenLM がそれを解析して EasyAdmin に使用状況を表示します。

## 前提条件

ProgeCAD の監視には次が必要です:

- ProgeCAD ライセンスサーバーに **OpenLM Broker** をインストール済み。  
- ネットワーク内の任意の Windows マシン（ライセンスサーバー含む）に **OpenLM Server** をインストール済み、または **OpenLM Cloud アカウント**。  

Broker が ProgeCAD ライセンスサーバーをローカルで問い合わせ、OpenLM Server にデータを転送します。

![Broker interface with log and license files](/img/legacy/broker-interface-with-log-and-license-files-6.png)

## OpenLM で ProgeCAD を監視する設定

1. [OpenLM Server をダウンロードしてインストール](https://www.openlm.com/knowledge-base/openlm-server-kb4100/)するか、Cloud アカウントを作成します。  
2. **EasyAdmin → Start → Administration → License Manager Servers → Add LM** を開きます。  
3. **Description** にわかりやすい名前（例: `My ProgeCAD license server`）を入力します。  
4. **Type** から **OpenLM Generic** を選択します。  
5. サーバーの **Hostname or IP**（例: `progecad_server`）を入力します。  
6. ライセンスサーバーの **Time Zone** を正しく設定します。  
7. **Description name** が Broker で使用する名前と一致していることを確認します。  
8. ProgeCAD の **Port**（例: `51168`）を入力します。Broker でも同じ番号を使用します。  
9. **Is Triad Configuration** はオフのままにします。ProgeCAD は triad 冗長化に対応していません。  
10. **Use Broker** をオンにします。  
11. **Save** をクリックします。

![Add license manager in EasyAdmin](/img/legacy/word-image-42305-2.png)

## OpenLM Broker の設定（デスクトップ UI）

1. 最新の **OpenLM Broker** をダウンロードしてインストールします。  
2. Broker で **Add Port** をクリックします。  
   - ライセンスサーバーノード（例: `progecad_server`）を選択します。  
   - Server と同じポート（例: `51168`）を入力します。  
   - **Type** から **OpenLM Generic** を選択します。  
   - **Apply → OK** をクリックします。  
3. **Commands** で **data_inquiry** を選択し、次を入力します:  
    ```
    "<Full path to NLMServerMonitor.exe>" /xml
    "C:\Program Files (x86)\ProgeCAD\NLM Server 2013 PRONG\NLMServerMonitor\NLMServerMonitor.exe" /xml
    ```
4. **Execute** をクリックしてコマンドを検証します。  
5. **Apply** をクリックします。  
6. **Status** コマンドでも手順 3〜5 を繰り返します。  
7. **Vendors** に **ProgeCAD** を入力します（大文字小文字を区別）。**Apply** をクリックします。  
8. **Restart Broker** をクリックします。

![Broker commands configuration](/img/legacy/word-image-42305-3.png)

## OpenLM Broker の設定（Web UI）

または Broker Web UI を使用します:

1. 最新の Broker をインストールします。  
2. `http://localhost:5090/` を開きます。  
3. **License Managers → Add License Manager** に移動します。  
4. **Type** から **OpenLM Generic** を選択し、ポート（例: `51168`）を入力して **Add** をクリックします。  

![Add license manager web UI](/img/legacy/word-image-42305-4.png)

5. **Commands** タブで **Executable path** に次を入力します:  
    ```
    "<Full path to NLMServerMonitor.exe>" /xml
    ```
6. **Save** をクリックし、続けて **Execute** で出力を検証します。  

![Broker web UI commands](/img/legacy/word-image-42305-5.png)

7. **Vendors** タブで **Add Vendor** をクリックし、`ProgeCAD`（または任意の名前）を入力して **Continue → Save** をクリックします。

## 設定の確認

設定後、新しいライセンスマネージャーを承認します:

1. **EasyAdmin → Start → Administration → License Manager Servers** を開きます。  
2. **Pending** アイコンをクリックして ProgeCAD ライセンスマネージャーを承認します。  

承認後、EasyAdmin で ProgeCAD のライセンス使用状況レポートを確認できます。
