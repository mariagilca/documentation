# Razorcat

以下の手順で OpenLM を設定し、Razorcat ライセンスマネージャーのライセンス使用状況を監視して統計情報を取得します。

## 要件

開始前に次を用意してください:

- 組織内のマシンに OpenLM Server v2.x をインストール済み  
- Razorcat と同じマシンに OpenLM Broker v22.5 以降  
- Broker を[サービスアカウント](https://learn.microsoft.com/en-us/windows-server/identity/ad-ds/manage/understand-service-accounts)で実行するよう設定済み  

## 監視機能

OpenLM Broker 経由で Razorcat に対して利用できる監視機能は次のとおりです:

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 分 | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Razorcat license manager](/img/legacy/how-openlm-interfaces-with-the-razorcatlicensemoni.png)  
*OpenLM と Razorcat ライセンスマネージャーの連携図*

:::note
OpenLM Broker を事前にインストールし、設定してから開始してください。
:::

### 手動設定（Broker デスクトップ UI）

1. **Add Port** をクリックします。  
2. Razorcat サーバーのポート番号（例: `36679`）を入力します。  
3. **License Manager Type** から **Razorcat** を選択します。  
4. **Commands** で **Update path for commands** の参照アイコンをクリックし、`flsutil.exe` があるフォルダ（通常は `C:\Program Files\Razorcat\FLS_4.2\bin`）を選択して **Update** をクリックします。  
5. **Apply** をクリックします。  
6. **Commands** の **Data Inquiry** を選択して **Execute** をクリックし、出力が有効であることを確認します。  
   - フォールバック FLS を使用する場合は `-h localhost` を追加します（ローカルホストのみ有効）。  
7. **Restart Broker** をクリックします。

### 手動設定（Broker Web UI）

1. ブラウザで [http://localhost:5090/](http://localhost:5090/) を開きます。  
2. **License Managers → Add License Manager** に移動します。  
   ![スクリーンショット: Manual configuration (Broker web UI)](/img/legacy/word-image-38965-3.png)  
3. 種別のドロップダウンから **Razorcat** を選択し、ポート番号を入力して **Add** をクリックします。  
   ![スクリーンショット 2: Manual configuration (Broker web UI)](/img/legacy/word-image-38965-4.png)  
4. **Commands** タブで **Executable Path** を `flsutil.exe` があるフォルダに設定します（拡大鏡アイコンで参照可）。  
5. **Service Name** を入力します（例: `Razorcat`）。  
   ![スクリーンショット 3: Manual configuration (Broker web UI)](/img/legacy/word-image-38965-5.png)  
6. **Vendors** タブ → **Add Vendor** に進み、**Razorcat** を入力して **Continue** をクリックします。  
   ![スクリーンショット 4: Manual configuration (Broker web UI)](/img/legacy/word-image-38965-6.png)  
7. **Save** をクリックします。

## OpenLM Server の設定

### EasyAdmin による自動設定

1. EasyAdmin を開きます（**Start → Widgets → License Manager - Servers**）。  
2. **Servers pending approval** アイコンをクリックします。  
   ![スクリーンショット: Automatic configuration through EasyAdmin](/img/legacy/word-image-38965-7.png)  
3. Razorcat のエントリをダブルクリックします（種別は **OpenLM Generic** と表示されます）。  
4. （任意）接続名を変更し、種別は **OpenLM Generic** のまま、**Enabled** をオンにして **Approve** をクリックします。  
   ![スクリーンショット 2: Automatic configuration through EasyAdmin](/img/legacy/word-image-38965-8.png)

### EasyAdmin による手動設定

自動設定が失敗した場合:

1. **Start → Administration → License Manager Servers** に移動します。  
2. **Add LM** をクリックします。  
3. **Type** から **OpenLM Generic** を選択します。  
4. 説明（例: `Razorcat`）を入力します。  
5. ライセンスサーバーの場所のタイムゾーンを設定します。  
6. Razorcat が動作しているマシンの **Hostname** と **Port** を入力します。  
7. **Is Triad Configuration** のチェックを外します。  
8. **Use Broker** をオンにします。  
9. **Save** をクリックします。

## 設定の確認

1. ブラウザで EasyAdmin を開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に Razorcat が表示され、緑色の丸アイコンになっていることを確認します。  
   ![スクリーンショット: Verify your configuration](/img/legacy/word-image-38965-9.png)  

:::note
新しい接続の後、アクティブ表示まで最大 3 分かかることがあります。
:::
