OpenLM は OpenLM Broker を介して Squish ライセンスサーバーを監視します。詳細な設定手順は現在準備中で、今後のドキュメントリリースで公開予定です。

## はじめに

- OpenLM Server v25.x 以降。
- Squish ライセンスサーバーと同じマシンにインストールされた OpenLM Broker。

:::note[ドキュメント準備中]
Squish の設定が今すぐ必要な場合は、[Customer Portal](https://customer.openlm.com) からチケットを発行し、このページを参照してください。ガイド完成までの間、OpenLM サポートが最新の手順をご案内します。
:::
