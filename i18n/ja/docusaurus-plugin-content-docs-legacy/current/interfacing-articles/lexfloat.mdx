以下の手順で OpenLM を設定し、LexFloat Server のライセンス使用状況を監視して統計情報を取得します。

## 要件

ライセンスマネージャーを問い合わせる前に、次を用意してください:

1. オンプレミスの OpenLM SLM（または OpenLM Platform アカウント）
2. LexFloat Server ライセンスマネージャーと同じマシンに OpenLM Broker v25.2 以降

## 監視機能

| Broker の LM タイプ | コマンド | ログ | 数量 | 有効期限 | 拒否 | 借用 | 割り当て | レポート粒度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| LexFloat Server | いいえ | はい | いいえ | いいえ | いいえ | いいえ | いいえ | 秒 |

Broker を使用すると、バッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the LexFloat Server License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit.png)  
*OpenLM と LexFloat Server License Manager の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM SLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を `http://localhost:5090` で開きます。  
   既定ポートが使用中の場合は `5091` または `5092` を試してください。
2. **License Managers** → **Add License Manager** に移動します。
3. **LM Type** のドロップダウンから **LexFloat Server** を選択します。
4. ポート番号（例: `889`）を入力して **Add** をクリックします。

   ![OpenLM Broker で LexFloat Server ライセンスマネージャーを追加。](/img/legacy/word-image-95237-2.png)  
   *OpenLM Broker への LexFloat Server ライセンスマネージャー追加*

5. **Vendors** タブに移動し、**Add Vendor** をクリックして `LexFloat Server` を入力し、**Continue** をクリックします。

   ![OpenLM Broker で LexFloat Server ベンダーを追加。](/img/legacy/word-image-95237-3.png)  
   *OpenLM Broker で LexFloat Server ベンダーを追加*

6. **Log Files** タブに移動し、**Add Log File** をクリックします。  
   **Watch file by pattern** をオフにします。複数のログを追加できます。**Continue** をクリックします。

   ![OpenLM Broker で LexFloat Server 用のログファイルを追加。](/img/legacy/word-image-95237-4.png)  
   *OpenLM Broker で LexFloat Server のログファイルを追加*

7. **Save** をクリックします。

## OpenLM の設定

上記手順が完了すると、Broker は OpenLM SLM にデータを送信しているはずです。  
EasyAdmin UI で設定を承認します:

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. **Servers Pending Approval** のリンクをクリックします。

   ![EasyAdmin の承認待ちライセンスマネージャー。](/img/legacy/word-image-95237-5.png)  
   *EasyAdmin の保留中ライセンスマネージャー*

4. 保留中の LexFloat Server エントリをダブルクリックします。**OpenLM Generic** と表示されます。

   ![EasyAdmin で OpenLM Generic として表示される承認待ちの LexFloat Server ライセンスマネージャー。](/img/legacy/word-image-95237-6-e1739779295261.png)  
   *EasyAdmin の保留中 LexFloat Server ライセンスマネージャー*

5. （任意）表示名を変更します。設定を確認して **Approve** をクリックします。

   ![EasyAdmin で LexFloat Server ライセンスマネージャーを承認。](/img/legacy/word-image-95237-7-e1739779164634.png)  
   *EasyAdmin で LexFloat Server ライセンスマネージャーを承認*

これで LexFloat Server が OpenLM SLM に追加されます。  
データの解析と表示に少し時間がかかる場合があります。  
緑色の丸アイコンは接続が有効であることを示します。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. 一覧に LexFloat Server ライセンスマネージャーが表示され、緑色の丸アイコンになっていることを確認します。

   ![EasyAdmin でアクティブな LexFloat Server 接続を示す緑色の丸。](/img/legacy/word-image-95237-8.png)  
   *EasyAdmin の緑色の丸アイコンは接続が有効であることを示します*

:::note
新しい接続の後、ステータス更新まで最大 3 分かかることがあります。
:::
