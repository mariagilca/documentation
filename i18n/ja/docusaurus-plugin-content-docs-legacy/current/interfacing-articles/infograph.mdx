以下の手順で OpenLM を設定し、InfoGraph License Manager のライセンス使用状況を監視してライセンス統計を取得します。

## 要件

ライセンスマネージャーを問い合わせる前に、次を用意してください:

1. オンプレミスの OpenLM SLM v2.x（または OpenLM Cloud アカウント）  
2. InfoGraph License Manager と同じマシンに OpenLM Broker v24.11 以降

## 監視機能

| Broker の LM タイプ | コマンド | ログ | 数量 | 有効期限 | 拒否 | 借用 | 割り当て | レポート粒度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| InfoGraph | いいえ | はい | いいえ | いいえ | いいえ | いいえ | いいえ | 秒 |

Broker を使用すると、バッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Broker の設定

![Adding InfoGraph License Manager in OpenLM Broker](/img/legacy/word-image-92953-1.png)  
*OpenLM Broker で InfoGraph License Manager を追加*

:::note
OpenLM Broker は事前にインストールし、OpenLM SLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を `http://localhost:5090` で開きます。  
   既定ポートが使用中の場合は `5091` または `5092` を試してください。
2. **License Managers** → **Add License Manager** に移動します。
3. **LM Type** のドロップダウンから **InfoGraph** を選択します。
4. ポート番号（例: `888`）を入力して **Add** をクリックします。
5. **Settings** タブに移動します。  
   - Broker がライセンスファイルパスを自動検出する場合があります。  
   - 検出できない場合は **Set license file path manually** を選択し、`lgraph.xml` を指定します。

   ![スクリーンショット: OpenLM Broker configuration](/img/legacy/word-image-92953-2.png)  
   *OpenLM Broker で InfoGraph のライセンスファイルパスを設定*

6. **Vendors** タブに移動し、**Add Vendor** をクリックして `InfoGraph` を入力し、**Continue** をクリックします。

   ![スクリーンショット 2: OpenLM Broker configuration](/img/legacy/word-image-92953-3.png)  
   *OpenLM Broker で InfoGraph ベンダーを追加*

7. **Log Files** タブに移動し、**Add Log File** をクリックします。  
   **Watch file by pattern** をオフにします。必要に応じて複数のログファイルを追加できます。**Continue** をクリックして **Save** をクリックします。

   ![スクリーンショット 3: OpenLM Broker configuration](/img/legacy/word-image-92953-4.png)  
   *OpenLM Broker で InfoGraph のログファイルを追加*

## OpenLM の設定

上記手順が完了すると、Broker は OpenLM SLM にデータを送信しているはずです。  
EasyAdmin UI で設定を承認します:

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. **Servers Pending Approval** のリンクをクリックします。

   ![スクリーンショット: OpenLM configuration](/img/legacy/word-image-92953-5.png)  
   *EasyAdmin の保留中ライセンスマネージャー*

4. 保留中の InfoGraph エントリをダブルクリックします。**OpenLM Generic** と表示されます。

   ![スクリーンショット 2: OpenLM configuration](/img/legacy/word-image-92953-6.png)  
   *EasyAdmin の保留中 InfoGraph ライセンスマネージャー*

5. **Display Name** に任意の名前（例: `InfoGraph`）を入力します。

   ![スクリーンショット 3: OpenLM configuration](/img/legacy/word-image-92953-7.png)  
   *InfoGraph ライセンスマネージャーの表示名を編集*

6. （任意）**Custom Fields** タブで国、使用範囲、説明などを追加します。

   ![スクリーンショット 4: OpenLM configuration](/img/legacy/word-image-92953-8.png)  
   *InfoGraph ライセンスマネージャーのカスタムフィールド*

7. 設定内容を確認して **Approve** をクリックします。

これで InfoGraph が OpenLM SLM に追加されます。ステータスの更新に最大 3 分かかることがあります。  
緑色の丸アイコンは接続が有効であることを示します。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. 一覧に InfoGraph ライセンスマネージャーが表示され、緑色の丸アイコンになっていることを確認します。

   ![スクリーンショット: Verify your configuration](/img/legacy/word-image-92953-9.png)  
   *EasyAdmin の緑色の丸アイコンは接続が有効であることを示します*

:::note
新しい接続の後、ステータス更新まで最大 3 分かかることがあります。
:::
