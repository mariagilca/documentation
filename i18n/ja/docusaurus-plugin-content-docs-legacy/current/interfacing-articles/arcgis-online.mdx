OpenLM は ArcGIS Online に接続して、ライセンス数と使用状況データを取得できます。  
> **注:** 2 要素認証 (2FA) が有効な ArcGIS Online アカウントは監視できません。続行する前に 2FA を無効にしてください。

## OpenLM に ArcGIS Online を追加

1. **EasyAdmin** で **Start → Administration → License Manager Servers** に移動します。  
2. **Add LM** をクリックします。  
   ![スクリーンショット: ArcGIS Online to OpenLM の追加](/img/legacy/adding-a-new-lm-1.png)  
3. 分かりやすい **Display Name** を入力します。  
4. **Type** で **ArcGIS Online** を選択します。  
5. **LM Address** に次を入力します:  
   ```
   https://www.arcgis.com
   ```
   6. ArcGIS Online の **admin username** と **password** を入力します。  
7. ライセンスマネージャーの **time zone** を選択します。  
8. **Test Connection** をクリックします。成功すると次のように表示されます:  
![スクリーンショット 2: ArcGIS Online to OpenLM の追加](/img/legacy/test-results-2.png)  
9. **Save** をクリックします。  

数分以内に、ライセンス使用状況と割り当てデータが OpenLM レポートに表示されます。  

![スクリーンショット 3: ArcGIS Online to OpenLM の追加](/img/legacy/test-results-3.png)
