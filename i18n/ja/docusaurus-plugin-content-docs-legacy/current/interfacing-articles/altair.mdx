このガイドでは、Altair License Server (ALS) と OpenLM を連携し、ライセンス使用状況の監視と統計情報の収集を行う方法を説明します。

## 要件

Altair License Server を問い合わせるには次を用意してください:  
1. 組織内のマシンまたは Cloud アカウントに **OpenLM Server v21.x 以降** をインストール済み。  
2. Altair License Server と同じマシンに **OpenLM Broker v21.x 以降** をインストール済み。  

## 監視機能

OpenLM Broker 経由で利用できる監視機能:  
- ライセンス使用状況の監視  
- 拒否レポート  
- ログベースのアクティビティデータ  
- Broker/Server 間のバッファ付き通信  
- ライセンスサービスのリモート起動・停止  

[サポート機能の一覧](https://www.openlm.com/license-manager-capabilities/)。  

## OpenLM Broker の設定

OpenLM と ALS の連携は LMX と類似していますが、使用状況の問い合わせに `almutil` ユーティリティを使用する点が異なります。

> 続行する前に、OpenLM Broker が[インストール](https://www.openlm.com/application-notes-v3-0/installing-openlm-v3-0/broker-comprehensive-installation-guide-an4004b/)され、OpenLM Server へレポートするよう[設定](../openlm-broker/openlm-broker-configuration.md)されていることを確認してください。

### Broker の自動設定

1. Broker 設定ツールで **Detect** をクリックします。  
   ![Autodetect Altair License Server](/img/legacy/autodetect-altair-license-server-1.png)  
   ALS サービスが稼働していれば、Broker が必要な設定でポートノードを自動作成します。  
2. **Apply** をクリックして変更を反映します。  
3. **Restart Broker** をクリックします。  

設定確認: **Commands → data_inquiry** に移動して **Execute** をクリックします。  

### Broker の手動設定

自動検出が失敗した場合:  

1. **Add Port** をクリックし、ALS のポート（既定: **6200**）を入力します。  
2. **License Manager Type** から **Altair** を選択して **Apply** をクリックします。  
3. **Commands** で `almutil.exe` を含むフォルダのパス（例: `C:\Program Files\Altair\licensing13.3\bin`）を設定し、**Update → Apply** をクリックします。  
4. **Vendors** で “Vendor Name to Be Filled” を選択し、わかりやすい名前（例: “Altair”）を入力して **Apply** をクリックします。  
5. **Restart Broker** をクリックします。  
6. 続けて OpenLM Server の設定を行います。  

![Broker configuration for Altair License Server](/img/legacy/openlm-broker-configuration-for-altair-license-ser-1.png)  

## OpenLM Server の設定

### EasyAdmin による自動設定

Broker が設定済みであれば、Server に自動でデータが送信されます。承認するには:  

1. **EasyAdmin** を開きます（ブラウザ: `http://<OpenLM Server FQDN>:5015` または **Windows Start → OpenLM → EasyAdmin**）。  
2. **License Manager Servers** で *Pending approval* のサーバーを見つけます。  
3. ALS サーバーを承認します。  
   ![スクリーンショット: Automatic configuration (EasyAdmin)](/img/legacy/word-image-42294-3.png) ![スクリーンショット 2: Automatic configuration (EasyAdmin)](/img/legacy/word-image-42294-4.png)  

### EasyAdmin による手動設定

自動承認が失敗した場合は、ALS を手動で追加します:  

1. **Administration → License Manager Servers → Add LM** に移動します。  
2. **Display name** を入力します。  
3. **Type** から **LMX** を選択します。  
4. （任意）**Description** を入力します（例: “Altair License Server”）。  
5. サーバーの場所に合わせて **Time Zone** を設定します。  
6. **Hostname** と **Port**（既定: **6200**）を入力します。  
7. 必要に応じて **Triad configuration** を有効にします。  
8. **Use Broker** をオンにします。  
9. **Save** をクリックします。  

![スクリーンショット: Manual configuration (EasyAdmin)](/img/legacy/word-image-42294-5.png)  

## 監視の確認

ALS の監視を確認するには:  

1. **EasyAdmin → Start → Widgets → License Manager Servers** を開きます。  
2. 一覧に ALS が表示されることを確認します。  
3. 接続されるとステータスが **緑色** で表示されます。  

![スクリーンショット: monitoring の確認](/img/legacy/word-image-42294-6.png)  

> 注: 新しい接続の場合、アクティブ表示まで最大 3 分かかることがあります。
