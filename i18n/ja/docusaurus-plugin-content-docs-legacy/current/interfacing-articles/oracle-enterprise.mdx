以下の手順で OpenLM を設定し、Oracle Enterprise Manager のライセンス使用状況を監視して統計情報を取得します。

## 要件

ライセンスマネージャーを問い合わせる前に、次をインストールしてください:

1. 組織内のマシンに OpenLM SLM v2.x
2. Oracle Enterprise Manager と同じマシンに OpenLM Broker v23.8 以降

## 監視機能

| Broker の LM タイプ | ライセンス総数 | ライセンス使用状況 | 拒否 | 借用 | 有効期限 | 冗長化 | レポート粒度 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Oracle Enterprise Manager | いいえ | はい | いいえ | いいえ | いいえ | いいえ | 秒 |

Broker を使用すると、バッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Oracle Enterprise Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit-2.png)  
*OpenLM と Oracle Enterprise Manager の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM SLM へレポートするよう設定しておく必要があります。
:::

### 方法 1 — Broker デスクトップ UI

1. OpenLM Broker デスクトップアプリケーションを開きます。
2. **Add Port** をクリックします。
3. ポート番号（例: `888`）を入力します。
4. **License Manager Type** から **Oracle Enterprise Manager** を選択して **Apply** をクリックします。

   ![OpenLM Broker デスクトップ UI で Oracle Enterprise Manager ライセンスマネージャータイプを選択。](/img/legacy/word-image-91985-2.png)

5. **Commands** ノードに移動します。**Update path for commands** で `lmsettings` 内の Oracle Enterprise Manager SQL ファイルがあるフォルダを参照し、**Update** をクリックします。

   ![OpenLM Broker の Commands ノードで Oracle Enterprise Manager の SQL ファイルのパスを設定。](/img/legacy/word-image-91985-3.png)

6. **data_inquiry** で **Execute** をクリックし、有効な出力を確認します。**Execute** を再度実行する前に **Apply** をクリックします。  
   このコマンドで問い合わせる内容:  
   - ベンダーのライセンスファイルに登録されたライセンス総数  
   - ユーザーにより現在チェックアウトされているライセンス数  

   ![OpenLM Broker デスクトップ UI での Oracle Enterprise Manager のライセンス数出力。](/img/legacy/word-image-91985-4.png)

7. **Vendors** で `Oracle` をベンダー名として入力し、**Apply** をクリックします。
8. Broker を再起動します。

### 方法 2 — Broker Web UI

1. Broker Web UI を `http://localhost:5090` で開きます。  
   既定ポートが使用中の場合は `5091` または `5092` を試してください。
2. **License Managers** → **Add License Manager** に移動します。
3. ドロップダウンから **Oracle Enterprise Manager** を選択し、ポート番号を入力して **Add** をクリックします。

   ![OpenLM Broker の Web UI で Oracle Enterprise Manager ライセンスマネージャーを追加。](/img/legacy/word-image-91985-6.png)

4. **Commands** で **Executable path** を `lmsettings` 内の Oracle Enterprise Manager SQL ファイルがあるフォルダに設定し、**Execute** をクリックします。

   ![OpenLM Broker の Commands タブで Oracle Enterprise Manager の実行ファイルのパスを設定。](/img/legacy/word-image-91985-7.png)

5. **Vendors** で **Add Vendor** をクリックし、`Oracle` を入力して **Continue** をクリックします。

   ![OpenLM Broker の Vendors タブで Oracle ベンダーを追加。](/img/legacy/word-image-91985-8.png)

6. **Save** をクリックします。

## OpenLM SLM の設定

Broker の設定後、EasyAdmin でライセンスマネージャーを承認します:

1. EasyAdmin を開きます。
2. **License Servers** で新しい Oracle Enterprise Manager エントリの赤い行をダブルクリックします。
3. わかりやすい名前を入力するか既定のままにし、**Type** を **OpenLM Generic** のまま **Approve** をクリックします。

自動設定が失敗した場合は手動で設定します:

1. **Start → Administration → License Manager Servers** に移動します。
2. **Add LM** をクリックします。
3. **Type** を **OpenLM Generic** に設定します。
4. 説明（例: `Oracle Enterprise Manager`）を入力します。
5. ライセンスサーバーの場所に合わせて **Time Zone** を設定します。
6. Broker 設定のホスト名とポートを入力します。
7. **Triad Configuration** をオフにし、**Use Broker** をオンにします。
8. **Save** をクリックします。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Servers** に移動します。
3. Oracle Enterprise Manager のエントリが緑色の丸アイコンで表示されることを確認します。

:::note
新しい接続の後、ステータス更新まで最大 3 分かかることがあります。
:::
