# Moldex3D

本ガイドでは、OpenLM を使用して Moldex3D License Manager を監視し、ライセンス使用状況と統計情報を取得する方法を説明します。

## 要件

次をインストールしてください:

1. **OpenLM Server v5.6 以降**、または OpenLM Cloud アカウント  
2. Moldex3D License Manager と同じマシンに **OpenLM Broker v4.12 以降**  

## 監視機能

OpenLM Broker 経由で利用できる監視機能は次のとおりです:

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否 | 借用ライセンス | 有効期限 | 冗長化 |
|---------------------------|------------|----------------|---------------|---------|-------------------|------------------|-------------|
| **対応** | 秒  | ✔              | ✔             | ✔       | ✔                 | ✔                | ❌          |

Broker を使用すると、次の機能も有効になります:

- OpenLM Server とのバッファ付き通信  
- ライセンスマネージャーサービスのリモート起動・停止  

## OpenLM Broker の設定

![Diagram: OpenLM interfacing with Moldex3D License Manager](/img/legacy/openlm-interfacing-with-moldex3d-license-manager-d.png)

Broker は `MDX3DLMUtil` ユーティリティを使用して Moldex3D License Manager をローカルで問い合わせ、データを OpenLM Server に送信します。  

:::note
続行する前に、Broker が[インストール](../openlm-broker/index.md)および[設定](../openlm-broker/openlm-broker-configuration.md)され、OpenLM Server にレポートするようになっていることを確認してください。
:::

### Broker の自動設定

1. Broker で **Detect** をクリックします。  
   ![Broker auto-detect for Moldex3D](/img/legacy/openlm-broker-auto-detect-for-moldex3d-lm.png)  
2. Moldex3D サービス（例: *Moldex3D-LM Service*）が稼働していれば、Broker が自動設定します。  
3. 設定後、**Restart Broker** を選択します。  
4. **data_inquiry → Execute** を実行し、出力が有効であることを確認することを推奨します。  

### Broker の手動設定

自動検出が失敗した場合:

1. **Add Port** をクリックします。  
2. Moldex3D のポート（既定: 2556）を入力します。  
3. **Type** から **Moldex3D** を選択し、**Apply** をクリックします。  
4. **Commands** で `MDX3DLMUtil.exe` があるフォルダを参照します（例: `C:\Moldex3D\LMSR\Tools\MDX3DLMUtil`）。**Update → Apply** をクリックします。  
5. **data_inquiry** で **Execute** をクリックし、出力が有効であることを確認します（エラーなし）。  
6. **Restart Broker** をクリックします。  

![Manual Broker configuration for Moldex3D](/img/legacy/openlm-broker-configuration-for-moldex3d-license-m.png)

### Broker Web UI の設定

1. 最新の Broker をインストールします。  
2. **http://localhost:5090/** を開きます。  
3. **License Managers** に移動します。  
   - Moldex3D サービスが稼働している場合は **Detect** をクリックします。  
   - 自動検出が失敗した場合は **Add License Manager** をクリックし、**Type** で **Moldex3D** を選択してポートを入力し、**Add** をクリックします。  
   ![Add Moldex3D LM in Broker Web UI](/img/legacy/Screenshot-2023-03-17-at-11.57.23-1.png)  
4. **Commands** で `MDX3DLMUtil.exe` のパスを設定し、**Execute** をクリックして確認します。  
5. **Vendors** で **Add Vendor** をクリックし、`Moldex3D` を入力して **Continue** をクリックします。  
   ![Vendors tab in Broker UI](/img/legacy/Screenshot-2023-03-17-at-12.10.24.png)  
6. **Save** をクリックします。

## OpenLM Server の設定

### EasyAdmin による自動設定

Broker が正しく設定されていれば、Server にデータが送信されます。EasyAdmin で承認します:

1. **EasyAdmin** を開きます（`http://<OpenLM Server>:5015` または Windows Start → OpenLM → EasyAdmin）。  
2. **License Manager Servers** で **There are # servers pending approval** をクリックします。  
   ![Pending approval in EasyAdmin](/img/legacy/word-image-42310-4.png)  
3. 保留中の LM エントリを編集します（ダブルクリックまたはペンアイコン）。  
   ![Edit pending LM](/img/legacy/word-image-42310-5.png)  
4. 必要に応じて **Display name** を更新します。  
5. **Approve** をクリックします。  
   ![Approve Moldex3D in EasyAdmin](/img/legacy/word-image-42310-6.png)  
6. Moldex3D License Manager が追加されます。  
   ![Approved Moldex3D LM in EasyAdmin](/img/legacy/word-image-42310-7.png)

### 手動設定

自動承認が失敗した場合:

1. EasyAdmin で **Start → Administration → License Manager Servers** に移動します。  
2. **Add LM** をクリックします。  
3. **Type** から **Moldex3D** を選択します。  
4. **Description** を入力します（例: `Moldex3D License Manager`）。  
5. 正しい **Time Zone** を設定します。  
6. Broker 設定と一致する **Hostname** と **Port** を入力します。  
7. **Is Triad Configuration** はオフのままにします。  
8. **Use Broker** をオンにします。  
9. **Save** をクリックします。  

![Manual server configuration for Moldex3D](/img/legacy/word-image-42310-8.png)

## 設定の確認

1. **EasyAdmin** を開きます（`http://<OpenLM Server hostname>:5015`）。  
2. **Start → Widgets → License Manager Servers** に移動します。  
3. 一覧に Moldex3D が表示されることを確認します。  
4. **緑色の Up to date** アイコンは接続が有効であることを示します。  

![Verify Moldex3D in EasyAdmin](/img/legacy/word-image-42310-9.png)

:::note
新しい接続の場合、ステータス表示の更新に最大 **3 分** かかることがあります。
:::
