# Lloyd’s Register Licence Manager (LiMBR)

この連携により、OpenLM は Lloyd’s Register Licence Manager（LiMBR）のライセンス使用状況、拒否、借用ライセンス、有効期限を監視できます。

## 要件

1. 組織内のマシンに OpenLM Server v21.x 以降をインストール済み、または Cloud アカウント。
2. LiMBR と同じマシンに OpenLM Broker v21.x 以降をインストール済み。

## 監視機能と特徴

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 開始時刻: 秒、終了時刻: 分 | ✔ | ✔ | ✔ | ✔ | ✔ | ❌ |

さらに OpenLM Broker を使用すると、バッファ付き通信と LiMBR サービスのリモート起動・停止が可能になります。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with LiMBR](/img/legacy/word-image-42114-1.png)  
*OpenLM と LiMBR の連携図*

OpenLM Broker は LiMBR のコマンドラインユーティリティを使ってローカルで問い合わせ、結果を集計して OpenLM Server に送信します。

:::note
OpenLM Broker は事前に[インストール](https://www.openlm.com/application-notes-v3-0/installing-openlm-v3-0/broker-comprehensive-installation-guide-an4004b/)し、OpenLM Server にレポートするよう[設定](https://www.openlm.com/Knowledgebase%20and%20articles/openlm-broker-configuration/)しておく必要があります。
:::

### 自動設定

1. Broker 設定ツールで **Detect** をクリックします。
2. LiMBR が稼働していれば、Broker が必要な設定でポートノードを作成します。
3. **Apply** をクリックします。
4. **Restart Broker** をクリックします。
5. 確認するには、**Commands → data_query** に移動して **Execute** をクリックします。

![](/img/legacy/word-image-42114-2.png)

### 手動設定

1. **Add Port** をクリックします。
2. LiMBR のポート番号（既定: `11362`）を入力します。
3. **License Manager Type** を **LiMBR** に設定して **Apply** をクリックします。
4. **Commands** で LiMBR のインストール先フォルダを参照し、**Update** → **Apply** をクリックします。
5. **status** で構成を確認します。
6. **data_inquiry** で **Execute** をクリックし、出力が有効であることを確認します。
7. **Restart Broker** をクリックします。
8. **Vendors** で **Vendor Name** に **LiMBR** を入力し、**Apply** をクリックします。
9. もう一度 **Apply** をクリックします。
10. **Restart Broker** をクリックします。

![Automatic Broker configuration](/img/legacy/automatic-broker-configuration.png)

## OpenLM Server の設定

### EasyAdmin による自動設定

1. **EasyAdmin** を開きます（`http://<OpenLM Server FQDN>:5015` または **Windows Start → OpenLM → OpenLM EasyAdmin User Interface**）。
2. **License Manager Servers** で新しい LiMBR エントリを承認します。

![](/img/legacy/word-image-42114-4.png)  
![](/img/legacy/word-image-42114-5.png)

### 手動設定

1. EasyAdmin で **Administration → License Manager Servers → Add LM** に移動します。
2. **Type** を **LiMBR** に設定します。
3. 表示名と説明（例: LiMBR）を入力します。
4. タイムゾーンを設定します。
5. ホスト名とポート（既定: `11362`）を入力します。
6. **Is Triad Configuration**: オフ。
7. **Use Broker**: オン。
8. **Save** をクリックします。

![](/img/legacy/word-image-42114-6.png)

## 設定の確認

1. EasyAdmin を開きます（`http://<OpenLM Server FQDN>:5015` または `Cloud.openlm.com`）。
2. **Start → Widgets → License Manager Servers** に移動します。
3. LiMBR が表示され、緑色の丸アイコンになっていることを確認します。

![](/img/legacy/word-image-42114-7.png)

:::note
新しい接続の後、EasyAdmin にアクティブとして表示されるまで最大 3 分かかることがあります。
:::
