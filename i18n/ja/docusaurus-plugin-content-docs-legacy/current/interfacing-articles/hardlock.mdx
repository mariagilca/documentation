以下の手順で OpenLM を設定し、Hardlock ライセンスマネージャーのライセンス使用状況を監視して統計情報を取得します。

## 要件

開始前に次を用意してください:

- 組織内のマシンに OpenLM SLM v5 以降をインストール済み  
- Hardlock と同じマシンに OpenLM Broker v4.14 以降

## 監視機能

OpenLM Broker 経由で Hardlock に対して利用できる監視機能は次のとおりです:

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスのレポート | 有効期限のレポート | 冗長化（複数サーバー） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | ログファイル解析 | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Hardlock license manager](/img/legacy/how-openlm-interfaces-with-the-hardlock-licensemon-1.png)  
*OpenLM と Hardlock ライセンスマネージャーの連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM SLM へレポートするよう設定しておく必要があります。
:::

### 手動設定（Broker デスクトップ UI）

1. **Add Port** をクリックします。  
2. Broker はログファイルのみを読み取るため、任意のポート番号（例: `21723`）を入力します。  
3. **License Manager Type** から **Hardlock** を選択し、**Apply** をクリックします。  
4. **Vendors** で *Vendor Name to Be Filled* を選択し、**Hardlock** を入力して **Apply** をクリックします。  
5. **Log Files** ノード → **Add Log File** に進みます。  
6. 新しい **log** ノードを選択し、**[…]** をクリックして Hardlock の `.log` ファイルの場所を参照します。  
7. **Apply** をクリックします。  
8. **Restart Broker** をクリックします。

### 手動設定（Broker Web UI）

1. ブラウザで [http://localhost:5090/](http://localhost:5090/) を開きます。  
2. **License Managers → Add License Manager** に移動します。  
   ![OpenLM Broker の Web UI で Add License Manager を開く。](/img/legacy/broker-web-ui-1.png)  
3. **Hardlock** を選択し、任意のポート番号（例: `888`）を入力して **Add** をクリックします。  
   ![OpenLM Broker の Web UI で Hardlock ライセンスマネージャーを追加。](/img/legacy/popup-2.png)  
4. **Vendors** で **Add Vendor** をクリックし、**Hardlock** を入力して **Continue** をクリックします。  
   ![OpenLM Broker の Vendors タブで Hardlock ベンダーを追加。](/img/legacy/add-lm-1.png)  
5. **Log Files** で **Add Log File** をクリックし、`.log` ファイルを参照して **Open** をクリックします。  
6. ベンダー **Hardlock** を選択して **Continue** をクリックします。  
   ![OpenLM Broker の Log Files タブで Hardlock のログファイルを追加。](/img/legacy/popup-3.png)  
7. **Save** をクリックします。

## OpenLM SLM の設定

### EasyAdmin による自動設定

1. EasyAdmin を開きます（**Start → Widgets → License Manager - Servers**）。  
2. Hardlock のエントリをダブルクリックします。  
   ![EasyAdmin の License Manager - Servers ウィジェットで Hardlock エントリを開く。](/img/legacy/olm-user-interface-screen-1.png)  
3. （任意）接続名を変更し、種別は **Hardlock** のまま **Approve** をクリックします。  
   ![EasyAdmin で Hardlock ライセンスマネージャーを承認。](/img/legacy/pending-license-manager-screen-1.png)

### EasyAdmin による手動設定

自動設定が失敗した場合:

1. **Start → Administration → License Manager Servers** に移動します。  
2. **Add LM** をクリックします。  
3. **Type** から **OpenLM Hardlock** を選択します。  
4. 説明（例: `Hardlock`）を入力します。  
5. ライセンスサーバーの場所のタイムゾーンを設定します。  
6. Broker で設定した **Hostname** と **Port** を入力します。  
7. **Is Triad Configuration** のチェックを外します。  
8. **Use Broker** をオンにします。  
9. **Save** をクリックします。  
   ![EasyAdmin で Use Broker を有効にして Hardlock ライセンスマネージャーを手動で追加。](/img/legacy/add-license-manager-screen-1.png)

## 設定の確認

1. ブラウザで EasyAdmin を開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に Hardlock が表示され、緑色の丸アイコンになっていることを確認します。  

:::note
新しい接続の後、アクティブ表示まで最大 3 分かかることがあります。
:::
