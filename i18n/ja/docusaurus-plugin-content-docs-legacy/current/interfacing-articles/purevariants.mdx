以下の手順で OpenLM を設定し、pure::variants License Manager のライセンス使用状況を監視して統計情報を取得します。

## 要件

開始前に、以下を満たしていることを確認してください:

1. 組織内のマシンに OpenLM SLM v2x をインストール済み、または OpenLM Platform アカウント  
2. pure::variants License Manager と同じマシンに OpenLM Broker v22.3 以降をインストール

## 監視機能

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否レポート | 借用ライセンスレポート | 有効期限レポート | 複数サーバー冗長 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 分単位 | ✔ | ✔ | ❌ | ❌ | ❌ | ❌ |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the pure::variants License Manager](/img/legacy/how-openlm-interfaces-with-the-coscom-licensemonit.png)  
*OpenLM と pure::variants License Manager の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を `http://localhost:5090/` で開きます（5090 が使用中の場合は別のポートを使用）。  
2. **License Managers** → **Add License Manager** に移動します。  
   ![OpenLM Broker の Web UI で Add License Manager を開く。](/img/legacy/word-image-54772-2.png)  
3. ドロップダウンから **Pure Variants** を選択し、ポート番号（例: 888）を入力して **Add** をクリックします。  
4. **Settings** タブで **Watch License File** がオフになっていることを確認します。  
5. **Commands** タブで pure::variants の実行ファイルパスを入力します。  
   ![OpenLM Broker の Commands タブで pure::variants の実行ファイルのパスを設定。](/img/legacy/word-image-54772-3.png)  
6. **Vendors** タブ → **Add Vendor** で `pure::variants` を入力し、**Continue** をクリックします。  
   ![OpenLM Broker の Vendors タブで pure::variants ベンダーを追加。](/img/legacy/word-image-54772-4.png)  
7. **Advanced** タブで pure::variants のログインとパスワードを入力します。  
8. **Save** をクリックします。

## OpenLM SLM の設定

### EasyAdmin による自動設定

1. EasyAdmin を開き、**Start → Widgets → License Manager Servers** に移動します。  
2. **Servers pending approval** のアイコンをクリックします。  
   ![EasyAdmin で Servers pending approval アイコンを選択。](/img/legacy/word-image-54772-5.png)  
3. pure::variants のエントリ（**OpenLM Generic** と表示）を選択し、設定内容を確認します。  
4. **Approve** をクリックします。  
   ![EasyAdmin で OpenLM Generic として表示される pure::variants エントリを承認。](/img/legacy/word-image-54772-6.png)  

pure::variants License Manager は自動で追加され、しばらくするとレポートが開始されます。

## 設定の確認

1. EasyAdmin を開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に pure::variants License Manager が表示され、緑色の丸のステータスになっていることを確認します。

:::note
新しい接続がアクティブとして表示されるまで最大 3 分かかることがあります。
:::
