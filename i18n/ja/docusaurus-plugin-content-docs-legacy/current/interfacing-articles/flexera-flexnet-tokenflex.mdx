# Flexera FlexNet (TokenFlex)

OpenLM は Flexera FlexNet (TokenFlex) のライセンス使用状況とトークン消費を監視できます。

## 要件

1. 中央のネットワークサーバーに OpenLM Server を 1 台インストールすること。
2. （推奨）FlexNet サーバーに OpenLM Broker をインストールし、ファイル監視、データバッファリング、リモート制御などの機能を利用すること。
3. トークン使用状況を監視するため、クライアントマシンに OpenLM Workstation Agent をインストールすること。

## Broker の設定

:::note
この設定を開始する前に、OpenLM Broker をインストールして OpenLM Server に接続してください。
:::

1. **OpenLM Broker Configuration** を開きます。
2. **OpenLM Servers** → **Add** → **localhost** を選択します。
3. **OpenLM Server hostname** を設定します。
4. **Check connectivity to OpenLM Server** → **Apply** をクリックします。
5. **Detect** をクリックして FlexLM ライセンスサーバーを検出します。
6. ライセンスサーバーのホスト名タブを選択します。
7. ポートが一覧にない場合は **Add Port** をクリックします。
8. **License Servers** で次を設定します:
   - **License Manager Type**: FlexLM
   - **License file path**: ベンダーのライセンスファイルのパス（利用可能な場合）
   - ライセンスファイルが表示されない場合は **Set Path Manually** → **Add** → ファイルを選択します。
   - **Watch License File** にチェックします。
9. **Apply** をクリックします。
10. **Commands** でベンダーの `lmutil.exe` のパスを設定し、**Update** → **Apply** をクリックします。
11. **Vendors** で次を設定します:
    - ベンダーがない場合は **Add Vendor** をクリックします。
    - **Name** をベンダー指定の正確な名前にします（例: `adskflex`, `ptc_d`, `MLM`, `ugslmd`）。
    - **Option File Description**: オプションファイルの分かりやすい名前。
    - **Option File Path**: オプションファイルのパス。
    - **Watch Options File** にチェックします。
12. **Log Files** で次を設定します:
    - ログがない場合は **Add Log** をクリックします。
    - 次を設定します:
      - **Type**: ログファイル種別
      - **Name**: 分かりやすい名前
      - **Path**: ベンダーのデバッグログファイルのパス
      - **Vendor**: ベンダー名
13. **Apply** をクリックします。
14. **Restart Broker** → **OK** をクリックしてツールを閉じます。
15. EasyAdmin で **Widgets → License Servers** に移動し、赤線のエントリで **Approve** をクリックします。
16. **OpenLM Server Configuration** でライセンスサーバーの **Token Support** を有効にします。
17. **Apply** をクリックします。

## サーバーを直接設定する場合（Broker なし）

1. **OpenLM Server Configuration** を開きます（**Windows Start → OpenLM → OpenLM Server**）。
2. **LM Tools** → **FlexLM** に移動します。
3. ライセンスサーバーから `lmutil.exe` を次へコピーします:  
   `C:\Program Files\OpenLM\OpenLM Server\LM\`
4. **LM Tools** で `lmutil.exe` のフルパスを入力します。
5. **License Servers** → **Add** で次を設定します:
   - **Type**: FlexLM
   - **Description**: サーバー名
   - **Time Zone**: ライセンスサーバーのタイムゾーン
   - **Hostname** と **Port**: サーバー情報
   - **Is Triad Configuration**: 該当する場合はチェック
   - **Use Broker**: 未チェック
   - **Read license file**: 未チェック
   - **Enable Token Support**: チェック
6. **Apply** をクリックします。

## 設定の確認

1. EasyAdmin を開きます。
2. **Widgets → License Servers** に移動します。
3. FlexNet (TokenFlex) サーバーが緑色のステータスで表示されることを確認します。

:::note
EasyAdmin でライセンスマネージャーがアクティブとして表示されるまで最大 3 分かかることがあります。
:::
