# ASH WARE

以下の手順で OpenLM を設定し、ASH WARE のライセンス使用状況を監視して統計情報を取得します。

## 要件

ライセンスマネージャーを問い合わせる前に、次を用意してください:

1. オンプレミスの OpenLM SLM（または OpenLM Cloud アカウント）
2. ASH WARE ライセンスマネージャーと同じマシンに OpenLM Broker v25.5 以降

## 監視機能

| Broker の LM タイプ | コマンド | ログ | 数量 | 有効期限 | 拒否 | 借用 | 割り当て | レポート粒度 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ASH WARE | はい | いいえ | はい | はい | いいえ | いいえ | いいえ | 秒 |

Broker を使用すると、バッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Broker の設定

![Diagram of OpenLM Broker connection to ASH WARE license manager](/img/legacy/word-image-97945-1.png)  
*OpenLM Broker による ASH WARE ライセンスマネージャー接続*

:::note
OpenLM Broker は事前にインストールし、OpenLM SLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を `http://localhost:5090` で開きます。  
   同じネットワーク上の別マシンからアクセスする場合は、次にアクセスしてトークンを生成します:  
   `http://localhost:5090/api/new-token`
2. **License Managers** → **Add License Manager** に移動します。
3. **LM Type** のドロップダウンから **ASH WARE** を選択します。
4. ポート番号（既定: `6333`）を入力して **Add** をクリックします。

   ![](/img/legacy/word-image-97945-2.png)  
   *Setting executable path for ASH WARE in OpenLM Broker*

5. **Executable Path** フィールドで ASH WARE の `.exe` ファイルのインストールディレクトリを指定します。
6. **Save** をクリックします。
7. 設定を確認するため、**Commands** タブで **Execute** をクリックします。

   ![](/img/legacy/word-image-97945-3.png)  
   *Example of a successful execution result*

8. **Vendors** タブに移動し、**Add Vendor** をクリックして `ASH WARE` を入力し、**Continue** をクリックします。

   ![](/img/legacy/word-image-97945-4.png)  
   *Adding ASH WARE vendor in OpenLM Broker*

9. **Save** をクリックします。

## OpenLM の設定

上記手順が完了すると、Broker は OpenLM SLM にデータを送信しているはずです。  
EasyAdmin UI で設定を承認します:

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. **Servers Pending Approval** のリンクをクリックします。

   ![](/img/legacy/word-image-97945-5.png)  
   *Pending license managers in EasyAdmin*

4. ASH WARE のエントリの編集アイコンをクリックします。  
   **Display Name** に任意の名前を入力します（例: `ASH WARE`）。

   ![](/img/legacy/word-image-97945-6.png)  
   *Editing display name for ASH WARE license manager*

5. （任意）**Custom Fields** タブで国、使用範囲、説明などを追加します。

   ![](/img/legacy/word-image-97945-7.png)  
   *Adding custom fields for ASH WARE license manager*

6. **Approve** をクリックします。

## 設定の確認

1. EasyAdmin を開きます。
2. **Start → Widgets → License Manager Servers** に移動します。
3. 一覧に ASH WARE ライセンスマネージャーが表示され、緑色の丸のステータスになっていることを確認します。

:::note
新しい接続の後、ステータス更新まで最大 3 分かかることがあります。
:::
