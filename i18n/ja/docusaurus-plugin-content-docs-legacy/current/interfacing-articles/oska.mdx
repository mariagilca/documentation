OpenLM は **OSKA License Manager** の監視に対応し、信頼性の高いライセンスレポートと使用状況統計を提供します。  
OSKA ライセンスサーバーは定期的に XML ファイルを生成し、OpenLM が解析して **EasyAdmin** に使用状況を表示します。  

## 前提条件

OSKA の監視には次が必要です:

- **OpenLM Broker** を OSKA ライセンスサーバーマシンにインストール  
- **OpenLM SLM** をネットワーク内の任意の Windows マシンにインストール（OSKA サーバーと同一でも可）  

Broker は OSKA ライセンスサーバーをローカルで問い合わせ、データを OpenLM SLM に送信します。

## 設定

### OpenLM Broker の設定

1. [最新の Broker をダウンロードしてインストール](https://www.openlm.com/downloads/)します。  
2. 自動検出が失敗する場合は、ライセンスマネージャーノードを選択して **Add Port** をクリックします。  
3. 新しいライセンスサーバーにポートを追加します:  
   - **oska_server** をクリックします。  
   - **Add Port** をクリックします。  
   - OSKA から提供された **Port number** を入力します（例: `12345`）。  
   - **License Manager Type** で **OpenLM Generic** を選択します。  
   - **Apply → OK** をクリックします。  
4. **Commands** ノードで次を設定します:  
   - `OpenLMConsole.exe` のフルパスを入力します。  
   - **Update → Apply** をクリックします。  
5. **data_inquiry** に OSKA のデータ照会コマンドのフルパスを入力します:  

   ```bash
   C:\Program Files (x86)\OSKA\OpenLMConsole.exe

   ```

   `OpenLMConsole.exe` はベンダーから提供されます。  
6. **Execute** をクリックしてテストし、続いて **Apply** をクリックします。  
7. `status` コマンドでも同様に設定します。  
8. **Vendors** を開き **Add Vendor** をクリックし、`OSKA` を入力します。  
9. **Apply** をクリックします（コマンド更新の確認が出た場合は **No** を選択）。  
10. **Restart Broker** をクリックします。  
11. （任意）Broker Web UI で設定します。  

### EasyAdmin で LM を追加

1. EasyAdmin を開き **Start → Administration → License Manager Servers** に移動します。  
2. **LM Servers** タブで **Add License Manager** をクリックします。  
3. **Type** で **OpenLM_Generic** を選択します。  
4. **Display Name** を入力します（例: `My OSKA License Server`）。  
5. **Time Zone** を設定します（例: `Istanbul UTC+3`）。  
6. **Hostname** と **Port** を入力します（例: `oska_license_server`, `12345`）。  
7. **Use Broker** にチェックします。  
8. **Save** をクリックします。  

### OSKA 設定の確認

1. EasyAdmin の Web インターフェイスを開きます。  
2. **Pending Approval** から OSKA を承認します。  
3. サーバー一覧に OSKA ライセンスマネージャーが表示されることを確認します。  
   - 緑色の丸はアクティブな接続を示します。
