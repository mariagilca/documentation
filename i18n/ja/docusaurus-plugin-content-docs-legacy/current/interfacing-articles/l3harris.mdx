# L3Harris

以下の手順で OpenLM を設定し、L3Harris License Manager のライセンス使用状況を監視して統計情報を取得します。

## 要件

開始前に、以下を満たしていることを確認してください:

1. OpenLM SLMC アカウント **または** 組織内のマシンに OpenLM Server v24 以降をインストール済み  
2. L3Harris License Manager と同じマシンに OpenLM Broker v24.4.5 以降をインストール

## 監視機能

| 機能 | 粒度 | ライセンス総数 | ライセンス使用状況 | 拒否 | 借用 | 有効期限 | 冗長 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 対応 | 秒単位 | ✔ | ❌ | ❌ | ❌ | ❌ | ❌ |

Broker によりバッファ付き通信が有効になり、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with L3Harris](/img/legacy/diagram-of-how-openlm-interfaces-with-the-aescript-1.png)  
*OpenLM と L3Harris の連携図*

:::note
OpenLM Broker は事前にインストールし、OpenLM へレポートするよう設定しておく必要があります。
:::

1. Broker Web UI を `http://localhost:5090` で開きます（既定ポートが使用中の場合は `5091`、`5092`）。  
2. **License Managers** → **Add License Manager** に移動します。  
3. ドロップダウンから **L3Harris** を選択し、ポート番号を入力します。  
   *ポート番号はデータ取得には使用されませんが、ライセンスのために必要です。*  
4. **Add** をクリックします。  
   ![スクリーンショット: OpenLM Broker configuration](/img/legacy/word-image-88565-2-1.png)  
5. **Commands** タブで L3Harris のログフォルダーを参照し、**Apply** をクリックします。  
6. **Executable path** フィールドに L3Harris ライセンスサーバー上の実行ファイルパスを指定します。  
7. **Vendors** に移動してベンダー名を設定します。  
8. **Log Files** → **Add Log File** に移動して次を設定します:
   - **Log type** – Usage Log  
   - **Log name (descriptive)** – ログを識別する任意の名前  
   - **Log path** – L3Harris のログフォルダーを指定  
   - **Vendor** – Vendors タブで定義したベンダー  
   - **Set data size limit (KB)** – 既定 `100`  
   - **Read file every (sec)** – 既定 `10`  
   - **Watch file by pattern** – Off  
   - **Encoding** – `windows-152`  
   ![スクリーンショット 2: OpenLM Broker configuration](/img/legacy/word-image-88565-3-1.png)
9. **Continue** をクリックし、続いて **Save** をクリックします。

## OpenLM Server の設定

### EasyAdmin による自動設定

1. EasyAdmin を `http://<OpenLM-Server-IP>:5015/` で開くか、**Windows Start → OpenLM → OpenLM EasyAdmin User Interface** から起動します。  
2. **License Manager Servers** で **Servers pending approval** のアイコンをクリックします。  
   ![スクリーンショット: Automatic configuration through EasyAdmin](/img/legacy/word-image-88565-4-1.png)  
3. L3Harris のエントリを選択し、内容を確認して **Approve** をクリックします。

承認後、L3Harris License Manager が一覧に表示され、短時間の処理後にレポートが開始されます。

## 設定の確認

1. EasyAdmin を開きます。  
2. **Start → Widgets → License Servers** に移動します。  
3. 一覧に L3Harris License Manager が表示され、緑色の丸のステータスになっていることを確認します。

:::note
新しい接続がアクティブとして表示されるまで最大 3 分かかることがあります。
:::
