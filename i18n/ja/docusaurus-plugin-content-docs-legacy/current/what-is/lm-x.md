## LM-Xとは?

LM-Xは、デンマークの小さな会社であるX-Formationによって開発されたライセンス管理ソフトウェアです。顧客は主にヨーロッパに拠点を置いていますが、ABB、LUK、NASAも含まれています。LM-Xは、Windows、Linux、Mac OS、およびいくつかのオープンソースプラットフォームで実行できます。ライセンスマネージャーは、ネットワーク、ノードロック、トークンベース、および従量課金制のライセンスをサポートしています。LM-Xは、ハードウェアとソフトウェアの両方のライセンス保護を希望する顧客向けに、HASPドングルとも統合されています。ライセンスの借用と猶予期間もサポートされています。

OpenLMは、LM-Xライセンスを監視するために次の機能を提供します。

- 拒否レポート *はい*
- レポート解決 *分単位*
- 借用ライセンスレポート *いいえ*
- 有効期限レポート *はい*
- 複数サーバー冗長サポート *いいえ*
- トークンライセンスサポート *はい*

LM-Xは、OpenLMが管理できる70以上のライセンスマネージャーの1つにすぎません。[リストを確認してください](https://www.openlm.com/license-manager-capabilities/)。

### X-Formationとは?

X-Formationは、約600社の顧客にライセンス管理ソフトウェアを供給しているデンマークの小さな独立系ソフトウェアベンダーです。小規模な組織ですが、ABB、LUK、NASA、Thales Aleniaなどの大企業をクライアントとして抱えていますが、最近のThalesによるGemaltoの買収により、その関係は終わる可能性があります。製品はLM-X License Managerであり、Mac OSを含むほとんどのプラットフォームで実行されます。X-Formationには、ライセンス認証と統計レポート製品もあります。2004年に設立された同社は、デンマークのオーフスに本社を置き、開発チームはポーランドのクラクフにあり、約25人の従業員がいます。
