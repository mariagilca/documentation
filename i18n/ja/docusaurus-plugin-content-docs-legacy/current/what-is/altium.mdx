## Altiumとは?

プリント基板（PCB）を設計するためのEDAソフトウェアの主要プロバイダーの1つとして、Altiumはオンプレミスサイト向けに独自のライセンスマネージャーを持っています。これは、サーバー用のライセンスで構成される2層のライセンスシステムであり、ユーザーライセンスのプールを制御します。同時ユーザーの最大数に達すると、ライセンスが解放されるまでユーザーは拒否されます。

OpenLMは、Altiumライセンスを監視するために次の機能を提供します。

| 機能 | サポート |
|-----------|---------|
| 拒否レポート | はい |
| レポート解像度 | 1分あたり |
| 借用ライセンスレポート | いいえ |
| 有効期限レポート | はい |
| 複数サーバー冗長サポート | 1つのバックアップ |
| トークンライセンスサポート | いいえ |
Altiumは、OpenLMが管理できる90以上のライセンスマネージャーの1つにすぎません。
## Altium 365とは?

Altium 365は、現在（2019年8月）ベータテストモードであり、Altiumの登録ユーザーが利用できるAltiumのクラウド製品です。
