## BetaLMとは?

BetaLMは、Beta Computer Aided Engineering Systemsが自社のコンピュータ支援エンジニアリング（CAE）製品向けに提供する独自のライセンスマネージャーです。これには、プリプロセッサとしての構造解析用自動ネット生成（ANSA）や、ポストプロセッサとしてのマルチドメイン後処理環境（META）が含まれます。このシミュレーションソフトウェアは、多くの場合バッチモードで実行されます。

OpenLMは、BetaLMライセンスに対して次の監視機能を提供します。

| 機能 | サポート |
|------------|---------|
| 拒否レポート | はい |
| レポート解像度 | 1秒あたり |
| 借用ライセンスレポート | 該当なし |
| 有効期限レポート | はい |
| 複数サーバー冗長サポート | トライアド |
| トークンライセンスサポート | いいえ |

BetaLMは、OpenLMが監視する90以上のライセンスマネージャーの1つです。完全な[リスト](https://www.openlm.com/license-manager-capabilities/)をご覧ください。

### Beta CAE Systemsについて

約25年前にルツェルンで設立されたスイスのコンピュータ支援エンジニアリング（CAE）ソフトウェア会社であるBeta Computer Aided Engineering Systemsは、米国、インド、日本、およびヨーロッパ全土に拠点を置き、世界中で事業を展開しています。製品には、自動車、航空宇宙、石油化学産業で使用される構造解析用自動ネット生成（ANSA）やマルチドメイン後処理環境（META）などがあります。同社はまた、独自のライセンスマネージャーであるBetaLMも開発しました。Beta CAEシミュレーションソフトウェアは、NVIDIAおよびAdvanced Micro Devices（AMD）のグラフィックスプロセッシングユニット（GPU）で実行されます。ANSAは、DassaultやSiemensなどの他のCAEベンダーからの幅広いデータ形式を取り込みます。
