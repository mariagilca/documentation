## ArcGIS Onlineとは?

ArcGIS Onlineは、EsriのArcGIS製品群のSaaSバージョンです。このクラウドサービスは、個人またはチーム向けのツールとして利用でき、チームオプションは、「GISプロフェッショナル」や「フィールドワーカー」など、組織内でユーザーが果たす役割に応じて分類されます。これらは「ユーザータイプ」として知られており、クラウドへの変換を希望する見込みのある新規顧客または既存の顧客は、従業員の構成に応じて必要なライセンスを決定する必要があります。ただし、必要に応じて新しいユーザーを追加することは可能です。「クリエーター」ユーザータイプには管理者権限があるため、常に少なくとも1つのクリエーターライセンスが必要です。Adobeとは異なり、表示専用（ビューアー）の役割にもライセンスが必要です。

お客様は、Amazon Web Services（AWS）、Microsoft Azure、Esri独自のクラウドサービスの3つのクラウドエコシステムのいずれかを選択することもできます。

Autodeskと同様に、Esriは永続的なユーザーをサブスクリプションユーザーに変換する動きを進めてきましたが、当初はArcGISコミュニティから強い否定的な反応があり、戦略を再考する必要がありました。クラウドバージョンを使用する場合、アップグレードやメンテナンスの支払いが必要ないため、特に個人や小規模な企業にとっては、ArcGIS Onlineに移行する利点があります。また、クラウドを介して作業を簡単に共有することもできます。

OpenLMは、ArcGIS Onlineライセンスを監視するために次の機能を提供します。

| 機能 | サポート |
|-----------|---------|
| 拒否レポート | いいえ |
| レポート解像度 | 1秒あたり |
| 借用ライセンスレポート | 該当なし |
| 有効期限レポート | はい |
| 複数サーバー冗長サポート | 該当なし |
| トークンライセンスサポート | いいえ |


### Esriとは?

Environmental Systems Research Institute, Inc.（Esri）は、1969年にJack Dangermondと彼の妻Lauraによって設立されました。Jackは、Howard Fisherによって設立されたハーバード大学コンピュータグラフィックス研究所で働いていました。当初、Esriは空間分析のコンサルティング会社であり、徐々に現在ArcGISとして知られているGISソフトウェアを開発しました。これは、1981年に最初にリリースされた、世界で最も一般的に使用されているGISソフトウェアです。

カリフォルニア州レッドランズの元のオフィスから、彼らは事業を成長させ、世界中に49のオフィスに拡大しました。現在も約9,000人の従業員と100万人以上のユーザーを抱える、個人所有の家族経営の会社です。
