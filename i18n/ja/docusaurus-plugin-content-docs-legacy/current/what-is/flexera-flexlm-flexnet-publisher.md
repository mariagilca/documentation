## FlexLMとは?

FlexLMはFlexeraの中核となるライセンス管理ソリューションであり、2000年から2009年にかけて元々使用されていたFlexNet Publisherに名称変更されました。

## FlexNet Publisherとは?

FlexNet Publisherは、FlexNet Licensing®傘下の中核製品です。ライセンス管理用の主要なソフトウェアアプリケーションであり、世界市場のほぼ半分を占めています。

ソフトウェアベンダーは、これを使用して、永久ライセンス、ノードロックライセンス、および従量課金制ライセンスを管理できます。

多くのお客様は、依然として「FlexLM」という名称に慣れ親しんでいます。

その他のライセンス製品は次のとおりです。

- IoTデバイス向けの小さなフットプリントを持つFlexNet Embedded
- FlexNet Embeddedやその他のデバイスにアクセスするCloud Monetization API
- ソフトウェアとハ​​ードウェアのライセンス管理を組み合わせた、ライセンス管理に対する「万全の」アプローチを望むベンダー向けのFlexNet IDドングル

OpenLMは、FlexNetライセンスを監視するために次の機能を提供します。

- 拒否レポート *はい*
- レポート解決 *秒単位*
- 借用ライセンスレポート *はい*
- 有効期限レポート *はい*
- 複数サーバー冗長サポート *はい*
- トークンライセンスサポート *はい*

FlexNetは、OpenLMが管理できる70以上のライセンスマネージャーの1つにすぎません。[リストを確認してください](https://www.openlm.com/license-manager-capabilities/)。

### Flexeraとは?

Flexeraとそのライセンス管理製品であるFlexLM Publisherには、長い歴史があります。このソフトウェアは、元々1988年にGLOBEtrotter SoftwareによってUNIX環境向けに開発され、1994年にGLOBEtrotterに買収されるまで権利を保有していたHighland Softwareによって販売されていました。その後、GLOBEtrotterは2000年にMacrovision Corpに買収され、製品名をFlexLMからFlexNet Publisherに変更しました。2008年、Macrovisionはソフトウェア部門をプライベートエクイティ会社のThomas Bravoに売却し、社名をAcresso Softwareに変更しましたが、Agresso Softwareによる法的な異議申し立てを受けて2009年に再びFlexera Softwareに変更し、製品名をFlexNet Publisherに変更しました。2011年、オンタリオ州教職員年金基金の民間投資部門であるTeachers' Private Capitalは、Flexera Softwareの過半数の株式を取得することに合意しました（株式の規模は非公開）。

Flexeraは、ブランドを構築するために着実にソフトウェア会社を買収してきました。

- 2010年、オーストラリアの企業であるManageSoftとそのSAM機能を使用して300万台のデバイスを使用する250社の企業顧客を買収しました。
- 2018年、クラウド管理機能のためにRightScaleを買収しました。
- 2019年、Rightscaleへの投資を補完するためにRISC Networksを買収しました。

Flexeraは、シカゴに本拠を置く非公開企業で、1300人以上の従業員と、3000万台のデバイスを管理する50,000以上の顧客を抱えています。世界をリードするソフトウェアライセンス管理プロバイダーであり、Gemaltoのハードウェアライセンス管理の大きな基盤があるため、ライセンス管理ではGemaltoに次ぐ第2位です。
