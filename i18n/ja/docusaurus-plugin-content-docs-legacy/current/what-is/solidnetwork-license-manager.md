## SolidNetwork License Manager (SNL)とは?

これは、ネットワークライセンスを持つサイト向けのSolidworks独自のライセンスマネージャーです。

ネットワークのお客様の場合、ライセンスマネージャーはリリースごとにアップグレードする必要があります。

![](/img/legacy/image3-1.png)

以前のバージョンのSolidworksでは、ライセンス保護にドングルを使用していましたが、新しいバージョンではソフトウェアベースのライセンスマネージャーを使用しており、ライセンスサーバーにインストールする必要があります。ソフトウェアの使用が許可されているクライアントは、クライアントマシンにライセンスシリアル番号をロードすることで示されます。これは、マシンを廃止する前に削除し、新しいマシンで再アクティブ化する必要があります。同時ユーザーライセンスとスタンドアロンライセンスが提供されます。

OpenLMは、SOLIDWORKSライセンスを監視するために次の機能を提供します。

- 拒否レポート *いいえ*
- レポート解決 *分単位*
- 借用ライセンスレポート *いいえ*
- 有効期限レポート *いいえ*
- 複数サーバー冗長サポート *いいえ*
- トークンライセンスサポート *いいえ*

SOLIDWORKSは、OpenLMが管理できる70以上のライセンスマネージャーの1つにすぎません。[リストを確認してください](https://www.openlm.com/license-manager-capabilities/)。

## Solidworksとは?

Solidworksは、1995年に設立されたDassaultの会社です。創設者のJohn HirschtickはMITの卒業生であり、根っからの起業家であり、同僚のAxel BicharaとMITで開発されたPremiseというCADモデラーソフトウェアを販売する会社をすでに設立していました。Premiseは時代を先取りしており、市場はまだ準備ができていませんでした。Computervisionに買収され、Johnも一緒に買収され、1193年までそこに留まり、その後、志を同じくする起業家のグループとWinchester Design Systemsを設立するために去りました。彼らは収入なしで始めましたが、すぐに新製品への投資家を引き付けました。彼らの差別化要因は、市場の他のほとんどがUnixベースであったのとは異なり、ソフトウェアがWindowsデスクトップで実行されるように記述されていたことでした。この手頃な価格のソフトウェアはSolidworksに改名され、1995年に発売されました。好評を博し、Dassaultの注目を集め、1997年に事業を買収し、Hirschtickは次の14年間で製品を1億ドルの事業に発展させました。今日、Solidworksは350万以上のライセンス所有者を抱え、2018年後半にバージョン29をリリースしました。
