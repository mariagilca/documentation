## Adobe Cloudとは?

Adobe Creative Cloud (CC) は、Adobeのすべてのグラフィックソフトウェアを単一のクラウド製品にバンドルしたSaaS製品で、Microsoft Azureでホストされています。Adobeは、永続的なライセンスモデルを置き換え、サブスクリプションベースのソフトウェアモデルを提供する最初の主要なソフトウェアベンダーとして有名であり、Autodeskなどの他のベンダーの間でトレンドを開始しました。

Creative Cloudには、個人、ビジネス、エンタープライズの顧客を対象としたさまざまな形態があります。CCにバンドルされている30以上の製品には、Acrobat Pro、Photoshop、InDesign、Dreamweaverなどがあります。グラフィックスへのアクセスは必要ないが、Acrobatのドキュメント管理機能が必要な顧客向けに、Document Cloudオプションがあります。また、Experience Cloudと呼ばれるマーケティング/顧客体験の提供もあります。

OpenLMは以前、お客様がカスタムライセンス機能を使用してライセンスにアクセスするためにアプリケーションマネージャーを使用してAdobeライセンスを管理できるようにしていました。リリース4.5では、Adobe Cloudライセンスは90以上のライセンスベンダーの1つとして監視できます（[リストを確認](https://www.openlm.com/license-manager-capabilities/)）。

OpenLMは、Adobe Creative Cloudライセンスを監視するために次の機能を提供します。

| 機能 | サポート |
|-----------|---------|
| 拒否レポート | いいえ |
| レポート解像度 | 1分あたり |
| 借用ライセンスレポート | 該当なし |
| 有効期限レポート | はい |
| 複数サーバー冗長サポート | 該当なし |
| トークンライセンスサポート | いいえ |

## Adobe Document Cloud (Adobe DC)とは?

Adobe Document Cloudは、主にデジタル署名を含むAcrobatの全機能を使用する必要がある企業向けのサブスクリプションベースのサービスですが、個人およびSMEバージョンも利用できます。Creative CloudとExperience Cloudの両方と統合されています。

リリース4.5では、Adobe Cloudライセンスは30以上のライセンスベンダーの1つとして監視できます（[リストを確認](https://www.openlm.com/license-manager-capabilities/)）。

OpenLMは、Adobe Document Cloudライセンスを監視するために次の機能を提供します。

| 機能 | サポート |
|-----------|---------|
| 拒否レポート | いいえ |
| レポート解像度 | 1分あたり |
| 借用ライセンスレポート | 該当なし |
| 有効期限レポート | はい |
| 複数サーバー冗長サポート | 該当なし |
| トークンライセンスサポート | いいえ |

## Adobe Experience Cloudとは?

Adobe Experience Cloudは2017年に発表され、以前はAdobe Marketing Cloud、Advertising Cloud、Analytics Cloudとして知られていた製品を組み合わせて、顧客体験を管理および測定するための包括的なソフトウェアバンドルを提供します。Creative CloudおよびDocument Cloudと統合されています。Experienceブーケに含まれる製品には、Audience Manager、Campaign、Targetなどがあります。


OpenLMは、Adobe Experience Cloudライセンスを監視するために次の機能を提供します。
