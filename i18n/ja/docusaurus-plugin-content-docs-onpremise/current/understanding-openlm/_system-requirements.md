# オンプレミス展開のシステム要件

## オペレーティングシステム

- Ubuntu 20.04 LTS以降
- RHEL 8以降

## Kubernetesのセットアップ

- MicroK8sまたはその他のサポートされているKubernetesディストリビューションを使用する
- イングレスコントローラーをインストールする
- Kubernetesダッシュボードをインストールする
- ポッドレベルのデータ用の永続ストレージをセットアップする

## インフラストラクチャ

インフラストラクチャには、データの保存、マイクロサービス間の通信の管理、およびキャッシュのサポートに使用されるコンポーネントが含まれます。
これらのコンポーネントはKubernetes内に展開するか、AzureやAWSなどのクラウドプロバイダーのマネージドサービスを使用できます。

- **MongoDB** – サービス用の非リレーショナルデータベース（Kubernetesに展開またはマネージドサービスとして）
- **Redis** – インメモリキャッシュ（Kubernetesに展開またはマネージドサービスとして）
- **SQL Server 2019以降** – 運用およびレポートデータ用のリレーショナルデータベース（別途展開またはマネージドサービスとして）
- **Kafka** – サービス間の通信用のメッセージングシステム

## TLS証明書

- UIアクセスにはワイルドカード証明書（ドメインレベル）が必要です
- TLS証明書はKubernetesシークレットとして保存する必要があります

## ハードウェア要件

### シングルノードクラスター

- **CPU**: 8コア以上
- **RAM**: 64 GB以上
- **ディスク**: 200 GB SSD（推奨）

### マルチノードクラスター（ノードごと）

- **CPU**: ノードごとに8コア以上
- **RAM**: ノードごとに32 GB以上（すべてのスケジュール可能なノードの合計で72 GB以上である必要があります）
- **ディスク**: 200 GB SSD（推奨）

> **注**: ピーク負荷とシステムのオーバーヘッドを処理するために、追加のRAMを割り当ててください。
