# 用語集

この用語集は、OpenLMドキュメント全体で使用される重要な用語、頭字語、フレーズを定義しています。

| **Term** | **Definition** |
|---|---|
| アラート | OpenLMアラートを使用すると、ライセンスマネージャーは条件を定義し、これらの条件が満たされたときに通知を受け取ることができ、ライセンスシステムの安定性を確保できます。 |
| アンナプルナ | OpenLMプラットフォームの最新バージョンで、ライセンス管理と監視機能が強化されています。 |
| API | アプリケーションプログラミングインターフェース。 |
| ブローカー | OpenLMとライセンスマネージャー間の通信を容易にし、ライセンス使用状況データを標準化された形式に変換する中間ソフトウェアコンポーネント。 |
| コンポーネント (OpenLM) | コアOpenLMプラットフォームとは別に展開され、機能を拡張するソフトウェアモジュール。例には、OpenLMライセンスサーバーブローカー、ワークステーションエージェント、ディレクトリ同期エージェントが含まれます。 |
| 同時使用 | 特定の瞬間に使用されているライセンスの数。 |
| 拒否された使用 | 利用可能なすべてのライセンスが使用中のためにライセンスアクセスがブロックされたインスタンス。 |
| 機能 | OpenLMによって追跡される、ライセンスされたソフトウェアアプリケーションの特定の機能、モジュール、またはコンポーネント。 |
| 履歴レポート | 過去の期間にわたるライセンス使用状況を分析するレポートで、傾向の特定や需要の予測に役立ちます。 |
| アイドル時間 | ライセンスがチェックアウトされているが、アクティブに使用されていない時間。 |
| ライセンスファイル | ライセンス数、アクティブ化された機能、有効期限、使用制限などのライセンス情報を含むデジタルドキュメント。 |
| ライセンスマネージャー | ライセンスの配布と使用を制御し、制限を超えないようにするソフトウェア。例：FlexNet、IBM LUM、Sentinel RMS。 |
| ライセンスサーバー | ライセンスマネージャーソフトウェアをホストし、ネットワーク全体でライセンスの配布と認証を処理するサーバー。 |
| ライセンス使用率 | 時間の経過とともに利用可能なライセンスのうち、どれだけが使用されているかを示すメトリックで、ソフトウェア使用効率の評価に役立ちます。 |
| マイクロサービス | 特定のタスクを実行する独立したソフトウェアサービスで、多くの場合、より大きなマイクロサービスベースのアーキテクチャの一部を形成します。 |
| オンプレミス | 組織独自のインフラストラクチャ（物理またはプライベートクラウド）でホストされているOpenLMソフトウェアを指します。 |
| OpenLMプラットフォーム | エンジニアリングライセンス、SAM、およびSaaS管理のためのOpenLMのサービスと製品を網羅するコアシステム。 |
| OpenLMトークン | OpenLMトークンは、OpenLMソフトウェアライセンス管理システム内で使用されるライセンスエンタイトルメントの一形態です。特定のOpenLM機能または機能にアクセスして利用するための、柔軟で再利用可能な測定単位として機能します。 |
| プラットフォーム | マイクロサービス上に構築された、OpenLMスイート内のライセンス管理と監視のための中央プラットフォーム。 |
| オプションファイル | ユーザーまたはグループの制限や借用設定など、ライセンスアクセスポリシーを制御するために使用されるFlexNet構成ファイル。 |
| 無期限ライセンス | 通常、初期費用と年間メンテナンスで、ソフトウェアが無期限に使用許諾されるモデル。オンプレミス展開でのみ利用可能です。 |
| 製品 (OpenLM) | コアまたはオプションの個別のOpenLM製品で、アクティブ化されるとシステムリソースを消費する場合があります。例：ドングル監視、ソフトウェアライセンス管理。 |
| プロジェクト | 追跡とレポートのために、チーム、部門、またはプロジェクトごとにライセンス使用状況データを整理するためのOpenLMの分類方法。 |
| リアルタイムレポート | 現在のライセンス使用状況、可用性、および拒否の最新ビューを提供するレポート。 |
| 役割 | OpenLMシステム内でユーザーに割り当てられた権限とアクセスレベルを定義します。 |
| セッション | OpenLMによって追跡されるユーザーのソフトウェア使用のアクティブなインスタンスで、開始/終了時間、アプリケーション、ワークステーションなどの詳細が含まれます。 |
| ユーザー | OpenLMによって追跡されるライセンスされたアプリケーションを使用する個人。名前、チーム、ワークステーションなどの属性が記録されます。 |
| 使用状況の監視 | ライセンス消費を分析および最適化するために、ソフトウェアの使用状況を追跡および記録するプロセス。 |
| ワークステーション | ユーザーがライセンスされたソフトウェアにアクセスするコンピューターまたはデバイスで、組織全体のライセンス使用状況をマッピングするためにOpenLMによって追跡されます。 |
| ワークステーションエージェント | エンドユーザーのワークステーションにインストールされるコンパクトなソフトウェアプログラムで、ソフトウェアライセンスの使用状況データを収集し、エージェントハブを介してOpenLMプラットフォームに送信します。 |
