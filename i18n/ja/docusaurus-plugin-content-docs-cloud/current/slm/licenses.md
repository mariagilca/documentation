## 概要

**Licenses** セクションでは、選択したライセンスマネージャーが管理するライセンスの詳細を表示します。ライセンスの可用性や使用状況などを追跡できます。

:::info[アプリでの場所]
OpenLM Platform の**アプリランチャー**（右上のグリッドアイコン）を開き、**Licenses and Features（ライセンスと機能）→ Licenses** を選択します。

**関連:** [License Servers](/cloud/slm/license-servers) · [License Allocations](/cloud/slm/license-allocations)
:::

## ライブ統計

各ライセンスの詳細を確認できます。

- 有効期限
- ライセンスパッケージ
- 使用状況

## 調達（Procurement）

ベンダーファイルから調達情報へ直接アクセスします。調達の詳細には、ライセンス有効期間および関連ライセンスパッケージの情報が含まれます。

## チェックアウトポリシー
**Checkout Policy** は以下でフィーチャーをグループ表示します。

- ライセンスサーバー
- ベンダー
- ライセンスタイプ
- 資産情報
- フィーチャー/製品名

## 製品パッケージ

製品名の変更やライセンスパッケージの設定が可能です。

1. **Product Package** セクションを開きます。
2. 製品名にマウスオーバーするとペンアイコンが表示されます。
3. ライセンスパッケージを設定/編集します。
4. 変更を保存します。

## フィーチャーの表示/非表示

特定のフィーチャーの表示/非表示を切り替えて、OpenLM の UI をワークフローに合わせてカスタマイズします。

- **Show/Hide Features** セクションに移動します。
- **Show** 列のトグルで各フィーチャーの表示/非表示を切替えます。
