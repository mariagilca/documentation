OpenLM License Manager は、組織がソフトウェアライセンスの利用状況を追跡、管理、最適化できるよう支援するソフトウェアライセンス管理ツールです。さまざまなライセンスタイプに対してリアルタイムの監視とレポートを提供します。これは OpenLM スイートの中核コンポーネントです。

## はじめに

OpenLM License Manager の監視を開始するには、次のコンポーネントと権限が用意されていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な API エンドポイントにアクセスするには、OpenLM Server 内で管理者権限を持つユーザーが必要です。

## データ収集の構成

1. API アクセスを有効化する: OpenLM Server で API が有効化されており、必要な読み取り権限を持つユーザーが利用可能であることを確認します。
2. 認証情報を追加する: OpenLM Cloud Broker ダッシュボードで OpenLM License Manager 連携を見つけ、サーバー URL とユーザー認証情報を入力します。

## OpenLM Platform で OpenLM License Manager を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. OpenLM License Manager データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. OpenLM License Manager の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
