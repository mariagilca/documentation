# OpenLM License Manager

OpenLM License Manager is a software license management tool that helps organizations track, manage, and optimize the use of their software licenses. It provides real-time monitoring and reporting for various license types. This is a core component of the OpenLM suite.

## はじめに

To begin monitoring OpenLM License Manager, ensure you have the following components and permissions in place:

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: You'll need a user with administrative rights within your OpenLM Server to access the necessary API endpoints.

## データ収集の構成

1. Activate API Access: 次を確認します： your OpenLM Server has the API activated and a user with the necessary read permissions is available.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the OpenLM License Manager integration and enter the server URL and user credentials.

## OpenLM Platform で OpenLM License Manager を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. OpenLM License Manager データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. OpenLM License Manager の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
