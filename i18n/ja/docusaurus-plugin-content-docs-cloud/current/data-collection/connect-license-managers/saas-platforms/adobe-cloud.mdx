# Adobe Cloud
Adobe Cloud 使用状況の監視

## Adobe Cloud について

Adobe Creative Cloud は、グラフィックデザイン、動画編集、ウェブ開発、写真編集のアプリケーションとサービスをまとめたスイートです。Photoshop、Illustrator、Premiere Pro など業界標準のツールが含まれています。利用状況を監視することで、サブスクリプションコストの最適化、ライセンスコンプライアンスの維持、各クリエイティブチームがどのツールを使用しているかの把握が可能になります。OpenLM Cloud Broker で Adobe Cloud を監視する方法は、Figma や Sketch など他のデザイン／クリエイティブ系プラットフォームを監視する場合と同様です。

## 前提条件

Adobe Cloud の監視を開始する前に、以下の要件を満たしていることを確認してください。

- OpenLM コンポーネント: データ収集には OpenLM Cloud Broker が必須です。基本的な監視には OpenLM SLM が必要です。
- プラットフォーム固有の要件: Adobe Admin Console への管理者アクセス権が必要です。これにより、ユーザーおよび製品の利用データにアクセスできる API キー、クライアント ID、クライアントシークレットを生成できます。

## データ収集の構成

1. Adobe Cloud 連携の設定については、サポートチーム（[support@openlm.com](mailto:support@openlm.com)）までお問い合わせください。

## レポートの閲覧

データ収集の準備が整ったら、Adobe Cloud の利用状況を分析するレポートを確認できます。

- ユーザーアクティビティの推移: プラットフォームの利用頻度と利用時間を可視化し、アクティブ／非アクティブなユーザーを特定します。
- 期限切れ／未使用ライセンスレポート: 使われていないライセンスを特定し、コスト最適化に役立てます。
