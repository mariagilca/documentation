Insightful は、従業員分析および生産性管理のプラットフォームです。従業員のアクティビティに関するインサイトを提供し、チームの効率向上を支援します。

## はじめに

Insightful の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な読み取り権限を持つ API キーを生成するには、Insightful アカウントへの管理者アクセスが必要です。

## データ収集の構成

Insightful の API では、認可に Bearer Token を使用します。トークンは次の手順で取得できます。

1. 管理者として組織のアカウントにサインインします。

2. API ページに移動します。

3. 新しいトークンを作成します。

4. トークンに名前を付けます。

5. 新しいトークンを生成します。トークンが提供されるのはこのときの一度のみであることに注意してください。

6. トークンをコピーし、安全に保管してください。

7. 認証情報を追加する: OpenLM Cloud Broker のダッシュボードで Insightful インテグレーションを見つけ、API キーを入力します。

## OpenLM Platform で Insightful を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Insightful データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Insightful の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
