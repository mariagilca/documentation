JetBrains Cloud は、ソフトウェア開発者やチーム向けの開発ツールおよびコラボレーションプラットフォームのスイートです。YouTrack、TeamCity、Space などの製品が含まれます。

## はじめに

JetBrains Cloud の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な読み取り権限を持つ永続トークンを生成するには、JetBrains Cloud インスタンスへの管理者アクセスが必要です。

## データ収集の構成

1. メインナビゲーションメニューから Administration → Access Management → Users を選択します。
2. 永続トークンを生成する対象のユーザーを選択します。
3. Account Security タブに切り替えます。
4. ページの Tokens セクションで New token ボタンをクリックします。
5. New Permanent Token ダイアログで、新しいトークンの名前とアクセススコープを指定します。トークンのスコープとは、ユーザーがこの新しいトークンを使用してアクセスを許可されるサービスの一覧です。
6. Create token ボタンをクリックします。

1. 新しいトークンを示すダイアログウィンドウが表示されます。

7. トークンをコピーし、安全な場所に保管します。トークンをコピーするには、次の 2 つの操作のいずれかを使用します。
8. 認証情報を追加する: OpenLM Cloud Broker のダッシュボードで JetBrains Cloud インテグレーションを見つけ、トークンと Company ID を入力します。
  ![JetBrains Cloud credential configuration in Cloud Broker](/img/saas-platforms/jetbrains-cloud/image32.png)
  *Cloud Broker での JetBrains Cloud 認証情報の設定*

## OpenLM Platform で JetBrains Cloud を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. JetBrains Cloud データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. JetBrains Cloud の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
