monday.com は、チームによるプロジェクト、ワークフロー、日常業務の管理を支援するワークオペレーティングシステム (Work OS) です。視覚的で共同作業に優れたプラットフォームであり、幅広い業界で利用されています。monday.com の利用状況を把握することは、サブスクリプションコストを最適化し、ライセンスがアクティブなチームメンバーによって使用されていることを確認するうえで重要です。

## はじめに

monday.com の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な読み取り権限を持つ API v2 トークンを生成するには、monday.com アカウントへの管理者アクセスが必要です。

## データ収集の構成

1. [monday.com](https://monday.com/) アカウントの管理者ユーザーである場合は、次の手順に従って API トークンにアクセスします。

1. [monday.com](https://monday.com/) アカウントにログインします。
2. 右上隅にあるアバターを選択します。
3. Administration → Connections → API を選択します。
4. 個人用トークンをコピーし、'API V2 Token' フィールドに貼り付けます。

2. 認証情報を追加する: OpenLM Cloud Broker のダッシュボードで monday.com インテグレーションを見つけ、API トークンを入力します。

![monday.com credential configuration in Cloud Broker](/img/saas-platforms/monday/image36.png)
*Cloud Broker での monday.com 認証情報の設定*

## OpenLM Platform で Monday を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Monday データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Monday の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
