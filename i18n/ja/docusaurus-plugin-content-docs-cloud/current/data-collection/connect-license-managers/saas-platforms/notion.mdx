# Notion

Notion is a versatile workspace for notes, project management, and knowledge bases. It allows teams to create and collaborate on documents, databases, and more.

## はじめに

To begin monitoring Notion, ensure you have the following components and permissions in place:

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: You'll need administrative access to your Notion workspace to create an integration and generate an API key with the necessary read permissions.

## データ収集の構成

1. Activate API Access: In your Notion workspace settings, create a new integration and generate an internal integration token.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Notion integration and enter the API token.

![Notion credential configuration in Cloud Broker](/img/saas-platforms/notion/image21.png)
*Cloud Broker での Notion 認証情報の設定*

## OpenLM Platform で Notion を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Notion データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Notion の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
