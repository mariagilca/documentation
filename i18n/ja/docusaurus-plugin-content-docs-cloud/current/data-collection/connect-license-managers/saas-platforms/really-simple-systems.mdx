# Really Simple Systems

Really Simple Systems is a cloud-based CRM system designed for small and medium-sized businesses. It helps companies manage sales, marketing, and customer service.

## はじめに

To begin monitoring Really Simple Systems, ensure you have the following components and permissions in place:

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: You'll need administrative access to your Really Simple Systems account to generate an API key with the necessary read permissions.

## データ収集の構成

1. Activate API Access: In your Really Simple Systems admin settings, create a new API key with read access to user and company data.

Step 1: Log into Really Simple Systems and navigate to “API V4”. This can be found in your settings under "Integrations".

Step 2: Create a new API key. Select **Manage your API keys and alerts** → **Generate new key**, choose a user, then select **Generate**. Really Simple Systems generates the API key.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Really Simple Systems integration and enter the API key.

![Really Simple Systems credential configuration in Cloud Broker](/img/saas-platforms/really-simple-systems/image9.png)
*Cloud Broker での Really Simple Systems 認証情報の設定*

## OpenLM Platform で Really Simple Systems を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Really Simple Systems データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Really Simple Systems の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
