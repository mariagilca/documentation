Salesforce は、企業が営業、マーケティング、カスタマーサービスを管理できるよう支援する、クラウドベースの主要な顧客関係管理（CRM）プラットフォームです。

## はじめに

Salesforce の監視を開始するには、次のコンポーネントと権限が用意されていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: Connected App を作成してコンシューマーキーとシークレットを取得するには、Salesforce 組織への管理者アクセスが必要です。

## データ収集の構成

1. API アクセスを有効化する: Salesforce の Setup で新しい Connected App を作成し、必要な API 権限を付与します。

メインナビゲーションの一番下のセクションから、Security → API Tokens を選択します。

Create Token をクリックします。

トークンが API にアクセスできるようにするには、Can access API を選択します。

トークンがイベントを送信できるようにするには、Can send events を選択します。

Personalization アカウント内の特定のデータセットへのアクセスを制限するには、Select datasets フィールドから

データセットを選択します。選択しない場合、トークンはアカウント内の現在および将来のすべてのデータセットに適用されます。

必要に応じて、トークンに関する Notes を追加します。

トークンを使用できる IP アドレスを定義するには、IP アドレスを IP Accept List フィールドに入力し、カンマで区切ります。設定すると、このリストにないアドレスから発信されたリクエストは拒否されます。

OK をクリックします。

2. 認証情報を追加する: OpenLM Cloud Broker ダッシュボードで Salesforce 連携を見つけ、user、password、token、consumer key、secret を入力します。

![Cloud Broker での Salesforce 認証情報の設定](/img/saas-platforms/salesforce/image8.png)
*Cloud Broker での Salesforce 認証情報の設定*

## OpenLM Platform で Salesforce を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Salesforce データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Salesforce の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
