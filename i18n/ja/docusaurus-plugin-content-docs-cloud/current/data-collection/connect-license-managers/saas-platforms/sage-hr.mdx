Sage HR は、オンボーディングや人事評価から勤怠管理や給与計算まで、あらゆる業務を支援する人事管理プラットフォームです。

## はじめに

Sage HR の監視を開始するには、次のコンポーネントと権限が用意されていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な読み取り権限を持つ API キーを生成するには、Sage HR アカウントへの管理者アクセスが必要です。

## データ収集の構成

1. API アクセスを有効化する: Sage HR の管理パネルで、ユーザーデータおよび従業員データへの読み取りアクセス権を持つ新しい API キーを作成します。

1. 右上の自分の名前を選択し、**Settings** を選択します。
2. 設定メニューで INTEGRATIONS をクリックし、次に API をクリックします。
3. ENABLE API ACCESS をクリックして API へのアクセスを有効化すると、固有の API キーが提供されます。

2. 認証情報を追加する: OpenLM Cloud Broker ダッシュボードで Sage HR 連携を見つけ、API キーを入力します。

![Cloud Broker での Sage HR 認証情報の設定](/img/saas-platforms/sage-hr/image29.png)
*Cloud Broker での Sage HR 認証情報の設定*

## OpenLM Platform で Sage HR を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Sage HR データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Sage HR の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
