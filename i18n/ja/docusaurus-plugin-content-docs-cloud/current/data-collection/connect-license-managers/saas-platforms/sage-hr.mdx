# Sage HR

Sage HR is a human resources management platform that helps businesses with everything from onboarding and performance management to time tracking and payroll.

## はじめに

To begin monitoring Sage HR, ensure you have the following components and permissions in place:

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: You'll need administrative access to your Sage HR account to generate an API key with the necessary read permissions.

## データ収集の構成

1. Activate API Access: In your Sage HR admin panel, create a new API key with read access to user and employee data.

1. Select your name in the top right, then select **Settings**.
2. On the settings menu, click INTEGRATIONS, then click API.
3. Click ENABLE API ACCESS to activate access to API and provide you with your unique API key.

2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Sage HR integration and enter the API key.

![Sage HR credential configuration in Cloud Broker](/img/saas-platforms/sage-hr/image29.png)
*Cloud Broker での Sage HR 認証情報の設定*

## OpenLM Platform で Sage HR を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Sage HR データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Sage HR の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
