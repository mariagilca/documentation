Atlas MongoDB は、最新のアプリケーション向けのクラウドベースのデータベースサービスです。柔軟性、拡張性、安全性に優れた方法でデータを管理できます。組織は、データストレージコストの管理、データベースパフォーマンスの最適化、コンプライアンスの確保のために、Atlas MongoDB の利用状況を監視します。

## はじめに

Atlas MongoDB の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: クラスターおよび利用状況データに対して必要な読み取り権限を持つ公開 API キーと秘密 API キーを生成するには、MongoDB Atlas アカウントへの管理者アクセスが必要です。

## データ収集の構成

1. OpenLM Cloud Broker で Atlas MongoDB のデータ収集を設定するには、次の手順に従います。
2. Atlas で Organization Access Manager ページを開きます。
3. 表示されていない場合は、ナビゲーションバーの Organizations メニューから対象の組織を選択します。
4. ナビゲーションバーの Access Manager メニューから Organization Access を選択します。
5. サイドバーで Access Manager をクリックします。
6. [Organization Access Manager](https://cloud.mongodb.com/go?l=https%3A%2F%2Fcloud.mongodb.com%2Fv2%23%2Forg%2F%3Corganization%3E%2Faccess%2Fusers) ページが表示されます。
7. Add new Service Account をクリックします。
8. サービスアカウントの情報を入力します。
9. Name を入力します。
10. Description を入力します。
11. Client Secret Expiration メニューから期間を選択します。
12. Organization Permissions メニューから、サービスアカウントに付与する[新しいロール](https://www.mongodb.com/docs/atlas/reference/user-roles/#std-label-organization-roles)を選択します。
13. Create をクリックします。
14. Client Secret をコピーして保存します。
15. API Access List Entry を追加します。
16. Add Access List Entry をクリックします。
17. このサービスアカウントについて Atlas が API リクエストを受け付ける IP アドレスまたは CIDR ブロックを入力します。
18. Atlas へのアクセスに使用しているホストがこのサービスアカウントを使用して API リクエストも行う場合は、Use Current IP Address をクリックすることもできます。
19. **Save** をクリックします。

認証情報を追加する: OpenLM Cloud Broker のダッシュボードで Atlas MongoDB インテグレーションを見つけ、Organization ID、Public Key、Private Key を入力します。

![Atlas MongoDB credential configuration in Cloud Broker](/img/saas-platforms/atlas-mongodb/image38.png)
*Cloud Broker での Atlas MongoDB 認証情報の設定*

接続を確認する: 接続をテストし、OpenLM がデータを正常に取得できることを確認します。

OpenLM で承認する: License Servers セクションで新しいデータソースを承認します。

データを確認する: Atlas MongoDB の利用状況データが OpenLM の Allocation サービスに表示されるようになります。

## OpenLM Platform で Atlas MongoDB を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Atlas MongoDB データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Atlas MongoDB の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
