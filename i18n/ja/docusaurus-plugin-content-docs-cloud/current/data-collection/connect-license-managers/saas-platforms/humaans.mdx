Humaans は、従業員データの管理、オンボーディング、レポート作成を支援する最新の HR プラットフォームです。HR 関連のすべての情報を集約するハブを提供するように設計されています。

## はじめに

Humaans の監視を開始するには、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker。
- プラットフォーム固有の要件: 必要な読み取り権限を持つ API トークンを生成するには、Humaans アカウントへの管理者アクセスが必要です。

## データ収集の設定

1. プラットフォームにログインします。
2. サイドバーで、3 点リーダーをクリックしてドロップダウンメニューを展開します。次に「API access tokens」をクリックします。
3. API キーを作成するか、既存のものを編集します。

- 既存の API キーがある場合は、編集ボタンを使用してキーのスコープを更新できます。
- 既存のキーがない場合は、「Generate new token」ボタンを使用して新しいキーを作成します。

4. 連携に必要なスコープを設定します。

- 最低限、名前、メールアドレス、役職などの基本的な従業員データを取得するには「View public data」が必要です。
- 退職した従業員を検出するために入社前の従業員を取得するには、「View public and private data」が必要です。このスコープがない場合、従業員は入社日まで取得されず、退職者として識別されません。
- 「View public and private data」を有効にすると、次の情報を読み取れるようになります。

- gender
- date of birth
- country
- city
- state
- zip_code
- remote_id
- job_title
- phone_number
- email_address
- 新規入社者および退職した従業員のデータ

- 連携に報酬データが必要な場合は、「View compensations」を有効にします。

5. 認証情報の追加: OpenLM Broker ダッシュボードで Humaans 連携を見つけ、API キーを入力します。

## OpenLM Platform で Humaans を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Humaans データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Humaans の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
