## Zoom について

Zoom は、バーチャル会議、ウェビナー、チャット、コラボレーションを可能にする、業界をリードするビデオ会議／コミュニケーションプラットフォームです。リモートワーク、オンライン教育、バーチャルイベントに不可欠なツールとなっています。Zoom の使用状況を監視することで、サブスクリプション費用を最適化し、会議の傾向を把握し、ライセンスを必要なユーザーに割り当てることができます。
