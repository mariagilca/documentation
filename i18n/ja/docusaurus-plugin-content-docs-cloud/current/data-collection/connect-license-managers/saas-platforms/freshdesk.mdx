Freshdesk は、統合されたチケットシステムを通じて企業が顧客からの問い合わせを処理できるよう支援する、クラウドベースのカスタマーサポートソフトウェアです。カスタマーサービスのワークフローを効率化し、業務効率を向上させます。

## はじめに

Freshdesk の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な読み取り権限を持つ API キーを生成するには、Freshdesk アカウントへの管理者アクセスが必要です。

## データ収集の構成

1. アカウントにサインインします。
2. 右上のプロフィール画像を選択し、**Profile Settings** を選択します。

    ![API キーオプションが表示された Freshdesk のプロファイル設定](/img/saas-platforms/freshdesk/image14.png)
    *API キーオプションが表示された Freshdesk のプロファイル設定*

3. 右側のペインで **View API key** を選択し、captcha 認証を完了します。
4. サードパーティのソリューションを認証する際に、必要に応じてこれをコピーして貼り付けます。

5. 認証情報を追加する: OpenLM Cloud Broker のダッシュボードで Freshdesk インテグレーションを見つけ、ドメイン名と API キーを入力します。

![Freshdesk credential configuration in Cloud Broker](/img/saas-platforms/freshdesk/image37.png)
*Cloud Broker での Freshdesk 認証情報の設定*

## OpenLM Platform で Freshdesk を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Freshdesk データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Freshdesk の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
