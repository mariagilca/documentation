## Tabnine について

Tabnine は、インテリジェントなコード補完候補を提供することでソフトウェア開発を加速する、AI 搭載のコード補完ツールです。数十億行のコードでトレーニングされた機械学習モデルを使用し、開発者がより速く、より少ないエラーでコードを記述できるよう支援します。Tabnine の使用状況を監視することで、サブスクリプション費用を最適化し、AI コーディングアシスタントのライセンスがもっとも活発な開発者に配分されているかを確認できます。

## 前提条件

Tabnine の監視を開始するには、次のコンポーネントと権限が揃っていることを確認してください：

- OpenLM コンポーネント：OpenLM Cloud Broker と OpenLM SLM が必要です。
- プラットフォーム固有の要件：必要な読み取り権限を持つ API 認証情報を生成するため、Tabnine Enterprise アカウントへの管理者アクセスが必要です。

## レポートの表示

レポートにアクセスして、使用状況のパターンを分析します。

- ユーザーアクティビティの傾向：もっとも活発な開発者を確認し、AI コード補完機能の利用状況を把握することで、ライセンスの再配分に役立てます。
- 期限切れ／未使用ライセンスのレポート：非アクティブなユーザーからライセンスを特定し回収して、コストを最適化します。
