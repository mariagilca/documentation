# ZoomInfo
ZoomInfo 使用状況の監視

## ZoomInfo について

ZoomInfo は、営業・マーケティングチーム向けに企業および担当者のデータを提供するゴー・トゥー・マーケットインテリジェンスプラットフォームです。見込み客の発見、エンゲージメント、商談成立を支援します。ZoomInfo の利用状況を監視すると、ライセンスが効率的に活用されているかを確認でき、サブスクリプションコストの最適化につながります。Salesflare や Pipedrive などの営業ツールを監視する場合と同様です。

## 前提条件

ZoomInfo の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。
- プラットフォーム固有の要件: ZoomInfo アカウントの管理者アクセス権が必要です。必要な読み取り権限を持つ API キーを生成します。

## データ収集の構成

ZoomInfo 連携の設定については、サポートチーム（[support@openlm.com](mailto:support@openlm.com)）までお問い合わせください。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: プラットフォームで最も活動している営業・マーケティング担当者を把握し、リソース配分に役立てます。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定してライセンスを回収し、コストを削減します。

※ SaaS を運用する際、退職者のアカウントを削除または無効化することは重要な機能です。OpenLM でも同様の課題があり、多くの企業で共通の問題だと考えています。誰かが退職すると、各サービスのアカウントを確認して削除する作業が大きな負担になります。
