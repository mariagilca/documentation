ActiveCampaign は、メールマーケティング、営業の自動化、リード管理に利用されるオールインワンのマーケティングおよび顧客関係管理 (CRM) プラットフォームです。マーケティングワークフローの自動化と顧客エンゲージメントの向上を支援します。

## はじめに

ActiveCampaign の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: API キーと API URL を生成するには、ActiveCampaign アカウントへの管理者アクセスが必要です。手順については、公式の [ActiveCampaign 認証ドキュメント](https://developers.activecampaign.com/reference/authentication)を参照してください。

## データ収集の構成

1. OpenLM Cloud Broker で ActiveCampaign のデータ収集を設定するには、次の手順に従います。

ActiveCampaign の API URL とキーは、アカウントの Developer Settings ページにあります。

1. "Settings"（歯車アイコン）をクリックします。
2. Account Settings メニューが表示されます。"Developer" オプションをクリックします。
3. API URL とキーをコピーして、サードパーティのアプリケーションに貼り付けます。

2. 認証情報を追加する: OpenLM Cloud Broker のダッシュボードで **Add a Service** を選択し、**ActiveCampaign** を選んでから、API URL とキーを入力します。

![ActiveCampaign credential configuration in Cloud Broker](/img/saas-platforms/activecampaign/image10.png)
*Cloud Broker での ActiveCampaign 認証情報の設定*

## OpenLM Platform で ActiveCampaign を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. ActiveCampaign データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. ActiveCampaign の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
