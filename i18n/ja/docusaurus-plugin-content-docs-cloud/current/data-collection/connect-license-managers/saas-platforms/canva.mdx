## Canva について

Canva は、プロフェッショナルなグラフィック、プレゼンテーション、SNS 投稿などをユーザーが作成できる、汎用性の高いオンラインデザイン／ビジュアルコミュニケーションプラットフォームです。直感的なドラッグ＆ドロップのインターフェイスと豊富なテンプレートライブラリを備え、マーケティングチーム、デザイナー、コンテンツクリエーターに広く利用されています。Canva の使用状況を監視することで、サブスクリプション費用を最適化し、デザインライセンスがアクティブなユーザーに割り当てられているかを確認できます。
