Zenefits は、給与計算、福利厚生、人事管理を支援するオールインワンの HR プラットフォームです。複雑な人事プロセスを簡素化し、コンプライアンスを確保します。

## はじめに

Zenefits の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な読み取り権限を持つ API キーとクライアントシークレットを生成するには、Zenefits アカウントへの管理者アクセスが必要です。

## データ収集の構成

1. API アクセスを有効にする: Zenefits の管理パネルで、ユーザーおよび従業員データへの読み取りアクセス権を持つ新しい API キーとクライアントシークレットを作成します。

手順 1: Admin Apps の下にある Company Profile を開きます。

手順 2: **Custom Integrations** を選択します。

手順 3: Rest API Access の下で Add Token を押します。

接続先の会社にアクセスを許可する Permissions を設定したら、Save を押します。

手順 4: API トークンをコピーして Link に貼り付けます。

目のアイコンを選択すると API トークンが表示されます。トークンをコピーし、OpenLM 担当者とのやり取りに含めてください。

2. 認証情報を追加する: OpenLM Cloud Broker のダッシュボードで Zenefits インテグレーションを見つけ、API キーとクライアントシークレットを入力します。

![Zenefits credential configuration in Cloud Broker](/img/saas-platforms/zenefits/image3.png)
*Cloud Broker での Zenefits 認証情報の設定*

## OpenLM Platform で Zenefits を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Zenefits データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Zenefits の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
