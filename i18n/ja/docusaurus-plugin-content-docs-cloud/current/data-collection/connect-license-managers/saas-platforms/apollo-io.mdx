## Apollo.io について

Apollo.io は、営業チームが見込み客を発見し、エンゲージメントを行い、より多くの取引を成立させるための包括的な営業インテリジェンス／エンゲージメントプラットフォームです。膨大なコンタクトおよび企業データベースに加え、アウトリーチの自動化、メールシーケンス、分析機能を提供します。Apollo.io の使用状況を監視することで、サブスクリプション費用を最適化し、営業インテリジェンスのライセンスが組織全体で効果的に活用されているかを確認できます。

## レポートの表示

レポートにアクセスして、使用状況のパターンを分析します。

- ユーザーアクティビティの傾向：もっとも活発なユーザーと利用されている機能を把握し、ライセンスの再配分に役立てます。
- 期限切れ／未使用ライセンスのレポート：非アクティブなユーザーからライセンスを特定し回収して、コストを最適化します。
