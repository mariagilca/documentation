# Bentley

Bentley provides software solutions for civil engineering, architecture, construction, and infrastructure. Products like MicroStation and OpenRoads are widely used for designing and managing large-scale projects.

## はじめに

To begin monitoring Bentley, ensure you have the following components and permissions in place:

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: You'll need administrative access to your Bentley license management system (for example, SELECTserver or CONNECT Licensing) to generate API keys or tokens with permissions to access usage data.

## データ収集の構成

1. Activate API Access: In the Bentley administrator portal, create an API key with read access for license and user data.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Bentley integration and enter user name and password.

![Bentley credential configuration in Cloud Broker](/img/saas-platforms/bentley/image11.png)
*Cloud Broker での Bentley 認証情報の設定*

## OpenLM Platform で Bentley を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Bentley データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Bentley の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
