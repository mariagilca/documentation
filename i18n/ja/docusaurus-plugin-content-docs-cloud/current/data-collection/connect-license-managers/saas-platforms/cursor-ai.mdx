Cursor AI は、開発チームで利用される AI 搭載のコードエディタです。OpenLM は OpenLM Cloud Broker を介して Cursor のライセンス使用状況を監視します。詳細な設定手順は現在準備中で、次回のドキュメントリリースで公開予定です。

## はじめに

- 有効な OpenLM Platform テナント。
- [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- ユーザーおよびライセンスデータへのアクセスを承認できる、Cursor 組織への管理者アクセス権。

:::note[ドキュメント準備中]
Cursor AI の設定が今すぐ必要な場合は、[Customer Portal](https://customer.openlm.com) からチケットを発行し、このページを参照してください。ドキュメント完成までの間、最新の手順を個別にご案内します。
:::
