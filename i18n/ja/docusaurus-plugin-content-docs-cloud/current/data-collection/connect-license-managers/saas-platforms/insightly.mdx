Insightly は、企業の営業、マーケティング、プロジェクト管理を支援する顧客関係管理 (CRM) プラットフォームです。顧客関係の管理やビジネスプロセスの自動化に活用できる多用途のツールです。

## はじめに

Insightly の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な読み取り権限を持つ API キーとシークレットを生成するには、Insightly アカウントへの管理者アクセスが必要です。

## データ収集の構成

1. Insightly で API Key と URL を確認するには、CRM のナビゲーションの右上にあるユーザーアイコンに移動し、User Settings を選択します。
2. ここで API キーと URL を確認できます。
3. 認証情報を追加する: OpenLM Cloud Broker のダッシュボードで Insightly インテグレーションを見つけ、API Key を入力します。

![Insightly credential configuration in Cloud Broker](/img/saas-platforms/insightly/image39.png)
*Cloud Broker での Insightly 認証情報の設定*

## OpenLM Platform で Insightly を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Insightly データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Insightly の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
