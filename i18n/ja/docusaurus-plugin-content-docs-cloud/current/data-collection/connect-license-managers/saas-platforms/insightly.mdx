# Insightly

Insightly is a customer relationship management (CRM) platform that helps businesses with sales, marketing, and project management. It's a versatile tool for managing customer relationships and automating business processes.

## はじめに

To begin monitoring Insightly, ensure you have the following components and permissions in place:

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: You'll need administrative access to your Insightly account to generate an API key and secret with the necessary read permissions.

## データ収集の構成

1. To find your API Key and URL in Insightly, simply navigate to the top right user icon in your CRM navigation and select User Settings.
2. From here you'll see your API key and URL.
3. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Insightly integration and enter the API Key.

![Insightly credential configuration in Cloud Broker](/img/saas-platforms/insightly/image39.png)
*Cloud Broker での Insightly 認証情報の設定*

## OpenLM Platform で Insightly を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Insightly データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Insightly の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
