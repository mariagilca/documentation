Google Analytics は、Web サイトのトラフィックを追跡してレポートする Web 分析サービスです。ユーザーの行動、トラフィックの参照元、コンバージョン指標に関するインサイトを提供します。

## はじめに

Google Analytics の監視を開始するには、次のコンポーネントと権限が用意されていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: 必要な API アクセスと権限を持つサービスアカウントを作成するには、Google Analytics アカウントへの管理者アクセスが必要です。

## データ収集の構成

1. Google Analytics アカウントにサインインします。
2. 左下の **Admin** を選択します。
3. Property 列で Data Streams を選択します。
4. Web サイトに該当するデータストリームを選択します。
5. 「G-」で始まり、その後に英数字が続く Measurement ID を探します。これが Google タグ ID です。

6. 認証情報を追加する: OpenLM Cloud Broker ダッシュボードで Google Analytics 連携を見つけ、Account ID を入力します。

*Cloud Broker での Google Analytics 認証情報の設定*

## OpenLM Platform で Google Analytics を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Google Analytics データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Google Analytics の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
