# Google Analytics

Google Analytics is a web analytics service that tracks and reports website traffic. It provides insights into user behavior, traffic sources, and conversion metrics.

## はじめに

To begin monitoring Google Analytics, ensure you have the following components and permissions in place:

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: You'll need administrative access to your Google Analytics account to create a Service Account with the necessary API access and permissions.

## データ収集の構成

1. Sign in to your Google Analytics account.
2. Select **Admin** in the lower-left corner.
3. In the Property column, select Data Streams.
4. Choose the relevant data stream for your website.
5. Look for the Measurement ID, which starts with "G-" followed by a series of letters and numbers. This is your Google tag ID.

6. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Google Analytics integration and type your Account ID.

![Google Analytics credential configuration in Cloud Broker](/img/saas-platforms/google-analytics/image12.png)
*Cloud Broker での Google Analytics 認証情報の設定*

## OpenLM Platform で Google Analytics を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Google Analytics データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Google Analytics の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::
