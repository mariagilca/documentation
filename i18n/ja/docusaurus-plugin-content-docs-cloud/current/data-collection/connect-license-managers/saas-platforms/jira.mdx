Jira は、ソフトウェア開発チームや IT チームで利用されている強力なプロジェクト管理および課題追跡ツールです。チームによるソフトウェアの計画、追跡、リリースを支援します。

## はじめに

Jira の監視を開始する前に、次のコンポーネントと権限が揃っていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: ユーザーおよびライセンスデータに対して必要な読み取り権限を持つ API トークンとキーを生成するには、Jira インスタンスへの管理者アクセスが必要です。

## データ収集の構成

1. Jira でスコープ付きの API トークンを作成するには:

1. [https://id.atlassian.com/manage-profile/security/api-tokens](https://id.atlassian.com/manage-profile/security/api-tokens) にログインします。
2. Create API token with scopes を選択します。
3. API トークンに、その用途がわかる名前を付けます。
4. API トークンの有効期限を選択します。

1. トークンの有効期限は 1 ～ 365 日です。

5. API トークンにアクセスを許可するアプリを選択します。
6. スコープを選択して、API トークンが Jira または Confluence で実行できる操作を指定します。
7. Create を選択します。
8. Copy to clipboard を選択し、トークンをスクリプトに貼り付けるか、安全な場所に保存します。

2. 認証情報を追加する: OpenLM Cloud Broker のダッシュボードで Jira インテグレーションを選択し、organization ID と API Key を入力します。

![Jira credential configuration in Cloud Broker](/img/saas-platforms/jira/image27.png)
*Cloud Broker での Jira 認証情報の設定*

## OpenLM Platform で Jira を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Jira データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Jira の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
