# Google Workspace

Google Workspace (formerly G Suite) is a cloud-based productivity and collaboration suite that includes Gmail, Docs, Drive, and Meet. It's used by organizations for communication, collaboration, and document management.

## はじめに

To begin monitoring Google Workspace, ensure you have the following components and permissions in place:

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: You'll need a Google Cloud Project with a Service Account and permissions to access the Google Workspace Admin SDK and Reports API.

## データ収集の構成

1. Activate API Access: In your Google Cloud Console, create a Service Account and grant it API permissions for your Google Workspace domain.
2. Add Credentials: In the OpenLM Cloud Broker dashboard, find the Google Workspace integration and enter the Service Account credentials.

## OpenLM Platform で Google Workspace を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Google Workspace データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Google Workspace の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
