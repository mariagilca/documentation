Google Workspace（旧称 G Suite）は、Gmail、Docs、Drive、Meet などを含むクラウドベースの生産性向上およびコラボレーションスイートです。組織でのコミュニケーション、コラボレーション、ドキュメント管理に使用されます。

## はじめに

Google Workspace の監視を開始するには、次のコンポーネントと権限が用意されていることを確認してください。

- OpenLM コンポーネント: [Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Cloud Broker。
- プラットフォーム固有の要件: サービスアカウントを持つ Google Cloud プロジェクトと、Google Workspace Admin SDK および Reports API にアクセスする権限が必要です。

## データ収集の構成

1. API アクセスを有効化する: Google Cloud Console でサービスアカウントを作成し、Google Workspace ドメインに対する API 権限を付与します。
2. 認証情報を追加する: OpenLM Cloud Broker ダッシュボードで Google Workspace 連携を見つけ、サービスアカウントの認証情報を入力します。

## OpenLM Platform で Google Workspace を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Google Workspace データソースを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **Allocation** を開きます。
2. Google Workspace の利用状況データが表示されることを確認します。

:::note
承認後、データの反映まで最大 3 分かかります。
:::

## レポートの閲覧

- **ユーザーアクティビティの推移** — プラットフォームで活発に活動しているユーザーを把握し、シートの再配分に活用できます。
- **期限切れまたは未使用ライセンス** — 非アクティブなユーザーを特定し、シートを回収します。
