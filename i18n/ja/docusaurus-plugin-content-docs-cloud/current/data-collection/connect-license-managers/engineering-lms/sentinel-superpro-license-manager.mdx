OpenLM で Sentinel SuperPro ライセンスマネージャーのライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

- OpenLM Platform。
- Sentinel SuperPro と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

OpenLM Broker を介して Sentinel SuperPro で利用できる現在の監視機能は次のとおりです。

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | Yes | No |

Broker コンポーネントを使用すると、次の機能も提供されます。

- OpenLM Server へのバッファリングされた通信

- ライセンスマネージャーサービスをリモートで開始/停止する機能

## OpenLM Broker の設定

続行する前に、Sentinel SuperPro と同じマシンに OpenLM Broker をインストールして設定します。
:::

## Broker の自動設定

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Detect** を開きます。

1. Sentinel SuperPro が表示されます。

1. 内容を確認して保存します。

    ![Broker UI での設定](/img/engineering-lms/sentinel-superpro-license-manager/image137.png)
*Broker UI での設定*

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** を開きます。

1. ポート番号を入力し、**LM Type** ドロップダウンから Sentinel SuperPro を選択します。**Add** をクリックします。

1. **Commands** タブで、Data Inquiry コマンドのパスが正しいことを確認します。

1. **Vendors** タブ → **Add Vendor** を開き、Sentinel SuperPro と入力して、**Continue** をクリックします。

1. **Save** をクリックします。

    ![OpenLM Platform を設定する](/img/engineering-lms/sentinel-superpro-license-manager/image119.png)
*OpenLM Platform を設定する*

## OpenLM Platform で Sentinel SuperPro License Manager を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Sentinel SuperPro License Manager ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Sentinel SuperPro License Manager が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
