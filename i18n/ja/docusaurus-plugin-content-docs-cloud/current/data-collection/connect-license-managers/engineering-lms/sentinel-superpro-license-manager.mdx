# Sentinel SuperPro License Manager

OpenLM でライセンス使用状況と次を収集するための設定手順： statistics from the Sentinel SuperPro license manager.

## はじめに

- OpenLM Platform。
- Sentinel SuperPro と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The current monitoring capabilities available for Sentinel SuperPro を OpenLM Broker 経由で are:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | Yes | No |

Using the Broker component also provides:

- Buffered communication to OpenLM Server

- Ability to remotely start/stop the license manager service

## Broker の自動検出

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Detect** を開きます

1. Sentinel SuperPro が表示されます

1. 内容を確認し、保存します

    ![Configuring through the Broker UI](/img/engineering-lms/sentinel-superpro-license-manager/image137.png)
*Broker UI での設定*

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. ポート番号を入力します and select Sentinel SuperPro from the LM Type dropdown. **Add** をクリックします。

1. **Commands** タブで、 ensure the Data Inquiry command path is correct.

1. Go to the Vendors tab → Add Vendor, enter Sentinel SuperPro, and **Continue** をクリックします.

1. **Save** をクリックします。

    ![Configure OpenLM Platform](/img/engineering-lms/sentinel-superpro-license-manager/image119.png)
*OpenLM Platform の設定*

## OpenLM Platform で Sentinel SuperPro License Manager を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Sentinel SuperPro License Manager ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Sentinel SuperPro License Manager が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
