# EasyCopy

OpenLM is a license management and monitoring system for a wide variety of network license types, such as Flexera FLEXnet Publisher (FLEXlm) and Sentinel RMS.

EasyCopy provides graphic solutions for engineering, geoscience, and life sciences. OpenLM is an EasyCopy business partner.

This article explains how to configure OpenLM to monitor the EasyCopy License Manager and generate license usage reports. This capability is available for EasyCopy version 8.7.12 and later.

## はじめに

- OpenLM Platform。
- EasyCopy と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    ![Configure OpenLM to interface with EasyCopy](/img/engineering-lms/easycopy/image26.png)
*OpenLM と EasyCopy の連携を設定*

## OpenLM Broker の設定

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. **Add License Manager** をクリックします。 From the LM type list, select OpenLM Generic. ポートを入力します (for example, 123) and **Add** をクリックします.

1. **Commands** タブで、 enter the path to eclic.exe openlm. **Execute** をクリックします to verify output.

1. **Vendors** タブで、 **Add Vendor** をクリックします and enter EasyCopy.

1. **Save** をクリックします。

## OpenLM Platform で EasyCopy を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. EasyCopy ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. EasyCopy が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
