OpenLM は、Flexera FLEXnet Publisher (FLEXlm) や Sentinel RMS など、多種多様なネットワークライセンスタイプに対応したライセンス管理および監視システムです。

EasyCopy は、エンジニアリング、地球科学、ライフサイエンス向けのグラフィックソリューションを提供します。OpenLM は EasyCopy のビジネスパートナーです。

本記事では、OpenLM を設定して EasyCopy License Manager を監視し、ライセンス使用状況レポートを生成する方法を説明します。この機能は EasyCopy バージョン 8.7.12 以降で利用できます。

## はじめに

- OpenLM Platform
- EasyCopy と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

    ![OpenLM と EasyCopy の連携を設定](/img/engineering-lms/easycopy/image26.png)
*OpenLM と EasyCopy の連携を設定*

## OpenLM Broker の設定

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** に移動します。

1. **Add License Manager** をクリックします。**LM type** リストから OpenLM Generic を選択します。ポート（例: 123）を入力し、**Add** をクリックします。

1. **Commands** タブで、eclic.exe openlm へのパスを入力します。**Execute** をクリックして出力を確認します。

1. **Vendors** タブで、**Add Vendor** をクリックし、EasyCopy と入力します。

1. **Save** をクリックします。

## OpenLM Platform で EasyCopy を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. EasyCopy ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. EasyCopy が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
