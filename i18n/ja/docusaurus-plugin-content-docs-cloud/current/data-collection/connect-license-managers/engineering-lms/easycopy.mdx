# EasyCopy

## 概要

OpenLM は Flexera FLEXlm や Sentinel RMS など多様なライセンス形式を監視できます。  
EasyCopy（Version 8.7.12 以降）では Broker によってライセンス使用状況を取り込み、OpenLM Web インターフェースで参照できます。

## 必要条件

1. OpenLM Platform
1. EasyCopy と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

![OpenLM と EasyCopy の連携図](/img/engineering-lms/easycopy/image26.png)

## Broker UI での設定

1. [http://localhost:5090](http://localhost:5090) で Broker UI を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. LM Type に *OpenLM Generic* を選択し、ポート（例: 123）を入力して **Add**。
1. **Commands** タブで `eclic.exe openlm` へのパスを入力し、**Execute** で出力を確認します。
1. **Vendors -> Add Vendor** で *EasyCopy* を追加します。
1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/easycopy/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューで **Pending Server** を選択します。
1. リストから EasyCopy を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/easycopy/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** に移動し、EasyCopy のステータスが緑表示であることを確認します。

> 新規接続の場合、ステータス更新に最大 3 分かかります。
