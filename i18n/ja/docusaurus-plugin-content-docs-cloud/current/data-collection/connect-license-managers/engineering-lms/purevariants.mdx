# pure::variants

OpenLM で pure::variants ライセンスマネージャーのライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

開始前に、次が揃っていることを確認してください。

- OpenLM Platform。
- Pure::variants と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the pure::variants License Manager](/img/engineering-lms/purevariants/image27.png)
*OpenLM と pure::variants の連携の概要*

本手順の前提として、OpenLM Broker をインストールし、OpenLM への報告設定を完了しておきます。

### 手動で追加
1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

    ![ドロップダウンから、 select Pure Variants and ポート番号を入力します (for example, 888). **Add** をクリックします。](/img/engineering-lms/purevariants/image12.png)
    *ドロップダウンから、 select Pure Variants and ポート番号を入力します (for example, 888). **Add** をクリックします。*
*ドロップダウンから、 select Pure Variants and ポート番号を入力します (for example, 888). **Add** をクリックします。*

1. **Settings** タブで、 make sure Watch License File is off.

1. Go to the Commands tab and enter the executable path for pure::variants.

    ![Go to the Vendors tab → Add Vendor, enter pure::variants, and **Continue** をクリックします.](/img/engineering-lms/purevariants/image134.png)
    *Go to the Vendors tab → Add Vendor, enter pure::variants, and **Continue** をクリックします.*
*Go to the Vendors tab → Add Vendor, enter pure::variants, and **Continue** をクリックします.*

    ![Go to the Advanced tab and enter the pure::variants login and password.](/img/engineering-lms/purevariants/image105.png)
*Advanced タブで pure::variants のログインとパスワードを入力*

1. **Save** をクリックします。

## OpenLM Platform で pure::variants を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. pure::variants ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. pure::variants が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
