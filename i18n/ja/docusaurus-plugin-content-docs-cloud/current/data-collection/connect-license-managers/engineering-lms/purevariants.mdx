pure::variants License Manager からライセンス使用状況の監視と統計の収集を行うように OpenLM を設定するには、次の手順に従います。

## はじめに

開始前に、次が揃っていることを確認してください。

- OpenLM Platform。
- Pure::variants と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

![OpenLM と pure::variants License Manager の連携の概要図](/img/engineering-lms/purevariants/image27.png)
*OpenLM と pure::variants License Manager の連携の概要図*

続行する前に、OpenLM Broker がすでにインストールされ、OpenLM へ報告するように設定されている必要があります。

### 手動で追加
1. Broker UI を開きます: `http://localhost:5090/`。

1. License Managers → Add License Manager に移動します。

    ![ドロップダウンから Pure Variants を選択し、ポート番号 (例: 888) を入力します。Add をクリックします。](/img/engineering-lms/purevariants/image12.png)
*ドロップダウンから Pure Variants を選択し、ポート番号 (例: 888) を入力します。Add をクリックします。*

1. Settings タブで、Watch License File がオフになっていることを確認します。

1. Commands タブに移動し、pure::variants の実行ファイルのパスを入力します。

    ![Vendors タブ → Add Vendor に移動し、pure::variants を入力して Continue をクリックします。](/img/engineering-lms/purevariants/image134.png)
*Vendors タブ → Add Vendor に移動し、pure::variants を入力して Continue をクリックします。*

    ![Advanced タブに移動し、pure::variants のログインとパスワードを入力します。](/img/engineering-lms/purevariants/image105.png)
*Advanced タブに移動し、pure::variants のログインとパスワードを入力します。*

1. Save をクリックします。

## OpenLM Platform で pure::variants を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. pure::variants ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. pure::variants が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
