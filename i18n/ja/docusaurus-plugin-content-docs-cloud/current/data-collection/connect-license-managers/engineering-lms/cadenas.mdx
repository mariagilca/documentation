# CADENAS

OpenLM でライセンス使用状況と次を収集するための設定手順： ライセンス統計 from CADENAS Server.

## はじめに

- OpenLM Platform。
- CADENAS と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the CADENAS Server License Manager](/img/engineering-lms/cadenas/image27.png)
*OpenLM と CADENAS Server の連携の概要*

:::note
本手順の前提として、OpenLM Broker をインストールし、OpenLM への報告設定を完了しておきます。
:::
1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Select CADENAS, ポート番号を入力し、 and **Add** をクリックします.

    ![Adding a CADENAS Server license manager in OpenLM Broker](/img/engineering-lms/cadenas/image110.png)
*OpenLM Broker で CADENAS Server ライセンスマネージャーを追加*

    Adding a CADENAS Server license manager in OpenLM Broker

1. Go to the Vendors tab. **Add Vendor** をクリックし、 enter CADENAS Server, and **Continue** をクリックします.

    ![Adding CADENAS Server vendor in OpenLM Broker](/img/engineering-lms/cadenas/image164.png)
*OpenLM Broker で CADENAS Server ベンダーを追加*

1. Go to the Log Files tab. **Add Log File** をクリックします。 Turn off Watch file by pattern. Add the log path, then **Continue** をクリックします. Adding a log file for CADENAS Server in OpenLM Broker

1. **Save** をクリックします。

    Configure OpenLM Platform

## OpenLM Platform で CADENAS を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. CADENAS ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. CADENAS が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
