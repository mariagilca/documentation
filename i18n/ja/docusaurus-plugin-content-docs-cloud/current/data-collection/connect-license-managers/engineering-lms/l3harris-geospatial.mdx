# L3Harris Geospatial

OpenLM でライセンス使用状況と次を収集するための設定手順： statistics from the L3Harris License Manager.

## はじめに

開始前に、次が揃っていることを確認してください。

- OpenLM Platform。
- L3Harris と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | No | No | No | No | No |

The Broker allows buffered communication and allows remote start/stop of the license manager service.

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with L3Harris](/img/engineering-lms/l3harris-geospatial/image27.png)
*OpenLM と L3Harris の連携の概要*

本手順の前提として、OpenLM Broker をインストールし、OpenLM への報告設定を完了しておきます。

1. Broker Web UI を開きます： http://localhost:5090 （既定のポートが使用中の場合は 5091 または 5092 を使用）.

1. **License Managers** → **Add License Manager** を開きます。

1. ドロップダウンから、 select L3Harris and enter a port number. The port number is not used for data capture but is required for licensing purposes.

1. **Add** をクリックします。

    ![**Commands** タブで、 次の場所を参照します： the folder containing the L3Harris log file and **Apply** をクリックします.](/img/engineering-lms/l3harris-geospatial/image65.png)
    ***Commands** タブで、 次の場所を参照します： the folder containing the L3Harris log file and **Apply** をクリックします.*
***Commands** タブで、 次の場所を参照します： the folder containing the L3Harris log file and **Apply** をクリックします.*

1. In the Executable path field, specify the executable path on the L3Harris license server.

1. Go to Vendors and set the vendor name.

1. Go to Log Files → Add Log File and configure:
    - Log type - Usage Log
    - Log name (descriptive) - any name to identify the log
    - Log path - 次の場所を参照します： the L3Harris logs folder
    - Vendor - vendor defined in the Vendors tab
    - Set data size limit (KB) - default 100
    - Read file every (sec) - default 10
    - Watch file by pattern - Off
    - Encoding - windows-1252

    ![Click Continue and then Save.](/img/engineering-lms/l3harris-geospatial/image112.png)
*Continue をクリックし、続いて Save をクリック*

## OpenLM Platform で L3Harris Geospatial を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. L3Harris Geospatial ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. L3Harris Geospatial が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
