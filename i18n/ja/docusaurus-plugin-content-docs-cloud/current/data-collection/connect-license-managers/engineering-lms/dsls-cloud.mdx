# DSLS Cloud

OpenLM でライセンス使用状況と次を収集するための設定手順： statistics from the Managed DSLS license manager.

## はじめに

開始前に、次が揃っていることを確認してください。

- OpenLM Platform。
- Managed DSLS と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

Monitoring capabilities depend on the query method:

- Querying remotely through OpenLM Server:
    - License totals
    - Buffered communication to overcome temporary network failures
    - Ability to start/stop the license manager service remotely
    - License denial reporting
    - 1-minute resolution for license usage reports
    - Reading Managed DSLS license and log files
    - Viewing license file content in OpenLM Web Interface

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Managed DSLS license manager](/img/engineering-lms/dsls-cloud/image34.png)
*OpenLM と Managed DSLS の連携の概要*

次のマシンに OpenLM Broker をインストールし設定します： Managed DSLS before proceeding.

### オプション 1 — 自動検出
1. Access the Broker web UI on the Managed DSLS machine.

1. **License Managers** を開き、**Detect** をクリックします。

1. Managed DSLS が表示されます

1. 内容を確認し、保存します

    If the service is running, Broker will auto-configure all required settings. For accuracy, review the following Manual configuration section.

### オプション 2 — 手動で追加
1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. From LM Type, select DSLS Cloud, ポート番号を入力し、 and **Add** をクリックします.

1. Go to the Commands tab and 実行ファイルのパスを次の場所に設定します： the Managed DSLS utility.

1. If running as a service, turn Use operating system start/stop commands file on and set the service name.

1. Turn Data Inquiry on and **Execute** をクリックします to test the connection.

1. Go to the Vendors tab → Add Vendor, enter the vendor name, and **Continue** をクリックします.

1. Go to the Log Files tab → Add Log File, select the latest Managed DSLS log file, choose the vendor, and **Continue** をクリックします.

1. **Save** をクリックします。

## OpenLM Platform で DSLS Cloud を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. DSLS Cloud ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. DSLS Cloud が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
