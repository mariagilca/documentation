OpenLM は OpenLM Broker を介して NI Volume License Manager（NI VLM）を監視します。NI VLM サーバーは FLEXlm として監視されます。さらに、NIVLM ポートを設定すると、OpenLM Broker は**切断済み（ホーム）ライセンスを借用ライセンスとして**報告します。詳細な設定手順は現在準備中で、次回のドキュメントリリースで公開予定です。

## はじめに

- OpenLM Platform。
- NI VLM サーバーのマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker **v26.6.1 以降**。

:::note[ドキュメント準備中]
NI VLM の詳細な設定手順は現在準備中です。今すぐ NI VLM の設定が必要な場合は、[Customer Portal](https://customer.openlm.com) からチケットを発行し、このページを参照してください。
:::
