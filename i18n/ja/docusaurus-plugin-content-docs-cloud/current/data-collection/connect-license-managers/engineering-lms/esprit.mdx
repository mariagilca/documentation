## はじめに

- OpenLM Platform。
- ESPRIT と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

1. OpenLM Broker Web UI → License Managers タブ (http://localhost:5090/#/license-managers) を開きます。

1. Add License Manager をクリックします。

1. 任意のポート番号を入力し、ライセンスマネージャーのタイプとして ESPRIT を選択します。

    ![Settings タブで、ライセンスファイルのパスを設定します。](/img/engineering-lms/esprit/image72.png)
*Settings タブで、ライセンスファイルのパスを設定します。*
    - 自動検出
    - または手動で設定 → Continue

1. Commands タブに移動し、ESPRIT の実行ファイルのパスを設定します。

    ![Vendors タブ → Add Vendor に移動します。わかりやすい名前を入力します。](/img/engineering-lms/esprit/image101.png)
*Vendors タブ → Add Vendor に移動します。わかりやすい名前を入力します。*

    ![Log File タブ → Add Log File に移動します。次を設定します。](/img/engineering-lms/esprit/image58.png)
*Log File タブ → Add Log File に移動します。次を設定します。*
    - Type: ESPRIT Server Usage
    - Log (Descriptive): ログを識別するための名前
    - Path: DptSecLogServerUsage.txt (ESPRIT のログフォルダー内)

    Vendor: 前の手順で作成したベンダーを選択します

    ![設定を保存します。](/img/engineering-lms/esprit/image31.png)
*設定を保存します。*

1. OpenLM Web Interface を開きます (http://SERVER_IP:5015)。

1. License Managers Pending Approval で、ESPRIT License Manager のエントリを承認します。

## OpenLM Platform で ESPRIT を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. ESPRIT ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. ESPRIT が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
