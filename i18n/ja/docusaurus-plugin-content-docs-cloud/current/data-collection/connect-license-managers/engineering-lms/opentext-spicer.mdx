OpenLM は OpenText と連携して、ライセンス使用状況を監視し、統計を取得できます。本ガイドは、OpenLM Broker v4.8.8 以降との連携を前提としています。EventLog Monitor ツールを使用する旧バージョンの Broker については、こちらの KB を参照してください。

## はじめに

- OpenLM Platform。
- OpenText と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | No | Yes | No |

Broker を使用すると、バッファリングされた通信や、ライセンスマネージャーサービスのリモートでの開始/停止も可能になります。

## OpenLM Broker の設定

![OpenLM と OpenText の連携](/img/engineering-lms/opentext-spicer/image27.png)
*OpenLM と OpenText の連携*

1. Broker UI を開きます: `http://localhost:5090/`。

1. License Managers → Add License Manager に移動します。

1. License Manager Type で OpenText を選択します。Apply をクリックします。

1. Vendors に、レポートに表示する名前 (例: OpenText) を入力します。

1. Log Files で Add Log File をクリックし、OpenText のログファイルのパス (例: C:\OpenText\ImgLM_##_##_##.txt) を参照します。

1. Advanced をクリックし、Watch Files by Pattern を有効にします。

1. Apply をクリックします。

1. Broker のインストールフォルダーにある opentext@PORT.properties ファイルを開き、設定を調整します。

    - monitored.log.next: newest (デフォルト)。テスト用には newer。

    - date.format: デフォルトは MM/dd/yyyy HH:mm:ss。

    - opentext.feature.name: 監視するフィーチャー (例: OpenText Desktop Viewer)。

    - `total.<FeatureName>`: そのフィーチャーのライセンス総数 (例: total. OpenText Desktop Viewer=10)。

1. 変更を保存し、Restart Broker をクリックします。

## OpenLM Platform で OpenText (Spicer) を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. OpenText (Spicer) ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. OpenText (Spicer) が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
