OpenLM を設定して、ASH WARE のライセンス使用状況を監視し、ライセンス統計を収集する手順は次のとおりです。

## はじめに

- OpenLM Platform。
- ASH WARE と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ASH WARE | Yes | No | Yes | Yes | No | No | No | Seconds |

Broker を使用すると、バッファリングされた通信が可能になり、ライセンスマネージャーサービスをリモートで開始および停止できます。

## OpenLM Broker の設定

![Broker UI を `http://localhost:5090/` で開きます。](/img/engineering-lms/ash-ware/image57.png)
*Broker UI を `http://localhost:5090/` で開きます。*
2. **License Managers** → **Add License Manager** に移動します。
3. **LM Type** ドロップダウンリストから ASH WARE を選択します。
4. ポート番号（既定: 6333）を入力し、**Add** をクリックします。
![OpenLM Broker での ASH WARE 実行ファイルのパス設定](/img/engineering-lms/ash-ware/image161.png)
*OpenLM Broker での ASH WARE 実行ファイルのパス設定*
5. **Executable Path** フィールドで、ASH WARE の .exe ファイルのインストールディレクトリを参照します。
6. **Save** をクリックします。
7. 設定を検証するには、**Commands** タブで **Execute** をクリックします。
![実行結果が成功した例](/img/engineering-lms/ash-ware/image64.png)
*実行結果が成功した例*
8. **Vendors** タブに移動します。**Add Vendor** をクリックし、ASH WARE と入力して **Continue** をクリックします。
![OpenLM Broker で ASH WARE ベンダーを追加](/img/engineering-lms/ash-ware/image87.png)
*OpenLM Broker で ASH WARE ベンダーを追加*
9. **Save** をクリックします。

## OpenLM Platform で ASH WARE を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. ASH WARE ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. ASH WARE が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
