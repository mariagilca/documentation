# GitLab

OpenLM で GitLab のライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

- OpenLM Platform。
- Gitlab と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The current monitoring capabilities for GitLab を OpenLM Broker 経由で are:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | Yes | No | Yes | No |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with GitLab](/img/engineering-lms/gitlab/image27.png)

:::note
OpenLM Broker must already be installed and configured to report to OpenLM Server before proceeding.
:::
### 手動で追加
1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Select Gitlab, ポート番号を入力し、 and **Add** をクリックします.

1. In the Commands node, select Data Inquiry and enter the GitLab API endpoint for users, for example:http://FQDN:80/api/v4/users

1. In C:\Program Files\OpenLM\OpenLM Broker, open the gitlab@80.properties file, provide login information, and save.

    ![In Broker, **Execute** をクリックします, then Apply. 次を確認します： the license data output is displayed.](/img/engineering-lms/gitlab/image102.png)
    *In Broker, **Execute** をクリックします, then Apply. 次を確認します： the license data output is displayed.*
*In Broker, **Execute** をクリックします, then Apply. 次を確認します： the license data output is displayed.*

1. Under Vendors, select the vendor placeholder node, enter GitLab, and **Apply** をクリックします.

1. **Restart Broker** をクリックします。

## OpenLM Platform で GitLab を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. GitLab ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. GitLab が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
