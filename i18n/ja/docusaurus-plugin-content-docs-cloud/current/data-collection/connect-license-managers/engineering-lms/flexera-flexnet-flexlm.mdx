OpenLM は、OpenLM Broker を介して Flexera FlexNet (FLEXlm および FlexNet Publisher としても知られています) を監視します。この連携は、ライセンスの使用状況、拒否、有効期限、オプションファイルの変更、TokenFlex のトークン消費を対象とします。

## はじめに

- OpenLM Platform。
- FlexNet ライセンスサーバーと同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。
- ベンダーの `lmutil.exe` へのパス。
- ベンダーデーモン名 (例: `adskflex`、`ptc_d`、`MLM`、`ugslmd`)。
- (任意) 拒否や詳細なイベントレポートが必要な場合は、FlexLM デバッグログファイルへのパス。

## OpenLM Broker の設定

Broker に FlexNet を自動検出させるか、手動で追加できます。自動検出はほとんどのインストールに対応します。標準以外のパスやカスタムサービス名を使用している場合は、手動設定に切り替えてください。

### オプション 1 — FlexNet を自動検出

1. Broker UI を `http://localhost:5090/` で開きます。
2. **License Managers** を開き、**Detect** を選択します。
3. FlexLM が一覧に表示されることを確認します。
4. **Validate** を選択し、次に **Save** を選択します。

    ![FlexLM の Broker による自動検出](/img/engineering-lms/flexera-flexnet-flexlm/image137.png)
    *FlexLM の Broker による自動検出*

FlexLM サービスが実行中の場合、Broker はポートとユーティリティのパスを自動的に設定します。検出によってすべてが正しく設定されない場合は、オプション 2 に進んでください。

### オプション 2 — FlexNet を手動で追加

1. Broker UI で、**License Managers** → **Add License Manager** を開きます。
2. **License Manager Type** から **FlexLM** を選択します。
3. FlexLM のポート番号を入力し、次に **Add** を選択します。
4. **Settings** で、ライセンスファイルのパスを追加します。ライセンスファイルが一覧に表示されない場合は、**Set Path Manually** → **Add** を選択してから、ファイルを選択します。**Watch License File** を有効にします。
5. **Commands** で、ベンダーの `lmutil.exe` への実行ファイルのパスを設定し、**Update** を選択してから **Apply** を選択します。**Execute** を選択して、有効な出力が得られることを確認します。

    ![lmutil のパスを確認して実行する](/img/engineering-lms/flexera-flexnet-flexlm/image127.png)
    *lmutil のパスを確認して実行する*

    :::tip
    一部のインストールでは、`lsmon` が別のフォルダーにあります。その場合は、`data_inquiry` ノードを手動で更新してください。
    :::

6. (Windows のみ) FlexLM がサービスとして実行されている場合は、**Use OS start/stop commands** を有効にして、`FlexLM License Manager` と入力します。
7. **Vendors** で、**Add Vendor** を選択し、ベンダーが提供するとおりに正確にベンダーデーモン名 (例: `adskflex`、`ptc_d`、`MLM`、`ugslmd`) を入力します。
8. (任意) **Options File Details** を展開して、オプションファイルのパスとバックアップを設定し、**Watch Options File** を有効にします。
9. (任意) **Log Files** で、**Add Log File** を選択し、**FlexLM Debug Log File** を選択して、パスを設定し、ベンダーを割り当ててから、**Continue** を選択します。

    ![FlexLM デバッグログファイルを追加する](/img/engineering-lms/flexera-flexnet-flexlm/image100.png)
    *FlexLM デバッグログファイルを追加する*

10. **Save** を選択します。

    ![設定を保存する](/img/engineering-lms/flexera-flexnet-flexlm/image77.png)
    *設定を保存する*

## Flexera FlexNet を OpenLM Platform で承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。

    ![Pending Server を開く](/img/engineering-lms/flexera-flexnet-flexlm/image10.png)
    *Pending Server を開く*

3. FlexNet ライセンスマネージャーを選択し、**Approve and Merge** を選択します。

    ![Approve and Merge](/img/engineering-lms/flexera-flexnet-flexlm/image3.png)
    *Approve and Merge*

## (任意) トークンサポートを有効にする

TokenFlex を使用している場合は、ライセンスマネージャーの承認後に、OpenLM Server の設定でそのライセンスサーバーの Token Support を有効にします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. FlexNet が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
