# Sentinel HASP

OpenLM は次の監視をサポートしています： for a wide and growing variety of license managers. This guide describes how to configure OpenLM to interface with Sentinel HASP, monitor ライセンス使用状況、 and obtain ライセンス統計.

OpenLM supports Sentinel HASP versions 5.0 and higher. Versions 4 and below are not supported.

## はじめに

Sentinel HASP にクエリするには、次を確認してください。

- OpenLM Platform。
- Sentinel HASP と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The following monitoring capabilities are available for Sentinel HASP を OpenLM Broker 経由で:

- Denials reporting: Yes

- Report resolution: By minute

- Borrowed license reporting: No

- Expiration date reporting: No

- Multiple server redundancy support: No

- Token license support: No

## OpenLM Broker の設定

![Diagram: OpenLM Broker querying Sentinel HASP locally](/img/engineering-lms/sentinel-hasp/image26.png)
*概要図: OpenLM Broker querying Sentinel HASP locally*

This method uses OpenLM Broker installed on the HASP server to query through command-line utilities and usage logs.

Recommended: Provides full monitoring, including denials and log-based data.

### Broker の手動設定

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. In Broker, **Add** をクリックします Port and enter the HASP server port (default: 5093).

1. Set LM Type to Sentinel HASP License Manager.

1. Under Commands, 次の場所を参照します： the folder containing Sentinel HASP command-line utilities. Click Update.

1. (Windows only) If HASP runs as a service, activate Use Service and enter Sentinel HASP License Manager.

1. **Apply** をクリックします。

1. Under data_inquiry, **Execute** をクリックします and confirm valid output.

1. Right-click Log Files → Add Log File.

1. Set Type = Other, then 次の場所を参照します： the HASP usage log file.

1. Click Apply and Restart Broker.

## OpenLM Platform で Sentinel HASP を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Sentinel HASP ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Sentinel HASP が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
