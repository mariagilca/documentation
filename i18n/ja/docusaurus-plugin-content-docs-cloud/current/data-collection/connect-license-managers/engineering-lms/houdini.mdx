# Houdini

OpenLM で Houdini のライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

- OpenLM Platform。
- Houdini と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Houdini | Yes | No | Yes | Yes | No | No | N/A | By minute |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with Houdini License Manager](/img/engineering-lms/houdini/image27.png)
*OpenLM と Houdini の連携の概要*

:::note
OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding.
:::
OpenLM Broker queries the Houdini license manager locally using the Network License Manager (sesinetd). It runs commands such as sesictrl.exe -i periodically to capture:

- Total licenses

- Licenses in use

- License expiration dates

- Usernames and hostnames

- License IDs and versions

### オプション 1 — 自動検出
1. Open the Broker web UI.

1. **License Managers** を開き、**Detect** をクリックします。

    ![Automatic detection in OpenLM Broker](/img/engineering-lms/houdini/image67.png)
*OpenLM Broker での自動検出*

1. If the Houdini service is running, Broker will detect it and create a port node with all required settings.

1. Click Apply to save.

1. Verify the setup by going to Commands → data_query and clicking Execute.

### オプション 2 — 手動で追加
自動検出が失敗した場合：

1. **License Managers** → **Add License Manager** を開きます。

    ![Manually adding a Houdini license manager in OpenLM Broker](/img/engineering-lms/houdini/image25.png)
*OpenLM Broker で Houdini ライセンスマネージャーを手動で追加*

1. Select Houdini from the LM Type drop-down list.

1. ポート番号（既定: 1075) and **Add** をクリックします.

1. In the Executable Path field, 次の場所を参照します： the root folder where Houdini (sesinetd) is installed, then **Save** をクリックします.

    ![Setting executable path for Houdini in OpenLM Broker](/img/engineering-lms/houdini/image85.png)
*OpenLM Broker での Houdini 実行ファイルパスの設定*

1. Go to the Vendors tab. Enter Houdini as the vendor name and **Continue** をクリックします.

    ![Adding Houdini vendor in OpenLM Broker](/img/engineering-lms/houdini/image103.png)
*OpenLM Broker で Houdini ベンダーを追加*

1. **Save** をクリックします。

## OpenLM Platform で Houdini を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Houdini ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Houdini が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
