Houdini からライセンス使用状況とライセンス統計を収集できるよう、次の手順で OpenLM を設定します。

## はじめに

- OpenLM Platform。
- Houdini と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Houdini | Yes | No | Yes | Yes | No | No | N/A | By minute |

Broker を使用すると、バッファリングされた通信が可能になり、ライセンスマネージャーサービスのリモートでの開始と停止も行えます。

## OpenLM Broker の設定

![OpenLM と Houdini License Manager の連携の概要](/img/engineering-lms/houdini/image27.png)
*OpenLM と Houdini License Manager の連携の概要*

:::note
続行する前に、OpenLM Broker をインストールし、OpenLM Server に報告するように設定しておく必要があります。
:::
OpenLM Broker は、Network License Manager (sesinetd) を使用してローカルで Houdini ライセンスマネージャーをクエリします。定期的に sesictrl.exe -i などのコマンドを実行して、次の情報を取得します。

- ライセンス総数

- 使用中のライセンス

- ライセンスの有効期限

- ユーザー名とホスト名

- ライセンス ID とバージョン

### オプション 1 — 自動検出
1. Broker Web UI を開きます。

1. **License Managers** を開き、**Detect** をクリックします。

    ![OpenLM Broker での自動検出](/img/engineering-lms/houdini/image67.png)
*OpenLM Broker での自動検出*

1. Houdini サービスが稼働している場合、Broker がこれを検出し、必要な設定がすべて含まれたポートノードを作成します。

1. **Apply** をクリックして保存します。

1. **Commands** → **data_query** を開いて **Execute** をクリックし、設定を確認します。

### オプション 2 — 手動で追加
自動検出が失敗した場合：

1. **License Managers** → **Add License Manager** を開きます。

    ![OpenLM Broker で Houdini ライセンスマネージャーを手動で追加](/img/engineering-lms/houdini/image25.png)
*OpenLM Broker で Houdini ライセンスマネージャーを手動で追加*

1. **LM Type** ドロップダウンリストから Houdini を選択します。

1. ポート番号（既定: 1075）を入力し、**Add** をクリックします。

1. **Executable Path** フィールドで、Houdini (sesinetd) がインストールされているルートフォルダーを参照し、**Save** をクリックします。

    ![OpenLM Broker での Houdini 実行ファイルパスの設定](/img/engineering-lms/houdini/image85.png)
*OpenLM Broker での Houdini 実行ファイルパスの設定*

1. **Vendors** タブを開きます。ベンダー名として Houdini を入力し、**Continue** をクリックします。

    ![OpenLM Broker で Houdini ベンダーを追加](/img/engineering-lms/houdini/image103.png)
*OpenLM Broker で Houdini ベンダーを追加*

1. **Save** をクリックします。

## OpenLM Platform で Houdini を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Houdini ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Houdini が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
