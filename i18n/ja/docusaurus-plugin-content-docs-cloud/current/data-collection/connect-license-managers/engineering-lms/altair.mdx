本ガイドでは、ライセンス使用状況を監視して統計を収集するために、OpenLM を Altair License Server (ALS) と連携させる方法を説明します。

## はじめに

はじめに、次が揃っていることを確認してください。

- OpenLM Platform。
- Altair と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## Broker の自動設定

1. Broker UI を開きます: `http://localhost:5090/`。
2. License Managers → Detect に移動します。
3. Altair が表示されます。
4. 検証して保存します。

## OpenLM Platform で Altair を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Altair ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Altair が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
