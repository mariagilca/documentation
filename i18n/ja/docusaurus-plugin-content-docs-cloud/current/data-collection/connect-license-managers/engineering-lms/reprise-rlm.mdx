# Reprise RLM

本ガイドでは、次の方法を説明します： configure OpenLM to interface with the Reprise License Manager (RLM), monitor ライセンス使用状況、 and obtain ライセンス統計.

## はじめに

- OpenLM Platform。
- Reprise RLM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

Capabilities depend on how you query the RLM license server:

- Through OpenLM Server only
  - License totals
  - License usage data

- Through OpenLM Broker
  - Everything listed earlier, plus:
  - Buffered communication to handle network failures
  - Remote start/stop of the license manager service
  - License denial information
  - 1-second resolution for usage reports
  - Read RLM license and log files
  - View RLM license file content in OpenLM Web Interface

## Broker の自動検出

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Detect** を開きます

1. Reprise RLM が表示されます

1. 内容を確認し、保存します

    ![Configuring through the Broker UI](/img/engineering-lms/reprise-rlm/image51.png)
*Broker UI での設定*

    検出が失敗した場合：

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Select RLM, enter the port (for example, 5054), and **Add** をクリックします.

1. Open the Settings tab.

1. Activate Set Path Manually → Add License File Manually. Enter the license file path.

1. Toggle Watch license file on.

1. **Commands** で、 次のパスを設定します： rlmutil.exe (typically C:\RLMServer). **Execute** をクリックします to test. If RLM uses a password, add the `-z <password>` parameter to the status and data inquiry commands.

    ![(Optional) If RLM runs as a service, enable Use operating system start/stop commands and enter the Service Name.](/img/engineering-lms/reprise-rlm/image115.png)

1. (Optional) If RLM runs as a service, activate Use operating system start/stop commands and enter the Service Name.

1. **Vendors** で、 **Add Vendor** をクリックします and enter the RLM vendor name.

1. **Log Files** で、 **Add** をクリックします Log File, enter the path, and link it to the vendor.

## OpenLM Platform で Reprise RLM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Reprise RLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Reprise RLM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
