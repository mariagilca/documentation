OpenLM を設定して、Razorcat ライセンスマネージャーのライセンス使用状況を監視し、統計を収集する手順は次のとおりです。

## はじめに

開始する前に、次が揃っていることを確認します。

- OpenLM Platform

- Razorcat と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

OpenLM Broker 経由での Razorcat の現在の監視機能は次のとおりです。

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

![OpenLM と Razorcat ライセンスマネージャーの連携の概要](/img/engineering-lms/razorcat/image27.png)
*OpenLM と Razorcat ライセンスマネージャーの連携の概要*

本手順を開始する前に、OpenLM Broker をインストールし設定しておきます。

### 手動で追加
- ブラウザーを開き、`http://localhost:5090/` にアクセスします。

1. **License Managers** → **Add License Manager** に移動します。

    ![種類のドロップダウンから Razorcat を選択し、ポート番号を入力して **Add** をクリックします。](/img/engineering-lms/razorcat/image70.png)
    *種類のドロップダウンから Razorcat を選択し、ポート番号を入力して **Add** をクリックします。*

    ![**Commands** タブで、flsutil.exe が格納されているフォルダーに **Executable Path** を設定します（または虫眼鏡アイコンで参照します）。](/img/engineering-lms/razorcat/image1.png)
    ***Commands** タブで、flsutil.exe が格納されているフォルダーに **Executable Path** を設定します（または虫眼鏡アイコンで参照します）。*

1. **Service Name**（例: Razorcat）を入力します。

    ![**Vendors** タブ → **Add Vendor** に移動し、Razorcat と入力して **Continue** をクリックします。](/img/engineering-lms/razorcat/image160.png)
    ***Vendors** タブ → **Add Vendor** に移動し、Razorcat と入力して **Continue** をクリックします。*

    ![**Save** をクリックします。](/img/engineering-lms/razorcat/image140.png)
    ***Save** をクリックします。*

## OpenLM Platform で Razorcat を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Razorcat ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Razorcat が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
