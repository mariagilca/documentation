OpenLM は OpenLM Broker を介して CADMATIC License Server を監視します。データ照会を設定すると、Broker は **Quantity、Usage、Usernames、Procurement** のデータを OpenLM Server に報告します。詳細な設定手順は現在準備中で、次回のドキュメントリリースで公開予定です。

## はじめに

- OpenLM Platform。
- CADMATIC License Server に到達可能で、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v26.x 以降。

:::note[ドキュメント準備中]
CADMATIC の詳細な設定手順は現在準備中です。今すぐ CADMATIC の設定が必要な場合は、[Customer Portal](https://customer.openlm.com) からチケットを発行し、このページを参照してください。
:::
