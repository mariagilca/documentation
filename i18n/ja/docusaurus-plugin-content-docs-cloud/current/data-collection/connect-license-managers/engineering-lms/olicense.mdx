# OLicense

OLicense is one of the license managers supported by OpenLM. 本ガイドでは、次の方法を説明します： configure OpenLM to interface with OLicense-Server in order to ライセンス使用状況と obtain ライセンス統計.

Broker method: OpenLM Broker is installed on the OLicense-Server machine, queries locally, and sends data to OpenLM Server.

## OpenLM Server からの直接クエリ

![Direct query between OpenLM Server and OLicense](/img/engineering-lms/olicense/image96.png)
*OpenLM Server と OLicense の直接クエリ*

## はじめに

- OpenLM Platform。
- OLicense と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    OpenLM Broker queries OLicense locally and sends data to OpenLM Server, ensuring buffered communication during network outages

    ![OpenLM Broker setup with OLicense](/img/engineering-lms/olicense/image26.png)
*OLicense との OpenLM Broker セットアップ*

## OpenLM Broker の設定

1. Broker UI を開きます： http://localhost:5090/.

1. Go to License Managers.
    - If OLicense is detected automatically, confirm and save.
    - If not, **Add** をクリックします License Manager → Select OLicense → Enter port (default: 80) → Click ADD.

    ![Adding OLicense manually in Broker](/img/engineering-lms/olicense/image169.png)
*Broker で OLicense を手動で追加*

1. **Commands** で、 次のパスを設定します： olixtool.exe. Execute to confirm output.

    ![Defining command path in Broker Web UI](/img/engineering-lms/olicense/image170.png)
*Broker Web UI でのコマンドパス指定*

1. **Vendors** で、 **Add Vendor** をクリックします → Enter "OLicense" → Continue.

1. Click SAVE.

1. Configure OpenLM Server as described earlier.

## OpenLM Platform で OLicense を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. OLicense ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. OLicense が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
