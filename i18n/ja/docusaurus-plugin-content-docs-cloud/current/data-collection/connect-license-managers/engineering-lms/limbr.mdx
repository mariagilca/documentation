本連携により、OpenLM で Lloyd's Register Licence Manager (LiMBR) のライセンス使用状況、拒否（denials）、貸出ライセンス、有効期限を監視できます。

## はじめに

- OpenLM Platform
- LiMBR と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| Start time: by second, end time: by minute | Yes | Yes | Yes | Yes | Yes | No |

さらに、OpenLM Broker を使用すると、バッファリングされた通信が可能になり、LiMBR サービスをリモートで開始または停止できます。

## OpenLM Broker の設定

![OpenLM と LiMBR の連携の概要](/img/engineering-lms/limbr/image27.png)
*OpenLM と LiMBR の連携の概要*

OpenLM Broker は、コマンドラインユーティリティを介してローカルで LiMBR に照会し、結果をコンパイルして OpenLM Server にデータを送信します。

:::note
続行する前に、OpenLM Broker をインストールし、OpenLM Server にレポートするように設定しておく必要があります。
:::
### 自動設定

1. Broker 設定ツールで **Detect** をクリックします。

1. LiMBR が実行中の場合、Broker は必要な設定を含むポートノードを作成します。

1. **Apply** をクリックします。

1. **Restart Broker** をクリックします。

1. 確認するには、**Commands** → **data_query** に移動し、**Execute** をクリックします。

    ![Broker UI での設定](/img/engineering-lms/limbr/image107.png)
*Broker UI での設定*

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** に移動します。

1. **License Manager Type** を LiMBR に設定し、**Apply** をクリックします。

1. **Commands** で、LiMBR がインストールされているフォルダーを参照し、**Update** をクリックしてから **Apply** をクリックします。

1. **status** で、設定を確認します。

1. **data_inquiry** で **Execute** をクリックし、出力が正しいことを確認します。

1. **Restart Broker** をクリックします。

1. **Vendors** で、**Vendor Name** に LiMBR と入力し、**Apply** をクリックします。

1. もう一度 **Apply** をクリックします。

1. **Restart Broker** をクリックします。

## OpenLM Platform で LiMBR を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. LiMBR ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. LiMBR が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
