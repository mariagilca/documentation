# LiMBR

本連携では、OpenLM で次を監視できます： Lloyd's Register Licence Manager (LiMBR) for ライセンス使用状況、 denials, borrowed licenses, and expiration dates.

## はじめに

- OpenLM Platform。
- LiMBR と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| Start time: by second, end time: by minute | Yes | Yes | Yes | Yes | Yes | No |

Additionally, using OpenLM Broker allows for buffered communication and the ability to remotely start or stop the LiMBR service.

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with LiMBR.](/img/engineering-lms/limbr/image27.png)
*OpenLM と LiMBR の連携の概要*

OpenLM Broker queries LiMBR locally through its command-line utility, compiles the results, and sends the data to OpenLM Server.

:::note
OpenLM Broker must already be installed and configured to report to OpenLM Server before proceeding.
:::
### Automatic configuration

1. In the Broker configuration tool, **Detect** をクリックします.

1. If LiMBR is running, Broker creates a port node with the required settings.

1. **Apply** をクリックします。

1. **Restart Broker** をクリックします。

1. To verify, go to Commands → data_query and **Execute** をクリックします.

    ![Configuring through the Broker UI](/img/engineering-lms/limbr/image107.png)
*Broker UI での設定*

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Set License Manager Type to LiMBR and **Apply** をクリックします.

1. **Commands** で、 次の場所を参照します： the folder where LiMBR is installed, click Update, then Apply.

1. In status, check configuration.

1. In data_inquiry, **Execute** をクリックします and ensure the output is valid.

1. **Restart Broker** をクリックします。

1. Under Vendors, enter LiMBR in Vendor Name and **Apply** をクリックします.

1. Click Apply again.

1. **Restart Broker** をクリックします。

## OpenLM Platform で LiMBR を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. LiMBR ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. LiMBR が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
