OpenLM は、OpenLM Broker 経由で COSCOM LicenseMonitor と連携し、ライセンスの使用状況、有効期限、その他の統計を監視できます。

## はじめに

- OpenLM Platform。
- COSCOM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | Yes | No |

Broker により、ライセンスサーバーとのバッファリングされた通信も可能になります。

## OpenLM Broker の設定

![OpenLM が COSCOM LicenseMonitor と連携する仕組み](/img/engineering-lms/coscom/image27.png)
*OpenLM が COSCOM LicenseMonitor と連携する仕組み*

Broker は COSCOM LicenseMonitor のログファイルを読み取り、データをまとめて OpenLM Server に送信します。

1. OpenLM Broker で **Add Port** をクリックします。

1. 任意のポート番号 (例: 888) を入力します。

1. **License Manager Type** リストから COSCOM を選択し、**Apply** をクリックします。

1. **Vendors** で、ベンダー名を COSCOM に設定し、**Apply** をクリックします。

1. **Log Files** で、**Add Log File** をクリックします。

1. 新しく作成したログノードを選択し、COSCOM LicenseMonitor の .log ファイルのパス (通常はインストール時の CLS Data パス) を参照して、**Apply** をクリックします。

1. **Restart Broker** をクリックします。

    OpenLM Platform を設定する

## OpenLM Platform で COSCOM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. COSCOM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. COSCOM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
