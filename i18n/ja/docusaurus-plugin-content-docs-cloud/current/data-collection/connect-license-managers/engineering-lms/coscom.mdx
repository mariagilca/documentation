# COSCOM

OpenLM は次と連携できます： COSCOM LicenseMonitor を OpenLM Broker 経由で to monitor ライセンス使用状況、 expirations, and other statistics.

## はじめに

- OpenLM Platform。
- COSCOM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | Yes | No |

Broker also allows buffered communication with the license server.

## OpenLM Broker の設定

![How OpenLM interfaces with the COSCOM LicenseMonitor](/img/engineering-lms/coscom/image27.png)
*OpenLM と COSCOM LicenseMonitor の連携*

The Broker reads the COSCOM LicenseMonitor log file, compiles the data, and sends it to OpenLM Server.

1. In OpenLM Broker, **Add** をクリックします Port.

1. Enter any port number (for example, 888).

1. Select COSCOM from the License Manager Type list and **Apply** をクリックします.

1. **Vendors** で、 set the vendor name to COSCOM and **Apply** をクリックします.

1. **Log Files** で、 **Add** をクリックします Log File.

1. Select the newly created log node, 次の場所を参照します： the path of the COSCOM LicenseMonitor .log file (typically the CLS Data path from installation), and **Apply** をクリックします.

1. **Restart Broker** をクリックします。

## OpenLM Platform で COSCOM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. COSCOM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. COSCOM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
