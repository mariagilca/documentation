OpenLM は多くのライセンスマネージャーの監視をサポートしています。本ガイドでは、OpenLM を Dassault Systèmes License Server (DSLS) と連携させ、使用状況を監視し、ライセンス統計を収集する方法を説明します。

## はじめに

- OpenLM Platform。
- DSLS と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## OpenLM Broker の設定

![Broker と DSLS の連携](/img/engineering-lms/dsls/image26.png)
*Broker と DSLS の連携*

1. Broker Web UI を `http://localhost:5090/` で開きます。

1. **License Managers** タブに移動します。

1. **Detect** を使用して DSLS を自動的に検出します。検出されない場合は、**Add License Manager** をクリックし、DSLS を選択してポートを入力し、**ADD** をクリックします。

    ![Broker で DSLS を追加](/img/engineering-lms/dsls/image55.png)
*Broker で DSLS を追加*

1. **Date format** と **Language** をライセンスファイルに合わせます。

1. **Commands** タブに移動し、DSLicSrv.exe へのパスを入力します。**Execute** を実行してテストします。DSLS でパスワードを使用している場合は、コマンド構文に追加します。各セミコロンの前に必ずスペースを入れてください。

1. **Vendors** タブ → **Add Vendor** → Dassault Systemes に移動します。

1. 複数サーバー構成の場合は、各 DSLS マシンに Broker をインストールします。

1. status、data_inquiry、denial の各コマンドがロケール en_US を使用していることを確認します。

### DSLS ログファイルの設定

1. **Log files** タブに移動し、**Add Log File** をクリックします。

1. 種類として Other を選択します。

1. ファイルに名前を付けます（例: DSLS log file）。

1. ファイルパスを入力するか参照します（例: C:\my_dsls_log.log）。

1. ベンダーとして Dassault Systemes を選択します。

1. ログがローテーションする場合は、**Watch files by pattern** をオンにします。

## OpenLM Platform で DSLS を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. DSLS ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. DSLS が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
