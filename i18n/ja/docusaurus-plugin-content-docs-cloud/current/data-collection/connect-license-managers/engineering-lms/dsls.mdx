# DSLS

OpenLM は次の監視をサポートしています： for many license managers. 本ガイドでは、次の方法を説明します： configure OpenLM to interface with Dassault Systèmes License Server (DSLS), monitor usage, and collect ライセンス統計.

## はじめに

- OpenLM Platform。
- DSLS と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

![Broker interface with DSLS](/img/engineering-lms/dsls/image26.png)
*Broker と DSLS の連携*

1. Broker Web UI を開きます： http://localhost:5090/.

1. Go to License Managers tab.

1. Use Detect to find DSLS automatically. If not detected, **Add** をクリックします License Manager, select DSLS, enter port, and click ADD.

    ![Adding DSLS in Broker](/img/engineering-lms/dsls/image55.png)
*Broker で DSLS を追加*

1. Match Date format and Language to the license file.

1. Go to Commands tab → enter path to DSLicSrv.exe. Run Execute to test.noteIf DSLS uses a password, add it in command syntax. 次を確認します： a space before each semicolon.

1. Go to Vendors tab → Add Vendor → Dassault Systemes.

1. For multi-server setups, install Broker on each DSLS machine.

1. 次を確認します： status, data_inquiry, and denial commands use locale en_US.

### DSLS ログファイルの設定

1. Go to Log files tab → **Add** をクリックします Log File.

1. Select type Other.

1. Name the file (for example, DSLS log file).

1. Enter or 次の場所を参照します： the file path (for example, C:\my_dsls_log.log).

1. Select vendor Dassault Systemes.

1. If logs rotate, check Watch files by pattern.

## OpenLM Platform で DSLS を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. DSLS ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. DSLS が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
