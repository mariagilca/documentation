# INFOR SLM

OpenLM でライセンス使用状況と次を収集するための設定手順： ライセンス統計 from Infor SLM License Manager.

## はじめに

ライセンスマネージャーへのクエリ前に、次をインストールしてください。

- OpenLM Platform。
- Infor SLM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

![Adding Infor SLM License Manager in OpenLM Broker](/img/engineering-lms/infor-slm/image9.png)
*OpenLM Broker で Infor SLM ライセンスマネージャーを追加*

:::note
OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding.
:::
1. Broker Web UI を開きます： http://localhost:5090. 既定のポートが使用中の場合は 5091 または 5092 を使用します。

1. **License Managers** → **Add License Manager** を開きます。

1. **LM Type** ドロップダウンリストから次を選択します： Infor SLM.

1. ポート番号を入力します (for example, 4325) and **Add** をクリックします.

1. Go to the Settings tab.
    - The Broker may auto-detect the license file path.
    - If not, select Set license file path manually and navigate to the license.xml file.

    ![Setting license file path for Infor SLM in OpenLM Broker](/img/engineering-lms/infor-slm/image92.png)
*OpenLM Broker での Infor SLM ライセンスファイルパスの設定*

1. Go to the Commands tab. Enter the Infor SLM host and port in the Data Inquiry field.

    ![Configuring data inquiry for Infor SLM in OpenLM Broker](/img/engineering-lms/infor-slm/image63.png)
*OpenLM Broker での Infor SLM データ問い合わせの設定*

1. Click Save, then **Execute** をクリックします to test the configuration.

    ![Successful execution output for Infor SLM license manager](/img/engineering-lms/infor-slm/image35.png)
*Infor SLM ライセンスマネージャーの実行結果が成功した例*

1. Go to the Vendors tab. **Add Vendor** をクリックし、 enter Infor SLM, and **Continue** をクリックします.

1. **Save** をクリックします。

## OpenLM Platform で INFOR SLM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. INFOR SLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. INFOR SLM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
