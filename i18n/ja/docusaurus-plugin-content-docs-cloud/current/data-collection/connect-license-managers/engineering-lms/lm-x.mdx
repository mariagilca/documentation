OpenLM は、増え続ける多種多様なライセンスマネージャーの監視をサポートしています。本ガイドでは、OpenLM を LM-X と連携させ、ライセンス使用状況を監視し、ライセンス統計を取得する方法を説明します。

ライセンス使用状況をローカルで照会し、データを OpenLM Server に転送するには、LM-X サーバーに OpenLM Broker をインストールします。

![概要図: OpenLM Broker が LM-X をローカルで照会する様子](/img/engineering-lms/lm-x/image34.png)
*概要図: OpenLM Broker が LM-X をローカルで照会する様子*

OpenLM Broker の使用は任意ですが、推奨されます。LM-X ホストにインストールすると、使用状況をローカルで照会し、OpenLM Server に転送します。Broker は、ネットワーク障害やセキュリティ制限が発生した場合でも、バッファリングされた通信を保証します。

さらに、Broker は LM-X に対してライセンス要求の拒否（denials）を照会でき、ライセンス効率に関する貴重な知見を提供します。

## はじめに

- OpenLM Platform。
- LMX と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## OpenLM Broker の設定

1. Broker Web UI を `http://localhost:5090/`#/license-managers で開きます。

1. **License Managers** で、**LM Type** に LMX を選択し、ポートを入力します。**Add** をクリックします。

    ![ベンダーを追加します。**Vendors** タブに切り替え → **Add Vendor** → 名前を入力 → **Continue**。](/img/engineering-lms/lm-x/image139.png)
*ベンダーを追加します。**Vendors** タブに切り替え → **Add Vendor** → 名前を入力 → **Continue**。*

    ![**Save** をクリックします。](/img/engineering-lms/lm-x/image4.png)
    ***Save** をクリックします。*

## OpenLM Platform で LM-X を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. LM-X ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. LM-X が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
