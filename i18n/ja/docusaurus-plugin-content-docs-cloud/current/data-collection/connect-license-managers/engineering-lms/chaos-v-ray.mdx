# Chaos V-Ray

OpenLM で Chaos V-Ray ライセンスマネージャーのライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

- OpenLM Platform。
- Chaos と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The Broker reads the Chaos V-Ray License Manager log file, compiles the data, and sends it to OpenLM for processing.

| Report resolution | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | No | No | No | No | No |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Chaos V-Ray License Manager](/img/engineering-lms/chaos-v-ray/image27.png)
*OpenLM と Chaos V-Ray の連携の概要*

1. Broker Web UI を開きます： http://localhost:5090 （既定のポートが使用中の場合は 5091 または 5092 を使用）.

1. **License Managers** → **Add License Manager** を開きます。

    ![ドロップダウンリストから次を選択します： Chaos and enter the port (for example, 35033).](/img/engineering-lms/chaos-v-ray/image48.png)
*ドロップダウンリストから次を選択します： Chaos and enter the port (for example, 35033).*

1. **Add** をクリックします。

    ![Go to Vendors → Add Vendor and enter the name Chaos V-Ray. **Continue** をクリックします。](/img/engineering-lms/chaos-v-ray/image6.png)
    *Go to Vendors → Add Vendor and enter the name Chaos V-Ray. **Continue** をクリックします。*
*Go to Vendors → Add Vendor and enter the name Chaos V-Ray. **Continue** をクリックします。*

1. Go to Log Files → Add Log File.

1. Specify the log file path manually or use the magnifier icon to browse.

1. Select Chaos V-Ray as the vendor and **Save** をクリックします.

## OpenLM Platform で Chaos V-Ray を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Chaos V-Ray ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Chaos V-Ray が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
