# TASKING License Manager (TLM)

OpenLM は次と連携できます： the TASKING License Management System (TLM) を OpenLM Broker 経由で to monitor ライセンス使用状況、 denials, and other statistics.

## はじめに

- OpenLM Platform。
- Tasking と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | Yes | Yes | No | No |

Broker also provides buffered communication, remote start/stop of the license service, and denials monitoring.

## OpenLM Broker の設定

![How OpenLM interfaces with TASKING](/img/engineering-lms/tasking-license-manager-tlm/image40.png)
*OpenLM と TASKING の連携*

Broker runs on the same machine as TLM and queries the license manager using the licdstat tool, then sends the data to OpenLM Server.

## Broker の自動検出

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Detect** を開きます

1. If the TASKING service is running, Broker will detect and configure it automatically.

    ![Configuring through the Broker UI](/img/engineering-lms/tasking-license-manager-tlm/image71.png)
*Broker UI での設定*

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Enter the TLM port number (default: 9090). Select TASKING from the License Manager Type list and **Add** をクリックします.

## OpenLM Platform で TASKING License Manager (TLM) を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. TASKING License Manager (TLM) ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. TASKING License Manager (TLM) が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
