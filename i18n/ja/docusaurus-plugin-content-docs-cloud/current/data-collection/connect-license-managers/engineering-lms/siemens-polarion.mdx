Siemens Polarion License Manager からライセンス使用状況と統計を収集できるよう、次の手順で OpenLM を設定します。

## はじめに

開始前に、次が揃っていることを確認してください。

- OpenLM Platform。
- Siemens Polarion と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

Siemens Polarion はログファイルの解析を通じて監視されます。Broker がログファイルを読み取り、データを集計して処理のために OpenLM Server に送信します。

## OpenLM Broker の設定

![OpenLM と Siemens Polarion License Manager の連携の概要](/img/engineering-lms/siemens-polarion/image27.png)
*OpenLM と Siemens Polarion License Manager の連携の概要*

続行する前に、OpenLM Broker をすでにインストールし、OpenLM に報告するように設定しておく必要があります。

### 手動で追加
1. Broker Web UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** を開きます。

    ![ドロップダウンから Siemens Polarion を選択し、ログファイルの読み取りのみを使用するため、任意のポート番号（例: 888）を入力します。**Add** をクリックします。](/img/engineering-lms/siemens-polarion/image48.png)

    ![**Vendors** タブで **Add Vendor** をクリックし、Siemens Polarion と入力して **Continue** をクリックします。](/img/engineering-lms/siemens-polarion/image13.png)
***Vendors** タブで **Add Vendor** をクリックし、Siemens Polarion と入力して **Continue** をクリックします。*

    ![Log Files タブを開きます。](/img/engineering-lms/siemens-polarion/image156.png)
*Log Files タブを開きます。*

    ![**Add Log File** をクリックします。](/img/engineering-lms/siemens-polarion/image30.png)
***Add Log File** をクリックします。*

1. Siemens Polarion のログファイルへのパスを参照するか、手動で入力します。

1. ベンダーリストから Siemens Polarion を選択します。

1. **Save** をクリックします。

## OpenLM Platform で Siemens Polarion を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Siemens Polarion ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Siemens Polarion が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
