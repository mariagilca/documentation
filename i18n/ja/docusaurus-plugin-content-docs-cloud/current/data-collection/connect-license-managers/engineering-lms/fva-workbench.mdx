OpenLM でライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

- OpenLM Platform。
- FVA-Workbench と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

OpenLM Broker を介した FVA-Workbench の現在の監視機能は次のとおりです。

| Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Report resolution |
| --- | --- | --- | --- | --- | --- | --- |
| Yes | No | Yes | Yes | No | No | By minute |

Broker を使用すると、バッファリングされた通信が可能になり、ライセンスマネージャーサービスをリモートで開始および停止できます。

## OpenLM Broker の設定

![OpenLM Broker はローカルでライセンスマネージャーにクエリを実行します。収集されたデータは処理のために OpenLM Server に送信されます。](/img/engineering-lms/fva-workbench/image27.png)
*OpenLM Broker はローカルでライセンスマネージャーにクエリを実行します。収集されたデータは処理のために OpenLM Server に送信されます。*

注: 続行する前に、OpenLM Broker をインストールし、OpenLM Server へレポートするように設定しておく必要があります。

### 手動で追加
- Broker の Web UI で、**License Managers** をクリックします。

1. **Add license manager** をクリックします。

1. **Add license manager** ダイアログで、FVA-Workbench LM のポート番号を入力します。

1. **LM type** ドロップダウンから FVA を選択します。

1. **Add** をクリックします。

    ![Commands タブを選択します。Data Inquiry で Execute をクリックし、出力が正しいことを確認します。](/img/engineering-lms/fva-workbench/image47.png)
*Commands タブを選択します。Data Inquiry で Execute をクリックし、出力が正しいことを確認します。*

    ![Vendors タブに切り替えます。Add Vendor をクリックし、Vendor Name フィールドに FVA-Workbench と入力して、Continue をクリックします。](/img/engineering-lms/fva-workbench/image76.png)
*Vendors タブに切り替えます。Add Vendor をクリックし、Vendor Name フィールドに FVA-Workbench と入力して、Continue をクリックします。*

1. **Advanced** タブを選択し、FVA-Workbench のログインとパスワードを入力します。

    ![あるいは、C:\Program Files\OpenLM\OpenLM Broker\lmsettings\fva.properties に移動して認証情報を手動で入力します。この方法を使用した場合は Broker サービスを再起動してください。](/img/engineering-lms/fva-workbench/image128.png)
*あるいは、C:\Program Files\OpenLM\OpenLM Broker\lmsettings\fva.properties に移動して認証情報を手動で入力します。この方法を使用した場合は Broker サービスを再起動してください。*

## OpenLM Platform で FVA-Workbench を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. FVA-Workbench ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. FVA-Workbench が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
