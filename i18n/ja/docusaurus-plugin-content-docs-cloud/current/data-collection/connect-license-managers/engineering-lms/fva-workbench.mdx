# FVA-Workbench

OpenLM でライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

- OpenLM Platform。
- FVA-Workbench と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The current monitoring capabilities for FVA-Workbench through the OpenLM Broker are:

| Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Report resolution |
| --- | --- | --- | --- | --- | --- | --- |
| Yes | No | Yes | Yes | No | No | By minute |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker の設定

![OpenLM Broker queries the license manager locally. Once collected, the data is sent to OpenLM Server for processing.](/img/engineering-lms/fva-workbench/image27.png)
*OpenLM Broker がローカルでライセンスマネージャーをクエリし、収集したデータを OpenLM Server に送信して処理します。*

Note: OpenLM Broker must already be installed and configured to report to OpenLM Server before proceeding.

### 手動で追加
- In the Broker web UI, click License Managers.

1. Click Add license manager.

1. In the Add license manager dialog, enter the FVA-Workbench LM port number.

1. From the LM type drop-down, select FVA.

1. **Add** をクリックします。

## OpenLM Platform で FVA-Workbench を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. FVA-Workbench ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. FVA-Workbench が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
