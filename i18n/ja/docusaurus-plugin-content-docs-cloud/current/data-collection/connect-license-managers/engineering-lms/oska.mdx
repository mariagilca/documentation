OpenLM は、信頼性の高いライセンスレポートと使用状況統計を提供するために、OSKA License Manager の監視をサポートしています。OSKA ライセンスサーバーは定期的に XML ファイルを生成し、OpenLM がそれを解析して、使用状況データを OpenLM Web Interface に表示します。

## はじめに

- OpenLM Platform。
- OSKA と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    Broker は OSKA ライセンスサーバーをローカルで照会し、データを OpenLM Server に送信します。

    ![Broker UI での設定](/img/engineering-lms/oska/image26.png)
*Broker UI での設定*

1. Broker UI を開きます: `http://localhost:5090/`。

1. License Managers → Add License Manager に移動します。

1. 自動検出が失敗した場合は、ライセンスマネージャーのノードを選択し、Add Port をクリックします。

1. 新しいライセンスサーバーにポートを追加します。
    - oska_server をクリックします。
    - Add Port をクリックします。
    - OSKA から提供されたポート番号 (例: 12345) を入力します。
    - License Manager Type から OpenLM Generic を選択します。
    - Apply → OK をクリックします。

1. Commands ノードで、次を行います。
    - OpenLMConsole.exe ファイルのフルパスを入力します。
    - Update → Apply をクリックします。

1. data_inquiry には、OSKA のデータ照会コマンドのフルパスを入力します。

    ```bash
    C:\Program Files (x86)\OSKA\OpenLMConsole.exe
    ```

    必要に応じて、OSKA のインストールパッケージから `OpenLMConsole.exe` をダウンロードします。

1. Execute をクリックしてテストし、続いて Apply をクリックします。

1. Status コマンドについても同様に繰り返します。

1. Vendors → Add Vendor を展開します。OSKA を入力します。

1. Apply をクリックします (コマンドの更新を求められた場合は No を選択します)。

1. Broker を再起動します。

## OpenLM Platform で OSKA を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. OSKA ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. OSKA が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
