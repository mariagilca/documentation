# OSKA

OpenLM は次の監視をサポートしています： of the OSKA License Manager to provide reliable license reports and usage statistics. The OSKA license server generates a periodic XML file, which OpenLM parses to present usage data in OpenLM Web Interface.

## はじめに

- OpenLM Platform。
- OSKA と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    The Broker queries the OSKA license server locally and sends data to the OpenLM Server.

    ![Configuring through the Broker UI](/img/engineering-lms/oska/image26.png)
*Broker UI での設定*

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. If auto-detect fails, select the license manager node → **Add** をクリックします Port.

1. Add a port to the new license server:
    - Click on oska_server.
    - Click Add Port.
    - Enter the Port number provided by OSKA (for example, 12345).
    - From License Manager Type, select OpenLM Generic.
    - Click Apply → OK

1. In the Commands node:
    - Enter the full path to the OpenLMConsole.exe file.
    - Click Update → Apply.

1. For data_inquiry, enter the full path to the OSKA data inquiry command:

    ```bash
    C:\Program Files (x86)\OSKA\OpenLMConsole.exe
    ```

    Download `OpenLMConsole.exe` from the OSKA installation package if required.

1. **Execute** をクリックします to test, then **Apply** をクリックします.

1. Repeat for the Status command.

1. Expand Vendors → Add Vendor. Enter OSKA.

1. Click Apply (select No if prompted to update commands).

1. Restart the Broker.

## OpenLM Platform で OSKA を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. OSKA ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. OSKA が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
