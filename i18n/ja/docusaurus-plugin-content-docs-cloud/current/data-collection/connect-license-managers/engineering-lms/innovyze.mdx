# Innovyze

本連携では、OpenLM で Innovyze のライセンス使用状況、否認、借用ライセンスを監視できます。

## はじめに

- OpenLM Platform。
- Innovyze と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | Yes | No | No |

Additionally, using OpenLM Broker allows for buffered communication and the ability to remotely start or stop the Innovyze service.

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with Innovyze.](/img/engineering-lms/innovyze/image52.png)
*OpenLM と Innovyze の連携の概要*

OpenLM Broker reads the Innovyze LicenseMonitor log file, compiles the data, and sends it to OpenLM Server for processing.

You must have OpenLM Broker installed and reporting to OpenLM Server before starting this configuration.

### Automatic configuration

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Detect** を開きます

1. Innovyze が表示されます

1. 内容を確認し、保存します

### 手動で追加
1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Set License Manager Type to Innovyze and **Apply** をクリックします.

1. Under Vendors, select "Vendor Name to Be Filled," enter Innovyze, and **Apply** をクリックします.

1. Select the Log Files node and **Add** をクリックします Log File.

1. Select the newly created log node, click […], and 次の場所を参照します： the CSV log file location (typically C:\ProgramData\InnovyzeLM#.#\Usage where #.# is the version, for example, 6.0).

1. Click Advanced, then check Watch Files by Pattern.

1. **Apply** をクリックします。

1. **Restart Broker** をクリックします。

## OpenLM Platform で Innovyze を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Innovyze ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Innovyze が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
