OpenLM で ZetaWare License Manager のライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

ライセンスマネージャーへのクエリ前に、次をインストールしてください。

- OpenLM Platform。
- Zataware と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ZetaWare | No | Yes | No | No | No | No | No | Seconds |

Broker を使用すると、バッファリングされた通信が可能になり、ライセンスマネージャーサービスをリモートで開始および停止できます。

## OpenLM Broker の設定

![OpenLM が ZetaWare License Manager と連携する仕組みの図](/img/engineering-lms/zetaware/image27.png)
*OpenLM が ZetaWare License Manager と連携する仕組みの図*

OpenLM Broker は、続行する前にインストールし、OpenLM Server へレポートするように設定しておく必要があります。

### 手動で追加
1. Broker の Web UI を `http://localhost:5090` で開きます。既定のポートが使用中の場合は 5091 または 5092 を使用します。

1. **License Managers** → **Add License Manager** を開きます。

1. **LM Type** ドロップダウンリストから ZetaWare を選択します。

1. ポート番号 (例: 888) を入力し、**Add** をクリックします。

    ![OpenLM Broker での ZetaWare ライセンスマネージャーの追加](/img/engineering-lms/zetaware/image20.png)
*OpenLM Broker での ZetaWare ライセンスマネージャーの追加*

1. **Vendors** タブを開きます。**Add Vendor** をクリックし、ZetaWare と入力して、**Continue** をクリックします。

    ![OpenLM Broker での ZetaWare ベンダーの追加](/img/engineering-lms/zetaware/image108.png)
*OpenLM Broker での ZetaWare ベンダーの追加*

1. **Log Files** タブを開きます。**Add Log File** をクリックします。**Watch file by pattern** をオフにします。アプリケーションごとに複数のログを追加できます。**Continue** をクリックします。

    ![OpenLM Broker での ZetaWare のログファイルの追加](/img/engineering-lms/zetaware/image168.png)
*OpenLM Broker での ZetaWare のログファイルの追加*

1. **Save** をクリックします。

## OpenLM Platform で Zetaware を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Zetaware ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Zetaware が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
