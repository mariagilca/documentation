# MathLM

OpenLM は次の監視をサポートしています： for a wide and growing variety of license managers. This guide describes how to configure OpenLM to interface with MathLM, monitor ライセンス使用状況、 and obtain ライセンス統計.

Install OpenLM Broker on the MathLM server to query locally and forward the data to OpenLM Server.

## はじめに

- OpenLM Platform。
- MathLM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    ![Diagram: OpenLM Broker querying MathLM locally](/img/engineering-lms/mathlm/image34.png)
*概要図: OpenLM Broker querying MathLM locally*

    The OpenLM Broker is optional but recommended. Installed on the MathLM host, it queries usage locally and forwards it to OpenLM Server. Broker ensures buffered communication in case of network outages or security restrictions

## Broker の自動検出

1. Download and install the latest version of OpenLM Broker on the MathLM server.

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Configure Broker to monitor the MathLM license server on the same port defined in OpenLM Web Interface.

1. In the status and data_inquiry fields, set the full path to monitorlm.exe. You can also set this path under Commands and apply it globally with Update.

1. Click Apply and then Restart Broker.

## OpenLM Platform で MathLM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. MathLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. MathLM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
