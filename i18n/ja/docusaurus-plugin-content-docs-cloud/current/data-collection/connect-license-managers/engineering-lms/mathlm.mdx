# MathLM

OpenLM は多数のライセンスマネージャーに対応しており、本ガイドでは MathLM を監視してライセンス使用状況と統計を取得する方法を説明します。MathLM サーバーに OpenLM Broker をインストールし、ローカル照会したデータを OpenLM Server に転送します。

## 必要条件

1. OpenLM Platform
1. MathLM と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

    ![Broker が MathLM をローカル照会するイメージ](/img/engineering-lms/mathlm/image34.png)
*Broker が MathLM をローカル照会するイメージ*

    Broker は任意ですが推奨されます。MathLM ホスト上で動作させることで、ローカルで取得したデータを OpenLM Server へ送信し、ネットワーク障害やセキュリティ制限があっても通信をバッファリングできます。

## Broker の自動構成

1. MathLM サーバーに最新の OpenLM Broker をインストールします。
1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** を開きます。
1. OpenLM Web Interface で定義したものと同じポートで MathLM ライセンスサーバーを監視するよう Broker を設定します。
1. **status** と **data_inquiry** の各フィールドに `monitorlm.exe` へのフルパスを設定します。**Commands** ノードでパスを指定し **Update** をクリックすると全ノードに反映できます。
1. **Apply** をクリックした後、**Restart Broker** を実行します。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/mathlm/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューの **Pending Server** を選択します。
1. MathLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/mathlm/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** を開き、MathLM が緑のステータスで表示されることを確認します。

> 新しい接続ではステータス反映まで最大 3 分かかる場合があります。
