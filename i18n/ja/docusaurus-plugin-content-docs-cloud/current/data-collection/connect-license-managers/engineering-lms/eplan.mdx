# EPLAN

## 必要条件

1. OpenLM Platform
1. EPLAN と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 秒 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 取得可 |
| 借用ライセンス | 取得可 |
| 期限日 | 取得不可 |
| 冗長構成 | 非対応 |

ネットワーク障害時でも Broker が通信をバッファリングするため、データ欠損を防げます。

## Broker UI での設定

![EPLAN ライセンスマネージャーとの連携図](/img/engineering-lms/eplan/image27.png)
*EPLAN ライセンスマネージャーとの連携図*

Broker は `ElmMonitor.exe` を定期的に実行し、生成されたログを OpenLM Generic 形式の XML に変換して OpenLM Server に送信します。

1. 最新の OpenLM Broker をインストールします。
1. [http://localhost:5090](http://localhost:5090) にアクセスします。
1. **License Managers** タブを開きます。
1. ライセンスマネージャーサービスが起動している場合は **Detect** をクリックし、自動検出結果を保存します。
1. Detect が動作しない場合は以下を実施します。
    - **Add License Manager** をクリック。
    - LM Type で *EPLAN* を選択し、ポート（例: 80）を入力して **Add**。
    - **Commands** タブで `ElmMonitor.exe` のパスを指定し、**Execute** で出力を確認。
    - **Vendors -> Add Vendor** を開き、*EPLAN*（任意の名称可）を入力して **Continue**。
    - **Save** をクリック。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/eplan/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューの **Pending Server** を選択します。
1. リストから EPLAN を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/eplan/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** に移動し、EPLAN のステータスが緑表示であることを確認します。

> 新しい接続では、ステータス更新まで最大 3 分かかります。
