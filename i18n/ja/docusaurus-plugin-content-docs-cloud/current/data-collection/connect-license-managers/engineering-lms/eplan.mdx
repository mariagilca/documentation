# EPLAN

## はじめに

- OpenLM Platform。
- EPLAN と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The monitoring capabilities available for the EPLAN license manager を OpenLM Broker 経由で are:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | Yes | No | No |

Using Broker also allows buffered communication in case of network interruptions.

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the EPLAN license manager.](/img/engineering-lms/eplan/image27.png)
*OpenLM と EPLAN の連携の概要*

The process works as follows:

1. Broker runs ElmMonitor.exe at set intervals to generate portions of the log file.

1. These fragments are compiled into one log file, then converted into an XML file in the OpenLM Generic format.

1. Broker sends all gathered license usage information to OpenLM Server. You can then view the data in OpenLM Web Interface.

### 手動で追加
1. Install the latest OpenLM Broker version.

1. Go to your Broker web UI (http://localhost:5090/).

1. Navigate to the License Managers tab.

1. If the license manager service is running, **Detect** をクリックします. Broker should automatically configure the EPLAN license manager.

1. If Detect does not work, follow these steps:
    - In the License Managers tab, **Add** をクリックします License Manager.
    - From the LM type drop-down list, select EPLAN. Enter a port number (for example 80). **Add** をクリックします。
    - In the configuration window, switch to the Commands tab. Browse to ElmMonitor.exe in the Executable path field. **Execute** をクリックします to validate output.
    - Switch to the Vendors tab. **Add Vendor** をクリックし、 type EPLAN (or another name), and **Continue** をクリックします.
    - **Save** をクリックします。

## OpenLM Platform で EPLAN を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. EPLAN ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. EPLAN が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
