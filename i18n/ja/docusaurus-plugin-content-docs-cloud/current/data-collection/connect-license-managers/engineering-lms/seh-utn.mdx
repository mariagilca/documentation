# SEH-UTN

本連携では、OpenLM で次を監視できます： SEH-UTN license dongle servers のライセンス使用状況と空き状況を監視します。

## はじめに

- OpenLM Platform。
- SEH-UTN と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## SEH Control Center

The SEH Control Center is a web interface for configuring the SEH-UTN dongle server.

![In the Control Center, note:](/img/engineering-lms/seh-utn/image126.jpg)
*Control Center で次を確認*

- License dongle server IP address (for example, 192.168.0.140) and server name.

- UTN port number (for example, 9200).

- Device names in the Attached devices window.

Use these details when configuring OpenLM.

## OpenLM Broker の設定

Do not install OpenLM Broker on a workstation that consumes dongle licenses, as utnm.exe does not report host/user details on consuming machines.

1. Install OpenLM Broker on a server or workstation with access to the SEH Control Center and the utnm.exe file.

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. In OpenLM Broker Configuration:
    - Select the license manager node.
    - Click Add Port if Auto-Detect fails.
    - Enter the UTN port number (for example, 9200).
    - Set License Manager Type to SEH-UTN.
    - Click Apply → OK.

1. Go to the Commands node and 次のパスを設定します： utnm.exe on the SEH dongle host.

1. 次を確認します： status and data_inquiry commands are configured.

1. **Vendors** で、 enter the vendor name.

1. **Restart Broker** をクリックします。

    ![At this point, OpenLM should start collecting SEH licensing information.](/img/engineering-lms/seh-utn/image90.png)
*この時点で OpenLM は SEH ライセンス情報の収集を開始します*

    At this point, OpenLM should start collecting SEH licensing information.

## OpenLM Platform で SEH-UTN を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. SEH-UTN ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. SEH-UTN が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
