# BetaLM

## はじめに

はじめに、次が揃っていることを確認してください。

- OpenLM Platform。
- BetaLM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## Configure through the Broker UI

Follow these steps on the machine where BetaLM is installed:

1. Broker UI を開きます： http://localhost:5090/
2. Navigate to License Managers → Add License Manager
3. Enter a descriptive Display name
4. From Type, select BetaLM
5. Enter the Hostname and Port (default: 6007)
6. Select the correct Time Zone for the license server
7. (Optional) Activate Triad Configuration if using a redundant setup (only if supported)
8. Set "Use Broker" to On
9. Click Save

## OpenLM Platform で BetaLM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. BetaLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. BetaLM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
