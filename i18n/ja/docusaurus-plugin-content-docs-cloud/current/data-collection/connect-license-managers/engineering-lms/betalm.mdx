## はじめに

はじめに、次が揃っていることを確認してください。

- OpenLM Platform。
- BetaLM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## Broker UI で設定する

BetaLM がインストールされているマシンで、次の手順を実行します。

1. Broker UI を開きます: `http://localhost:5090/`
2. License Managers → Add License Manager に移動します。
3. わかりやすい Display name を入力します。
4. Type から BetaLM を選択します。
5. Hostname と Port (デフォルト: 6007) を入力します。
6. ライセンスサーバーに適切な Time Zone を選択します。
7. (任意) 冗長構成を使用する場合は、Triad Configuration を有効にします (対応している場合のみ)。
8. 「Use Broker」を On に設定します。
9. Save をクリックします。

## OpenLM Platform で BetaLM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. BetaLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. BetaLM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
