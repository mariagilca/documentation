OpenLM を設定して、IPGLock ライセンスマネージャーのライセンス使用状況を監視し、統計を収集する手順は次のとおりです。

## はじめに

- OpenLM Platform
- IPGLock と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

OpenLM Broker 経由での IPGLock の現在の監視機能は次のとおりです。

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | No | Yes | No |

### 手動設定（Broker Web UI）

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** に移動します。

    ![**Commands** タブで、Service Name が正しいことを確認し、**Execute** をクリックして Telnet コマンドが動作することを検証します。](/img/engineering-lms/ipg-lock/image118.png)
    ***Commands** タブで、Service Name が正しいことを確認し、**Execute** をクリックして Telnet コマンドが動作することを検証します。*

    ![**Vendors** タブ → **Add Vendor** に移動し、IPGLock と入力して **Continue** をクリックします。](/img/engineering-lms/ipg-lock/image111.png)
    ***Vendors** タブ → **Add Vendor** に移動し、IPGLock と入力して **Continue** をクリックします。*

    ![**Log Files** タブに移動し、IPGLock のログファイルを参照して **Continue** をクリックします。](/img/engineering-lms/ipg-lock/image106.png)

## OpenLM Platform で IPG Lock を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. IPG Lock ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. IPG Lock が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
