# INTES PERMAS

本連携では、OpenLM で INTES PERMAS のライセンス使用状況と空き状況を監視できます。

## はじめに

- OpenLM Platform。
- INTES PERMAS と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute/second | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

OpenLM Broker communicates with INTES PERMAS to collect license data and send it to OpenLM Server.

You must have OpenLM Broker installed and reporting to OpenLM Server before starting this configuration.

### 手動設定

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Set License Manager Type to INTES.

1. In the Commands tab → status tab, enter the path to INTES_OpenLM.exe, for example:C:\Program Files (x86)\AMPORTAK\INTES_OpenLM.exe

1. In the Commands tab → data_inquiry tab, enter the path to AMP_OpenLM.exe, for example:C:\Program Files (x86)\AMP\AMP_OpenLM.exe

1. **Apply** をクリックします。

1. **Vendors** タブで、 **Add Vendor** をクリックします if none exists.

1. Select the vendor and set Name to INTES PERMAS.

1. **Apply** をクリックします。

1. Click Restart Broker → click OK → close the tool.

## OpenLM Platform で INTES PERMAS を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. INTES PERMAS ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. INTES PERMAS が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
