# INTES PERMAS

INTES PERMAS ライセンスを OpenLM と連携し、使用状況と可用性を取得します。

1. OpenLM Platform
1. INTES PERMAS と同じマシンにインストールされた OpenLM Broker v25.x 以降

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 分 / 秒 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 期限日 | 非対応 |
| 冗長構成 | 非対応 |

## Broker 設定

Broker が INTES PERMAS のデータを収集し、OpenLM Server に送信します。事前に Broker をインストールし、OpenLM へ接続してください。

### 手動設定

1. [http://localhost:5090](http://localhost:5090) を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. LM Type を *INTES* に設定します。
1. **Commands -> status** で `INTES_OpenLM.exe`（例: `C:\Program Files (x86)\AMPORTAK\INTES_OpenLM.exe`）へのパスを入力します。
1. **Commands -> data_inquiry** で `AMP_OpenLM.exe`（例: `C:\Program Files (x86)\AMP\AMP_OpenLM.exe`）へのパスを入力します。
1. **Apply** をクリックします。
1. **Vendors -> Add Vendor** で *INTES PERMAS* を追加し **Apply**。
1. **Restart Broker -> OK** をクリックし、ツールを閉じます。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。
1. 左メニューの **Pending Server** を選び、INTES を **Approve and Merge**。
1. **License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新しい接続では、反映まで最大 3 分かかります。
