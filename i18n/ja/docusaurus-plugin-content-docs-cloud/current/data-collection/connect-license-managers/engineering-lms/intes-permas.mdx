本連携により、OpenLM で INTES PERMAS のライセンス使用状況と空き状況を監視できます。

## はじめに

- OpenLM Platform
- INTES PERMAS と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute/second | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

OpenLM Broker は INTES PERMAS と通信してライセンスデータを収集し、OpenLM Server に送信します。

この設定を開始する前に、OpenLM Broker をインストールし、OpenLM Server にレポートしている状態にしておく必要があります。

### 手動設定

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** に移動します。

1. **License Manager Type** を INTES に設定します。

1. **Commands** タブ → **status** タブで、INTES_OpenLM.exe へのパスを入力します。例: C:\Program Files (x86)\AMPORTAK\INTES_OpenLM.exe

1. **Commands** タブ → **data_inquiry** タブで、AMP_OpenLM.exe へのパスを入力します。例: C:\Program Files (x86)\AMP\AMP_OpenLM.exe

1. **Apply** をクリックします。

1. **Vendors** タブで、ベンダーが存在しない場合は **Add Vendor** をクリックします。

1. ベンダーを選択し、**Name** を INTES PERMAS に設定します。

1. **Apply** をクリックします。

1. **Restart Broker** をクリック → **OK** をクリック → ツールを閉じます。

## OpenLM Platform で INTES PERMAS を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. INTES PERMAS ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. INTES PERMAS が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
