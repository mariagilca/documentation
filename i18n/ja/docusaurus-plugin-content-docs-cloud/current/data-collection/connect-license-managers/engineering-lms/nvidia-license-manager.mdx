本ガイドでは、NVIDIA License Manager と連携してライセンス使用状況を監視し、統計を収集するための OpenLM の設定方法を説明します。

## はじめに

- OpenLM Platform。
- NVIDIA License Manager と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** を開きます。

1. **License Servers** を開き、**Add** をクリックします。

1. 次のように設定します。
    1. Type: Nvidia
    1. Description: サーバー名
    1. Time Zone: ライセンスサーバーのタイムゾーン
    1. Hostname and Port: サーバーの詳細
    1. Is Triad Configuration: 該当する場合はチェックを入れる
    1. UserPassword: Nvidia 管理ポータルのユーザー名とパスワード
    1. Is secure connection (https): 該当する場合はチェックを入れる
    1. Use Broker: チェックを外す
    1. Read license file: チェックを外す

1. **Apply** をクリックします。

## OpenLM Platform で Nvidia License Manager を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Nvidia License Manager ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Nvidia License Manager が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
