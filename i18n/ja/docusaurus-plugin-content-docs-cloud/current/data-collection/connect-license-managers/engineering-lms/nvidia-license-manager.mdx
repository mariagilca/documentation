# Nvidia License Manager

本ガイドでは、OpenLM を次と連携する方法を説明します： the NVIDIA License Manager to ライセンス使用状況と 統計を収集します.

## はじめに

- OpenLM Platform。
- the NVIDIA License Manager と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Go to License Servers → **Add** をクリックします.

1. Configure:
    1. Type: Nvidia
    1. Description: server name
    1. Time Zone: license server time zone
    1. Hostname and Port: server details
    1. Is Triad Configuration: check if applicable
    1. UserPassword: Nvidia admin portal username and password
    1. Is secure connection (https): check if applicable
    1. Use Broker: unchecked
    1. Read license file: unchecked

1. **Apply** をクリックします。

## OpenLM Platform で Nvidia License Manager を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Nvidia License Manager ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Nvidia License Manager が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
