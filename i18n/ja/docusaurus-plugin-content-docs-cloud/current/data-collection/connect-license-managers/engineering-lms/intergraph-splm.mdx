# Intergraph SPLM

本ドキュメントでは、次の方法を説明します： interface OpenLM with the Intergraph SmartPlant License Manager (SPLM) to ライセンス使用状況と obtain ライセンス統計.

## はじめに

- OpenLM Platform。
- Intergraph SPLM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

OpenLM は次を監視できます： the following Intergraph SPLM activity:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | No | No |

Installing OpenLM Broker on the SPLM host machine also allows buffered communication to OpenLM Server in case of network interruptions.

## OpenLM Server + Broker での連携

![Diagram: OpenLM Broker querying SPLM locally](/img/engineering-lms/intergraph-splm/image40.png)
*概要図: OpenLM Broker querying SPLM locally*

This option uses OpenLM Broker to run SPLM's command-line utility (pdlice.exe). Broker buffers usage data, ensuring continuity even if the server connection is interrupted.

### Broker configuration

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Select SPLM from the License Manager Type menu.

1. Enter the SPLM port number (for example, 807). **Add** をクリックします。

1. **Commands** で、 実行ファイルのパスを次の場所に設定します： the pdlice.exe utilities (for example, C:\Win32applingr\pdlice\bin\pdlice).

1. **Vendors** で、 add a new vendor and give it a name (for example, SPLM).

1. 設定を保存します。

## OpenLM Platform で Intergraph SPLM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Intergraph SPLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Intergraph SPLM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
