# GEOVIA

本ガイドでは、OpenLM を次と連携する方法を説明します： GEOVIA License Manager to ライセンス使用状況と 統計を収集します.

## はじめに

- OpenLM Platform。
- GEOVIA と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

Monitoring capabilities available を OpenLM Broker 経由で are shown in the following table:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes* | Yes | Yes | No | Yes | No |

* License totals are reported according to the "max" concurrent license limit for all versions. Individual version limits are not counted. Classes are not currently supported.

Additionally, OpenLM Broker provides buffered communication and the ability to remotely start or stop the license service.

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with GEOVIA License Manager](/img/engineering-lms/geovia/image27.png)
*OpenLM と GEOVIA の連携の概要*

Broker queries license usage through the NetworkLicenceManager tool and the ssilm.log file. This data is sent to OpenLM Server for processing.

Make sure OpenLM Broker is already installed and configured before continuing.

### Broker の自動検出

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Detect** を開きます

1. GEOVIA が表示されます

1. 内容を確認し、保存します

### 手動で追加
You can also configure GEOVIA through the Broker Web UI (http://localhost:5090/):

**License Managers** → **Add License Manager** を開きます。

Select GEOVIA from the drop-down and ポート番号を入力します.

![Under Commands, 次のパスを設定します： NetworkLicenceManager.exe.](/img/engineering-lms/geovia/image98.png)
*Under Commands, 次のパスを設定します： NetworkLicenceManager.exe.*

Under Vendors, add Dassault Systèmes or any descriptive name.

![Save and restart Broker.](/img/engineering-lms/geovia/image122.png)
*保存して Broker を再起動*

## OpenLM Platform で GEOVIA を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. GEOVIA ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. GEOVIA が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
