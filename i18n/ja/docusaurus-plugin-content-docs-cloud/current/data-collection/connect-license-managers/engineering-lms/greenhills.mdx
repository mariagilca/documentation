# Greenhills

OpenLM は次を監視できます： the usage of Green Hills licenses. There are two options for querying the license server:

- Quick method: OpenLM Server queries the license server remotely.

- Robust method: OpenLM Broker queries the server locally and sends the data to OpenLM Server. This method adds robustness against communication failure, bypasses networking and security limitations, and may activate log file parsing in the future.

## はじめに

- OpenLM Platform。
- Green Hills と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    ![Configuring through the Broker UI](/img/engineering-lms/greenhills/image96.png)
*Broker UI での設定*

1. Open a browser → go to http://localhost:5090/.

1. Navigate to License Managers → Add License Manager.

1. Select Green Hills from the drop-down and enter any port (for example, 888). **Add** をクリックします。

1. Go to Vendors → Add Vendor → enter Green Hills. Click Confirm.

1. Go to Log Files → Add Log File.
    - Browse or enter the path manually.
    - Assign it to the Green Hills vendor.

1. **Save** をクリックします。

## OpenLM Platform で Greenhills を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Greenhills ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Greenhills が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
