# AEScripts

OpenLM は OpenLM Broker を介して AEScripts ライセンスマネージャーを監視し、ライセンス統計を収集します。

## はじめに

はじめに、次が揃っていることを確認してください。

- OpenLM Platform。
- AEScripts と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | No | No | No |

Using Broker also allows buffered communication and the ability to remotely start or stop the license manager service.

## OpenLM Broker の設定

![How OpenLM interfaces with AEScripts License Manager](/img/engineering-lms/aescripts/image157.png)
*OpenLM と AEScripts ライセンスマネージャーの連携*

### Broker UI での設定
1. Broker UI を開きます： [http://localhost:5090](http://localhost:5090).
2. Go to Menu: License Managers → Add License Manager.
3. Select AEScripts, ポート番号を入力し、 and **Add** をクリックします.
4. **Commands** で、 set the executable path and adjust start/stop toggles if needed.
5. **Log Files** で、 **Add** をクリックします Log File, then fill in:
   - Type: AEScripts Log
   - Log name: descriptive name
   - Log Path: path to AEScripts logs folder
   - Vendor: AEScripts
   - Encoding: UTF-16
6. **Continue** をクリックし、続いて **Save** をクリックします。

## OpenLM Platform で AEScripts を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. AEScripts ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. AEScripts が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
