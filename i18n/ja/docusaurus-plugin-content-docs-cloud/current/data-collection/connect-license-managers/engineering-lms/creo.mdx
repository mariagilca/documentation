# CREO

This document outlines the steps required to integrate Creo License Manager with OpenLM. By completing the configuration, you can monitor ライセンス使用状況、 gather statistics, and ensure optimized license management.

## はじめに

- OpenLM Platform。
- Creo と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The current monitoring capabilities available for CREO を OpenLM Broker 経由で are as follows:

| Denials | Expiration Date Reporting | Logs |
| --- | --- | --- |
| Yes | Yes | Yes |

## OpenLM Broker の設定

- Open a web browser and access the Broker interface using the URL:

http://localhost:5090 (adjust the port number if it's not the default, for example, 5091 or 5092).

1. Navigate to the License Managers tab.

1. **Add License Manager** をクリックします。

1. In the pop-up window:

    - Select Creo from the drop-down list.

    - Enter the Creo port number (for example, 25).

    - **Add** をクリックします。

    ![Step 3: Configure License File Settings](/img/engineering-lms/creo/image17.png)
*ステップ 3: ライセンスファイルの設定*

    Step 3: Configure License File Settings

    - Go to the Settings tab. The Broker can auto-detect the license file.

    - Verify the detected file path, or select Set license file path manually to navigate to the license.xml file.

    - **Save** をクリックします。

    ![Step 4: Commands tab](/img/engineering-lms/creo/image94.png)
*ステップ 4: Commands タブ*

    Step 4: Commands tab

1. Switch to the Commands tab.

1. **Save** をクリックし、続いて **Execute** をクリックします。 A positive run command result will look like this:

    ![Configure OpenLM Platform](/img/engineering-lms/creo/image35.png)
*OpenLM Platform の設定*

## OpenLM Platform で CREO を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. CREO ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. CREO が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
