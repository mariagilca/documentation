本ドキュメントでは、Creo License Manager を OpenLM と連携するために必要な手順を説明します。設定を完了することで、ライセンス使用状況の監視、統計の収集、最適化されたライセンス管理を実現できます。

## はじめに

- OpenLM Platform。
- Creo と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

OpenLM Broker 経由で利用できる CREO の現在の監視機能は、次のとおりです。

| Denials | Expiration Date Reporting | Logs |
| --- | --- | --- |
| Yes | Yes | Yes |

## OpenLM Broker の設定

- Web ブラウザーを開き、次の URL を使用して Broker インターフェイスにアクセスします。

`http://localhost:5090` (デフォルト以外の場合は、ポート番号を調整します。例: 5091 または 5092)。

1. License Managers タブに移動します。

1. Add License Manager をクリックします。

1. ポップアップウィンドウで、次を行います。

    - ドロップダウンリストから Creo を選択します。

    - Creo のポート番号 (例: 25) を入力します。

    - Add をクリックします。

    ![ステップ 3: ライセンスファイルの設定](/img/engineering-lms/creo/image17.png)
*ステップ 3: ライセンスファイルの設定*

    - Settings タブに移動します。Broker はライセンスファイルを自動検出できます。

    - 検出されたファイルパスを確認するか、Set license file path manually を選択して license.xml ファイルを参照します。

    - Save をクリックします。

## OpenLM Platform で CREO を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. CREO ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. CREO が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
