# Altium Enterprise Server

OpenLM は OpenLM Broker を介して Altium Enterprise Server を監視します。詳細な設定手順は現在準備中で、次回のドキュメントリリースで公開予定です。

## はじめに

- OpenLM Platform。
- Altium Enterprise Server と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

:::note[ドキュメント準備中]
Altium Enterprise Server の設定が今すぐ必要な場合は、[Customer Portal](https://customer.openlm.com) からチケットを発行し、このページを参照してください。ドキュメント完成までの間、最新の手順を個別にご案内します。
:::
