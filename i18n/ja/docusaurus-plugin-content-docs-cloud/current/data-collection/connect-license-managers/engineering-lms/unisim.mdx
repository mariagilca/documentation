本ドキュメントでは、OpenLM を UniSim License Manager と連携させてライセンス使用状況を監視し、統計を収集する方法を説明します。

## はじめに

UniSim ライセンスマネージャーを照会するには、次をインストールします。

- OpenLM Platform
- UniSim と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

OpenLM Broker 経由での現在の監視機能は次のとおりです。

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | No | Yes | Yes | No | No | No |

Broker を使用すると、バッファリングされた通信が可能になり、ライセンスマネージャーサービスをリモートで開始または停止できます。

## OpenLM Broker の設定

![OpenLM と UniSim の連携の概要](/img/engineering-lms/unisim/image27.png)
*OpenLM と UniSim の連携の概要*

### オプション 1 — 自動検出
1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Detect** に移動します。

1. UniSim が表示されます。

1. 内容を検証して保存します。

### オプション 2 — 手動で追加
自動検出が機能しない場合は、ライセンスマネージャーを手動で追加して設定します。

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** に移動します。

1. UniSim LM のポート番号（例: 6607）を入力します。

1. **License Manager Type** リストから UniSim を選択します。**Apply** をクリックします。

1. **Commands** に移動します。**Update path for commands** で、UniSim のインストールルートフォルダーを入力するか参照します。**Update** をクリックし、続いて **Apply** をクリックします。

1. Broker はベンダー名とログファイルのパスを自動的に追加します。

1. **Apply** をクリックします。

1. **Restart Broker** をクリックします。

## OpenLM Platform で UniSim を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. UniSim ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. UniSim が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
