# UniSim

本ドキュメントでは、次の方法を説明します： interface OpenLM with UniSim License Manager to ライセンス使用状況を監視し、統計を収集します。

## はじめに

To query UniSim license manager, install:

- OpenLM Platform。
- UniSim と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

Current monitoring capabilities を OpenLM Broker 経由で:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | No | Yes | Yes | No | No | No |

Using Broker also allows buffered communication and the ability to start or stop the license manager service remotely.

## OpenLM Broker の設定

![Diagram of OpenLM interface with UniSim](/img/engineering-lms/unisim/image27.png)
*OpenLM が with UniSim を監視する仕組み*

### オプション 1 — 自動検出
1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Detect** を開きます

1. UniSim が表示されます

1. 内容を確認し、保存します

### オプション 2 — 手動で追加
If auto-detect does not work, add and configure the license manager manually:

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Enter the UniSim LM port number (for example, 6607).

1. Select UniSim from the License Manager Type list. **Apply** をクリックします。

1. Go to Commands. In Update path for commands, enter or 次の場所を参照します： the UniSim installation root folder. **Update** をクリックし、続いて **Apply** をクリックします。

1. Broker automatically adds vendor name and log file path.

1. **Apply** をクリックします。

1. **Restart Broker** をクリックします。

## OpenLM Platform で UniSim を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. UniSim ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. UniSim が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
