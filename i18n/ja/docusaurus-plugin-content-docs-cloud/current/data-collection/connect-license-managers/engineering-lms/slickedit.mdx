# SlickEdit

SlickEdit is a cross-platform, multi-language source code and text editor. It provides various coding tools and time-saving programming features. SlickEdit 2014 supports over 40 languages across 9 different platforms.

Usage of SlickEdit is licensed and managed by a proprietary license manager. 本ガイドでは、次の方法を説明します： configure OpenLM to monitor the SlickEdit license manager, track ライセンス使用状況、 and collect ライセンス統計.

## はじめに

- OpenLM Platform。
- SlickEdit と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Download and install the latest OpenLM Broker version from the Downloads page.

1. In Broker, select the license manager node. Click Add Port if Auto-Detect did not find SlickEdit.

1. Configure Broker to monitor the SlickEdit license server (for example, slickedit_license_server) on port 27100.

1. Set the vendor name to SlickEdit.

1. In the Commands node, enter the full path to the selicutil.exe executable. Click Update and Apply.

1. Set the SlickEdit commands for Status and Data_inquiry as shown in the following image, replacing `<fullpath>` with the actual path to selicutil.exe.

1. Configuring Broker commands for SlickEdit.
    1. **Restart Broker** をクリックします。
    1. You can also configure Broker through the Broker web UI.

    ![Configuring SlickEdit in Broker web UI.](/img/engineering-lms/slickedit/image151.png)
*Broker Web UI での SlickEdit 設定*

## OpenLM Platform で SlickEdit を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. SlickEdit ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. SlickEdit が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
