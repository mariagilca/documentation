# Hosted HyperWorks Units

## 必要条件

- OpenLM Platform
- Hosted HyperWorks Units (HHWU) と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## Broker UI での設定

1. [http://localhost:5090](http://localhost:5090) を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. ドロップダウンで HHWU を選択し、ポート番号を入力して **Add**。
1. 必要に応じて Commands / Vendors / Log Files を設定し、**Save** をクリックします。

## OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。
1. 左メニューで **Pending Server** を選び、HHWU を Approve & Merge します。
1. **License Servers Live** で緑ステータスであることを確認します。
