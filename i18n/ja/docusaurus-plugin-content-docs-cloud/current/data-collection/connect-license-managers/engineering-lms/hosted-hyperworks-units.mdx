OpenLM を設定して、Hosted HyperWorks Units (HHWU) License Manager のライセンス使用状況を監視し、統計を収集する手順は次のとおりです。

## はじめに

- OpenLM Platform
- HHWU と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| LM Type in the Broker | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- |
| HHWU | Yes | Yes | No | No | Yes | No | Minutes |

Broker を使用すると、バッファリングされた通信が可能になり、ライセンスマネージャーサービスをリモートで開始および停止できます。

### 手動で追加
1. Broker Web UI を `http://localhost:5090` で開きます。既定のポートが使用中の場合は、5091 または 5092 を試します。

1. **License Managers** → **Add License Manager** に移動します。

1. ドロップダウンリストから Hosted HyperWorks Units (HHWU) を選択し、ポート番号を入力して **Add** をクリックします。

    ![**Commands** で、HHWU のコマンドラインユーティリティが格納されているフォルダーに実行ファイルのパスを設定し、**Execute** をクリックします。](/img/engineering-lms/hosted-hyperworks-units/image91.png)

    ![**Vendors** で **Add Vendor** をクリックし、Altair と入力して **Continue** をクリックします。](/img/engineering-lms/hosted-hyperworks-units/image32.png)

## OpenLM Platform で Hosted HyperWorks Units を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Hosted HyperWorks Units ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Hosted HyperWorks Units が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
