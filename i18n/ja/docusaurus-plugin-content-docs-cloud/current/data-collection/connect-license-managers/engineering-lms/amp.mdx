OpenLM は OpenLM Broker を通じて AMP を監視します。AMP は定期的に XML ファイルを生成し、OpenLM がそれを解析して OpenLM Platform に表示します。

## はじめに

- OpenLM Platform。
- AMP と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。
- `AMP_OpenLM.exe` へのパス（ベンダーから提供されるか、AMP のインストールフォルダーにあります）。

## OpenLM Broker の設定

![OpenLM Broker が AMP をクエリし、OpenLM Server にデータを転送する仕組み](/img/engineering-lms/amp/image26.png)
*OpenLM Broker が AMP をクエリし、OpenLM Server にデータを転送する仕組み*

1. Broker UI を `http://localhost:5090/` で開きます。
2. **License Managers** → **Add License Manager** を開きます。
3. **AMP** を選択し、ポート番号（例: `2306`）を指定します。
4. **License Manager Type** から **OpenLM Generic** を選択します。
5. **Commands** で、`AMP_OpenLM.exe` へのパスを設定します。例:

    ```bash
    C:\Program Files (x86)\AMPORTAKAMP\AMP_OpenLM.exe
    ```

6. **Update** を選択し、続いて **Apply** を選択します。
7. **Execute** を選択し、データの取得が機能することを確認します。
8. Status コマンドについても同様に繰り返します。
9. **Vendors** で `AMP YAZILIM`（大文字と小文字を区別）と入力します。
10. **Apply** を選択し、続いて **Restart Broker** を選択します。

## OpenLM Platform で AMP を承認

![Pending Server で AMP を承認](/img/engineering-lms/amp/image10.png)
*Pending Server で AMP を承認*

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. AMP ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. AMP が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
