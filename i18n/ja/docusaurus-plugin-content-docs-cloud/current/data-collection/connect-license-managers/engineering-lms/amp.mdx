# AMP

OpenLM monitors AMP を OpenLM Broker 経由で. AMP generates a periodic XML file, which OpenLM parses and displays in OpenLM Platform.

## はじめに

- OpenLM Platform。
- AMP と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。
- The path to `AMP_OpenLM.exe` (provided by the vendor or located in the AMP installation folder).

## OpenLM Broker の設定

![How OpenLM Broker queries AMP and forwards data to OpenLM Server](/img/engineering-lms/amp/image26.png)
*OpenLM Broker が AMP をクエリし OpenLM Server にデータを転送する仕組み*

1. Broker UI を `http://localhost:5090/` で開きます.
2. **License Managers** → **Add License Manager** を開きます。
3. Select **AMP** and specify the port number (for example, `2306`).
4. From **License Manager Type**, select **OpenLM Generic**.
5. In **Commands**, 次のパスを設定します： `AMP_OpenLM.exe`. For example:

    ```bash
    C:\Program Files (x86)\AMPORTAKAMP\AMP_OpenLM.exe
    ```

6. Select **Update**, then **Apply**.
7. **Execute** を選択します to confirm data retrieval works.
8. Repeat for the Status command.
9. In **Vendors**, enter `AMP YAZILIM` (case-sensitive).
10. Select **Apply**, then **Restart Broker**.

## OpenLM Platform で AMP を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. AMP ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. AMP が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
