# Materialise Magics

OpenLM で Materialise Magics のライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

ライセンスマネージャーへのクエリ前に、次をインストールしてください。

- OpenLM Platform。
- Materialise Magics と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Materialise Magics | Yes | No | Yes | Yes | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker の設定

![OpenLM Broker configured to connect to the Materialise Magics license manager](/img/engineering-lms/materialise-magics/image28.png)
*Materialise Magics ライセンスマネージャーに接続するよう設定された OpenLM Broker*

:::note
OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding.
:::
1. Broker Web UI を開きます： http://localhost:5090. If you want to access it from another machine on the same network, generate a token by visiting:http://localhost:5090/api/new-token

1. **License Managers** → **Add License Manager** を開きます。

1. **LM Type** ドロップダウンリストから次を選択します： Materialise Magics.

1. ポート番号（既定: 7010) and **Add** をクリックします.

1. In the Executable Path field, 次の場所を参照します： the installation directory of the Materialise Magics .exe file.

    ![Setting executable path for Materialise Magics in OpenLM Broker](/img/engineering-lms/materialise-magics/image147.png)
*OpenLM Broker での Materialise Magics 実行ファイルパスの設定*

1. **Save** をクリックします。

1. To verify the configuration, go to the Commands tab and **Execute** をクリックします.

    ![Verifying Materialise Magics license manager connection](/img/engineering-lms/materialise-magics/image84.png)
*Materialise Magics ライセンスマネージャー接続の検証*

    Verifying Materialise Magics license manager connection

1. If successful, the output will resemble the following example:

    ![Successful connection output](/img/engineering-lms/materialise-magics/image130.png)
*接続成功時の出力*

1. Go to the Vendors tab. **Add Vendor** をクリックし、 enter Materialise, and **Continue** をクリックします.

    ![Adding Materialise vendor in OpenLM Broker](/img/engineering-lms/materialise-magics/image66.png)
*OpenLM Broker で Materialise ベンダーを追加*

    Adding Materialise vendor in OpenLM Broker

1. **Save** をクリックします。

## OpenLM Platform で Materialise Magics を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Materialise Magics ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Materialise Magics が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
