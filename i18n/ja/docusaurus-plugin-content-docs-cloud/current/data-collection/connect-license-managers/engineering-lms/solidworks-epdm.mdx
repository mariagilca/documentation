# SolidWorks EPDM

Scope

OpenLM は次の監視をサポートしています： a wide and growing variety of license managers. This document explains how to configure OpenLM to monitor the Solidworks EPDM database and track license usage and reporting.

## はじめに

- OpenLM Platform。
- Solidworks と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    Configure OpenLM Server for EPDM

1. 次を確認します： you have a single OpenLM Serveron a central network server.

1. From the Windows Start menu, go to OpenLM → OpenLM Server.

1. Select the LM Tools tab → EPDM.

1. Enter the EPDM connection string fields:
    - Server Name → EPDM server hostname or IP
    - Database Name → EPDM database name
    - SQL Username → database username
    - Password → password for the username

1. Click Test to validate the connection.

1. Go to License Servers → Add and configure:
    - Type → EPDM
    - Description → descriptive server name
    - Time Zone → license server time zone
    - Hostname and Port → any text (not significant for EPDM)
    - Is Triad Configuration → select if applicable
    - Clear the checkboxes for Use Broker and Use License File

1. **Apply** をクリックします。

1. For added functionality, consider:
    - Installing the OpenLM Workstation Agent
    - Evaluating Features

1. Review results in OpenLM Reports.

## OpenLM Platform で SolidWorks EPDM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. SolidWorks EPDM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. SolidWorks EPDM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
