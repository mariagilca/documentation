対象範囲

OpenLM は、多種多様で拡大し続けるライセンスマネージャーの監視をサポートしています。本ドキュメントでは、Solidworks EPDM データベースを監視し、ライセンスの使用状況とレポートを追跡するように OpenLM を設定する方法について説明します。

## はじめに

- OpenLM Platform。
- Solidworks と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    EPDM 用に OpenLM Server を設定する

1. 中央ネットワークサーバー上に OpenLM Server が 1 台あることを確認します。

1. Windows のスタートメニューから、OpenLM → OpenLM Server を開きます。

1. **LM Tools** タブ → EPDM を選択します。

1. EPDM 接続文字列の各フィールドを入力します。
    - Server Name → EPDM サーバーのホスト名または IP
    - Database Name → EPDM データベース名
    - SQL Username → データベースのユーザー名
    - Password → そのユーザー名のパスワード

1. **Test** をクリックして接続を検証します。

1. **License Servers** → **Add** を開き、次のように設定します。
    - Type → EPDM
    - Description → わかりやすいサーバー名
    - Time Zone → ライセンスサーバーのタイムゾーン
    - Hostname and Port → 任意のテキスト (EPDM では重要ではありません)
    - Is Triad Configuration → 該当する場合は選択
    - **Use Broker** と **Use License File** のチェックボックスをオフにします

1. **Apply** をクリックします。

1. 追加機能として、次を検討してください。
    - OpenLM Workstation Agent のインストール
    - 機能の評価

1. OpenLM Reports で結果を確認します。

## OpenLM Platform で SolidWorks EPDM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. SolidWorks EPDM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. SolidWorks EPDM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
