# Venturis

本ドキュメントでは、OpenLM で Venturis ライセンスマネージャーを監視し、統計を収集する設定方法を説明します。

## はじめに

To query Venturis License Manager, install:

- OpenLM Platform。
- Venturis と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

Current monitoring capabilities を OpenLM Broker 経由で:

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

OpenLM Broker reads the Venturis log file. Data is compiled and sent to OpenLM Server. License files are configured manually in Broker. Broker reads the log file and tracks session changes. The license file and options file are monitored for updates based on the configured Watch interval.

### 手動で追加
1. Open a browser and go to http://localhost:5090/.

1. Go to License Managers → Add license manager.

1. Select Venturis as the license manager type, enter the port (for example, 2679), and **Add** をクリックします.

1. **Settings** で、 choose one of:
    - Detect license file path automatically
    - Set license file manually
    - Allow license file sorting
    - Watch license file

1. **Commands** で、 set Executable path to the i4blt executable on the IBM LUM license server.

1. **Vendors** で、 enter the correct vendor name.

1. **Save** をクリックします。

## OpenLM Platform で Venturis を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Venturis ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Venturis が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
