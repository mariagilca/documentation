本ドキュメントでは、OpenLM で Venturis License Manager を監視し、ライセンス統計を収集する設定方法を説明します。

## はじめに

Venturis License Manager を照会するには、次をインストールします。

- OpenLM Platform
- Venturis と同じマシンにインストールされた OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

OpenLM Broker 経由での現在の監視機能は次のとおりです。

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

OpenLM Broker は Venturis のログファイルを読み取ります。データはコンパイルされ、OpenLM Server に送信されます。ライセンスファイルは Broker で手動設定します。Broker はログファイルを読み取り、セッションの変更を追跡します。ライセンスファイルとオプションファイルは、設定された Watch 間隔に基づいて更新が監視されます。

### 手動で追加
1. ブラウザーを開き、`http://localhost:5090/` にアクセスします。

1. **License Managers** → **Add license manager** に移動します。

1. ライセンスマネージャーの種類として Venturis を選択し、ポート（例: 2679）を入力して **Add** をクリックします。

1. **Settings** で、次のいずれかを選択します。
    - Detect license file path automatically
    - Set license file manually
    - Allow license file sorting
    - Watch license file

1. **Commands** で、IBM LUM ライセンスサーバー上の i4blt 実行ファイルに実行ファイルのパスを設定します。

1. **Vendors** で、正しいベンダー名を入力します。

1. **Save** をクリックします。

## OpenLM Platform で Venturis を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Venturis ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Venturis が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
