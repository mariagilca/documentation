# LexFloatServer

OpenLM でライセンス使用状況と次を収集するための設定手順： ライセンス統計 from LexFloat Server.

## はじめに

ライセンスマネージャーへのクエリ前に、次をインストールしてください。

- OpenLM Platform。
- LexFloat と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| LexFloat Server | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the LexFloat Server License Manager](/img/engineering-lms/lexfloatserver/image27.png)
*OpenLM と LexFloat Server の連携の概要*

OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding.

### 手動で追加
1. Broker Web UI を開きます： http://localhost:5090.

1. **License Managers** → **Add License Manager** を開きます。

1. **LM Type** ドロップダウンリストから次を選択します： LexFloat Server.

1. ポート番号を入力します (for example, 889) and **Add** をクリックします.

    ![Adding LexFloat Server license manager in OpenLM Broker](/img/engineering-lms/lexfloatserver/image146.png)
*OpenLM Broker で LexFloat Server ライセンスマネージャーを追加*

1. Go to the Vendors tab. **Add Vendor** をクリックし、 enter LexFloat Server, and **Continue** をクリックします.

    ![Adding LexFloat Server vendor in OpenLM Broker](/img/engineering-lms/lexfloatserver/image16.png)
*OpenLM Broker で LexFloat Server ベンダーを追加*

1. Go to the Log Files tab. **Add Log File** をクリックします。 Turn off Watch file by pattern. You can add multiple logs. **Continue** をクリックします。

    ![Adding a log file for LexFloat Server in OpenLM Broker](/img/engineering-lms/lexfloatserver/image88.png)
*OpenLM Broker で LexFloat Server のログファイルを追加*

1. **Save** をクリックします。

## OpenLM Platform で LexFloatServer を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. LexFloatServer ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. LexFloatServer が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
