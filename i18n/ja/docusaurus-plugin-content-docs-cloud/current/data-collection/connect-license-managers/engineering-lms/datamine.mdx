Datamine ライセンスマネージャーからライセンス使用状況と統計を収集できるよう、次の手順で OpenLM を設定します。

## はじめに

- OpenLM Platform。
- Datamine と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

OpenLM Broker を通じた Datamine の現在の監視機能は次のとおりです。

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

![OpenLM と Datamine ライセンスマネージャーの連携の概要](/img/engineering-lms/datamine/image27.png)
*OpenLM と Datamine ライセンスマネージャーの連携の概要*

:::note
OpenLM Broker は Datamine の .csv ログファイルを読み取り、処理したデータを OpenLM Server に送信します。
:::
### 手動設定（Broker Web UI）

1. ブラウザーを開き、`http://localhost:5090/` にアクセスします。

1. **License Managers** → **Add License Manager** を開きます。

    ![Datamine を選択し、任意のポート番号（例: 888）を入力して **Add** をクリックします。](/img/engineering-lms/datamine/image70.png)
*Datamine を選択し、任意のポート番号（例: 888）を入力して **Add** をクリックします。*

    ![Log Files で Add Log File をクリックします。](/img/engineering-lms/datamine/image141.png)
*Log Files で Add Log File をクリックします。*

1. .csv ログファイルの場所を入力するか、参照して指定します。

    ![Continue をクリックし、続いて Save をクリックします。](/img/engineering-lms/datamine/image109.png)
*Continue をクリックし、続いて Save をクリックします。*

## OpenLM Platform で Datamine を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Datamine ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Datamine が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
