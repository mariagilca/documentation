# Datamine

Datamine ライセンスマネージャーを OpenLM で監視する手順です。

## 必要条件

1. OpenLM Platform
1. Datamine と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 秒 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 非対応 |
| 借用ライセンス | 非対応 |
| 期限日 | 非対応 |
| 冗長構成 | 非対応 |

## Broker UI での設定

![Datamine と OpenLM の連携図](/img/engineering-lms/datamine/image27.png)
*Datamine と OpenLM の連携図*

Broker は Datamine の `.csv` ログファイルを読み込み、OpenLM Server に送信します。

### 手動設定

1. ブラウザで [http://localhost:5090](http://localhost:5090) を開きます。
1. **License Managers -> Add License Manager** をクリックします。

    ![Datamine の追加](/img/engineering-lms/datamine/image70.png)
*Datamine の追加*

1. *Datamine* を選び、ポート番号（例: 888）を入力して **Add**。

    ![ログファイルの追加](/img/engineering-lms/datamine/image141.png)
*ログファイルの追加*

1. **Log Files -> Add Log File** をクリックします。
1. `.csv` ログファイルの保存先を入力または参照します。

    ![保存](/img/engineering-lms/datamine/image109.png)
*保存*

1. **Continue -> Save** をクリックします。

## OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/datamine/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューで **Pending Server** を選択します。
1. リストから Datamine を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/datamine/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** に移動し、Datamine のステータスが緑表示であることを確認します。

> 新しい接続では、ステータス更新に最大 3 分かかります。
