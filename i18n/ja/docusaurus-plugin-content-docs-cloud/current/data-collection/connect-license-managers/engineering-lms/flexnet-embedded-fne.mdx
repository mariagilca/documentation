# Flexnet Embedded (FNE)

本ガイドでは、次の方法を説明します： configure OpenLM to monitor a FlexNet Embedded license manager and collect usage statistics.

## How it works

OpenLM Server queries the FlexNet Embedded server's XML API to retrieve license usage and statistics. The data is aggregated and displayed in OpenLM Web Interface reports. For more details, see What is FlexNet Embedded?.

![Diagram of how OpenLM Server interfaces with a FlexNet Embedded server](/img/engineering-lms/flexnet-embedded-fne/image145.png)
*OpenLM Server と FlexNet Embedded サーバーの連携*

## はじめに

- OpenLM Platform。
- Flexnet Embedded と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Select Flexnet Embedded, ポート番号を入力し、 and **Add** をクリックします.

1. Fill in the fields:
    - Type: FlexNet Embedded
    - Description: recognizable name (for example, FlexNet Embedded server)
    - Time zone: match the license server's location
    - Hostname: server hostname or IP
    - Port: see the following instructions
    - Vendor name: for example, Avid, NVIDIA

1. Click Test to verify.

1. Click Apply, then Save.

## OpenLM Platform で Flexnet Embedded (FNE) を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Flexnet Embedded (FNE) ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Flexnet Embedded (FNE) が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
