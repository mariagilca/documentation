# Licman

OpenLM は次と連携できます： Licman to ライセンス使用状況を監視し、統計を収集します。 The Licman server is queried locally by OpenLM Broker, which sends the data to OpenLM Server for monitoring and reporting.

## はじめに

- OpenLM Platform。
- Licman と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Licman | Yes | No | Yes | Yes | No | No | No | Seconds |


Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

![Configuring through the Broker UI](/img/engineering-lms/licman/image34.png)
*Broker UI での設定*

1. Open a browser and go to http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Select Licman, enter a port, and **Add** をクリックします.

1. **Commands** で、 次のパスを設定します： licman20_appl.exe.

1. **Vendors** で、 enter the Licman vendor name.

1. **Save** をクリックします。

    ![Configure OpenLM Platform](/img/engineering-lms/licman/image37.png)
*OpenLM Platform の設定*

## OpenLM Platform で Licman を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Licman ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Licman が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
