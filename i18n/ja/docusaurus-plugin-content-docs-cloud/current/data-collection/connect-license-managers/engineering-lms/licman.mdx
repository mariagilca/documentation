# Licman

OpenLM は Licman と連携してライセンス使用状況を監視し、統計情報を取得できます。Licman サーバーは OpenLM Broker がローカルで照会し、取得したデータを OpenLM Server に送信します。

## 必要条件

1. OpenLM Platform
1. Licman と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

![Broker UI での設定](/img/engineering-lms/licman/image34.png)
*Broker UI での設定*

以下の手順で Broker と OpenLM Platform を構成します。

1. ブラウザーで http://localhost:5090/ を開きます。
1. **License Managers -> Add License Manager** を開きます。
1. Licman を選択し、ポート番号を入力して **Add** をクリックします。
1. **Commands** で `licman20_appl.exe` へのパスを設定します。
1. **Vendors** で Licman のベンダー名を入力します。
1. **Save** をクリックします。

![OpenLM Platform での設定](/img/engineering-lms/licman/image37.png)
*OpenLM Platform での設定*

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/licman/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューの **Pending Server** を選択します。
1. リストから Licman ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/licman/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** を開きます。
1. Licman が緑のステータスで表示されていることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかることがあります。
