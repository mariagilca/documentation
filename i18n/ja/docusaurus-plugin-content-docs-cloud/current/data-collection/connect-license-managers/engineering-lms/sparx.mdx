# Sparx

## はじめに

- OpenLM Platform。
- Sparx と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

1. Broker UI を開きます： http://localhost:5090/.

1. Navigate to License Managers → Add License Manager.

1. Select Sparx as the LM type, enter port (default 7770), and **Add** をクリックします.

    ![Configure command and execution options as needed (for example, start/stop toggles, periodic/on-demand inquiry).](/img/engineering-lms/sparx/image143.png)
*必要に応じてコマンドおよび実行オプションを設定（例: start/stop トグル、定期／オンデマンドの問い合わせ）*

    ![Add log file configuration (same as earlier).](/img/engineering-lms/sparx/image131.png)
*ログファイル設定を追加（前述と同じ）*
    - Type: SSKS Log
    - Path: ssksLog.log
    - Encoding: UTF-16

    ![設定を保存します。](/img/engineering-lms/sparx/image8.png)
*設定を保存します。*

## OpenLM Platform で Sparx を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Sparx ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Sparx が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
