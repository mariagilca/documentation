## はじめに

- OpenLM Platform。
- Sparx と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** に移動します。

1. LM タイプとして Sparx を選択し、ポート (デフォルトは 7770) を入力して、**Add** をクリックします。

    ![必要に応じてコマンドおよび実行オプションを設定します (例: 開始/停止の切り替え、定期/オンデマンドの問い合わせ)。](/img/engineering-lms/sparx/image143.png)
*必要に応じてコマンドおよび実行オプションを設定します (例: 開始/停止の切り替え、定期/オンデマンドの問い合わせ)。*

    ![ログファイル設定を追加します (前述と同じ)。](/img/engineering-lms/sparx/image131.png)
*ログファイル設定を追加します (前述と同じ)。*
    - Type: SSKS Log
    - Path: ssksLog.log
    - Encoding: UTF-16

    ![設定を保存します。](/img/engineering-lms/sparx/image8.png)
*設定を保存します。*

## OpenLM Platform で Sparx を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Sparx ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Sparx が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
