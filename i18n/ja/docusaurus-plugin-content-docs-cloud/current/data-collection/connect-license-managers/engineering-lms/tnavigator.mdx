# tNavigator

OpenLM で tNavigator ライセンスマネージャーのライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

開始前に、次が揃っていることを確認してください。

- OpenLM Platform。
- tNavigator と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| Report resolution | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | No | No | Yes | No |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the tNavigator License Manager](/img/engineering-lms/tnavigator/image27.png)
*OpenLM と tNavigator の連携の概要*

本手順の前提として、OpenLM Broker をインストールし、OpenLM への報告設定を完了しておきます。

### 手動で追加
1. On the tNavigator license manager machine, open the Broker web UI at http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

    ![Select tNavigator from the drop-down list and ポート番号を入力します. **Add** をクリックします。](/img/engineering-lms/tnavigator/image159.png)
    *Select tNavigator from the drop-down list and ポート番号を入力します. **Add** をクリックします。*
*Select tNavigator from the drop-down list and ポート番号を入力します. **Add** をクリックします。*

1. **Commands** タブで、 次の場所を参照します： or type the installation path of the tNavigator License Manager.

1. **Execute** をクリックします to verify there are no errors.

1. Go to Vendors → Add Vendor. Enter tNavigator and **Continue** をクリックします.

1. Go to Log Files → Add Log File. Browse to the tNavigator log file location, turn Watch File by Pattern on, and **Continue** をクリックします.

1. **Save** をクリックします。

## OpenLM Platform で tNavigator を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. tNavigator ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. tNavigator が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
