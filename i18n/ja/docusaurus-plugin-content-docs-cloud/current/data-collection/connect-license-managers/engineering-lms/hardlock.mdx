# Hardlock

Hardlock ライセンスマネージャーを OpenLM で監視する手順です。

## 必要条件

1. OpenLM Platform
1. Hardlock と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | ログ解析 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 期限日 | 非対応 |
| 冗長構成 | 非対応 |

## Broker UI での設定

![Hardlock ライセンスマネージャーとの連携図](/img/engineering-lms/hardlock/image27.png)
*Hardlock ライセンスマネージャーとの連携図*

> Broker は事前に OpenLM Server へ接続済みである必要があります。

1. [http://localhost:5090](http://localhost:5090) で Broker UI を開きます。
1. **License Managers -> Add License Manager** をクリックします。

    ![Hardlock を選択して追加](/img/engineering-lms/hardlock/image12.png)
*Hardlock を選択して追加*

1. *HardLock* を選択し、ポート番号を入力して **Add**。

    ![Vendor 追加](/img/engineering-lms/hardlock/image153.png)
*Vendor 追加*

1. **Vendors -> Add Vendor** をクリックし、*Hardlock* を入力して **Continue**。

    ![ログファイル設定](/img/engineering-lms/hardlock/image167.png)
*ログファイル設定*

1. **Log Files -> Add Log File** をクリックし、ログファイル（.log）を指定します。
1. 追加した Hardlock ベンダーを選び **Continue**。

    ![保存](/img/engineering-lms/hardlock/image38.png)
*保存*

1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/hardlock/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューで **Pending Server** を選択します。
1. リストから Hardlock を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/hardlock/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** に移動し、ステータスが緑表示であることを確認します。

> 新しい接続では、反映まで最大 3 分かかります。
