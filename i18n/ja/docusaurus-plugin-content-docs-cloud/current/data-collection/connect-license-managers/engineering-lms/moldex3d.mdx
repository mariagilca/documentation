# Moldex3D

本ガイドでは、次の方法を説明します： monitor the Moldex3D License Manager with OpenLM to obtain license usage and statistics.

## はじめに

次をインストールしてください。

- OpenLM Platform。
- Moldex3D と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The following table shows the monitoring capabilities available を OpenLM Broker 経由で:

| Report resolution | License totals | License usage | Denials | Borrowed licenses | Expiration dates | Redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By second | Yes | Yes | Yes | Yes | Yes | No |

Using Broker also allows:

- Buffered communication with OpenLM Server

- Remote start/stop of the license manager service

### オプション 1 — 自動検出
1. In Broker, **Detect** をクリックします.

    ![If the Moldex3D service (for example, Moldex3D-LM Service) is running, Broker detects and configures it automatically.](/img/engineering-lms/moldex3d/image107.png)
*Moldex3D サービス（例: Moldex3D-LM Service）が稼働している場合、Broker が自動的に検出・設定します。*

1. After configuration, select Restart Broker.

1. Also run data_inquiry → Execute to confirm valid output.

### オプション 2 — 手動で追加
1. Install the latest Broker.

1. Open http://localhost:5090/.

1. Go to License Managers.
    - If the Moldex3D service is running, **Detect** をクリックします.
    - If autodetect fails, **Add** をクリックします License Manager. From Type, select Moldex3D. ポートを入力します and **Add** をクリックします.

## OpenLM Platform で Moldex3D を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Moldex3D ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Moldex3D が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
