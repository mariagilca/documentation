# ProgeCAD

ProgeCAD is a 2D and 3D design software for CAD and concept sketching. It is compatible with AutoCAD and supports Direct Modeling in native .dwg format.

OpenLM は次の監視をサポートしています： the ProgeCAD Network License Manager (NLM) for versions 13.0.18 onward. The license server creates a periodic XML file, which OpenLM parses to present usage results in the OpenLM Web Interface.

## はじめに

Monitoring ProgeCAD requires:

- OpenLM Platform。
- ProgeCAD と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## OpenLM Broker の設定

Alternatively, use the Broker web UI:

- Open http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. From Type, select OpenLM Generic. ポートを入力します (for example, 51168) and **Add** をクリックします.

    ![Go to the Commands tab. In Executable path, enter:](/img/engineering-lms/progecad/image95.png)
*Commands タブで Executable path に入力*

    ```bash
    "<Full path to NLMServerMonitor.exe>" /xml
    ```

1. Click Save, then Execute to validate the output.

## OpenLM Platform で ProgeCAD を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. ProgeCAD ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. ProgeCAD が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
