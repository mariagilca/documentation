# canvas x geo

本ドキュメントでは、次に必要な手順を説明します： interface OpenLM with Canvas, allowing you to ライセンス使用状況を監視し、統計を収集します。

## はじめに

- OpenLM Platform。
- Canvas と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

The current monitoring capabilities for Canvas を OpenLM Broker 経由で are:

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Canvas | No | Yes | No | No | No | No | No | Per second |

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the Canvas License Manager](/img/engineering-lms/canvas-x-geo/image27.png)
*OpenLM と Canvas の連携の概要*

本手順の前提として、OpenLM Broker をインストールし、OpenLM への報告設定を完了しておきます。

1. Broker UI を開きます： http://localhost:5090/.

1. **License Managers** → **Add License Manager** を開きます。

1. Select Canvas, ポート番号を入力し、 and **Add** をクリックします.

    ![Adding a Canvas license manager in OpenLM Broker](/img/engineering-lms/canvas-x-geo/image138.png)
*OpenLM Broker で Canvas ライセンスマネージャーを追加*

1. Select the Vendors tab. **Add Vendor** をクリックします。 In the pop-up, enter Canvas as the vendor name and **Continue** をクリックします.

    ![Adding Canvas vendor in OpenLM Broker](/img/engineering-lms/canvas-x-geo/image125.png)
*OpenLM Broker で Canvas ベンダーを追加*

1. Switch to the Log Files tab. **Add Log File** をクリックします。 Make sure Watch file by pattern is turned off. You can add multiple logs. Browse to the location of the activity log, then **Continue** をクリックします.

    ![Adding a log file for Canvas in OpenLM Broker](/img/engineering-lms/canvas-x-geo/image99.png)
*OpenLM Broker で Canvas のログファイルを追加*

1. **Save** をクリックします。

## OpenLM Platform で canvas x geo を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. canvas x geo ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. canvas x geo が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
