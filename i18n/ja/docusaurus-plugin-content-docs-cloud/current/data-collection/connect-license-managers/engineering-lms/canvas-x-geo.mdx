本ドキュメントでは、OpenLM を Canvas と連携させ、ライセンス使用状況を監視して統計を取得するために必要な手順を説明します。

## はじめに

- OpenLM Platform。
- Canvas と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

OpenLM Broker を通じた Canvas の現在の監視機能は次のとおりです。

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Canvas | No | Yes | No | No | No | No | No | Per second |

## OpenLM Broker の設定

![OpenLM と Canvas License Manager の連携の概要](/img/engineering-lms/canvas-x-geo/image27.png)
*OpenLM と Canvas License Manager の連携の概要*

続行する前に、OpenLM Broker をすでにインストールし、OpenLM に報告するように設定しておく必要があります。

1. Broker UI を `http://localhost:5090/` で開きます。

1. **License Managers** → **Add License Manager** を開きます。

1. Canvas を選択し、ポート番号を入力して **Add** をクリックします。

    ![OpenLM Broker での Canvas ライセンスマネージャーの追加](/img/engineering-lms/canvas-x-geo/image138.png)
*OpenLM Broker での Canvas ライセンスマネージャーの追加*

1. **Vendors** タブを選択します。**Add Vendor** をクリックします。ポップアップで、ベンダー名として Canvas を入力し、**Continue** をクリックします。

    ![OpenLM Broker での Canvas ベンダーの追加](/img/engineering-lms/canvas-x-geo/image125.png)
*OpenLM Broker での Canvas ベンダーの追加*

1. **Log Files** タブに切り替えます。**Add Log File** をクリックします。**Watch file by pattern** がオフになっていることを確認します。複数のログを追加できます。アクティビティログの場所を参照し、**Continue** をクリックします。

    ![OpenLM Broker での Canvas のログファイルの追加](/img/engineering-lms/canvas-x-geo/image99.png)
*OpenLM Broker での Canvas のログファイルの追加*

1. **Save** をクリックします。

## OpenLM Platform で canvas x geo を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. canvas x geo ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. canvas x geo が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
