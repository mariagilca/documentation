Kisters VSLM License Manager からライセンス使用状況の監視と統計の収集を行うように OpenLM を設定するには、次の手順に従います。

## はじめに

開始前に、次をインストールしてください。

- OpenLM Platform。
- VSLM と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- |
| VSLM | No | No | No | Yes | Yes | No | Seconds |

Broker を使用すると、バッファリングされた通信や、ライセンスマネージャーサービスのリモートでの開始/停止も可能になります。

## OpenLM Broker の設定

続行する前に、OpenLM Broker がすでにインストールされ、OpenLM へ報告するように設定されている必要があります。

### 手動で追加
1. Broker Web UI を開きます: `http://localhost:5090`。デフォルトのポートが使用中の場合は、5091 または 5092 を試してください。Detect をクリックして、ライセンスマネージャーを自動検出することもできます。

1. License Managers → Add License Manager に移動します。

1. ドロップダウンリストから VSLM を選択し、ポート番号 (例: 888) を入力して Add をクリックします。

    ![Commands で、設定を確認するか、必要に応じて調整します。](/img/engineering-lms/kisters-vslm/image113.png)
*Commands で、設定を確認するか、必要に応じて調整します。*

    ![Vendors で Add Vendor をクリックし、VSLM を入力して Continue をクリックします。](/img/engineering-lms/kisters-vslm/image154.png)
*Vendors で Add Vendor をクリックし、VSLM を入力して Continue をクリックします。*

    ![Log Files で Add Log File をクリックし、VSLM のログの場所を参照して、Watch file by pattern がオフになっていることを確認します。](/img/engineering-lms/kisters-vslm/image171.png)

## OpenLM Platform で Kisters VSLM を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Kisters VSLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Kisters VSLM が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
