# Kisters VSLM

以下の手順で Kisters VSLM ライセンスマネージャーを OpenLM に接続します。

## 必要条件

開始前に以下を用意します。

1. OpenLM Platform
1. VSLM と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| Broker 上の LM タイプ | VSLM |
| 総ライセンス数 | 取得不可 |
| 使用状況 | 取得不可 |
| 否認 | 非対応 |
| 借用 | 取得可 |
| 期限日 | 取得可 |
| 冗長構成 | 非対応 |
| レポート解像度 | 秒単位 |

Broker を利用すると通信のバッファリングやライセンスサービスのリモート制御も可能です。

## Broker UI での設定

![VSLM と OpenLM の連携図](/img/engineering-lms/kisters-vslm/image27.png)
*VSLM と OpenLM の連携図*

> Broker は事前に OpenLM へ接続済みである必要があります。

1. [http://localhost:5090](http://localhost:5090)（使用中の場合は 5091 / 5092）で Broker UI を開きます。**Detect** を使って自動検出も可能です。
1. **License Managers -> Add License Manager** をクリックします。
1. ドロップダウンから *VSLM* を選択し、ポート（例: 888）を入力して **Add**。

    ![Commands の設定](/img/engineering-lms/kisters-vslm/image113.png)
*Commands の設定*

1. **Commands** タブで必要な設定を確認・調整します。

    ![ベンダー追加](/img/engineering-lms/kisters-vslm/image154.png)
*ベンダー追加*

1. **Vendors -> Add Vendor** をクリックし、*VSLM* を入力して **Continue**。

    ![ログ設定](/img/engineering-lms/kisters-vslm/image171.png)
*ログ設定*

1. **Log Files -> Add Log File** をクリックし、VSLM ログの場所を指定します。`Watch file by pattern` はオフにします。

    ![保存](/img/engineering-lms/kisters-vslm/image73.png)
*保存*

1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/kisters-vslm/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューで **Pending Server** を選択します。
1. VSLM ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/kisters-vslm/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新しい接続では反映まで最大 3 分かかります。
