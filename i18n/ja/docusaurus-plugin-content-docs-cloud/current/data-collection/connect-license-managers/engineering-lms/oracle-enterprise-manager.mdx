# Oracle Enterprise Manager

OpenLM で Oracle Enterprise Manager のライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

- OpenLM Platform。
- Oracle Enterprise Manager と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    Monitoring capabilities

    | Item | Value |
    | --- | --- |
    | LM Type in the Broker | Oracle Enterprise Manager |
    | License totals | No |
    | License usage | Yes |
    | Denials | No |
    | Borrowing | No |
    | Expiration date | No |
    | Redundancy | No |
    | Report resolution | Seconds |

    Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

    ![Diagram of how OpenLM interfaces with the Oracle Enterprise Manager](/img/engineering-lms/oracle-enterprise-manager/image27.png)
*OpenLM と Oracle Enterprise Manager の連携の概要*

    OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding

## OpenLM Broker の設定

1. Broker Web UI を開きます： http://localhost:5090. 既定のポートが使用中の場合は 5091 または 5092 を使用します。

1. **License Managers** → **Add License Manager** を開きます。

1. Select Oracle Enterprise Manager from the drop-down list, ポート番号を入力し、 and **Add** をクリックします.

## OpenLM Platform で Oracle Enterprise Manager を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Oracle Enterprise Manager ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Oracle Enterprise Manager が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
