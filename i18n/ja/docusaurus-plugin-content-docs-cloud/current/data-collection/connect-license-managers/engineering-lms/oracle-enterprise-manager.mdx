OpenLM で Oracle Enterprise Manager のライセンス使用状況および統計を収集するための設定手順は以下のとおりです。

## はじめに

- OpenLM Platform。
- Oracle Enterprise Manager と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

    監視機能

    | Item | Value |
    | --- | --- |
    | LM Type in the Broker | Oracle Enterprise Manager |
    | License totals | No |
    | License usage | Yes |
    | Denials | No |
    | Borrowing | No |
    | Expiration date | No |
    | Redundancy | No |
    | Report resolution | Seconds |

    Broker を使用すると、バッファリングされた通信が可能になり、ライセンスマネージャーサービスをリモートで開始および停止できます。

    ![OpenLM が Oracle Enterprise Manager と連携する仕組みの図](/img/engineering-lms/oracle-enterprise-manager/image27.png)
*OpenLM が Oracle Enterprise Manager と連携する仕組みの図*

    続行する前に、OpenLM Broker をインストールし、OpenLM Server へレポートするように設定しておく必要があります。

## OpenLM Broker の設定

1. Broker の Web UI を `http://localhost:5090` で開きます。既定のポートが使用中の場合は 5091 または 5092 を使用します。

1. **License Managers** → **Add License Manager** を開きます。

1. ドロップダウンリストから Oracle Enterprise Manager を選択し、ポート番号を入力して、**Add** をクリックします。

    ![Commands で、lmsettings 内の Oracle Enterprise Manager の SQL ファイルを含むフォルダーに実行ファイルのパスを設定し、Execute をクリックします。](/img/engineering-lms/oracle-enterprise-manager/image74.png)

    ![Vendors で、Add Vendor をクリックし、Oracle と入力して、Continue をクリックします。](/img/engineering-lms/oracle-enterprise-manager/image11.png)

## OpenLM Platform で Oracle Enterprise Manager を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Oracle Enterprise Manager ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Oracle Enterprise Manager が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
