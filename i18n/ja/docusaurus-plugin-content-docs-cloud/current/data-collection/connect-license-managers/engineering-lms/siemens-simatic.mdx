本ドキュメントでは、OpenLM を Siemens SIMATIC と連携してライセンス使用状況と統計を収集する方法を説明します。

## はじめに

Siemens SIMATIC にクエリを実行するには、次をインストールしてください。

- OpenLM Platform。
- SIMATIC と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

OpenLM Broker を介した現在の監視機能は次のとおりです。

| Report resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- |
| By minute | Yes | Yes | No | No | No | No |

## OpenLM Broker の設定

![OpenLM と Siemens SIMATIC の連携の図](/img/engineering-lms/siemens-simatic/image27.png)
*OpenLM と Siemens SIMATIC の連携の図*

Broker は Siemens SIMATIC のログファイルを読み取ります。読み取り後、データはまとめられて OpenLM Server に送信されます。

### 手動で追加
続行する前に、OpenLM Broker をインストールし、OpenLM Server へレポートするように設定しておく必要があります。

1. ブラウザーを開いて `http://localhost:5090/` にアクセスします。

1. **License Managers** をクリックし、次に **Add License Manager** をクリックします。

    ![ポップアップで、ライセンスマネージャーのタイプを選択し、任意のポート番号 (例: 888) を入力してから、Add をクリックします。](/img/engineering-lms/siemens-simatic/image12.png)
*ポップアップで、ライセンスマネージャーのタイプを選択し、任意のポート番号 (例: 888) を入力してから、Add をクリックします。*

    ![Vendors を開きます。Add Vendor をクリックし、名前を入力してから、Confirm をクリックします。](/img/engineering-lms/siemens-simatic/image21.png)
*Vendors を開きます。Add Vendor をクリックし、名前を入力してから、Confirm をクリックします。*

    ![Log Files を開きます。](/img/engineering-lms/siemens-simatic/image33.png)
*Log Files を開きます。*

    ![Add Log File をクリックし、パスを手動で入力するか、虫眼鏡アイコンを使用して参照します。](/img/engineering-lms/siemens-simatic/image46.png)
*Add Log File をクリックし、パスを手動で入力するか、虫眼鏡アイコンを使用して参照します。*

1. ログファイルを選択し、Open をクリックします。

1. ドロップダウンから、ベンダー Siemens SIMATIC を選択します。

1. **Continue** をクリックします。

    ![Save をクリックします。](/img/engineering-lms/siemens-simatic/image86.png)
*Save をクリックします。*

    ![OpenLM Platform を設定する](/img/engineering-lms/siemens-simatic/image59.png)
*OpenLM Platform を設定する*

## OpenLM Platform で Siemens SIMATIC を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Siemens SIMATIC ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Siemens SIMATIC が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
