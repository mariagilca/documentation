# QPS

OpenLM でライセンス使用状況と次を収集するための設定手順： ライセンス統計 from QPS License Manager.

## はじめに

ライセンスマネージャーへのクエリ前に、次をインストールしてください。

- OpenLM Platform。
- QPS と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | Commands | Logs | Quantity | Expiration date | Denied | Borrowing | Allocations | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| QPS | No | Yes | No | No | No | No | No | Seconds |

Using the Broker also allows buffered communication and allows remote start and stop of the license manager service.

## OpenLM Broker の設定

![Diagram of how OpenLM interfaces with the QPS License Manager](/img/engineering-lms/qps/image27.png)
*OpenLM と QPS の連携の概要*

OpenLM Broker must be installed and configured to report to OpenLM Server before proceeding.

### 手動で追加
1. Broker Web UI を開きます： http://localhost:5090. 既定のポートが使用中の場合は 5091 または 5092 を使用します。

1. **License Managers** → **Add License Manager** を開きます。

1. **LM Type** ドロップダウンリストから次を選択します： QPS.

1. ポート番号を入力します (for example, 1234) and **Add** をクリックします.

    ![Adding QPS license manager in OpenLM Broker](/img/engineering-lms/qps/image93.png)
*OpenLM Broker で QPS ライセンスマネージャーを追加*

1. **Commands** タブで、 次のパスを設定します： the QPS installation folder.

    ![Configuring command path for QPS in OpenLM Broker](/img/engineering-lms/qps/image136.png)
*OpenLM Broker での QPS コマンドパスの設定*

1. Go to the Vendors tab. **Add Vendor** をクリックし、 enter QPS, and **Continue** をクリックします.

    ![Adding QPS vendor in OpenLM Broker](/img/engineering-lms/qps/image133.png)
*OpenLM Broker で QPS ベンダーを追加*

1. Go to the Log Files tab. **Add Log File** をクリックします。 Turn off Watch file by pattern. You can add multiple logs for different applications. **Continue** をクリックします。

    ![Adding log files for QPS in OpenLM Broker](/img/engineering-lms/qps/image19.png)
*OpenLM Broker で QPS のログファイルを追加*

1. **Save** をクリックします。

## OpenLM Platform で QPS を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. QPS ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. QPS が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
