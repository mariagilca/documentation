OpenLM は ArcGIS Online に接続し、ライセンス数と使用状況データを取得します。

## はじめに

- OpenLM Platform。
- OpenLM Broker v25.x 以降。[Broker Hub](/cloud/data-collection/broker-hub) でインストールおよび承認します。
- ArcGIS Online の管理者認証情報。

:::warning[二要素認証はサポートされていません]
OpenLM は、二要素認証（2FA）が有効になっている ArcGIS Online アカウントを監視できません。続行する前に、監視対象アカウントの 2FA を無効にしてください。
:::

## ArcGIS Online を OpenLM に追加

1. OpenLM Platform で **License Manager Servers** に移動します。
2. **Add LM** を選択します。
3. わかりやすい **Display Name** を入力します。

    ![わかりやすい Display Name を入力](/img/engineering-lms/amp/image144.png)
    *わかりやすい Display Name を入力*

4. **Type** から **ArcGIS Online** を選択します。
5. **LM Address** に `https://www.arcgis.com` を入力します。
6. ArcGIS Online の管理者ユーザー名とパスワードを入力します。
7. ライセンスマネージャーのタイムゾーンを選択します。
8. **Test Connection** を選択し、テストに合格することを確認します。

    ![接続成功](/img/engineering-lms/amp/image22.png)
    *接続成功*

9. **Save** を選択します。

ライセンスの使用状況と割り当てのデータは、数分以内に OpenLM のレポートに表示されます。

## OpenLM Platform で ArcGIS Online を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. ArcGIS Online ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. ArcGIS Online が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
