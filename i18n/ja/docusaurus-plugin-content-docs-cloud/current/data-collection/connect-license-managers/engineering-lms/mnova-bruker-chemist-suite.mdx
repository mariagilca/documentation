Mnova Bruker Chemist Suite License Manager からライセンス使用状況と統計を収集できるよう、次の手順で OpenLM を設定します。

## はじめに

開始前に、次をインストールしてください。

- OpenLM Platform。
- Mnova と同じマシンにインストールされ、[Broker Hub](/cloud/data-collection/broker-hub) で承認された OpenLM Broker v25.x 以降。

## 監視機能

| LM Type in the Broker | License totals | License usage | Denials | Borrowing | Expiration date | Redundancy | Report resolution |
| --- | --- | --- | --- | --- | --- | --- | --- |
| MlicAdmin | No | No | No | No | Yes (if the license file for the feature is provided) | No | Seconds |

Broker を使用すると、バッファリングされた通信が可能になり、ライセンスマネージャーサービスのリモートでの開始と停止も行えます。

## OpenLM Broker の設定

![OpenLM と Mnova License Manager の連携の概要](/img/engineering-lms/mnova-bruker-chemist-suite/image27.png)
*OpenLM と Mnova License Manager の連携の概要*

続行する前に、OpenLM Broker をインストールし、OpenLM に報告するように設定しておく必要があります。

### 手動で追加
1. Broker Web UI を `http://localhost:5090` で開きます。既定のポートが使用中の場合は 5091 または 5092 を試します。

1. **License Managers** → **Add License Manager** を開きます。

1. ドロップダウンリストから MlicAdmin を選択し、ポート番号（例: 888）を入力して **Add** をクリックします。

    ![Settings でライセンスファイルを設定します。](/img/engineering-lms/mnova-bruker-chemist-suite/image166.png)
*Settings でライセンスファイルを設定します。*
    - **Detect license file automatically** を選択するか、
    - 機能ごとに **Set license file path manually** を選択します。

    ![手動で追加する場合は、Add license file path をクリックし、各機能のライセンスファイルを参照します。](/img/engineering-lms/mnova-bruker-chemist-suite/image49.png)
*手動で追加する場合は、Add license file path をクリックし、各機能のライセンスファイルを参照します。*

1. **Allow license file sorting** と **Watch license file** がオフになっていることを確認します。

1. **Vendors** で **Add Vendor** をクリックし、Mnova と入力して **Continue** をクリックします。

    ![Log Files で Add Log File をクリックし、Watch file by pattern がオフであることを確認してから Continue をクリックします。](/img/engineering-lms/mnova-bruker-chemist-suite/image5.png)
*Log Files で Add Log File をクリックし、Watch file by pattern がオフであることを確認してから Continue をクリックします。*

    ![Save をクリックします。](/img/engineering-lms/mnova-bruker-chemist-suite/image149.png)
*Save をクリックします。*

## OpenLM Platform で Mnova Bruker Chemist Suite を承認

1. OpenLM Platform にサインインします。
2. メニューから **License Servers** → **Pending Server** を開きます。
3. Mnova Bruker Chemist Suite ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

## 連携の検証

1. OpenLM Platform で **License Servers Live** → **Server Statistics** を開きます。
2. Mnova Bruker Chemist Suite が緑のステータスで表示されることを確認します。

:::note
新規接続の場合、ステータスの反映まで最大 3 分かかります。
:::
