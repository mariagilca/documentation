# LinkedIn Sales Navigator
LinkedIn Sales Navigator 使用状況の監視

## LinkedIn Sales Navigator について

LinkedIn Sales Navigator は、営業担当者が適切な見込み客を見つけ、インサイトを把握し、潜在顧客とエンゲージメントを図るためのプレミアムツールです。Sales Navigator の利用状況を監視すると、営業チームがプラットフォームを有効活用しているか確認でき、ライセンスの無駄を防げます。Salesforce や Pipedrive などの営業ツールを監視する場合と同様です。

## 前提条件

LinkedIn Sales Navigator の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。自動化オプションとして License Access Control（LAC）を利用できます。FlexLM ではフルサポート、DSLS・RLM・Autodesk Cloud・LinkedIn では実験的サポートです。
- プラットフォーム固有の要件: LinkedIn Sales Navigator アカウントの管理者アクセス権が必要です。必要な権限を持つ API キーを取得します。

## データ収集の構成

LinkedIn Sales Navigator 連携の設定については、サポートチーム（[support@openlm.com](mailto:support@openlm.com)）までお問い合わせください。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: プラットフォームを利用している営業担当者とその活動量を把握します。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定してライセンスを回収し、コストを最適化します。
