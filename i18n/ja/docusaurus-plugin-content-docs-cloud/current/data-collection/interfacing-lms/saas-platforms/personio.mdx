# Personio
Personio 使用状況の監視

## Personio について

Personio は、中小企業向けのオールインワン HR ソフトウェアプラットフォームです。採用・オンボーディングから給与計算、パフォーマンス管理まで対応します。Personio の利用状況を監視すると、HR ライセンスを有効活用でき、コスト最適化につながります。BambooHR や Sage HR などの HR プラットフォームを監視する場合と同様です。

## 前提条件

Personio の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。
- プラットフォーム固有の要件: Personio アカウントの管理者アクセス権が必要です。必要な読み取り権限を持つ API キーとクライアント ID を生成します。

## データ収集の構成

OpenLM Cloud Broker で Personio のデータ収集を設定するには、次の手順に従います。

1. Personio の設定で API 認証情報を作成し、従業員およびユーザーデータを読み取れる権限を付与します。
   1. **Marketplace > Connected Integrations** に移動します。
   2. 画面右上の **Create custom integration** をクリックします。
   3. 必要な設定を行い、API 資格情報を生成します。
2. OpenLM Cloud Broker ダッシュボードで Personio 連携を選択し、API キーとクライアント ID を入力します。

   ![](/img/saas-platforms/personio/image33.png)

3. 接続を確認します。OpenLM がデータを取得できることをテストします。
4. OpenLM で承認します。「License Servers」セクションで新しいデータソースを承認します。
5. データを確認します。Personio の使用状況データが OpenLM Allocation サービスに表示されます。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: プラットフォームで最も活動している人事担当者を把握し、リソース配分に役立てます。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定してライセンスを回収します。
