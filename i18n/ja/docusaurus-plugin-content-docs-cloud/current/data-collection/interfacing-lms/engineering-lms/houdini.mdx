# Houdini

Houdini License Manager を OpenLM で監視する手順です。

## 必要条件

1. OpenLM Platform
1. Houdini と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## Broker UI での設定

1. [http://localhost:5090](http://localhost:5090) を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. Houdini（sesinetd）を選択し、ポート番号を入力して **Add**。
1. **Commands** で `sesictrl.exe` など必要な実行ファイルのパスを設定します。
1. **Vendors** で *Houdini* を追加します。
1. **Log Files** を設定し、必要に応じて `Watch files by pattern` を有効化します。
1. **Save** をクリックします。

## OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。
1. 左メニューの **Pending Server** から Houdini を選び、**Approve and Merge** をクリックします。
1. **License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新しい接続では反映まで最大 3 分かかります。
