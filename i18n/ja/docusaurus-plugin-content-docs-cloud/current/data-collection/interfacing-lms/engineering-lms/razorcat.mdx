# Razorcat

Razorcat ライセンスマネージャーを OpenLM で監視し、ライセンス使用状況と統計を取得する手順を説明します。

## 必要条件

開始前に以下を用意します。

- OpenLM Platform
- Razorcat と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 値 |
| --- | --- |
| レポート解像度 | 分 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 期限日 | 非対応 |
| 冗長構成 | 非対応 |

## OpenLM Broker の構成

![Razorcat ライセンスマネージャーと OpenLM の連携図](/img/engineering-lms/razorcat/image27.png)
*Razorcat ライセンスマネージャーと OpenLM の連携図*

OpenLM Broker をインストールし、設定を完了させてから以下の手順を実施します。

## Broker UI での設定

1. ブラウザーで http://localhost:5090/ を開きます。
1. **License Managers -> Add License Manager** を開きます。

    ![Razorcat を選択して追加](/img/engineering-lms/razorcat/image70.png)
*Razorcat を選択して追加*

1. タイプのドロップダウンで Razorcat を選択し、ポート番号を入力して **Add** をクリックします。

    ![Commands タブで flsutil.exe のフォルダーを指定](/img/engineering-lms/razorcat/image1.png)
*Commands タブで flsutil.exe のフォルダーを指定*

1. **Commands** タブで flsutil.exe が存在するフォルダーを指定します（虫眼鏡アイコンから参照可能）。
1. サービス名（例: Razorcat）を入力します。

    ![Vendor を追加](/img/engineering-lms/razorcat/image160.png)
*Vendor を追加*

1. **Vendors -> Add Vendor** を開き、Razorcat と入力して **Continue** をクリックします。

    ![保存ボタン](/img/engineering-lms/razorcat/image140.png)
*保存ボタン*

1. **Save** をクリックします。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/razorcat/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューの **Pending Server** を選択します。
1. Razorcat ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/razorcat/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** で Razorcat が緑のステータスで表示されることを確認します。

> 新しい接続ではステータスが更新されるまで最大 3 分かかる場合があります。
