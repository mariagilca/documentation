# canvas x geo

OpenLM と Canvas を連携し、ライセンス使用量を取得する手順を説明します。

## 必要条件

1. OpenLM Platform
1. Canvas と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| Broker 上の LM タイプ | Canvas |
| Commands | 非対応 |
| Logs | 対応 |
| 総ライセンス数 | 取得不可 |
| 期限日 | 取得不可 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 割り当て | 非対応 |
| レポート解像度 | 1 秒 |

## Broker UI での設定

![Canvas ライセンスマネージャーとの連携図](/img/engineering-lms/canvas-x-geo/image27.png)
*Canvas ライセンスマネージャーとの連携図*

> Broker は事前に OpenLM Server への接続設定を行ってください。

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** を選択します。
1. *Canvas* を選び、ポート番号を入力して **Add** をクリックします。

    ![Canvas ライセンスマネージャーの追加](/img/engineering-lms/canvas-x-geo/image138.png)
*Canvas ライセンスマネージャーの追加*

1. **Vendors** タブで **Add Vendor** をクリックし、ベンダー名に *Canvas* を入力して **Continue**。

    ![Canvas ベンダーの追加](/img/engineering-lms/canvas-x-geo/image125.png)
*Canvas ベンダーの追加*

1. **Log Files** タブで **Add Log File** をクリックし、`Watch file by pattern` をオフにしたうえでアクティビティログを指定します。複数ログの追加も可能です。

    ![Canvas のログファイル追加](/img/engineering-lms/canvas-x-geo/image99.png)
*Canvas のログファイル追加*

1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/canvas-x-geo/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューの **Pending Server** を選択します。
1. リストから Canvas ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/canvas-x-geo/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** に移動し、Canvas のステータスが緑で表示されることを確認します。

> 新規接続では、ステータス更新に最大 3 分かかります。
