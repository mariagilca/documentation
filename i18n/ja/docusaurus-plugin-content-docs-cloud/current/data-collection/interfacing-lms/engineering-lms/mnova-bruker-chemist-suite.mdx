# Mnova Bruker Chemist Suite

以下の手順で OpenLM を構成し、Mnova Bruker Chemist Suite License Manager の使用状況と統計を取得します。

## 必要条件

開始前に次をインストールします。

1. OpenLM Platform
1. Mnova と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 値 |
| --- | --- |
| Broker での LM Type | MlicAdmin |
| 総ライセンス数 | 取得不可 |
| 使用状況 | 取得不可 |
| 否認 | 取得不可 |
| 借用 | 取得不可 |
| 期限日 | 対応（該当機能のライセンスファイルが必要） |
| 冗長構成 | 非対応 |
| レポート解像度 | 秒 |

Broker を利用すると通信のバッファリングに加え、ライセンスマネージャーサービスのリモート起動・停止が可能です。

## OpenLM Broker の構成

![OpenLM が Mnova License Manager と連携する仕組み](/img/engineering-lms/mnova-bruker-chemist-suite/image27.png)
*OpenLM が Mnova License Manager と連携する仕組み*

> OpenLM Broker はあらかじめインストールし、OpenLM へのレポート設定を済ませてから先に進んでください。

## Broker UI での設定

1. http://localhost:5090 で Broker Web UI を開きます。デフォルトポートを使用できない場合は 5091 または 5092 を試してください。
1. **License Managers -> Add License Manager** を開きます。
1. ドロップダウンで MlicAdmin を選択し、ポート番号（例: 888）を入力して **Add** をクリックします。

    ![設定でライセンスファイルを構成](/img/engineering-lms/mnova-bruker-chemist-suite/image166.png)
*設定でライセンスファイルを構成*

1. **Settings** でライセンスファイルを構成します。
    - **Detect license file automatically** を選択するか、
    - 各機能ごとに **Set license file path manually** を選択します。

    ![ライセンスファイルパスを追加](/img/engineering-lms/mnova-bruker-chemist-suite/image49.png)
*ライセンスファイルパスを追加*

1. 手動で追加する場合は **Add license file path** をクリックし、対象機能のライセンスファイルを指定します。
1. **Allow license file sorting** と **Watch license file** が無効になっていることを確認します。
1. **Vendors** で **Add Vendor** をクリックし、Mnova と入力して **Continue** をクリックします。

    ![ログファイルを追加](/img/engineering-lms/mnova-bruker-chemist-suite/image5.png)
*ログファイルを追加*

1. **Log Files** で **Add Log File** をクリックし、**Watch file by pattern** を無効のまま **Continue** をクリックします。

    ![保存ボタン](/img/engineering-lms/mnova-bruker-chemist-suite/image149.png)
*保存ボタン*

1. **Save** をクリックします。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/mnova-bruker-chemist-suite/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューの **Pending Server** を選択します。
1. リストから Mnova ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/mnova-bruker-chemist-suite/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** を開きます。
1. Mnova が緑のステータスで表示されていることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかることがあります。
