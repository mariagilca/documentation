# Comos

以下の手順で Comos ライセンスマネージャーを OpenLM で監視します。

1. OpenLM Platform
1. Comos と同じマシンにインストールされた OpenLM Broker v25.x 以降

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 秒 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 取得可 |
| 借用ライセンス | 取得不可 |
| 期限日 | 取得可 |
| 冗長構成 | 非対応 |

## OpenLM Broker の設定

![Comos と OpenLM の連携図](/img/engineering-lms/comos/image27.png)
*Comos と OpenLM の連携図*

> Broker をインストールし、OpenLM への接続設定を済ませてから開始してください。

### 自動検出

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Detect** を実行します。
1. Comos が検出されたら内容を確認し、保存します。

### 手動設定

1. ブラウザで http://localhost:5090/ を開きます。
1. **License Managers -> Add License Manager** をクリックします。

    ![Comos を選択して追加](/img/engineering-lms/comos/image70.png)
*Comos を選択して追加*

1. *Comos* を選択し、ポート番号を入力して **Add**。

    ![Commands タブで Comos パスを設定](/img/engineering-lms/comos/image62.png)
*Commands タブで Comos パスを設定*

1. **Commands** タブで Comos インストールパスを指定し、**Execute** でエラーがないことを確認します。

    ![Vendor の追加](/img/engineering-lms/comos/image104.png)
*Vendor の追加*

1. **Vendors -> Add Vendor** を開き、*Comos* を入力して **Continue**。

    ![ログファイルの追加](/img/engineering-lms/comos/image56.png)
*ログファイルの追加*

1. **Log Files -> Add Log File** で Comos ログを指定し、`Watch file by pattern` をオンにして **Continue**。

    ![設定を保存](/img/engineering-lms/comos/image79.png)
*設定を保存*

1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/comos/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューで **Pending Server** を選択します。
1. リストから Comos を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/comos/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** に移動し、Comos のステータスが緑表示であることを確認します。

> 新しい接続では、ステータス更新に最大 3 分かかることがあります。
