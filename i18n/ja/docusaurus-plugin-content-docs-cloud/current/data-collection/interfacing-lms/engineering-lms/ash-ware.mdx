# ASH WARE

ASH WARE ライセンスマネージャーを OpenLM で監視する手順を示します。

## 必要条件

1. OpenLM Platform
1. ASH WARE と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| Broker 上の LM タイプ | ASH WARE |
| Commands | 対応 |
| Log 収集 | 非対応 |
| 総ライセンス数 | 取得可 |
| 期限日 | 取得可 |
| 否認（Denied） | 非対応 |
| 借用ライセンス | 非対応 |
| 割り当て情報 | 非対応 |
| レポート解像度 | 秒単位 |

Broker を利用すると、通信のバッファリングやライセンスマネージャーサービスのリモート起動／停止も可能です。

## OpenLM Broker の設定

![http://localhost:5090/ で Broker UI を開く](/img/engineering-lms/ash-ware/image57.png)
*http://localhost:5090/ で Broker UI を開く*

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** を開きます。
1. **LM Type** で *ASH WARE* を選択します。
1. ポート番号（既定: 6333）を入力し **Add** をクリックします。

![実行ファイルパスの設定](/img/engineering-lms/ash-ware/image161.png)
*実行ファイルパスの設定*

1. **Executable Path** に ASH WARE 実行ファイルのパスを設定します。
1. **Save** をクリックします。
1. **Commands** タブの **Execute** で設定を検証します。

![コマンド実行結果の例](/img/engineering-lms/ash-ware/image64.png)
*コマンド実行結果の例*

1. **Vendors** タブで **Add Vendor** をクリックし、ベンダー名に *ASH WARE* を入力して **Continue**。

![Vendor 追加](/img/engineering-lms/ash-ware/image87.png)
*Vendor 追加*

1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

![左メニューで Pending Server を選択](/img/engineering-lms/ash-ware/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューで **Pending Server** を選択します。
1. リストから ASH WARE ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

![設定の検証](/img/engineering-lms/ash-ware/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** で ASH WARE のステータスが緑表示であることを確認します。

> 新しい接続では、ステータス更新に最大 3 分かかることがあります。
