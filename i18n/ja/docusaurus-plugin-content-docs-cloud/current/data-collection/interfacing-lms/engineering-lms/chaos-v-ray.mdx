# Chaos V-Ray

以下の手順で Chaos V-Ray License Manager を OpenLM で監視します。

## 必要条件

1. OpenLM Platform
1. Chaos V-Ray と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 秒 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得不可 |
| 否認（Denials） | 取得不可 |
| 借用ライセンス | 取得不可 |
| 期限日 | 取得不可 |
| 冗長構成 | 非対応 |

Broker は Chaos V-Ray のログファイルを読み取り、OpenLM に送信します。

## Broker UI での設定

![Chaos V-Ray との連携図](/img/engineering-lms/chaos-v-ray/image27.png)
*Chaos V-Ray との連携図*

1. [http://localhost:5090](http://localhost:5090)（使用中の場合は 5091 / 5092 など）で Broker UI を開きます。
1. **License Managers -> Add License Manager** を選択します。

    ![Chaos を選択しポートを入力](/img/engineering-lms/chaos-v-ray/image48.png)
*Chaos を選択しポートを入力*

1. ドロップダウンから *Chaos* を選択し、ポート（例: 35033）を入力して **Add**。

    ![ベンダー追加](/img/engineering-lms/chaos-v-ray/image6.png)
*ベンダー追加*

1. **Vendors -> Add Vendor** でベンダー名に *Chaos V-Ray* を入力して **Continue**。
1. **Log Files -> Add Log File** をクリックし、ログファイルのパスを指定します（手動入力または参照）。
1. ベンダーに *Chaos V-Ray* を選択し **Save**。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. メニューから **License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/chaos-v-ray/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューの **Pending Server** を選択します。
1. リストから Chaos ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/chaos-v-ray/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** に移動し、Chaos が緑表示であることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかります。
