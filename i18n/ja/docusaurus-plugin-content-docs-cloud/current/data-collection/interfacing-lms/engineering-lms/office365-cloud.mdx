# Office365 Cloud

現在、Office365 Cloud を OpenLM と連携させるための詳細手順を整備しています。準備が整うまで、以下の前提条件を確認してください。

1. OpenLM Platform
1. 対象サーバーにインストールされた OpenLM Broker v25.x 以降
1. Office365 テナントの管理者資格情報

最終的な設定ガイドには Broker の詳細手順、検証チェックリスト、スクリーンショットを掲載予定です。
