# AEScripts

OpenLM Broker を介して AEScripts License Manager を監視し、ライセンス統計を収集できます。

## 必要条件

1. OpenLM Platform（Annapurna）
1. AEScripts と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 秒 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認（Denials） | 取得可 |
| 借用ライセンス | 取得不可 |
| 期限日 | 取得不可 |
| 冗長構成 | 非対応 |

Broker を利用すると、通信のバッファリングやライセンスマネージャーサービスのリモート起動／停止も可能になります。

### Broker UI での設定手順

1. http://localhost:5090 で Broker UI を開きます。
1. **License Managers -> Add License Manager** を選択します。
1. ライセンスマネージャーに AEScripts を選び、ポート番号を入力して **Add**。
1. **Commands** で実行ファイルパスや Start/Stop の設定を確認・調整します。
1. **Log Files -> Add Log File** をクリックし、以下を入力します。
    - Type: *AEScripts Log*
    - Log name: 任意の説明名
    - Log Path: AEScripts のログフォルダー
    - Vendor: *AEScripts*
    - Encoding: *UTF-16*
1. **Continue -> Save** の順で保存します。

## OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/aescripts/image10.png)
*左メニューで Pending Server を選択*

1. 左メニューの **Pending Server** を選択します。
1. リストから AEScripts ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/aescripts/image3.png)
*設定の検証*

1. **Menu -> License Servers Live -> Server Statistics** へ進み、AEScripts のステータスが緑で表示されることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかることがあります。
