プロセスセッションを使用して、プロセスマネージャーサービスを使用して監視するプロセスの過去のセッションデータを表示します。スタンドアロンライセンスとネットワークフローティングライセンスのセッションデータを表示できます。

:::info[アプリでの場所]
OpenLM Platform の**アプリランチャー**（右上のグリッドアイコン）を開き、**Agents（エージェント）→ Process Sessions** を選択します。

**事前準備:** 監視するプロセスを [プロセスマネージャー(Process Manager)](/cloud/automations/process-manager) に登録し、各対象マシンにワークステーションエージェントをインストールします。

**関連:** [使用状況(Usage)](/cloud/reporting/ui-reports/usage)
:::

:::note
プロセスセッションデータは使用状況(Usage)には表示されません。Brokerストリーミングデータは、[使用状況サービス(Usage Service)](./usage.mdx)の現在消費されているライセンス（CCL）とライセンスアクティビティレポートでのみ利用できます。
:::

## 前提条件

- **エージェントアクティビティマネージャー(Agent Activity Manager)**: 各対象マシンにワークステーションエージェントをインストールします。
- **プロセスマネージャー(Process Manager)**: 監視する[プロセス](/cloud/automations/process-manager)を登録します。

## 設定

1. **Process Sessions**サービスを開きます。
2. プロセスマネージャーで登録したプロセスのセッション履歴を表示します。
3. キーワードフィルター、列フィルター、および検索を使用してビューを絞り込みます。
4. 必要に応じてデータをCSVにエクスポートします。
5. 日付範囲でフィルタリングして、特定の期間のセッションを表示します。

高度な分析のために、BIツールでこれらのレポートを表示することもできます。
