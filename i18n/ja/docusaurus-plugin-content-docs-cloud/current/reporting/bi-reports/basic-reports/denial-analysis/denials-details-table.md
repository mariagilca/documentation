**拒否詳細テーブル**を使用して、ライセンス拒否イベントの詳細なドリルスルービューを表示します。このレポートは、**拒否レポート(Denials)**と**拒否統合レポート(Denials Integrated)**の両方からアクセスできます。

![拒否（Denials）詳細テーブル](/img/reporting/denials-details-table.png)
*拒否（Denials）詳細テーブル*

## 可能なこと

- 個々の拒否インシデントを詳細に調査します。
- エラーコードとタイムスタンプを理解します。
- 繰り返し発生する問題と影響を受けるユーザーまたは部門を特定します。

## 視覚化

このテーブルには、次のフィールドを持つ拒否イベントの詳細な記録が含まれています。

## 表示される値

- **ユーザー名**
- **ユーザーグループ**
- **名**
- **姓**
- **ワークステーション**
- **拒否時間**
- **サーバー**
- **ポート**
- **ホスト名**
- **フィーチャー**
- **バージョン**
- **ライセンスタイプ**
- **追加キー**
- **ライセンス数**
- **メジャーエラーコード**
- **マイナーエラーコード**
- **エラーメッセージ**

これらのフィールドは、使用指向とシステムまたはライセンスの問題を関連付けるのに役立ち、より良い監査とライセンス計画を可能にします。

## フィルター

拒否統合レポートで使用される同じフィルターセットを適用します。

- **日付期間**: 2015年1月1日～2030年12月31日
- **フィーチャー名**
- **ライセンスタイプ**
- **エラーメッセージ**
- **ユーザー名**
- **サーバー名**
- **ベンダー**
- **バージョン**
- **ワークステーション**
- **拒否カテゴリ**
- **拒否ステータス**
- **グループ名**
- **追加キー**
