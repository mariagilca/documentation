# アクティブユーザー

このレポートを使用して、組織全体のアクティブなライセンス使用状況を表示します。時間の経過に伴うアクティブユーザー数を示し、アクティビティの監視、使用傾向の特定、および部門やライセンスサーバー全体でのユーザー行動の分析のためのセッションレベルの詳細を提供します。

セッションに記録された終了時間がない場合、ユーザーはアクティブと見なされます。

## 視覚化

**時間別のアクティブユーザー数**
この棒グラフは、特定の時間間隔でアクティブだったユーザー数を示します。
- X軸は、選択した時間単位（年、四半期、月、または日）を示します。
- Y軸は、一意のアクティブユーザー数を示します。

時間ポイントを選択して、その期間のセッションレベルのデータにドリルダウンします。

**表示される値:**
- **時間**
- **アクティブユーザー数**: 進行中のセッションを持つユーザーの数。セッションに終了時間がない場合、セッションはアクティブと見なされます。この値は、個別のユーザーIDをカウントすることによって計算されます。

**アクティブユーザー詳細テーブル**
このインタラクティブなテーブルには、各アクティブユーザーの詳細なアクティビティが一覧表示されます。

**表示される値:**
- **ユーザーID**: ユーザーの一意の識別子
- **名と姓**: ユーザーの氏名
- **メールと電話**: 利用可能な場合の連絡先の詳細
- **部門**: ユーザーが所属する部門
- **ライセンスサーバー**: ライセンスを管理するサーバー
- **グループ名**: ユーザーに割り当てられたグループ
- **機能名**: 使用されているライセンス機能またはソフトウェア
- **ホスト名**: ライセンスにアクセスしているマシンまたはホスト
