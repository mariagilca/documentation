# ホストの可用性

このレポートを使用して、ライセンスサーバーの可用性を監視します。各サーバーのホスト名、使用するポート、および現在のステータスが表示されるため、どのサーバーが到達可能かをすばやく確認できます。

緑色のステータスは、ホストが利用可能であることを意味します。赤色は、ホストが到達不能であることを意味します。

## 視覚化

**ホストの可用性の詳細**
このテーブルは、ライセンスサーバーのリアルタイムの接続情報を提供します。ホスト名、通信ポート、およびステータスが含まれており、どのサーバーがオンラインでアクセス可能かを特定するのに役立ちます。

## 表示される値

- **ホスト名**: ライセンスサーバーのネットワーク名またはIPアドレス。
- **ポート**: サーバーがライセンス要求をリッスンするポート。
- **ステータス**: ホストが現在到達可能かどうかを示します。
