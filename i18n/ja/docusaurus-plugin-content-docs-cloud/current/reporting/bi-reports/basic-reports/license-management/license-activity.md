# ライセンスアクティビティ(License Activity)

**ライセンスアクティビティLicense Activity**レポートを使用して、ユーザーの行動と全体的なライセンス使用率を分析します。このレポートは、各ユーザーセッションのライセンスのチェックアウトおよびチェックインイベントの時系列ビューを示します。

![ライセンスアクティビティ](/img/reporting/license-activity.png)

## 可能なこと

- 個人およびグループ化されたライセンスの使用状況を監視します。
- 総使用時間、アイドル時間、およびアクティブな使用時間を追跡します。
- 効率分析のためにセッションレベルのデータにドリルダウンします。

## 視覚化

### ライセンスアクティビティのグループ化ビュー

このチャートは、以下でグループ化されたライセンス使用状況を表示します。

- ユーザー
- フィーチャー
- サーバー
- ベンダー
- グループ
- プロジェクト
- ワークステーション

**表示される値:**

- **フィルター期間なしの総使用時間（時間）**
- **総使用時間（時間）**
- **アイドル期間（時間）**
- **実際の使用時間（時間）**


## フィルター

グループ化されたチャートは、以下を使用してフィルターできます。

- **日付期間**: 
- **サーバー名**
- **ライセンスタイプ**
- **フィーチャー名**
- **製品名**
- **ベンダー**
- **ユーザー名**
- **プロジェクト名**
- **グループ名**
- **ワークステーション**
- **ユーザーの国**
- **追加キー**
- **セッション長のカテゴリ**

### セッション長のカテゴリ

```text
期間 < 5分 → "0–5"
期間 ≥ 5分かつ < 10分 → "5–10"
期間 ≥ 10分かつ < 15分 → "10–15"
期間 ≥ 15分 → "15分以上"
```

## ライセンスアクティビティテーブル

**ライセンスアクティビティテーブル**は、個々のユーザーセッションの詳細なビューを提供します。このテーブルを使用して、セッションレベルの行動とライセンスデータを分析します。

### 可能なこと

- 個々のセッションの開始時刻と終了時刻を表示します。
- セッションごとのアイドル時間と使用時間を表示します。
- ベンダー、サーバー、ライセンスタイプなどのライセンス固有のメタデータを取得します。

### 視覚化

グループ化されたチャートからのドリルスルーを介して**ライセンスアクティビティテーブル**にアクセスできます。テーブルには次のものが表示されます。

- ユーザー名、名、姓、メール
- セッションの開始時刻と終了時刻
- アイドル時間と総使用時間
- ワークステーションとIPアドレス
- ライセンスメタデータ（ベンダー、サーバー、ライセンスタイプ、フィーチャー、バージョン）
- プロジェクト、グループ、および部門の詳細
- 借用ライセンスのステータス
- 追加キーと製品

**表示される値:**

- **総使用時間（時間）**
- **アイドル期間（時間）**


## フィルター

ライセンスアクティビティテーブルは、グループ化されたレポートと同じフィルターを使用します。

- **日付期間**:
- **バージョン**
- **サーバー名**
- **ライセンスタイプ**
- **フィーチャー名**
- **製品名**

- **グループ名**

- **ユーザーの国**
- **追加キー**
- **セッション長のカテゴリ**

### セッション長のカテゴリ

```text
期間 < 5分 → "0–5"
期間 ≥ 5分かつ < 10分 → "5–10"
期間 ≥ 10分かつ < 15分 → "10–15"
```
