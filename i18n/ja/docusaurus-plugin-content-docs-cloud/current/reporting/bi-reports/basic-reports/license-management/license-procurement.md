**ライセンス調達license-procurement**レポートを使用して、調達したすべてのライセンスに関する情報を表示します。このレポートは、エンタイトルメントの追跡、ライセンスインベントリの監視、および調達コンプライアンスの維持に役立ちます。

![ライセンス調達](/img/reporting/license-procurement.png)

## 可能なこと

- ライセンス数量と調達状況を確認します。
- 有効期限が近づいているライセンスを特定します。
- 過去および今後の購入詳細を追跡します。

## 視覚化

### ライセンス調達テーブル

このテーブルには、取得したライセンスに関する詳細なデータが表示されます。ライセンスのメタデータ、ライフサイクル日、数、およびステータスインジケーターが含まれており、ライセンスコンプライアンスと更新サイクルを管理するのに役立ちます。

**表示される列:**

- **サーバー**: ライセンスサーバー名。
- **ベンダー**: ライセンスを発行したベンダー。
- **フィーチャー名**: ライセンスされたフィーチャーまたは性能。
- **製品名**: 関連するソフトウェア製品。
- **追加キー**: 分類用の追加メタデータ。
- **発行日**: ライセンスが最初に発行された日時。
- **開始日**: ライセンスがアクティブになった日時。
- **有効期限**: ライセンスの有効期限が切れるように設定されている日時。
- **期限切れ**: ライセンスが現在期限切れかどうかを示します。
- **数量**: 調達したライセンスの数。
- **バージョン**: ライセンスされた機能のバージョン。
- **ライセンスタイプ**: ライセンスのタイプ（例：フローティング、ノードロック）。

### 有効期限のロジック

有効期限のステータスは、次のルールを使用して計算されます。

```text
有効期限が空白または2030年12月31日より後の場合 → 永続
有効期限が将来で、2030年12月31日以前の場合 → 期限切れではない
有効期限が今日より前の場合 → 期限切れ
```
