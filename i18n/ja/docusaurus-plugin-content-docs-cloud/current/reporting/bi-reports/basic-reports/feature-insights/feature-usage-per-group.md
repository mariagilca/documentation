**グループごとの機能使用状況**レポートを使用して、各ユーザーグループがソフトウェア機能をどのように使用しているかを表示します。このレポートは、対象を絞ったグループレベルの分析をサポートし、どのチームがどの機能をどのサーバーでどの程度使用しているかを理解するのに役立ちます。

![グループごとの機能使用状況](/img/reporting/feature-usage-per-group.png)

## 可能なこと

- ユーザーグループ全体で機能レベルのライセンス使用状況を分析します。
- 部門またはチームレベルでの使用傾向を特定します。
- 戦略的なライセンス計画と再割り当てをサポートします。

## 視覚化

このレポートには、選択した期間のグループ全体の機能使用状況を表示するためのチャート形式とテーブル形式の両方が含まれています。

### 表示される値

- **グループ名**
- **機能**
- **サーバー**
- **ベンダー**
- **使用時間（時間）**
