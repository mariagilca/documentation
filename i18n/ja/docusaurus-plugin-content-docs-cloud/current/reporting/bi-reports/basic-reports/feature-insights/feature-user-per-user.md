**ユーザーごとのフィーチャー使用状況feature-usage-per-user**レポートを使用して、個々のユーザーによるライセンス消費を分析します。このレポートは、ユーザーレベルでの使用傾向を特定するのに役立ち、主要なユーザーを見つけ、ライセンス割り当てを最適化し、フィーチャーの採用を評価するのを容易にします。

![ユーザーごとのフィーチャー使用状況](/img/reporting/feature-usage-per-user.png)
*ユーザーごとのフィーチャー使用状況*

## 可能なこと

- 個々のユーザーがライセンスフィーチャーをどのように使用しているかを理解します。
- 使用パターンが高いまたは低いユーザーを特定します。
- 実際の使用行動に基づいてライセンス計画をサポートします。

## 視覚化

このレポートには、選択した期間のユーザーごとのフィーチャレベルの使用状況を表示するチャート形式とテーブル形式の両方が含まれています。

### 表示される値

- **ユーザー**
- **フィーチャー**
- **サーバー**
- **ベンダー**
- **使用時間（時間）**
