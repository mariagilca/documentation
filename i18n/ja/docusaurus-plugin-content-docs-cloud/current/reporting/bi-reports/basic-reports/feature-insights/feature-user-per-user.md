**ユーザーごとの機能使用状況**レポートを使用して、個々のユーザーによるライセンス消費を分析します。このレポートは、ユーザーレベルでの使用傾向を特定するのに役立ち、主要なユーザーを見つけ、ライセンス割り当てを最適化し、機能の採用を評価するのを容易にします。

![ユーザーごとの機能使用状況](/img/reporting/feature-usage-per-user.png)

## 可能なこと

- 個々のユーザーがライセンス機能をどのように使用しているかを理解します。
- 使用パターンが高いまたは低いユーザーを特定します。
- 実際の使用行動に基づいてライセンス計画をサポートします。

## 視覚化

このレポートには、選択した期間のユーザーごとの機能レベルの使用状況を表示するチャート形式とテーブル形式の両方が含まれています。

### 表示される値

- **ユーザー**
- **機能**
- **サーバー**
- **ベンダー**
- **使用時間（時間）**
