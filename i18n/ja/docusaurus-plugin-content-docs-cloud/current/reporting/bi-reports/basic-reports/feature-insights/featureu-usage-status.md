**フィーチャー使用状況(feature-usage-status)**レポートを使用して、各ライセンスフィーチャーの現在および過去の使用統計を表示します。このレポートは、使用傾向の追跡、借用ライセンスアクティビティの監視、およびよりスマートなライセンス決定のサポートに役立ちます。

![フィーチャー使用状況](/img/reporting/feature-usage-status.png)

## 可能なこと

- ライセンスフィーチャーがリアルタイムでどのように使用されているかを監視します。
- 製品、フィーチャー、またはサーバーごとに過去の使用パターンを分析します。
- 再割り当てまたは更新計画のために、十分に活用されていない、または借用されたライセンスを特定します。

## 視覚化

このレポートは、フィーチャーレベルでのライブおよび過去のライセンス使用状況データを含む詳細な概要テーブルを示します。

### フィーチャー使用状況の概要

このテーブルには次のものが含まれます。

- **使用率**: 現在使用中のライセンスの割合。
- **総数量**: 利用可能なライセンスの数。
- **使用済みライセンス**: アクティブなライセンス数。
- **借用ライセンス**: ライセンスが借用されているかどうかを示すインジケーター。
- **フィーチャー名**
- **ベンダー**
- **サーバー名とポート**
- **ライセンスタイプ**
- **バージョン**
- **製品名**
