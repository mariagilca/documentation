User consumption analysis レポートは、AI とのやり取りをきめ細かくユーザー中心の視点で示します。日次の導入傾向、トークン消費量の総計、集中的な利用バーストを浮き彫りにします。このレポートを使用して、ヘビーユーザーを特定し、日次の支出を追跡し、実際の需要に基づいてユーザーがプレミアムライセンスを必要とするかどうかを検証できます。

## 可視化

- **ユーザー別トークン総数ツリーマップ:** 各ユーザーをトークン消費量の総計に応じた面積で表示する比例面積チャートで、消費量が最も多いユーザーの序列を一目で把握できます。

**表示される値:**

- グループ化: ユーザー名
- サイズ: 消費トークンの総計（総トークン数の合計）
- 色: レコード数

- **日次トークンとコストのコンボチャート:** 日次のトークン量と日次のコストを重ねて表示する二軸の時系列で、日ごとの傾向を追跡し、スパイクを発見できます。

**表示される値:**

- X 軸: 日付（日）
- 棒（左 Y 軸）: 消費トークンの総計（総トークン数の合計）
- 線（右 Y 軸）: コスト消費の総計（生コストの合計）

- **ユーザー別ピーク 5 時間トークン棒グラフ:** 各ユーザーについて、移動する 5 時間ウィンドウ内での最大トークン消費量を示します。これにより、ユーザーが上位ティアのライセンスを必要とするか、それとも利用が十分に分散していて標準ティアで足りるかを判断できます。

**表示される値:**

- Y 軸: ユーザー名
- X 軸: ピーク 5 時間トークン（ピーク 5 時間トークンの最大値）

- **ユーザー利用状況詳細テーブル:** ユーザー単位のメトリクス、アクティブな日付、トークンの内訳、関連するコストを一覧化した表形式の台帳です。

**表示される値:**

- ユーザー名
- メール
- 割り当てられたライセンスの種類（フィーチャー名から導出）
- モデル名
- 最終アクティブ日
- 利用あり（Yes または No）
- 入力トークンの総計
- 出力トークンの総計
- トークン消費の総計
- コスト消費の総計
