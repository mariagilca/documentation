# FAQ とトラブルシューティング

## よくある質問

### MCP レポートサーバーとは何ですか？

OpenLM MCP レポートサーバーは、Claude、ChatGPT、Cursor などの AI アシスタントと OpenLM のライセンス管理データを接続するサービスです。Model Context Protocol (MCP) 標準を使用しているため、レポートデータを自然言語でクエリできます。

### AI クライアントの有料サブスクリプションは必要ですか？

必要です。MCP サーバーへの接続には、AI プラットフォームの有料サブスクリプション (例：Claude Pro、ChatGPT Plus、または同等の有料プラン) が最低限必要です。無料プランではカスタム MCP コネクターやサーバーを追加できません。

### どの AI クライアントに対応していますか？

MCP サーバーは、Claude Desktop、Claude.ai、Claude Code、Cursor、Windsurf、ChatGPT、Gemini CLI、および LibreChat に対応しています。MCP 標準に対応する今後の AI プラットフォームも、同じサーバー URL で統合できる可能性があります。

### MCP サーバーはオンプレミスデプロイでも利用できますか？

OpenLM はオンプレミス版の MCP サーバーを提供していますが、本番運用前に追加の構成が必要です。オンプレミスのお客様は、ブラウザベースの AI クライアントではなく、デスクトップ AI アプリケーション (例：Claude Desktop、Cursor) を使用する必要があります。ブラウザベースの AI クライアントは、プライベートネットワーク内では利用できない可能性のある、公開アクセス可能な URL を必要とするためです。

### どのようなデータをクエリできますか？

テナントの OpenLM レポートデータベースで利用可能なあらゆるデータをクエリできます。これには、ライセンス使用状況、機能の利用率、ユーザーおよびグループ分析、履歴トレンド、最適化の推奨事項が含まれます。プロンプト例については、[ツールおよび機能リファレンス](./tools-reference) を参照してください。

### グラフやダッシュボードを生成できますか？

生成できますが、ビジュアル出力のレベルは AI のサブスクリプションプランによって異なります。Claude Pro や ChatGPT Plus などの上位プランでは、インタラクティブな HTML ダッシュボード、グラフ、チャートを生成できます。基本の有料プランでは通常、テキストベースの応答とテーブルが返されます。

### データの精度はどの程度ですか？

MCP サーバーは、OpenLM データベースから実際のレポートデータを返します。ただし、AI アシスタントによるデータの解釈と提示には誤りが含まれることがあります。AI モデルのデータ解釈には最大 3% の誤差が含まれる可能性があります。特にライセンス最適化の推奨事項については、OpenLM Platform の BI レポートとダッシュボードで AI が生成したインサイトを検証してください。

### サーバーの認証方法は何ですか？

MCP サーバーは OAuth 認証を使用します。初回接続時に OpenLM のログインページにリダイレクトされます。認証情報でサインインすると、セキュアなセッションが確立され、すべてのクエリは組織のデータ範囲に限定されます。

### US と EU のどちらの URL を使用すればよいですか？

OpenLM テナントがホストされているリージョンに対応する URL を使用してください。不明な場合は、OpenLM の管理者に確認してください。

- **Prod US:** `https://cloud-us.openlm.com/mcp`
- **Prod EU:** `https://cloud-eu.openlm.com/mcp`

### 組織内の複数人が同時に接続できますか？

できます。各ユーザーは独自の OpenLM 認証情報で独立して認証されます。すべてのクエリは組織のテナントデータ範囲に限定されるため、複数のチームメンバーが MCP サーバーを同時に使用しても競合は発生しません。

## トラブルシューティング

### AI クライアントで MCP コネクターを追加できない

- AI プラットフォームの有料サブスクリプションを所有していることを確認してください。無料プランではカスタム MCP コネクターに対応していません。
- ChatGPT では、アプリを作成する前に、設定で Developer Mode が有効になっていることを確認してください。
- Claude.ai では、組織が制限している場合、**Add custom connector** オプションが無効になっていることがあります。管理者に連絡してください。

### 認証に失敗する、またはログインページが表示されない

- ブラウザがポップアップやリダイレクトをブロックしていないことを確認してください。OAuth フローは、新しいブラウザウィンドウまたはタブで OpenLM のログインページを開きます。
- ブラウザの Cookie とキャッシュをクリアして、認証プロセスをやり直してください。
- お使いの環境 (Prod US または Prod EU) に対応する正しい MCP サーバー URL を使用していることを確認してください。
- 企業のファイアウォールや VPN を経由している場合、MCP サーバー URL へのアクセスがブロックされていないことを確認してください。

### MCP サーバーが接続されているがデータが返されない

- OpenLM アカウントがレポートデータへのアクセスに適切な権限を持っていることを確認してください。
- クエリしている期間のデータがテナントに存在することを確認してください。
- 「すべてのアクティブなライセンスを表示して」のようなクエリを試し、基本的な接続性を確認してください。
- 開発用や QA 用の URL を使用している場合、その環境にテストデータが読み込まれていることを確認してください。

### 接続がタイムアウトする

- Gemini CLI の場合、`settings.json` 構成でタイムアウト値を増やしてください。デフォルトのタイムアウト 30000 ミリ秒 (30 秒) では、複雑なクエリには不十分な場合があります。
- 他のクライアントの場合、インターネット接続が安定しており、MCP サーバー URL にアクセスできることを確認してください。
- 大規模なクエリやレポートは処理に時間がかかることがあります。日付範囲を絞り込むか、クエリを簡略化してみてください。

### AI クライアントが誤った結果や予想外の結果を表示する

- AI モデルはデータを解釈するため、まれに内容を誤って表示することがあります。結果は OpenLM ダッシュボードと照合してください。
- より具体的な詳細 (正確な日付範囲、製品名、部門など) を含めて、クエリを言い換えてみてください。
- 新しい会話を開始し、同じクエリを再度試してください。会話の初期のコンテキストが結果に影響を与えることがあります。

### グラフやダッシュボードが生成されない

- グラフや HTML ダッシュボードを含むビジュアル出力には、Claude Pro や ChatGPT Plus などの上位 AI サブスクリプションが必要です。
- プロンプトでビジュアル出力をリクエストしてください。例：「部門別のライセンス使用量を棒グラフで表示して。」
- 下位プランの場合、AI はビジュアルコンテンツではなくテキストベースのサマリーとテーブルを返します。

### npx コマンドが失敗する、または mcp-remote が見つからない

- Node.js と npm がシステムにインストールされていることを確認してください。npx コマンドは npm 5.2 以降に含まれています。
- npx が mcp-remote パッケージをダウンロードできるよう、インターネットアクセスがあることを確認してください。
- `npm cache clean --force` を実行してから、npx コマンドを再試行してみてください。

## サポートを受ける

上記の手順で問題を解決できない場合は、OpenLM Data Engineering チームにお問い合わせください。次の情報を含めてください。

- 使用している AI クライアントとバージョン
- 接続先の MCP サーバー URL
- 正確なエラーメッセージまたは予期しない動作
- 可能であればスクリーンショット
