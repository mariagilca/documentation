:::info クラウドプラットフォーム専用
OpenLM MCP コネクターは、**OpenLM クラウドプラットフォーム (US および EU テナント) でのみ** 利用可能です。オンプレミスデプロイには対応していません。
:::

OpenLM MCP コネクターは、ソフトウェアライセンス管理データをお好みの AI アシスタントに直接取り込みます。オープン標準である Model Context Protocol (MCP) を基盤としており、テナント固有のレポートデータを自然言語でクエリできます。

レポートを手動で実行したり、ビジネスインテリジェンス (BI) ツールでフィルターを作成したりする代わりに、AI アシスタントに平易な言葉で質問します。OpenLM MCP コネクターは、質問を GraphQL 経由で OpenLM データベースへの構造化クエリに変換し、データを取得して、結果を会話に返します。

## 仕組み

OpenLM MCP コネクターは、AI アシスタントと OpenLM レポートデータベースの橋渡しを担います。以下のステップで処理が進みます。

1. **質問します。** AI アシスタントに「今月最も多く使用されたライセンス機能のトップ 10 を表示して」のような自然言語のクエリを入力します。
2. **AI が OpenLM MCP コネクターにリクエストを送信します。** AI クライアントは、MCP 標準プロトコルを使用してクエリを OpenLM MCP コネクターに転送します。
3. **OpenLM MCP コネクターがデータをクエリします。** コネクターはリクエストを、テナント固有の OpenLM レポートデータベースに対する GraphQL API 呼び出しに変換します。
4. **結果が返されます。** データは OpenLM MCP コネクターを経由して AI アシスタントに戻り、テキスト、テーブル、グラフ、またはダッシュボードとしてフォーマットされます。

## 主な機能

OpenLM MCP コネクターを接続すると、以下のことができます。

- **ライセンス使用状況データをクエリする。** ライセンス消費量、機能の利用率、ピーク使用時間、組織全体の傾向について質問できます。
- **レポートとサマリーを生成する。** OpenLM ダッシュボードを操作することなく、経営層向けサマリー、詳細な内訳、カスタムレポートをオンデマンドで取得できます。
- **ライセンス最適化の提案を受ける。** 未使用のライセンス、使用率の低いシート、コスト削減の機会について、AI による推奨事項を受け取れます。
- **ビジュアルダッシュボードを作成する。** 上位プランの AI サブスクリプションを使用すると、インタラクティブな HTML ダッシュボード、グラフ、チャートを会話内で直接生成できます。
- **フォローアップの質問をする。** 会話形式でクエリを絞り込めます。最初に広範な質問から始めて、やり直すことなく特定の内容まで掘り下げることができます。

## 対応 AI クライアント

OpenLM MCP コネクターは、幅広い AI プラットフォームに対応しています。以下のいずれのクライアントからも接続できます。

| クライアント | 種類 | 備考 |
|---|---|---|
| Claude Desktop | デスクトップアプリ | Claude Pro 以上のサブスクリプションが必要 |
| Claude Code | CLI | npx コマンドを使用したターミナルアクセス |
| Cursor | デスクトップアプリ | MCP をネイティブサポートする IDE |
| Windsurf | デスクトップアプリ | MCP Marketplace を備えた IDE |
| ChatGPT | Web アプリ | ChatGPT Plus サブスクリプションが必要。Developer Mode も必要 |
| Gemini CLI | CLI | ターミナルアクセス。OAuth 認証 |
| LibreChat | Web アプリ | オープンソース、セルフホスト、Streamable HTTP トランスポート |

:::warning
OpenLM MCP コネクターを AI プラットフォームに接続するには、Claude Pro、ChatGPT Plus、またはそれに相当する有料サブスクリプションが必要です。無料プランではカスタム MCP コネクターを追加できません。
:::

## デプロイ環境

OpenLM MCP コネクターは以下の環境で利用可能です。お使いのリージョンに対応する URL を使用してください。

| 環境 | OpenLM MCP コネクター URL |
|---|---|
| Prod US | `https://cloud-us.openlm.com/mcp` |
| Prod EU | `https://cloud-eu.openlm.com/mcp` |


## 認証

OpenLM MCP コネクターは OAuth 認証を使用します。AI クライアントを初めて接続するとき、ブラウザで OpenLM のログインページにリダイレクトされます。OpenLM の認証情報でサインインすると、OpenLM MCP コネクターはセキュアでテナント固有のセッションを確立します。以降のクエリはすべて、組織のデータ範囲に限定されます。

## 出力内容は AI のサブスクリプションプランに依存します

受け取る出力の種類は、使用する AI クライアントのサブスクリプションプランによって異なります。

| サブスクリプションプラン | 機能 |
|---|---|
| 基本の有料プラン | テキストベースの応答、テーブル、データサマリー |
| Pro や Plus などの上位プラン | インタラクティブな HTML ダッシュボード、グラフ、チャート、経営層向けレポート |

## データの精度と検証

AI モデルは、まれに不正確な結果を生成することがあります。OpenLM MCP コネクターは実際のレポートデータを提供しますが、AI アシスタントによるデータの解釈や提示には誤りが含まれる可能性があります。

:::warning
ビジネス上の意思決定を行う前に、特にライセンス最適化の推奨事項については、OpenLM Platform の BI レポートとダッシュボードで AI が生成したインサイトを検証してください。
:::
