# はじめに

このガイドでは、OpenLM Platform（Annapurna バージョン）の登録、オンボーディング、コンポーネントのセットアップ、利用者の責任、事前準備について説明します。

## 前提条件

OpenLM Platform をクラウドでセットアップする前に、次のものを準備してください。

### OpenLM Platform クラウドアカウント
- 有効かつ登録済みの OpenLM Platform アカウントが必要です。

### オンプレミスコンポーネント用インフラ
- 以下をインストールするための物理または仮想サーバーおよびユーザーのワークステーション
  - OpenLM Broker
  - Workstation Agent
  - Directory Synchronization Agent (DSA)
- サポートされている OS:
  - Broker、Workstation Agent、DSA: Windows 10 以上、Windows Server 2016 以上、Ubuntu、または RHEL

### インターネットおよびネットワークアクセス
- オンプレミスコンポーネントを OpenLM Platform に接続するための安定したインターネットアクセス
  - 厳しいファイアウォールやプロキシの制約は避けること
- 次のネットワークアクセスが必要です:
  - OpenLM Broker → ライセンスマネージャーサーバー
  - DSA → ローカル LDAP ディレクトリまたはクラウドディレクトリ（例: Azure AD）

### ソフトウェアライセンスマネージャーの知識
- 使用しているライセンスマネージャーの種類を把握していること（例: FlexNet、IBM LUM、Sentinel RMS）
- それらの設定方法を理解していること

### ネットワークとセキュリティの準備
- 基本的なネットワーク構成、ファイアウォールルール、安全な通信方法に精通していること

## OpenLM の登録

OpenLM に登録するには、次の手順に従ってください。

### 登録ページにアクセス

1. [OpenLM のウェブサイト](https://www.openlm.com/free-trial/) にアクセスします。
2. **OpenLM Platform Annapurna version** セクションで **Register now** をクリックします。

### 登録方法を選択

次の 2 つの方法で登録できます:  
![Identity registration screen](/img/getting_started/identity-registration.png)

- **ソーシャルログイン**（Google、Microsoft、GitHub）:
  - プロバイダーを選択します。
  - プロバイダーのログインページで認証します。
  - 認証後、OpenLM ホームページとオンボーディングガイドにリダイレクトされます。

- **直接登録**:
  - ユーザー名を入力し、パスワードを作成します。
  - **Register** をクリックします。
  - 登録後、**Login** をクリックしてシステムにアクセスします。
  - OpenLM ホームページとオンボーディングガイドにリダイレクトされます。

## OpenLM コンポーネントのセットアップ

OpenLM は 4 つのコンポーネントを使用して、さまざまな環境からデータを収集します。

- **Broker**
- **Workstation Agent**
- **Directory Synchronization Agent (DSA)**

各コンポーネントは、必要なデータに応じて異なるマシンで動作します。  
たとえば、Broker はライセンスマネージャーからデータを収集するためにライセンスサーバー上で動作します。  
Workstation Agent はエンドユーザーのマシン上で動作し、監視と自動化をサポートします。

インストール前に、必ずコンポーネントを認証してください。  
**Identity Service** を使用して、デプロイ予定の各コンポーネント用の認証ファイルを生成します。  
このファイルは JSON オブジェクトで、コンポーネントが信頼され、OpenLM システムに接続できることを確認します。

詳しい手順は [Authorization in Identity Service](https://www.openlm.com/documentation/cloud/services/identity#authorization) を参照してください。

これらのファイルはインストール時に必要となるため、事前に生成しておきましょう。

### Workstation Agent のインストール

<Checklist>
  <ChecklistItem title="インストーラーをダウンロード">
    [ダウンロードページ](https://openlm.com/documentation/downloads) からプラットフォーム用インストーラーを入手します。

  </ChecklistItem>

### Directory Synchronization Agent (DSA) のインストール

<Checklist>
  <ChecklistItem title="インストーラーをダウンロード">

  </ChecklistItem>
  <ChecklistItem title="サービスを開始">
    DSA サービスを開始します。  
    これにより Directory Synchronization Service (DSS) と同期し、ユーザーデータの収集を開始します。

</Checklist>
