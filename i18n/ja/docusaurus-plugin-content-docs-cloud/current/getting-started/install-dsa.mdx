DSA は、ディレクトリソースにアクセスできるマシン上で稼働します。Directory Synchronization Service を介して、ローカルディレクトリ (LDAP) またはクラウドディレクトリ (Azure AD、Google) から OpenLM Platform にユーザーとグループのデータを同期します。

## 開始する前に

- 対象のマシンが[システム要件](/cloud/deployment-operations/system-requirements)を満たしていることを確認します。
- DSA 用の[認証ファイル](./authorize-components)があることを確認します。
- LDAP ディレクトリの場合: マシンがディレクトリサーバーへの内部ネットワークアクセスを持っていることを確認します。
- クラウドディレクトリ (Azure AD、Google) の場合: マシンがインターネットにアクセスできることを確認します。

## インストール手順

<Checklist>
  <ChecklistItem title="インストーラーをダウンロードする">
    [ダウンロードページ](https://www.openlm.com/downloads/)から DSA インストーラーをダウンロードします。
  </ChecklistItem>
  <ChecklistItem title="インストーラーを実行する">
    ディレクトリソースにアクセスできるマシンに DSA をインストールします。
  </ChecklistItem>
  <ChecklistItem title="認証ファイルをアップロードする">
    [コンポーネントの認証](./authorize-components) のステップで生成した認証ファイルをアップロードします。
  </ChecklistItem>
  <ChecklistItem title="ディレクトリ接続を設定する">
    DSA アプリケーションを起動します。Directory Synchronization Service (DSS) の URL を入力し、DSS から同期定義を追加します。
  </ChecklistItem>
  <ChecklistItem title="サービスを開始する">
    DSA サービスを開始します。Directory Synchronization Service に接続し、ユーザーとグループのデータの同期を開始します。
  </ChecklistItem>
</Checklist>

詳細な手順、インタラクティブなウォークスルー、トラブルシューティングについては、[OpenLM コンポーネントのインストールと設定](/cloud/deployment-operations/components-installation) を参照してください。
