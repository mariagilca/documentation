OpenLM Reporting API は、組織のライセンス分析データへリアルタイムかつ構造化された形でアクセスできる、GraphQL ベースのデータアクセスレイヤーです。すべてのデータモジュールでフィルタリング、ソート、ページネーション、集計をサポートする、単一の柔軟な GraphQL エンドポイントを使用できます。

## 利用可能なデータモジュール

API は複数のデータモジュールへのアクセスを提供しており、それぞれがライセンス管理の特定領域をカバーします。データモジュールとは、独立してクエリ・フィルター・分析できる、ライセンス関連情報のカテゴリーです。OpenLM では、レポーティング要件に応じてモジュールを追加できます。

| # | モジュール | カバー範囲 |
|---|--------|---------------|
| 1 | License Usage | 誰が、どのライセンスを、いつ、どのくらいの時間使用したかを追跡。ユーザー、機能、期間、継続時間でフィルター可能。 |
| 2 | Denials | ライセンスリクエストの拒否を記録。ユーザー、機能、期間、拒否タイプでフィルター可能。 |
| 3 | Server Status | ライセンスサーバーの現在および過去のステータスを表示。サーバー名やステータスでフィルター可能。 |
| 4 | Concurrent Measures | ライセンスの同時使用データを取得：特定の時点で利用可能な数のうち、どれだけが使用中だったかを記録。機能、使用中／空きライセンス範囲でフィルター可能。 |
| 5 | Allocations | ライセンス割り当てトランザクションを追跡。アクティブ／非アクティブのステータスや期間でフィルター可能。サマリー：アクティブと非アクティブの割り当て件数。 |
| 6 | Procurement | 有効期限の追跡を含むライセンス調達レコードを管理。期限切れ／有効ステータスや有効期限ウィンドウでフィルター可能。サマリー：期限切れ、30 日以内に期限切れ、有効の件数。 |
| 7 | Touchpoints | ユーザーインタラクションのタッチポイントを記録。イベントタイプ、ソース、Web サイトでフィルター可能。サマリー：固有ユーザー数、ワークステーション数、ソース数。 |
| 8 | Processes | ライセンスを使用するアプリケーションプロセスを記録。シャットダウン理由やエージェントステータスでフィルター可能。サマリー：シャットダウン理由とエージェントステータスの内訳。 |
| 9 | Dongle Monitoring | ハードウェアドングルを監視。接続ステータスや拒否リストフラグでフィルター可能。サマリー：接続中、切断中、拒否リスト件数。 |
| 10 | Not Used Licenses | 利用可能だが現在使用されていないライセンスを特定。機能、サーバー、利用可能ライセンス数でフィルター可能。 |

## クエリ機能

各データモジュールはさまざまな種類のクエリをサポートしており、ライセンスデータへの包括的なアクセスを提供します。

### 一覧表示とフィルタリング

オプションのフィルタリング・ソートを使って、ページネーションされたレコードリストを取得できます。

- **フィルタリング**：各モジュールは、日付範囲、テキストマッチング、数値範囲、Boolean フラグを含む 10 〜 50 以上のフィルターフィールドをサポートします。
- **ソート**：利用可能な任意のフィールドで、昇順または降順にソート可能。
- **ページネーション**：すべてのリストクエリは、合計件数、合計ページ数、現在のページ、ナビゲーションフラグなどのメタデータを含むページネーションされた結果を返します。

### レコード参照

一意の識別子を使って、単一レコードを詳細に取得できます。

### 集計と分析

`GROUP BY` 集計を使い、複数の次元にわたるデータ分析が可能です。サポートされる集計タイプ：

| 集計 | 説明 |
|-------------|-------------|
| `COUNT` | 各グループのレコード数をカウント |
| `SUM` | 数値フィールドをグループごとに合計 |
| `AVG` | 数値フィールドのグループごとの平均 |
| `MIN` | 各グループの最小値 |
| `MAX` | 各グループの最大値 |
| `COUNT_DISTINCT` | 各グループの一意な値をカウント |

任意のフィールドでグループ化でき、集計とフィルターを組み合わせて目的に沿った分析が可能です。

### サマリーとグループサマリー

- **サマリー**：各モジュールに固有の事前構築済み統計（例：アクティブな割り当ての合計、期限切れ調達件数、接続中ドングルの数など）。
- **グループサマリー**：同じサマリー統計を、任意のグループ化フィールド（例：機能別、ユーザー別、サーバー別）で分割したもの。

## クエリ例

以下の例は、さまざまなモジュールで実現できるデータ取得の種類を示します。

### ライセンス使用上位ユーザー

AutoCAD の合計使用時間がもっとも長い 50 人のユーザーを取得します。

```graphql
query {
  licenseUsageAggregates(
    groupBy: "user_name"
    aggregateType: SUM
    aggregateField: "duration"
    filter: { featureName: "AutoCAD" }
    pageSize: 50
    orderBy: "value"
    orderDesc: true
  ) {
    items {
      groupValue
      value
    }
    pageInfo {
      totalCount
    }
  }
}
```

### 機能別のライセンス拒否

過去 30 日間に、機能ごとに何件の拒否が発生したかをカウントします。

```graphql
query {
  denialsAggregates(
    groupBy: "feature_name"
    aggregateType: COUNT
    aggregateField: "id"
    filter: {
      timestampFrom: "2026-03-08"
      timestampTo: "2026-04-08"
    }
    orderBy: "value"
    orderDesc: true
  ) {
    items {
      groupValue
      value
    }
  }
}
```

### 調達サマリー

ライセンス調達状況の概要を素早く取得します。

```graphql
query {
  licenseProcurementSummary {
    totalProcurements
    expiredCount
    expiringWithin30Days
    activeCount
  }
}
```

### フィルター済みのライセンス使用リスト

特定のユーザーの MATLAB 使用レコードを、ページネーションされたリストで取得します。

```graphql
query {
  licenseUsage(
    filter: {
      userName: "john.smith"
      featureName: "MATLAB"
    }
    page: 1
    pageSize: 25
    orderBy: "timestamp"
    orderDesc: true
  ) {
    items {
      userName
      featureName
      timestamp
      duration
    }
    pageInfo {
      totalCount
      totalPages
      currentPage
      hasNextPage
    }
  }
}
```
