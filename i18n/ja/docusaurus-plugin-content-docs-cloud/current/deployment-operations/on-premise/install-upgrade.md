# インストールとアップグレード

## 準備

- クラスタのデプロイ先（オンプレミスのハードウェアまたは自社クラウドのK8s）を決め、ハードウェアとK8sの専門知識がそろっていることを確認します。

## インストール手順

- Helmの値（ingress、TLS証明書、ストレージクラス、シークレット）を設定します。
- チャートをデプロイし、主要サービスが正常であることを確認します。
- エージェント（Broker、Workstation Agent、DSA）をオンプレミスのエンドポイントに接続します。

## デプロイオプション

- **小規模・一体型VM**: 低負荷環境では、KubernetesとOpenLMが含まれたオールインワンのVMイメージ/スクリプトを使用します。
- **クラウド管理型K8s（AWS/Azure）**: Helmを実行する前に、プロバイダー固有の要件（ネットワーク、ストレージクラス、IAM/ID管理）を満たしてください。

## アップグレード

- リリースノートに紐づけたチェックリストに沿ってチャートをアップグレードします。
- アップグレード後にサービスとデータフローを検証し、ロールバック計画を維持します。

## TLSとIngress

- 公開エンドポイントには信頼できる証明書を使用し、KubernetesのSecretとして保存します。
- チャートのデプロイ前にIngressコントローラーが構成されていることを確認します。
