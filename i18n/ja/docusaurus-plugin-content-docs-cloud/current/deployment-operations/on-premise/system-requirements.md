# オンプレミスのシステム要件

以下はお客様管理のインフラにOpenLMを導入する際の一般的な要件です。メンテナンス、更新、バックアップはお客様の責任で行います。

## クラスタの最小リソース

- CPU: 16 vCPU（ノード合計）
- RAM: 70 GB（ノード合計）
- ストレージ: データ保持要件に応じたSSDバックエンドのボリューム

## オペレーティングシステム

- Kubernetesがサポートするディストリビューション（例: Ubuntu、RHEL、クラウドプロバイダーのマネージドK8s など）

## Kubernetesとネットワーキング

- IngressコントローラーとTLS終端を備えたKubernetesクラスタ
- ステートフルサービス向けの永続ストレージクラス
- Broker/DSAからライセンスマネージャーやディレクトリへの接続性

## 注意事項

- サイジングは想定されるエージェント/ブローカー数と使用量に対して検証してください。
- プロバイダー固有の要件（AWS、Azure、小規模VMなど）は「インストールとアップグレード」のページに記載されています。
