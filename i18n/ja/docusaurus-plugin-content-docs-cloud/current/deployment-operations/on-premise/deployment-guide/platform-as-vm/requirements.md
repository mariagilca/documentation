# 要件

Platform as VM デプロイでは、OpenLM Platform 全体を単一の仮想マシンまたはベアメタルサーバー上で実行します。Kubernetes（K3s）、データベース、メッセージブローカー、キャッシュ、プラットフォームサービスは、すべてデプロイスクリプトによって自動的にインストールされます。

## システム要件

| リソース | 最小（評価用） | 推奨 |
| --- | --- | --- |
| CPU | 4 コア | 8 コア以上 |
| RAM | 32 GB | 64 GB |
| ストレージ | 100 GB SSD | 500 GB 以上の SSD（IOPS 依存） |
| OS | AlmaLinux 10.1 | AlmaLinux 10.1 / RHEL 10.x |

:::warning
最小構成は、低負荷の評価、デモ、PoC 環境向けです。稼働中の Broker やユーザーが存在する本番用途では、推奨構成を使用してください。
:::

## オペレーティングシステム

正式サポート:

- **AlmaLinux 10.1**（安定版） - 主対象であり、十分に検証済み
- **RHEL 10.x** - エンタープライズ向け代替

その他の RHEL 系ディストリビューションでも動作する可能性はありますが、正式サポート対象ではありません。

## ネットワーク要件

- インストール中、VM からインターネットへの outbound アクセスが必要です。デプロイスクリプトは依存関係、コンテナイメージ、Helm チャートを動的に取得します。
- エージェントとユーザーが接続するマシンから、**443** と **80** 番ポートへアクセスできる必要があります。
- ドメインを VM の IP アドレスへ向ける DNS レコードが必要です。
- ドメイン用の有効な TLS 証明書と秘密鍵が必要です。

## キャパシティ上の考慮事項

このデプロイパスは、小規模な顧客環境向けです。すべてのサービスが単一マシンを共有するため、マルチノードクラスタ構成と比べて、システムが処理できる負荷には実用上の上限があります。

環境が単一 VM の容量を超える場合は、[オンプレミスマシン](../on-premise-machines/requirements)、[AWS](../aws/requirements)、または [Azure](../azure/requirements) などのマルチノード構成への移行を検討してください。
