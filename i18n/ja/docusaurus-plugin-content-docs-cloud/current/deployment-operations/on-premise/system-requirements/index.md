# システム要件

OpenLM をお客様が管理するインフラに導入する場合は、このセクションを参照してください。

## 共通プラットフォームのベースライン

以下の要件は、お客様管理の Kubernetes デプロイメント全体に共通です。

| リソース | ベースライン |
| --- | --- |
| CPU | ワーカーノード合計 16 vCPU |
| メモリ | ワーカーノード合計 70 GB RAM |
| ストレージ | 保持要件に応じたソリッドステートの永続ボリューム |
| Kubernetes | Ingress と TLS を備えたサポート対象の Kubernetes ディストリビューション |
| 接続性 | Broker、Directory Synchronization Agent（DSA）、ライセンスマネージャー、ディレクトリサービスからのネットワーク接続 |

## 共通要件

- ステートフルワークロード向けの永続ストレージクラスを使用します。
- Ingress レイヤーで TLS 終端を使用します。
- 想定される Broker 数、利用量、レポート量、保持期間に対してサイジングを確認します。
- 必要な OpenLM サービスがクラスタのエンドポイントに到達できることを確認します。
