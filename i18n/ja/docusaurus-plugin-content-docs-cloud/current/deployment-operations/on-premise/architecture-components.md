# アーキテクチャとコンポーネント

OpenLM Platformはコンテナ化されたマイクロサービスとして動作し、Kubernetesによってオーケストレーションされることで高可用性とスケーラビリティを実現します。

![アーキテクチャ図](./arch-diagram.jpg)

## 主要レイヤー

- **インフラ**: お客様管理のコンピュート、ネットワーク、永続ストレージ。
- **Kubernetesクラスタ**: すべてのプラットフォームサービスをホストし、スケーリングと自己修復を管理。
- **APIゲートウェイ**: 外部トラフィックの単一入口で、ルーティングと認証を担当。
- **マイクロサービス**: ライセンス使用状況の収集、レポート、管理サービスがPodとして稼働。
- **データ永続化**: 設定データと使用データ向けの内部データベース。

## デプロイパッケージ

- 必要なマニフェスト（Deployment、Service、ConfigMapなど）を含むHelmチャートとして提供。
- お客様が値（ingress、ストレージ、証明書など）を設定し、Helmでデプロイやアップグレードを実施。

## 小規模・一体型の選択肢

小規模またはPoC向けには、KubernetesとOpenLMがあらかじめ含まれたオールインワンのVMイメージを提供できます。
