## OpenLM Brokerのインストールと設定

次の手順に従って、OpenLM Brokerをインストールおよび設定します。

<details>
  <summary>Linuxディストリビューション</summary>

  <details>
    <summary>tar.gz</summary>
    1. tar.gzパッケージをダウンロードします。
    2. コマンドを使用してパッケージを展開します： `tar -xzf openlm-broker.tar.gz`
    3. 展開されたディレクトリに移動します。
    4. インストールスクリプトを実行します： `./install.sh`
    5. 画面の指示に従ってインストールを完了します。
  </details>

  <details>
    <summary>RPM</summary>
    1. RPMパッケージをダウンロードします。
    2. コマンドを使用してパッケージをインストールします： `sudo rpm -ivh openlm-broker.rpm`
    3. 画面の指示に従ってインストールを完了します。
  </details>

  <details>
    <summary>DEB</summary>
    1. DEBパッケージをダウンロードします。
    2. コマンドを使用してパッケージをインストールします： `sudo dpkg -i openlm-broker.deb`
    3. 依存関係の問題がある場合は、 `sudo apt-get install -f` を実行します。
    4. 画面の指示に従ってインストールを完了します。
  </details>

</details>

<details>
  <summary>Windowsのインストール</summary>

  1. [OpenLM ウェブサイト](https://www.openlm.com/downloads/) から最新バージョンの OpenLM Broker をダウンロードします。  
  2. インストーラを実行し、インストールウィザードに従います。  
  3. **OpenLM Broker Configuration Tool** を開きます。  
  4. **Add Server** をクリックしてライセンスサーバーを追加します。  
  5. 接続設定および認証情報を構成します。  
  6. **Check Connectivity** をクリックして接続を確認します。  
  7. **Apply** をクリックして変更を保存します。  

</details>

</TabItem>

## Workstation Agentのインストールと設定

Workstation Agentをインストールおよび設定するには：

<details>
  <summary>Windowsのインストール</summary>

  1. [OpenLM ダウンロードページ](https://www.openlm.com/downloads/) から Workstation Agent インストーラをダウンロードします。 
  2. インストーラを実行し、プロンプトに従います。  
  3. Workstation Agent アプリケーションを起動します。  
  4. OpenLM 管理者から提供された組織固有の認証情報を入力します。  
  5. **Test Connection** をクリックして接続を確認します。  
  6. **Save** をクリックして設定を適用します。  

</details>

<details>
  <summary>Linuxディストリビューション</summary>

  </details>

## Directory Synchronization Agent (DSA) のインストールと設定

<DSAArcadeEmbed />

DSA をインストールおよび設定するには以下の手順に従います。

1. [OpenLM ダウンロードページ](https://www.openlm.com/downloads/) から DSA インストーラをダウンロードします。  
2. インストーラを実行します。  
3. DSA アプリケーションを起動します。  
4. Directory Synchronization Service (DSS) の URL を入力します。  
5. DSS から同期定義を追加します。  
6. アクセスを設定します:  
   - ローカルディレクトリ (LDAP) の場合、ディレクトリへのネットワークアクセスを確保してください。  
   - クラウドディレクトリ (Azure AD, Google) の場合、それらのディレクトリへの外部アクセスを確保してください。  
7. **Test Connection** をクリックして検証します。  
8. **Save** をクリックします。
