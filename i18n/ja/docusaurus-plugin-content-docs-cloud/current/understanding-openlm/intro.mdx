# OpenLM とは

OpenLM ドキュメントへようこそ。

OpenLM は、エンジニアリングやサイエンスなどの技術分野に特化したソフトウェアライセンス管理およびソフトウェア資産管理（SAM）ソリューションです。オンプレミス/ハイブリッド/クラウド環境にまたがるライセンス使用の監視・最適化・制御を支援します。

OpenLM は FlexNet、DSLS、Sentinel RMS、Reprise、LM-X など 100 種以上のライセンスマネージャーをサポートします。Autodesk Cloud などのクラウド型ライセンシング向けツールも備えています。

## 主な機能

- コンプライアンスと監査対応  
  ベンダー準拠のレポート作成、ポリシー適用、不正検知で監査に備えます。

- クラウドライセンス管理  
  SaaS やトークン方式のライセンスを専用ツールで監視・制御します。

- 高度な使用分析  
  ユーザー/フィーチャ/ワークステーション別のリアルタイム・履歴データから傾向やアイドル消費を把握します。

- ポリシー適用とアクセス制御  
  自動リリース、アクセス制限、割当ルールにより否認を低減します。

- エンタープライズ連携  
  LDAP/SAML、ITSM、レポートツール、社内システムと連携します。

- マルチ環境対応  
  分散/仮想化/クラウド環境を単一 UI から一元管理します。
