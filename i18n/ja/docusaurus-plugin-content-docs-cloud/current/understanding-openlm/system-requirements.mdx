<TabItem value="workstation-agent" label="Workstation Agent">

インフラストラクチャ要件
最小ハードウェア要件
デュアルコアCPU

2 GBのRAM

プラットフォームサポート
テスト済み環境:

Windows 10

Windows 11

Ubuntu 18

Ubuntu 20

CentOS 8

依存関係
Linux Workstation AgentをCentOSにtar.gzパッケージでインストールする場合、事前にlibXScrnSaverライブラリをインストールする必要があります。

Workstation Agentは自己完結型の.NETアプリです（追加のランタイムは不要です）。

ネットワーク要件
Workstation Agentは、以下との通信にTCPポート443への接続が必要です。
  - Agents Hub
  - OpenLM Identity

<TabItem value="dsa" label="DSA">

ハードウェア要件
デュアルコアCPU

4 GBメモリ（推奨：8 GB）

プラットフォーム要件
Windowsのみ

依存関係
インストーラーの実行には.NET Framework 4.5.2以上が必要です。

自己完結型の.NET Coreアプリケーションです（追加のランタイムは不要です）。

ポート設定
インストール中、ポート8081が空いている必要があります。
  - 占有されている場合は、DSAのインストールフォルダ（C:\Program Files\OpenLM\OpenLM Directory Synchronization Agent）にあるkestrel.configを編集してください。
  - ポート番号を変更し、Directory Synchronization Agentサービスを再起動します。

ネットワーク要件
OpenLMサーバーとは別にインストールする場合:

DSAマシンはポート7026への送信アクセスが必要です。

サポートされているディレクトリサービス
Microsoft Active Directory

NetIQ eDirectory

ApacheDS

AzureAD

</TabItem>
