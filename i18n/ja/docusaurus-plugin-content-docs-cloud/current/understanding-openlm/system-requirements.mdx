# OpenLM コンポーネントのシステム要件

<Tabs>

<TabItem value="workstation-agent" label="Workstation Agent">

## インフラ要件

### 最小ハードウェア要件

- デュアルコア CPU  
- 2 GB RAM  

### プラットフォームサポート

テスト済み環境:  
- Windows 10  
- Windows 11  
- Ubuntu 18  
- Ubuntu 20  
- CentOS 8  

### 依存関係

- Linux Workstation Agent は、CentOS 上で tar.gz パッケージを使用してインストールする際に、事前に `libXScrnSaver` ライブラリをインストールしておく必要があります。  
- Workstation Agent は自己完結型の .NET アプリです（追加のランタイムは不要）。  

### ネットワーク要件

- Workstation Agent は以下と通信するために TCP ポート 443 への接続が必要です:  
  - Agents Hub  
  - OpenLM Identity  

</TabItem>

<TabItem value="dsa" label="DSA">

## ハードウェア要件

- デュアルコア CPU  
- 4 GB メモリ（推奨: 8 GB）  

### プラットフォーム要件

- Windows のみ  

### 依存関係

- インストーラを実行するには .NET Framework 4.5.2 以上が必要です。  
- 自己完結型 .NET Core アプリケーション（追加のランタイムは不要）。  

### ポート構成

- インストール時にポート 8081 が空いている必要があります。  
  - 使用中の場合は、DSA インストールフォルダ (`C:\Program Files\OpenLM\OpenLM Directory Synchronization Agent`) 内の `kestrel.config` を編集してください。  
  - ポート番号を変更し、Directory Synchronization Agent サービスを再起動します。  

### ネットワーク要件

OpenLM Server とは別の環境にインストールする場合:  
- DSA マシンはポート 7026 への送信アクセスが必要です。  

### サポートされるディレクトリサービス

- Microsoft Active Directory  
- NetIQ eDirectory  
- ApacheDS  
- AzureAD  

</TabItem>

<TabItem value="broker" label="Broker">

## システム要件

- メモリ: 4 GB RAM（推奨: 8 GB）  
- Java 要件:  
  - 最新リリースの Java 8 または 11（OpenJDK サポート）  
- Windows インストーラには .NET Framework 4.5.2 以上が必要です。
