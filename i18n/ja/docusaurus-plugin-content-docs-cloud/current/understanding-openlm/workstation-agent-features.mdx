# OpenLM Workstation Agent の役割

OpenLM Workstation Agent はエンドユーザーマシンにインストールされ、ソフトウェアライセンスの使用状況を監視・最適化するのに役立ちます。ライセンスサーバーとBrokerが報告する以上に、ライセンスソフトウェアがどのように、いつ、実際に使用されているかについて、リアルタイムでエンドポイントレベルの可視性を提供します。

このガイドでは、Workstation Agentがどのように役立つかを説明します:

- アイドル状態のライセンスを検出して回収する  
- 高度な管理ポリシーを適用する  
- ユーザーに透明性と制御を提供する  

## アイドルライセンス

ライセンスはしばしばチェックアウトされたまま、実際には使用されていないことがあります。例えば、ユーザーが AutoCAD を開いたまま席を離れると、ライセンスは占有されたままになります。このような行動は以下を引き起こします:

- **アクセス拒否**: 他のユーザーがソフトウェアを利用できなくなる  
- **誤った需要**: 高いチェックアウト率が過剰購入につながる  
- **予算の浪費**: アイドルライセンスが価値を生まないままリソースを消費する  

## アイドル時間の監視と未使用ライセンスの回収

### アイドル時間の追跡

アイドル時間とは、ライセンスアプリケーションが開いているが、実際には使用されていない時間（そのアプリへのキーボードやマウス入力がない状態）です。Workstation Agent はアイドル時間を追跡し、OpenLM に送信します。

セッションがアイドル時間のしきい値を超えると、OpenLM はそれをアイドルとマークし、以下を表示します:

- 実行中のすべてのソフトウェアセッション  
- 各アプリケーションのアイドル時間  
- アクティビティと非アクティビティを示すセッションタイムライン  

### アイドルライセンスの自動回収

ライセンスハーベスティングにより、アイドルセッションからライセンスを回収し、他のユーザー用のプールに戻します。  

### ハーベスティング方法の選択

OpenLM はアプリケーションやライセンスタイプに応じて、いくつかのハーベスティング方法をサポートしています:

- **保存して閉じる (Save & Close)**: ユーザーの作業を保存し、アプリを閉じます。OpenLM 拡張機能が必要です。主な対象:  
  - ArcGIS / ArcGIS Pro  
  - AutoCAD  
  - SOLIDWORKS  
  - MATLAB  
  - CATIA  

- **一時停止と再開 (Suspend & Resume)**: アプリを一時停止します（FlexLM に最適）。ユーザーは個人ダッシュボードから再開できます。  

- **強制終了 (Kill)**: 保存せずにアプリを強制終了します。他の方法が利用できない場合のみ使用します。  

## セッション制御とポリシー定義

### Process Managerを使用した監視ルールの定義

Process Managerを使って、Workstation Agentが各アプリケーションをどのように扱うかを設定できます。

#### プロセスの設定

**Process** タブで:

- **Name**: 実行ファイル名を正確に入力（大文字・小文字を区別）。  
- **License server トグル**:  
  - On: プロセスをライセンス・フィーチャーに関連付け  
  - Off: スタンドアロンアプリ用  

#### アイドル動作の定義

**License Release** タブで:

- **リリース方法**: Save & Close、Suspend & Resume、Agent Procedure、または None を選択  
- **リリース条件**: アイドルしきい値（例: 60 分）を設定、または利用率が一定レベルに達した場合のみリリース（例: 90%）  
- **高度な検出**: CPU、I/O、アクティビティレベルに基づいて調整  
- **Agent Procedure**: `Agent Kill`、`Agent Save&Close` などのカスタムアクションを定義  

### シャドウライセンスのポリシー適用

**Shadow Licenses** タブを使用して、ライセンスマネージャーが存在しないアプリケーションを管理します。

#### 消費ルールの定義

- **ポリシータイプ**:  
  - *Process*: 実行中のインスタンスごとに 1 ライセンス  
  - *Workstation*: マシンごとに 1 ライセンス  
  - *User at Workstation*: ユーザー/マシンの組み合わせごとに 1 ライセンス  
- **名前付きユーザー制限**: 同じユーザーが複数のマシンでアプリを使用することを防止  
- **同時実行とバージョン制御**: 複数バージョンの利用をブロック、または同時利用を制限  

#### リリースルールの定義

- **リリース遅延**: 猶予時間を設定（例: 10 分）  
- **バケット期間**:  
  - `DAY`: ライセンスは深夜にリリース  
  - `HOUR`: 毎正時にリリース  
  - `NONE`: 遅延後すぐにリリース  

### Process Sessionsレポートの確認

**Process Sessions** レポートは、ライセンスチェックアウト情報を超えて、ユーザーマシン上で何が起きたかを記録します。

データには以下が含まれます:

- プロセス名、ユーザー、ホスト  
- セッションの開始・終了時間  
- 合計アイドル時間  
- シャットダウン理由（例: ユーザーまたはWorkstation Agentによる終了）  

:::note
過去セッションのアイドル時間を確認するには、ライセンスサーバーデータではなく **Process Sessions** レポートを使用してください。
:::

### Personal Dashboardを使ったセルフサービスのサポート

Personal Dashboardは、ユーザーが自分のライセンス使用状況を理解・管理するのに役立ちます。

主な機能:

- **ライセンス利用状況**: リアルタイムの状態を表示し、誰がライセンスを保持しているかを確認  
- **最近閉じたアプリ**: OpenLM によって閉じられたアプリを表示し、**Resume** ボタンで再度開くことが可能  
- **プロジェクト**: 使用状況を特定のプロジェクトに紐付け、レポート用に記録  
- **ライブフィード**: ローカルWorkstation Agentからの診断ログを表示
