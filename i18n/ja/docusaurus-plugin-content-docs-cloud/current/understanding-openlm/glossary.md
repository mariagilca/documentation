# 用語集

この用語集では、OpenLM ドキュメント全体で使用される主要な用語、略語、およびフレーズを定義します。

| **用語** | **定義** |
|----------|----------|
| アラート | OpenLM アラートを使用すると、ライセンス管理者が条件を定義し、その条件が満たされたときに通知を受け取ることができ、ライセンスシステムの安定性を確保できます。 |
| Annapurna | OpenLM プラットフォームの最新バージョンで、強化されたライセンス管理および監視機能を提供します。 |
| API | アプリケーション プログラミング インターフェース。 |
| Broker | OpenLM とライセンスマネージャー間の通信を仲介し、ライセンス使用状況データを標準化された形式に変換するソフトウェアコンポーネント。 |
| コンポーネント (OpenLM) | OpenLM プラットフォームのコアから独立して導入され、機能を拡張するソフトウェアモジュール。例: OpenLM License Server Broker、Workstation Agent、Directory Sync Agent。 |
| 同時使用 | 任意の時点で使用中のライセンス数。 |
| 使用拒否 | 利用可能なライセンスがすべて使用中のため、ライセンスアクセスがブロックされる事例。 |
| 機能 (Feature) | OpenLM によって追跡される、ライセンス対象ソフトウェアアプリケーションの特定の機能、モジュール、またはコンポーネント。 |
| 履歴レポート | 過去の期間にわたるライセンス使用状況を分析するレポートで、傾向の把握や需要予測に役立ちます。 |
| アイドル時間 | ライセンスがチェックアウトされているが実際には使用されていない時間。 |
| ライセンスファイル | ライセンス数、アクティブな機能、有効期限、使用制限などのライセンス情報を含むデジタル文書。 |
| ライセンスマネージャー | ライセンスの配布と使用を制御し、制限を超えないよう管理するソフトウェア。例: FlexNet、IBM LUM、Sentinel RMS。 |
| ライセンスサーバー | ライセンスマネージャーソフトウェアをホストし、ネットワーク全体でライセンス配布と認証を処理するサーバー。 |
| ライセンス利用率 | 利用可能なライセンスのうちどれだけが使用されているかを時間の経過とともに示す指標で、ソフトウェア利用効率を評価するのに役立ちます。 |
| マイクロサービス | 特定のタスクを実行する独立したソフトウェアサービスで、マイクロサービスベースのアーキテクチャの一部を構成することが多い。 |
| オンプレミス | OpenLM ソフトウェアを組織の自社インフラ（物理環境またはプライベートクラウド）上でホストすることを指します。 |
| OpenLM プラットフォーム | エンジニアリングライセンス、SAM、SaaS 管理のための OpenLM のサービスと製品を包含するコアシステム。 |
| OpenLM トークン | OpenLM ソフトウェアライセンス管理システム内で使用されるライセンス権利の一形態。特定の OpenLM 機能や機能性にアクセス・利用するための柔軟で再利用可能な単位として機能します。 |
| プラットフォーム | OpenLM スイート内でライセンス管理と監視の中心となるプラットフォームで、マイクロサービスを基盤としています。 |
| オプションファイル | FlexNet の設定ファイルで、ユーザーやグループの制限、借用設定などのライセンスアクセス方針を制御するために使用されます。 |
| 永続ライセンス | ソフトウェアを無期限で使用できるライセンスモデルで、通常は前払い料金と年間保守費用が必要。オンプレミス環境でのみ利用可能。 |
| 製品 (OpenLM) | コアまたはオプションの OpenLM 提供物で、有効化されるとシステムリソースを消費する場合があります。例: ドングル監視、ソフトウェアライセンス管理。 |
| プロジェクト | OpenLM 内で、ライセンス使用データをチーム、部門、またはプロジェクトごとに分類し、追跡およびレポートする方法。 |
| リアルタイムレポート | 現在のライセンス使用状況、利用可能数、拒否数を最新の状態で表示するレポート。 |
| ロール | OpenLM システム内でユーザーに割り当てられる権限とアクセスレベルを定義。 |
| セッション | ユーザーがソフトウェアを使用しているアクティブなインスタンスで、開始/終了時間、アプリケーション、ワークステーションなどの詳細が OpenLM によって追跡されます。 |
| ユーザー | OpenLM によって追跡されるライセンス対象アプリケーションを使用する個人。名前、チーム、ワークステーションなどの属性が記録されます。 |
| 使用状況監視 | ソフトウェアの使用状況を追跡・記録し、ライセンス消費を分析・最適化するプロセス。 |
| ワークステーション | ユーザーがライセンス対象ソフトウェアにアクセスするコンピュータまたはデバイスで、OpenLM によって組織全体のライセンス使用状況をマッピングするために追跡されます。 |
| Workstation Agent | エンドユーザーのワークステーションにインストールされ、ソフトウェアライセンス使用データを収集し、Agents Hub を経由して OpenLM プラットフォームに送信するコンパクトなソフトウェアプログラム。 |
