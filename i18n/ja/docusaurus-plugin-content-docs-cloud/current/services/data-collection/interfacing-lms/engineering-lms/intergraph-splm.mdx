# Intergraph SPLM

Intergraph SmartPlant License Manager (SPLM) を OpenLM と連携し、ライセンス使用状況を取得する方法です。

## 必要条件

1. OpenLM Platform
1. Intergraph SPLM と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 分 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 期限日 | 非対応 |
| 冗長構成 | 非対応 |

## OpenLM Server のみでの連携

![OpenLM Server が SPLM を直接照会する構成](/img/engineering-lms/intergraph-splm/image96.png)

OpenLM Server から SPLM をリモート照会して使用データを取得できます。

## OpenLM Server + Broker での連携

![Broker が SPLM をローカル照会する構成](/img/engineering-lms/intergraph-splm/image40.png)

Broker が `pdlice.exe` を実行してデータを取得し、ネットワーク断があってもバッファリングを行います。

### Broker 設定

1. [http://localhost:5090](http://localhost:5090) を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. *SPLM* を選択し、ポート（例: 807）を入力して **Add**。
1. **Commands** で `pdlice.exe` へのパス（例: `C:\Win32applingr\pdlice\bin\pdlice`）を設定します。
1. **Vendors -> Add Vendor** で *SPLM* など任意の名称を追加します。
1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。
1. 左メニューで **Pending Server** を選択し、Intergraph SPLM を **Approve and Merge**。
1. **License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新しい接続では、反映まで最大 3 分かかります。
