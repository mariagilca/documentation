# FlexNet Embedded（FNE）

## 仕組み

OpenLM Server は FlexNet Embedded サーバーの XML API を定期的に呼び出し、ライセンス使用状況と統計を取得します。取得したデータは集約され、OpenLM Web インターフェースで確認できます。

![FlexNet Embedded と OpenLM Server の連携図](/img/engineering-lms/flexnet-embedded-fne/image145.png)

## 必要条件

1. OpenLM Platform
1. FlexNet Embedded と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## Broker UI での設定

1. [http://localhost:5090](http://localhost:5090) を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. *FlexNet Embedded* を選び、ポート番号を入力して **Add**。
1. 以下の項目を入力します。
    - Type: *FlexNet Embedded*
    - Description: 例) FlexNet Embedded server
    - Time zone: ライセンスサーバーのタイムゾーン
    - Hostname: サーバーのホスト名または IP
    - Port: 指定ポート
    - Vendor name: 例) Avid、NVIDIA
1. **Test** をクリックして接続を確認します。
1. **Apply -> Save** で設定を保存します。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/flexnet-embedded-fne/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. FlexNet Embedded ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/flexnet-embedded-fne/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新しい接続では、反映まで最大 3 分かかります。
