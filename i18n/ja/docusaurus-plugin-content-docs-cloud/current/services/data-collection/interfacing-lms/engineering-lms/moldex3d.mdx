# Moldex3D

本ガイドでは Moldex3D License Manager を OpenLM で監視し、ライセンス使用状況と統計を取得する方法を説明します。

## 必要条件

以下をインストールしてください。

1. OpenLM Platform
1. Moldex3D と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

OpenLM Broker で利用できる機能は次のとおりです。

| 項目 | 値 |
| --- | --- |
| レポート解像度 | 秒 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 取得可 |
| 借用ライセンス | 取得可 |
| 期限日 | 取得可 |
| 冗長構成 | 非対応 |

Broker を使用すると、OpenLM Server との通信をバッファリングし、ライセンスマネージャーサービスのリモート起動／停止も可能になります。

## OpenLM Broker の構成

![Broker が MDX3DLMUtil を利用して Moldex3D をローカル照会し、データを OpenLM Server へ送信](/img/engineering-lms/moldex3d/image121.png)

Broker は `MDX3DLMUtil` ユーティリティを使って Moldex3D をローカルで照会し、得られたデータを OpenLM Server に送ります。

> 事前に Broker をインストールし、OpenLM Server へレポートするよう構成しておいてください。

## Broker の自動検出

1. Broker で **Detect** をクリックします。

    ![Moldex3D-LM Service を検出する例](/img/engineering-lms/moldex3d/image107.png)

1. Moldex3D サービス（例: Moldex3D-LM Service）が稼働していれば自動で検出・設定されます。
1. 設定後、**Restart Broker** を選択します。
1. 念のため **data_inquiry -> Execute** で出力を確認します。

## Broker UI での手動構成

1. 最新の Broker をインストールします。
1. http://localhost:5090/ を開きます。
1. **License Managers** へ移動します。
    - Moldex3D サービスが稼働している場合は **Detect** をクリックします。
    - 自動検出できない場合は **Add License Manager** をクリックし、Type で Moldex3D を選択、ポートを入力して **Add**。

    ![Commands で MDX3DLMUtil.exe のパスを設定](/img/engineering-lms/moldex3d/image124.png)

1. **Commands** で `MDX3DLMUtil.exe` のパスを設定し、**Execute** で確認します。
1. **Vendors** で **Add Vendor** をクリックし、Moldex3D と入力して **Continue**。

    ![保存ボタン](/img/engineering-lms/moldex3d/image82.png)

1. **Save** をクリックします。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/moldex3d/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. Modelex3D ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/moldex3d/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** を開き、緑ステータスで表示されることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかることがあります。
