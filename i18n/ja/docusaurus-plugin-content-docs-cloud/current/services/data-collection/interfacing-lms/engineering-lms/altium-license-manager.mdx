# Altium License Manager

Altium License Manager を OpenLM と連携させることで、使用状況・有効期限・否認イベントを監視できます。

## 必要条件

1. OpenLM Platform
1. Altium と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 分 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認（Denials） | 取得不可 |
| 借用ライセンス | 取得不可 |
| 期限日 | 取得可 |
| 冗長構成 | 非対応 |

## OpenLM Broker の設定

1. ブラウザで [http://localhost:5090](http://localhost:5090)（既定ポート。使用中の場合は 5091 / 5092 など）を開きます。
1. **License Managers** タブで **Add License Manager** をクリックします。
1. ポップアップで以下を設定します。
    - ドロップダウンから *Altium* を選択
    - ポート番号（例: 9780）を入力
    - **Add** をクリック

    ![Commands タブ](/img/engineering-lms/altium-license-manager/image36.png)

1. **Commands** タブで以下を確認します。
    - Data Inquiry が Altium 環境に合わせて設定されていること
    - `C:\Program Files\OpenLM\OpenLM Broker\` 内の `altium@<port>` ファイルを編集し、Altium のユーザー名とパスワードを追記
    - 保存後、Broker UI に戻り **Execute** で出力を確認

1. **Vendors** タブで
    - **Add Vendor** をクリック
    - ベンダー名に *Altium* を入力し **Continue**

    ![Broker 設定の保存](/img/engineering-lms/altium-license-manager/image81.png)

1. **Save** をクリックして Broker 設定を完了します。

## OpenLM Platform の設定

1. OpenLM Platform を開きます。
1. メニューから **License Servers** を選択します。

    ![左メニューで Pending Server を選択](/img/engineering-lms/altium-license-manager/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. リストから Altium ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/altium-license-manager/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** へ進み、Altium のステータスが緑で表示されることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかります。
