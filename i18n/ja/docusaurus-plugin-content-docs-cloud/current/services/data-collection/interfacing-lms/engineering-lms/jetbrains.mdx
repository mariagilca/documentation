# JetBrains

JetBrains Floating License Server (FLS) を OpenLM で監視し、ライセンス統計を取得する方法です。

## 必要条件

1. OpenLM Platform
1. JetBrains FLS と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 分 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 期限日 | 非対応 |
| 冗長構成 | 非対応 |

Broker を使用すると、通信のバッファリングやライセンスサービスのリモート制御が行えます。

## Broker の設定

![JetBrains FLS 連携図](/img/engineering-lms/jetbrains/image27.png)

1. [http://localhost:5090](http://localhost:5090) を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. ポート（既定: 8080）を入力し、Type に *JetBrains* を選択して **Apply**。
1. **Commands** で Update path を JetBrains FLS ルートに設定し、**Update -> Apply**。
1. `data_inquiry` コマンドの URL で `<TOKEN>` を実際の JetBrains トークンに置き換えます。
1. **Execute -> Apply** をクリックして出力を確認します。
1. **Vendors** でベンダー名を *JetBrains* に設定し、**Apply**。
1. Broker を再起動します。

## OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。
1. 左メニューで **Pending Server** を選択し、JetBrains FLS を **Approve and Merge**。
1. **License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新規接続では、反映まで最大 3 分かかります。
