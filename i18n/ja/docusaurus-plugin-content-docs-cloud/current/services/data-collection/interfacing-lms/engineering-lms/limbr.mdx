# LiMBR

OpenLM は Lloyd's Register Licence Manager (LiMBR) を監視し、ライセンス使用状況、否認、借用、期限情報を取得できます。

## 必要条件

1. OpenLM Platform
1. LiMBR と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能と特長

| 項目 | 値 |
| --- | --- |
| レポート解像度 | 開始時刻: 秒単位、終了時刻: 分単位 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認レポート | 取得可 |
| 借用ライセンスレポート | 取得可 |
| 期限レポート | 取得可 |
| 冗長構成 | 非対応 |

Broker を利用すると通信をバッファリングでき、LiMBR サービスのリモート起動・停止も行えます。

## OpenLM Broker の構成

![OpenLM と LiMBR の連携イメージ](/img/engineering-lms/limbr/image27.png)

OpenLM Broker はコマンドラインユーティリティを介して LiMBR をローカル照会し、結果を集約して OpenLM Server に送信します。

> OpenLM Broker はあらかじめインストールし、OpenLM Server へのレポート設定を済ませてから先に進んでください。

### 自動構成

1. Broker 構成ツールで **Detect** をクリックします。
1. LiMBR が稼働中であれば、自動的に必要な設定を備えたポートノードが作成されます。
1. **Apply** をクリックします。
1. **Restart Broker** をクリックします。
1. 確認のため **Commands -> data_query** で **Execute** をクリックします。

    ![Broker UI での設定](/img/engineering-lms/limbr/image107.png)

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** を開きます。
1. **License Manager Type** に LiMBR を選択し、**Apply** をクリックします。
1. **Commands** で LiMBR のインストールフォルダーを参照し、**Update -> Apply** の順で保存します。
1. **status** ノードで設定を確認します。
1. **data_inquiry** で **Execute** をクリックし、出力が有効であることを確認します。
1. **Restart Broker** をクリックします。
1. **Vendors** で Vendor Name に LiMBR と入力し、**Apply** をクリックします。
1. もう一度 **Apply** をクリックします。
1. **Restart Broker** をクリックします。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/limbr/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. リストから LiMBRP ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/limbr/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** を開きます。
1. LiMBPR が緑のステータスで表示されることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかることがあります。
