# pure::variants

pure::variants License Manager を OpenLM で監視し、ライセンス使用状況と統計を取得する手順を説明します。

## 必要条件

事前に以下を準備します。

1. OpenLM Platform
1. Pure::variants と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 値 |
| --- | --- |
| レポート解像度 | 分 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得可 |
| 否認 | 取得不可 |
| 借用 | 取得不可 |
| 期限日 | 取得不可 |
| 冗長構成 | 非対応 |

## OpenLM Broker の構成

![pure::variants License Manager と OpenLM の連携図](/img/engineering-lms/purevariants/image27.png)

> OpenLM Broker はあらかじめインストールし、OpenLM へレポートするよう構成しておいてください。

## Broker UI での設定

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** をクリックします。

    ![pure::variants を追加](/img/engineering-lms/purevariants/image12.png)

1. ドロップダウンから Pure Variants を選択し、ポート番号（例: 888）を入力して **Add** をクリックします。
1. **Settings** タブで **Watch License File** がオフになっていることを確認します。
1. **Commands** タブで pure::variants の実行ファイルパスを入力します。

    ![Vendor の追加](/img/engineering-lms/purevariants/image134.png)

1. **Vendors -> Add Vendor** を開き、pure::variants と入力して **Continue**。

    ![Advanced タブで認証情報を入力](/img/engineering-lms/purevariants/image105.png)

1. **Advanced** タブで pure::variants のログイン情報を入力します。
1. **Save** をクリックします。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/purevariants/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. Pure::Variants ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/purevariants/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** を開き、Pure::Variants が緑のステータスで表示されることを確認します。
