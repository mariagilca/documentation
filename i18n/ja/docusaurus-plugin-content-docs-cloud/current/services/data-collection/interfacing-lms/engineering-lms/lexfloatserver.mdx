# LexFloatServer

以下の手順で LexFloat Server を OpenLM と連携します。

## 必要条件

1. OpenLM Platform
1. LexFloat と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| Broker 上の LM タイプ | LexFloat Server |
| Commands | 非対応 |
| Logs | 対応 |
| 総ライセンス数 | 非対応 |
| 期限日 | 非対応 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 割り当て | 非対応 |
| レポート解像度 | 秒単位 |

Broker を利用すると通信のバッファリングやサービスのリモート制御が可能です。

## Broker UI での設定

![LexFloat Server 連携イメージ](/img/engineering-lms/lexfloatserver/image27.png)

> Broker をインストールし、OpenLM SLM へ接続してください。

1. [http://localhost:5090](http://localhost:5090) を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. ドロップダウンから *LexFloat Server* を選択し、ポート（例: 889）を入力して **Add**。

    ![LexFloat Server の追加](/img/engineering-lms/lexfloatserver/image146.png)

1. **Vendors -> Add Vendor** をクリックし、*LexFloat Server* を入力して **Continue**。

    ![ベンダー追加](/img/engineering-lms/lexfloatserver/image16.png)

1. **Log Files -> Add Log File** をクリックし、`Watch file by pattern` をオフにしてログパスを指定します。必要に応じて複数のログを追加できます。

    ![ログファイル追加](/img/engineering-lms/lexfloatserver/image88.png)

1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/lexfloatserver/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. LexFloat ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/lexfloatserver/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新規接続では反映まで最大 3 分かかります。
