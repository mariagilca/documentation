# ESPRIT

![ESPRIT License Manager と OpenLM Broker の連携図](/img/engineering-lms/esprit/image27.png)

## 必要条件

1. OpenLM Platform
1. ESPRIT と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## Broker UI での設定

1. **OpenLM Broker Web UI -> License Managers**（例: http://localhost:5090/#/license-managers）を開きます。
1. **Add License Manager** をクリックします。
1. 任意のポート番号を入力し、ライセンスマネージャータイプとして *ESPRIT* を選択します。

    ![Settings タブでライセンスファイルを指定](/img/engineering-lms/esprit/image72.png)

1. **Settings** タブに移動し、ライセンスファイルパスを設定します（自動検出または手動指定）。

1. **Commands** タブで ESPRIT 実行ファイルのパスを設定します。

    ![Vendors タブでベンダーを追加](/img/engineering-lms/esprit/image101.png)

1. **Vendors -> Add Vendor** でベンダー名を入力し追加します。

    ![ログファイル設定](/img/engineering-lms/esprit/image58.png)

1. **Log Files -> Add Log File** をクリックし、以下を設定します。
    - Type: *ESPRIT Server Usage*
    - Log (Descriptive): 任意の名称
    - Path: `DptSecLogServerUsage.txt`（ESPRIT ログフォルダー）
1. ベンダーは前ステップで追加したものを選択します。

    ![設定を保存](/img/engineering-lms/esprit/image31.png)

1. **Save** をクリックします。
1. OpenLM Web Interface（例: http://SERVER_IP:5015）で、ESPRIT ライセンスマネージャーを Pending から承認します。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/esprit/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. リストから ESPRIT を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/esprit/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** に移動し、ESPRIT のステータスが緑表示であることを確認します。

> 新しい接続では、反映まで最大 3 分かかります。
