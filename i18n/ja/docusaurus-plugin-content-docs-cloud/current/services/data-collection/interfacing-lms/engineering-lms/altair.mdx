# Altair

Altair License Server (ALS) を OpenLM と連携し、ライセンス使用状況や統計を収集する手順を説明します。

## 必要条件

1. OpenLM Platform
1. Altair と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## Broker の自動検出

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Detect** を実行します。
1. Altair が自動検出されます。
1. 設定内容を確認し、保存します。

## OpenLM Platform の設定

1. OpenLM Platform を開きます。
1. **Menu -> License Servers** に移動します。

   ![左メニューで Pending Server を選択](/img/engineering-lms/altair/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. リストから Altair ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

   ![設定の検証](/img/engineering-lms/altair/image3.png)

1. **OpenLM Web Interface -> Menu -> License Servers Live -> Server Statistics** に進み、Altair のステータスが緑表示であることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかることがあります。
