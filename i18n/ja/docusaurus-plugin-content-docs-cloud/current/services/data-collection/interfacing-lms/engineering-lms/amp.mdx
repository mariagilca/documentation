# AMP

OpenLM は AMP と連携してライセンス使用状況を取得できます。AMP が定期的に生成する XML ファイルを OpenLM Broker が読み込み、Web インターフェースで表示します。

## 必要条件

1. OpenLM Platform
1. AMP と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

    ![Broker UI での設定](/img/engineering-lms/amp/image26.png)

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. AMP を選択し、ポート番号（例: 2306）を入力します。
1. **License Manager Type** を *OpenLM Generic* に設定します。
1. **Commands** で `AMP_OpenLM.exe` のパスを指定します（ベンダーから提供されたファイル、または AMP インストールフォルダーにあります）。

    ```bash
    C:\Program Files (x86)\AMPORTAKAMP\AMP_OpenLM.exe
    ```

1. **Update -> Apply** の順にクリックします。
1. **Execute** をクリックしてデータ取得を確認します。
1. Status コマンドについても同様に設定します。
1. **Vendors** でベンダー名に `AMP YAZILIM`（大小文字を区別）を入力します。
1. **Apply** をクリックし、Broker を再起動します。

    ![OpenLM Platform の設定](/img/engineering-lms/amp/image120.png)

1. OpenLM Platform を開きます。
1. メニューから **License Servers** を選択します。

    ![左メニューで Pending Server を選択](/img/engineering-lms/amp/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. リストから AMP を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/amp/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** で AMP のステータスが緑表示であることを確認します。

> 新しい接続が反映されるまで最大 3 分かかることがあります。

## ArcGIS Online

OpenLM は ArcGIS Online とも連携してライセンス数と使用データを取得できます。  
※ 2 要素認証を有効にしている ArcGIS Online アカウントは監視できません。事前に無効化してください。

### 必要条件

1. OpenLM Platform
1. ArcGIS Online と同じマシンにインストールされた OpenLM Broker v25.x 以降

### ArcGIS Online を OpenLM に追加

1. **OpenLM Server Web Interface -> License Manager Servers** を開きます。
1. **Add LM** をクリックします。

    ![Display Name の入力](/img/engineering-lms/amp/image144.png)

1. わかりやすい **Display Name** を入力します。
1. **Type** で *ArcGIS Online* を選択します。
1. **LM Address** に `https://www.arcgis.com` を入力します。
1. ArcGIS Online 管理者のユーザー名とパスワードを入力します。
1. ライセンスマネージャーが動作するタイムゾーンを選択します。
1. **Test Connection** をクリックし、接続が成功することを確認します。

    ![保存操作](/img/engineering-lms/amp/image22.png)

1. **Save** をクリックします。数分後、レポートに使用データと割り当てデータが表示されます。

### OpenLM Platform の設定

1. OpenLM Platform を開きます。
1. **Menu -> License Servers** へ移動します。

    ![左メニューで Pending Server を選択](/img/engineering-lms/amp/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. リストから ArcGIS Online を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/amp/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** に移動し、ArcGIS Online のステータスが緑で表示されることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかります。
