# L3Harris Geospatial

L3Harris License Manager を OpenLM で監視する手順です。

## 必要条件

開始前に以下を準備します。

1. OpenLM Platform
1. L3Harris と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| レポート解像度 | 1 秒 |
| 総ライセンス数 | 取得可 |
| 使用状況 | 取得不可 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 期限日 | 非対応 |
| 冗長構成 | 非対応 |

Broker を利用すると通信のバッファリングやライセンスサービスのリモート制御が可能になります。

## Broker UI での設定

![L3Harris と OpenLM の連携図](/img/engineering-lms/l3harris-geospatial/image27.png)

> Broker は OpenLM に接続済みである必要があります。

1. [http://localhost:5090](http://localhost:5090)（使用中なら 5091/5092）を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. ドロップダウンで *L3Harris* を選び、任意のポート番号を入力して **Add**。  
   （ポートはデータ取得には使用されませんが必須項目です）

    ![Commands タブ](/img/engineering-lms/l3harris-geospatial/image65.png)

1. **Commands** タブで、L3Harris ログファイルが配置されているフォルダーを指定します。
1. 実行ファイルのパスを入力します。
1. **Vendors** でベンダー名を設定します。
1. **Log Files -> Add Log File** をクリックし、以下を設定します。
    - Log type: *Usage Log*
    - Log name: 任意の識別名
    - Log path: L3Harris のログフォルダー
    - Vendor: 先ほど登録したベンダー
    - Set data size limit (KB): 既定 100
    - Read file every (sec): 既定 10
    - Watch file by pattern: オフ
    - Encoding: windows-1252

    ![保存画面](/img/engineering-lms/l3harris-geospatial/image112.png)

1. **Continue -> Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/l3harris-geospatial/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. L3Harris ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/l3harris-geospatial/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新規接続では、反映まで最大 3 分かかります。
