# ProgeCAD

ProgeCAD は AutoCAD 互換の 2D / 3D 設計ソフトウェアで、ネイティブ .dwg 形式のダイレクトモデリングをサポートします。OpenLM は ProgeCAD Network License Manager (NLM) v13.0.18 以降を監視できます。ライセンスサーバーが定期的に出力する XML ファイルを OpenLM が解析し、Web インターフェイス上に使用状況を表示します。

## 前提条件

ProgeCAD の監視には次が必要です。

- OpenLM Platform
- ProgeCAD と同じマシンにインストールされた OpenLM Broker v25.x 以降

## Broker UI での設定

Broker Web UI を使用する場合は以下の手順に従います。

1. http://localhost:5090/ を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. **Type** で *OpenLM Generic* を選択し、ポート（例: 51168）を入力して **Add**。

    ![Commands タブでの設定例](/img/engineering-lms/progecad/image95.png)

1. **Commands** タブを開き、**Executable path** に次を入力します。

    ```bash
    "<NLMServerMonitor.exe へのフルパス>" /xml
    ```

1. **Save** をクリックし、**Execute** で出力を確認します。

    ![Vendors で ProgeCAD を追加](/img/engineering-lms/progecad/image117.png)

1. **Vendors** タブで **Add Vendor** をクリックし、ProgeCAD（任意の名称）を入力して **Continue -> Save**。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/progecad/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. ProgeCAD ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/progecad/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** で ProgeCAD が緑のステータスで表示されることを確認します。

> 新しい接続の場合、ステータスが反映されるまで最大 3 分かかります。
