# BetaLM

## 必要条件

1. OpenLM Platform
1. BetaLM と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## Broker UI での設定

BetaLM がインストールされているマシンで次の手順を実行します。

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** を選択します。
1. **Display name** に説明的な名前を入力します。
1. **Type** で *BetaLM* を選択します。
1. ホスト名とポート（既定: 6007）を入力します。
1. ライセンスサーバーのタイムゾーンを選択します。
1. 冗長構成を使用する場合は **Triad Configuration** を有効にします（BetaLM が対応している場合）。
1. **Use Broker** を On に設定します。
1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. メニューから **License Servers** を選択します。
1. 左メニューで **Pending Server** を選択します。

    ![Pending Server の選択](/img/engineering-lms/betalm/image10.png)

1. リストから BetaLM ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/betalm/image3.png)

1. **License Servers Live -> Server Statistics** を開き、BetaLM のステータスが緑表示であることを確認します。

> 新しい接続では、ステータスが反映されるまで最大 3 分かかることがあります。
