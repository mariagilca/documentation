# DSLS

Dassault Systèmes License Server (DSLS) を OpenLM と連携し、ライセンス使用状況や統計を取得する方法を解説します。

## 必要条件

1. OpenLM Platform
1. DSLS と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## Broker UI での設定

![Broker と DSLS の構成](/img/engineering-lms/dsls/image26.png)

1. [http://localhost:5090](http://localhost:5090) で Broker UI を開きます。
1. **License Managers** タブで **Detect** を実行し、DSLS を自動検出します。検出されない場合は **Add License Manager** をクリックし、*DSLS* を選択してポートを入力します。

    ![DSLS の追加](/img/engineering-lms/dsls/image55.png)

1. ライセンスファイルと同じ日付形式 / 言語を設定します。
1. **Commands** タブで `DSLicSrv.exe` のパスを入力し、**Execute** をクリックします。  
    ※ パスワードを使用している場合はコマンドに追加し、セミコロン前に半角スペースを入れてください。
1. **Vendors -> Add Vendor** を開き、ベンダー名を *Dassault Systemes* に設定します。
1. 冗長構成では、各 DSLS サーバーに Broker をインストールします。
1. `status`、`data_inquiry`、`denial` コマンドは `en_US` ロケールで動作していることを確認します。

### DSLS ログの設定

1. **Log Files -> Add Log File** をクリックします。
1. **Type** は *Other* を選択。
1. ファイル名（例: DSLS log file）を入力します。
1. ログファイルのパス（例: `C:\my_dsls_log.log`）を指定します。
1. ベンダーに *Dassault Systemes* を選択します。
1. ログがローテーションする場合は `Watch files by pattern` をオンにします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/dsls/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. リストから DSLS を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/dsls/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** に移動し、DSLS のステータスが緑表示であることを確認します。

> 新しい接続では、ステータス更新に最大 3 分かかります。
