# Nvidia License Manager

本ガイドでは Nvidia License Manager（Altair License Serverベース）を OpenLM で監視し、ライセンス使用状況と統計情報を取得する手順を説明します。

## 必要条件

1. OpenLM Platform
1. Nvidia License Manager と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## Broker UI での設定

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. OpenLM Web インターフェイスの **License Servers -> Add** を開き、以下を設定します。
    1. **Type**: Nvidia
    1. **Description**: サーバー名
    1. **Time Zone**: 該当ライセンスサーバーのタイムゾーン
    1. **Hostname / Port**: サーバー情報
    1. **Is Triad Configuration**: 必要に応じて選択
    1. **UserPassword**: Nvidia 管理ポータルのユーザー名とパスワード
    1. **Is secure connection (https)**: HTTPS を使用する場合はチェック
    1. **Use Broker**: チェックを外す
    1. **Read license file**: チェックを外す
1. **Apply** をクリックします。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/nvidia-license-manager/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. リストから Nvidia ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/nvidia-license-manager/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** を開き、Nvidia が緑のステータスで表示されることを確認します。

> 新しい接続の場合、ステータスが反映されるまで最大 3 分かかることがあります。
