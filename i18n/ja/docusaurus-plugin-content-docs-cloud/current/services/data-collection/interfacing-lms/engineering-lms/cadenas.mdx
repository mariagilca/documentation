# CADENAS

以下の手順で CADENAS Server を OpenLM と連携し、ライセンス使用状況を取得します。

## 必要条件

1. OpenLM Platform
1. CADENAS と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| Broker 上の LM タイプ | Cadenas |
| Commands | 非対応 |
| Logs | 対応 |
| 総ライセンス数 | 取得可 |
| 期限日 | 取得不可 |
| 否認（Denied） | 非対応 |
| 借用ライセンス | 非対応 |
| 割り当て | 非対応 |
| レポート解像度 | 秒単位 |

## OpenLM Broker の設定

![OpenLM と CADENAS Server の連携イメージ](/img/engineering-lms/cadenas/image27.png)

> Broker は事前に OpenLM への接続設定を済ませておいてください。

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers -> Add License Manager** を選択します。
1. *CADENAS* を選び、ポート番号を入力して **Add** をクリックします。

    ![CADENAS ライセンスマネージャーの追加](/img/engineering-lms/cadenas/image110.png)

1. **Vendors** タブで **Add Vendor** をクリックし、*CADENAS Server* を入力して **Continue**。

    ![CADENAS ベンダーの追加](/img/engineering-lms/cadenas/image164.png)

1. **Log Files** タブで **Add Log File** をクリックし、`Watch file by pattern` をオフにしてログパスを指定、**Continue** で追加します。

1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/cadenas/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. リストから CADENAS を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/cadenas/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** で CADENAS のステータスが緑表示であることを確認します。

> 新しい接続の場合、反映まで最大 3 分かかることがあります。
