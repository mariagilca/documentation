# Olicense

OLicense は OpenLM がサポートするライセンスマネージャーの 1 つです。本ガイドでは OLicense-Server と連携し、ライセンス使用状況や統計を取得する方法を説明します。

Broker 方式: OLicense-Server 上に OpenLM Broker をインストールし、ローカル照会したデータを OpenLM Server に送信します。

## OpenLM Server の直接照会（ダイレクト方式）

![OpenLM Server と OLicense の直接接続イメージ](/img/engineering-lms/olicense/image96.png)

## 必要条件

1. OpenLM Platform
1. OLicense と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

    Broker は OLicense をローカルで照会し、ネットワーク障害時も通信をバッファリングしながら OpenLM Server にデータを送信します。

    ![OLicense と連携する OpenLM Broker](/img/engineering-lms/olicense/image26.png)

## Broker UI での構成

1. http://localhost:5090/ で Broker UI を開きます。
1. **License Managers** を開きます。
    - OLicense が自動検出された場合は内容を確認して保存します。
    - 検出されない場合は **Add License Manager** をクリックし、OLicense を選択、ポート（既定: 80）を入力して **ADD** をクリックします。

    ![Broker で OLicense を手動追加](/img/engineering-lms/olicense/image169.png)

1. **Commands** で `olixtool.exe` のパスを設定し、**Execute** で出力を確認します。

    ![コマンドパスの設定例](/img/engineering-lms/olicense/image170.png)

1. **Vendors -> Add Vendor** をクリックし、名前に `OLicense` を入力して **Continue**。
1. **SAVE** をクリックします。
1. 先述の手順に従って OpenLM Server を構成します。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/olicense/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. OLicense ライセンスマネージャーを選択し、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/olicense/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** を開き、OLicense が緑ステータスで表示されることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかることがあります。
