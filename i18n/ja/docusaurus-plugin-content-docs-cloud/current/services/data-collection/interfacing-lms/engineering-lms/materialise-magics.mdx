# Materialise Magics

OpenLM で Materialise Magics のライセンス使用状況と統計情報を取得する手順を以下に示します。

## 必要条件

ライセンスマネージャーを照会する前に次をインストールしてください。

1. OpenLM Platform
1. Materialise Magics と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 値 |
| --- | --- |
| Broker での LM Type | Materialise Magics |
| Commands | 対応 |
| Logs | 非対応 |
| Quantity | 対応 |
| Expiration date | 対応 |
| Denied | 非対応 |
| Borrowing | 非対応 |
| Allocations | 非対応 |
| レポート解像度 | 秒 |

Broker を利用することで通信のバッファリングや、ライセンスマネージャーサービスのリモート起動・停止も可能になります。

## Broker UI での設定

![Materialise Magics ライセンスマネージャーに接続した OpenLM Broker](/img/engineering-lms/materialise-magics/image28.png)

*Materialise Magics ライセンスマネージャーに接続した OpenLM Broker の例*

> OpenLM Broker はあらかじめインストールし、OpenLM SLM へのレポート設定を行ってから先に進んでください。

1. http://localhost:5090 で Broker Web UI を開きます。同一ネットワーク上の別マシンからアクセスする場合は http://localhost:5090/api/new-token にアクセスしてトークンを生成します。
1. **License Managers -> Add License Manager** を開きます。
1. **LM Type** から Materialise Magics を選択します。
1. ポート番号（デフォルト: 7010）を入力し、**Add** をクリックします。
1. **Executable Path** で Materialise Magics の .exe ファイルがあるインストールディレクトリを参照します。

    ![実行ファイルパスを設定](/img/engineering-lms/materialise-magics/image147.png)

1. **Save** をクリックします。
1. 確認のため **Commands** タブで **Execute** をクリックします。

    ![Materialise Magics への接続を検証](/img/engineering-lms/materialise-magics/image84.png)

    *Materialise Magics への接続結果*

1. 接続に成功すると、次のような出力が表示されます。

    ![成功時の出力例](/img/engineering-lms/materialise-magics/image130.png)

1. **Vendors** タブへ移動し、**Add Vendor** をクリックして Materialise と入力し、**Continue** をクリックします。

    ![Materialise ベンダーの追加](/img/engineering-lms/materialise-magics/image66.png)

    *OpenLM Broker で Materialise ベンダーを追加*

1. **Save** をクリックします。

### OpenLM Platform の構成

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/materialise-magics/image10.png)

1. 左メニューの **Pending Server** を選択します。
1. リストから Materialise Magic ライセンスマネージャーを選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/materialise-magics/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** を開きます。
1. Materialise Magic が緑のステータスで表示されていることを確認します。

> 新しい接続の場合、ステータスが更新されるまで最大 3 分かかることがあります。
