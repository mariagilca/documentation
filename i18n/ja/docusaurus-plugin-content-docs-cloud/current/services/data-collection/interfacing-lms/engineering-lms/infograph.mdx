# Infograph

以下の手順で InfoGraph License Manager を OpenLM と連携します。

## 必要条件

1. OpenLM Platform
1. InfoGraph と同じマシンにインストールされた OpenLM Broker v25.x 以降、[Broker Hub](/cloud/services/data-collection/broker-hub) で承認します。

## 監視機能

| 項目 | 取得可否 |
| --- | --- |
| Broker 上の LM タイプ | InfoGraph |
| Commands | 非対応 |
| Logs | 対応 |
| 総ライセンス数 | 非対応 |
| 期限日 | 非対応 |
| 否認 | 非対応 |
| 借用 | 非対応 |
| 割り当て | 非対応 |
| レポート解像度 | 秒単位 |

Broker を利用すると通信のバッファリングやライセンスサービスのリモート制御も可能です。

### Broker UI の設定

![Broker での設定例](/img/engineering-lms/infograph/image78.png)

> Broker は OpenLM SLM に接続済みである必要があります。

1. [http://localhost:5090](http://localhost:5090)（使用中の場合は 5091/5092）で Broker UI を開きます。
1. **License Managers -> Add License Manager** をクリックします。
1. *InfoGraph* を選択し、ポート番号（例: 888）を入力して **Add**。
1. **Settings** タブでライセンスファイルの自動検出結果を確認し、必要に応じて `lgraph.xml` を手動で指定します。

    ![ライセンスファイル設定](/img/engineering-lms/infograph/image23.png)

1. **Vendors -> Add Vendor** で *InfoGraph* を入力し **Continue**。

    ![ベンダー追加](/img/engineering-lms/infograph/image123.png)

1. **Log Files -> Add Log File** をクリックし、`Watch file by pattern` をオフにしてログパスを指定します。必要に応じて複数追加できます。

    ![ログファイル追加](/img/engineering-lms/infograph/image18.png)

1. **Save** をクリックします。

### OpenLM Platform の設定

1. OpenLM Platform にログインします。
1. **Menu -> License Servers** を開きます。

    ![左メニューで Pending Server を選択](/img/engineering-lms/infograph/image10.png)

1. 左メニューで **Pending Server** を選択します。
1. InfoGraph を選び、**Approve and Merge** をクリックします。

    ![設定の検証](/img/engineering-lms/infograph/image3.png)

1. **Menu -> License Servers Live -> Server Statistics** でステータスが緑表示であることを確認します。

> 新規接続では、ステータス更新に最大 3 分かかります。
