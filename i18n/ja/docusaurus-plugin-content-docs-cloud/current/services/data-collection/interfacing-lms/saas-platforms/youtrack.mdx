# YouTrack
YouTrack 使用状況の監視

## YouTrack について

YouTrack は JetBrains が提供するプロジェクト管理・課題管理システムです。開発チームがプロジェクト計画、タスク追跡、バグ管理を行う際に利用されます。YouTrack の利用状況を監視すると、開発チームの生産性を把握し、コストを最適化できます。Jira や GitLab などのプロジェクト管理プラットフォームを監視する場合と同様です。

## 前提条件

YouTrack の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。自動化が必要な場合は OpenLM OneDirectorySync や License Allocation Control の導入を検討してください。
- プラットフォーム固有の要件: YouTrack インスタンスの管理者アクセス権が必要です。必要な読み取り権限を持つ永続トークンを生成します。

## データ収集の構成

OpenLM Cloud Broker で YouTrack のデータ収集を設定するには、次の手順に従います。

1. YouTrack の管理パネルで新しい永続トークンを作成し、ユーザーおよびプロジェクトデータを読み取れる権限を付与します。
2. OpenLM Cloud Broker ダッシュボードで YouTrack 連携を選択し、トークンを入力します。
3. 接続を確認します。OpenLM が YouTrack API と通信できることをテストします。
4. OpenLM で承認します。「License Servers」セクションで新しいデータソースを承認します。
5. データを確認します。YouTrack の使用状況データが OpenLM Allocation サービスに表示されます。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: プラットフォームで最も活動しているチームや開発者を把握し、リソース配分に役立てます。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定してライセンスを回収します。
