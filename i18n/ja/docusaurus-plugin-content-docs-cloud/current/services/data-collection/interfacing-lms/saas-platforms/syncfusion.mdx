# Syncfusion
Syncfusion 使用状況の監視

## Syncfusion について

Syncfusion は、モダンな Web／モバイル／デスクトップアプリケーションを構築するためのソフトウェアコンポーネントとフレームワークを提供しています。開発者はユーザーインターフェースや各種機能を迅速に実装できます。Syncfusion の利用状況を監視すると、ライセンスが有効に活用されているか確認でき、コストを最適化できます。JetBrains Cloud や GitLab などの開発プラットフォームを監視する場合と同様です。

## 前提条件

Syncfusion の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。
- プラットフォーム固有の要件: Syncfusion アカウントの管理者アクセス権が必要です。必要な読み取り権限を持つ API キーを生成します。

## データ収集の構成

Syncfusion 連携の設定については、サポートチーム（[support@openlm.com](mailto:support@openlm.com)）までお問い合わせください。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: プラットフォーム上で最も活動している開発者を把握し、リソース配分に役立てます。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定してライセンスを回収します。
