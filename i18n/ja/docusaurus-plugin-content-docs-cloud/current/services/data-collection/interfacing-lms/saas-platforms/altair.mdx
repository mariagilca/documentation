# Altair
Altair 使用状況の監視

## Altair について

Altair は、エンジニアリングや製造業を中心に、シミュレーション、ハイパフォーマンスコンピューティング、データ分析向けのソフトウェアを提供しています。HyperWorks や solidThinking などの製品により、設計、モデリング、シミュレーションを支援します。Altair の利用状況を監視すると、コスト管理やライセンス最適化を進められます。Intergraph や Bentley といった他のエンジニアリング系プラットフォームを管理する場合と同じ考え方です。

## 前提条件

Altair の監視を開始する前に、以下のコンポーネントと権限を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。
- プラットフォーム固有の要件: Altair のライセンスサーバーおよび関連管理ポータルにアクセスできる管理者権限が必要です。API キーや構成ファイルを取得する際に使用します。

## データ収集の構成

1. Altair 連携の設定については、サポートチーム（[support@openlm.com](mailto:support@openlm.com)）までご連絡ください。

## レポートの閲覧

利用状況を分析するために、次のレポートを確認します。

- ユーザーアクティビティの推移: ピーク利用時間や、どのチームがどの Altair モジュールを利用しているかを把握できます。
- 期限切れ／未使用ライセンスレポート: 未使用ライセンスを特定して再割り当てまたは削減し、コストを抑制します。
