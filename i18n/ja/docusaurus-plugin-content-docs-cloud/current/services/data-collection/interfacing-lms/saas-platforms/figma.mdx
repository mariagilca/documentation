# Figma
Figma 使用状況の監視

## Figma について

Figma は、デザイナー、プロダクトマネージャー、開発者が共同で利用するインターフェースデザインツールです。クラウドベースのプラットフォーム上で、デザインの作成、プロトタイピング、共有をすべて行えます。Figma の利用状況を監視すると、サブスクリプションコストの最適化とデザインライセンスの有効活用を図れます。Adobe Cloud や Sketch など、他のクリエイティブ／デザインツールを監視する場合と同様です。

## 前提条件

Figma の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。
- プラットフォーム固有の要件: Figma の組織またはチームアカウントの管理者アクセス権が必要です。必要な読み取り権限を持つパーソナルアクセストークンを生成します。

## データ収集の構成

Figma 連携の設定については、サポートチーム（[support@openlm.com](mailto:support@openlm.com)）までお問い合わせください。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: アクティブなユーザーや担当プロジェクトを把握し、ライセンス再配分の判断材料にします。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定し、ライセンスを回収してコストを最適化します。
