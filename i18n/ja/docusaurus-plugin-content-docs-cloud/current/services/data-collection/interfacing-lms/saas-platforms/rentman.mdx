# Rentman
Rentman 使用状況の監視

## Rentman について

Rentman は、イベントおよび制作業界向けのレンタル管理ソフトウェアです。機材、スタッフ、プロジェクトの管理を支援します。Rentman の利用状況を監視すると、ライセンスを効率的に活用でき、コストを最適化できます。Odoo などの業務管理ツールを監視する場合と同様です。

## 前提条件

Rentman の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。自動化が必要な場合は OpenLM OneDirectorySync や License Allocation Control を検討してください。
- プラットフォーム固有の要件: Rentman アカウントの管理者アクセス権が必要です。ユーザーおよびプロジェクトデータを読み取れる API キーを生成します。

## データ収集の構成

OpenLM Cloud Broker で Rentman のデータ収集を設定するには、次の手順に従います。

1. Rentman のアカウント設定で API アクセスを有効にし、読み取り専用の API キーを作成します。
2. OpenLM Cloud Broker ダッシュボードで Rentman 連携を選択し、API キーを入力します。

   ![](/img/saas-platforms/rentman/image17.png)

3. 接続を確認します。OpenLM が Rentman API と通信できることをテストします。
4. OpenLM で承認します。「License Servers」セクションで新しいデータソースを承認します。
5. データを確認します。Rentman の使用状況データが OpenLM Allocation サービスに表示されます。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: 最もアクティブなユーザーを把握し、ライセンス再配分に役立てます。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定してライセンスを回収します。
