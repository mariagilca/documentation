# Fluida
Fluida 使用状況の監視

## Fluida について

Fluida は、従業員の勤怠管理、休暇申請、スマートスケジューリングを支援する HR プラットフォームです。人事プロセスを効率化し、コンプライアンスを確保できます。Fluida の利用状況を監視すると、ライセンスが有効に活用されているか確認でき、コスト最適化につながります。BambooHR や Sage HR など他の HR プラットフォームを監視する場合と同様のアプローチです。

## 前提条件

Fluida の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。自動化を検討する場合は OpenLM OneDirectorySync や License Allocation Control の活用をおすすめします。
- プラットフォーム固有の要件: Fluida アカウントの管理者アクセス権が必要です。必要な読み取り権限を持つ API キーを生成します。

## データ収集の構成

OpenLM Cloud Broker で Fluida のデータ収集を設定するには、次の手順に従います。

1. Fluida プラットフォームにログインします。
2. **Company > Settings > API** に移動します。
3. **Add a New Key** をクリックします。
4. 分かりやすい名前を入力し、すべての権限を許可したうえでキーを有効化します。
5. OpenLM Cloud Broker ダッシュボードで Fluida 連携を選択し、Company ID と API トークンを入力します。

   ![](/img/saas-platforms/fluida/image30.png)

6. 接続を確認します。OpenLM がデータを取得できることをテストします。
7. OpenLM で承認します。「License Servers」セクションで新しいデータソースを承認します。
8. データを確認します。Fluida の使用状況データが OpenLM Allocation サービスに表示されます。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: プラットフォーム上で最も活動している人事担当者を把握し、リソース配分に役立てます。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定し、ライセンスを回収します。
