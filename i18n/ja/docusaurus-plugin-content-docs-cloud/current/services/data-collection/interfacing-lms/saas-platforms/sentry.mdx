# Sentry
Sentry 使用状況の監視

## Sentry について

Sentry は、開発者がコードの不具合を診断・修正し、パフォーマンスを最適化するためのアプリケーション監視プラットフォームです。リアルタイムのエラートラッキングとパフォーマンス監視を提供します。Sentry の利用状況を監視すると、ライセンスがアクティブな開発者に割り当てられているか確認でき、コストを最適化できます。LaunchDarkly や GitLab などの DevOps ツールを監視する場合と同様です。

## 前提条件

Sentry の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。自動化が必要な場合は OpenLM OneDirectorySync や License Allocation Control の導入を検討してください。
- プラットフォーム固有の要件: Sentry 組織への管理者アクセス権が必要です。必要な読み取り権限を持つ API トークンを生成します。

## データ収集の構成

OpenLM Cloud Broker で Sentry のデータ収集を設定するには、次の手順に従います。

1. 組織設定で新しい内部インテグレーションを作成し、メンバーや組織データを読み取れるトークンを生成します。
   - 「Permissions」で呼び出す API に必要な権限を選択します。各 API エンドポイントのドキュメントに必要なスコープが記載されています。
   - **Save Changes** をクリックします。
   - ページ下部の「Tokens」で生成されたトークンをコピーし、安全な場所に保管します。
2. OpenLM Cloud Broker ダッシュボードで Sentry 連携を選択し、API トークンを入力します。

   ![](/img/saas-platforms/sentry/image24.png)

3. 接続を確認します。OpenLM が Sentry API と通信できることをテストします。
4. OpenLM で承認します。「License Servers」セクションで新しいデータソースを承認します。
5. データを確認します。Sentry の使用状況データが OpenLM Allocation サービスに表示されます。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: プラットフォームで最も活動している開発者を把握し、リソース配分に役立てます。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定してライセンスを回収します。
