# Insightful
Insightful 使用状況の監視

## Insightful について

Insightful は、ワークフォース分析と生産性管理のプラットフォームです。従業員アクティビティを可視化し、チームの効率向上を支援します。Insightful の利用状況を監視すると、プラットフォームが最大限活用されているか、ライセンスが適切に割り当てられているかを確認できます。BambooHR や Humaans などの HR／生産性ツールを監視する場合と同様です。

## 前提条件

Insightful の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。自動化が必要な場合は OpenLM OneDirectorySync や License Allocation Control の導入を検討してください。
- プラットフォーム固有の要件: Insightful アカウントの管理者アクセス権が必要です。読み取り権限を持つ API キーを生成します。

## データ収集の構成

Insightful の API は Bearer トークンによる認証を利用しています。以下の手順でトークンを取得し、OpenLM Cloud Broker に設定します。

1. 組織の管理者アカウントで Insightful にログインします。
2. **API** ページに移動します。
3. 新しいトークンを作成します。
4. トークンに分かりやすい名前を付けます。
5. 「Generate new token」をクリックしてトークンを生成します（このタイミングのみトークンが表示されます）。
6. トークンをコピーし、安全な場所に保管します。
7. OpenLM Cloud Broker ダッシュボードで Insightful 連携を選択し、API キーを入力します。

   ![](/img/saas-platforms/insightful/image40.png)

8. 接続を確認します。OpenLM がデータを取得できることをテストします。
9. OpenLM で承認します。「License Servers」セクションで新しいデータソースを承認します。
10. データを確認します。Insightful の使用状況データが OpenLM Allocation サービスに表示されます。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: ユーザーのアクティビティや利用パターンを監視します。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定し、ライセンスを回収します。
