# TeamCity
TeamCity 使用状況の監視

## TeamCity について

TeamCity は JetBrains が提供する CI/CD サーバーです。ビルド、テスト、デプロイのプロセスを自動化でき、開発者の生産性向上に役立ちます。TeamCity の利用状況を監視すると、開発チームのアクティビティを把握し、コスト最適化につながります。GitLab や Buddy などの CI/CD プラットフォームを監視する場合と同様です。

## 前提条件

TeamCity の監視を開始する前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。
- プラットフォーム固有の要件: TeamCity インスタンスの管理者アクセス権が必要です。必要な読み取り権限を持つ永続トークンを生成します。

## データ収集の構成

OpenLM Cloud Broker で TeamCity のデータ収集を設定するには、次の手順に従います。

1. TeamCity の管理パネルで新しい永続トークンを作成し、ユーザーおよびビルドデータを読み取れる権限を付与します。
2. OpenLM Cloud Broker ダッシュボードで TeamCity 連携を選択し、トークンを入力します。
3. 接続を確認します。OpenLM が TeamCity API と通信できることをテストします。
4. OpenLM で承認します。「License Servers」セクションで新しいデータソースを承認します。
5. データを確認します。TeamCity の使用状況データが OpenLM Allocation サービスに表示されます。

## レポートの閲覧

利用状況を分析するために、以下のレポートを活用します。

- ユーザーアクティビティの推移: プラットフォームで最も活動しているチームや開発者を把握し、リソース配分に役立てます。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーを特定してライセンスを回収します。
