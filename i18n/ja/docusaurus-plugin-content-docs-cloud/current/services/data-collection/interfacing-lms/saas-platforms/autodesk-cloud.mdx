# Autodesk Cloud
Autodesk Cloud 使用状況の監視

## Autodesk Cloud について

Autodesk Cloud は、建築、エンジニアリング、建設、製造業向けに設計されたクラウドベースの設計・製造ソフトウェア群を提供します。Revit、AutoCAD、Fusion 360 などのツールが含まれています。高額なライセンスコストが発生するため、Autodesk Cloud の利用状況を監視することで、ライセンスを適切なユーザーが効率的に利用しているかを確認できます。Bentley や Intergraph などのエンジニアリング／デザインプラットフォームを管理する場合と同様です。

## 前提条件

Autodesk Cloud の監視を始める前に、以下の要件を確認してください。

- OpenLM コンポーネント: OpenLM Cloud Broker と OpenLM SLM が必要です。自動化が必要な場合は OpenLM OneDirectorySync や License Allocation Control を検討してください。
- プラットフォーム固有の要件: Autodesk Account Management ポータルへの管理者アクセス権が必要です。利用状況データへのアクセス権を持つ API キーやトークンを取得します。

## データ収集の構成

Autodesk Cloud 連携の設定については、サポートチーム（[support@openlm.com](mailto:support@openlm.com)）までお問い合わせください。

## レポートの閲覧

利用状況を分析するために、次のレポートを確認します。

- ユーザーアクティビティの推移: どのプロジェクトやユーザーがライセンスを多く消費しているかを把握し、再割り当てに活用します。
- 期限切れ／未使用ライセンスレポート: 非アクティブなユーザーからライセンスを回収し、コスト削減につなげます。
