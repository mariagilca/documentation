# クラウドブローカー（Cloud Broker）


**Cloud Broker** は、クラウドベースのアプリケーション向け Broker サービスの管理・設定インターフェースを提供します。ライセンスサーバーと OpenLM システム間の円滑な通信を確保するため、クラウドブローカーの監視・更新・設定に利用します。

OpenLM プラットフォームから直接アクセスできます。

## 構成手順

以下の手順で Cloud Broker を構成します。

1. **Navigation** から **Cloud Broker** を開きます。
2. 一覧から対象サービスを選択します。
3. 選択したサービスのパラメータを調整します。
4. **Save** を選択して変更を適用します。
