# Freshworks アラート

本ガイドでは、Freshworks アラート連携の概要、設定手順、主な機能を説明します。

## 概要

Freshworks アラート連携により、Freshworks アカウントと監視ツールを接続して、監視と通知をシームレスに実現します。これにより、重要イベントに対してタイムリーに通知を受け、即座に対応できます。

## 主な機能

- **リアルタイム通知**: 重要イベントを即時に通知。
- **柔軟な設定**: 要件に合わせてアラート設定をカスタマイズ。
- **シームレス連携**: 既存の監視ツールと接続。
- **実行可能な示唆**: パフォーマンスや問題の洞察を提供。

## 前提条件

連携設定の前に次を確認してください。

- 管理者権限を持つ Freshworks アカウント
- 監視ツールの API 認証情報
- 連携を構成するための権限

## 設定手順

以下の手順で Freshworks アラート連携を構成します。

1. **Freshworks にログイン**:
    - Freshworks アカウントにアクセスし、認証情報でログインします。

2. **Integrations ページへ移動**:
    - 設定メニューから「Integrations」を選択します。

3. **監視ツールの選択**:
    - 連携する監視ツールを選択します。

4. **API 情報の入力**:
    - 監視ツールの API キーや認証情報を入力します。

5. **アラートルールの設定**:
    - アラートのトリガー条件やしきい値を定義します。

6. **テスト**:
    - テストアラートを送信し、連携が機能していることを確認します。

7. **Save**:
    - 設定を保存して連携を有効化します。

## アラートの管理

- **閲覧**: アラートダッシュボードで、発生中/解決済みのアラートを確認。
- **確認（Acknowledge）**: 対応中であることを示すため既読化。
- **解決**: 問題解消後にアラートをクローズ。

## トラブルシューティング

連携で問題が発生した場合:

- API 認証情報が正しいか確認。
- 監視ツールの API にアクセスできるか確認。
- ネットワーク/ファイアウォール制限の有無を確認。
- Freshworks のログでエラー詳細を確認。
