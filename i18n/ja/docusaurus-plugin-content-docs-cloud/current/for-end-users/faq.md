# よくある質問

## なぜ私のコンピューターに Workstation Agent がインストールされているのですか？

Workstation Agent は、組織がソフトウェアの使用状況を追跡し、ライセンスを公平に共有できるように支援します。監視対象はライセンス対象のアプリケーションのみで、個人のファイルやアクティビティは対象外です。

## OpenLM によりコンピューターが遅くなりますか？

Workstation Agent は軽量に設計されており、最小限のリソース使用量でバックグラウンドで動作します。

## なぜライセンスが拒否されたのですか？

リクエストした時点で、利用可能なライセンスがすべて使用中でした。対処法については、[拒否されたときの対処法](./dealing-with-denials) を参照してください。

## 自分の使用データを確認できますか？

はい。OpenLM ポータルにログインすると、アクティブなセッションと使用履歴を確認できます。[個人ダッシュボード](./personal-dashboard) を参照してください。

## 困ったときは誰に連絡すればよいですか？

IT 管理者またはライセンス管理者に連絡してください。ツール固有の問題については、OpenLM サポートチームにエスカレーションされる場合があります。
