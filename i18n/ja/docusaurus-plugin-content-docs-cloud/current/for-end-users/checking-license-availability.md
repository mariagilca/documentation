ライセンスを使用するアプリケーションを起動する前に、現在ライセンスが利用可能かどうかを確認できます。

## ポータルからの確認

1. OpenLM ポータルにログインします (URL は管理者から提供されます)。
2. **License Availability** に移動するか、製品名で検索します。
3. ダッシュボードで、使用中と空きのライセンス数を確認できます。

## ヒント

- すべてのライセンスが使用中の場合は、数分後に再度確認してください。セッションが終了するとライセンスが解放されることがよくあります。
- 必要なときに常にライセンスを取得できない場合は、管理者に連絡してください。
