# 拒否されたときの対処法

ライセンスの拒否は、現在すべてのライセンスが使用中であることを意味します。対処方法は以下のとおりです。

## すぐにできる対応

1. **待って再試行**: ユーザーがアプリケーションを閉じるとライセンスは解放されます。数分後に再度試してください。
2. **空き状況を確認**: [OpenLM ポータル](./checking-license-availability) にログインして、現在のライセンス数とライセンスを保持しているユーザーを確認します。
3. **ライセンス保持者に連絡**: 最後のライセンスを保持しているユーザーが分かり、急ぎの用件であれば、直接連絡してください。

## 拒否が頻繁に発生する場合

継続的な拒否は、組織がさらにライセンスを必要としていることを示している可能性があります。拒否が発生した日時を記録し、管理者や IT チームに報告してください。OpenLM は拒否レポートを生成し、管理者がライセンスを追加購入するための根拠として活用できます。
