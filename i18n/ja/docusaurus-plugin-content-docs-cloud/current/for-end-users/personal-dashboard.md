# 個人ダッシュボード

OpenLM のユーザーポータルでは、自分のソフトウェア使用状況とライセンスアクティビティを確認できます。

## 表示できる情報

- **アクティブなセッション**: 現在開いていて、ライセンスを使用しているソフトウェア
- **使用履歴**: 各ライセンスツールをどのくらいの頻度で使用しているか
- **ライセンスの空き状況**: 現在何本のライセンスが空いていて、何本が使用中か

## ダッシュボードへのアクセス

管理者から OpenLM ポータルの URL が提供されます。組織の認証情報 (コンピューターや業務アプリで使用しているものと同じ) でログインしてください。
