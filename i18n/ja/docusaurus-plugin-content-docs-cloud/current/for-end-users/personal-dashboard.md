OpenLM のユーザーポータルでは、自分のソフトウェア使用状況とライセンスアクティビティを確認できます。

## 表示できる情報

- **アクティブなセッション**: 現在開いていて、ライセンスを使用しているソフトウェア
- **使用履歴**: 各ライセンスツールをどのくらいの頻度で使用しているか
- **ライセンスの空き状況**: 現在何本のライセンスが空いていて、何本が使用中か

## ダッシュボードへのアクセス

個人ダッシュボードは、お使いのコンピューターで動作する OpenLM Workstation Agent によって提供されます。IT チームが Agent をインストールすると、ダッシュボードがマシン上で利用可能になります。展開方法によっては、インストール後に自動的に開く場合もあれば、管理者から開き方の案内がある場合もあります。組織の認証情報 (コンピューターや業務アプリで使用しているものと同じ) でサインインしてください。

:::note[管理者向け]
前提条件と展開オプションについては、[個人ダッシュボードのセットアップ](/cloud/users/personal-dashboard) を参照してください。
:::
