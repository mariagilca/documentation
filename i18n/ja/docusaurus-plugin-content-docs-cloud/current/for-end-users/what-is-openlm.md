# OpenLM とは

OpenLM は、組織がライセンスソフトウェアへのアクセスを管理するために使用しているシステムです。誰がどのプログラムをどのくらいの時間使用しているかを追跡し、チーム全体でライセンスが公平かつ効率的に共有されるようにします。

以下のような形で OpenLM に気づくことがあります。

- **Workstation Agent**: コンピューター上にインストールされる小さなバックグラウンドアプリケーションで、ソフトウェアの使用状況を報告します。
- **ライセンス拒否の通知**: プログラムを開こうとしたときにすべてのライセンスが使用中だった場合、OpenLM から通知が届いたり、リクエストがキューに入れられたりすることがあります。
- **個人ダッシュボード**: ライセンスの空き状況や自身の使用履歴を確認できるウェブポータルです。

OpenLM はバックグラウンドで動作し、作業を妨げません。その目的は、ライセンスを必要とするすべてのユーザーがライセンスを取得できるようにすることです。
