Manage users, groups, email aliases, user aliases, and workstations. View, create, and edit entries for each entity.
## Prerequisites
Users and Groups is enabled by default for every account.

## Users panel
The Users panel lists all users added from any source (manual, license usage, options file, agent, LDAP).
**Controls**  
- **Top right:**  
  - **Import** – Export the current list as a CSV template, modify it, then re-import to update or add users.  
  - **Export** – Download the list as CSV or PDF.  
  - **Refresh** – Reload the list.  
  - **Filter** – Enable column filters.  
  - **Search** – Find users by any field.  
  - **Columns menu (⋮)** – Show or hide columns, restore defaults, or print the current page.  
- **Top left:**  
  - **Add user** – Open the Add User form.  
  - **Disable user** – Deactivate selected users.  
  - **Show disabled** – Toggle visibility of disabled users.  
![Users panel](/img/users_and_groups/users.png "This is the users panel")



### Add a new user
1. Click **Add user**.  
2. In the **General** tab, **Username** is required; all other fields are optional.  
3. For **Title**, choose from the dropdown or enter a custom title and click **Add to list**.  
4. Toggle **Enabled** on or off (default: on).  
5. Select **Country** from the dropdown (used by Compliance).  
6. Fill in any additional fields as needed:  
   - First Name  
   - Last Name  
   - Email  
   - Display Name  
   - Phone  
   - Mobile Phone  
   - Description  
   - Department  
   - Office  
   - Source (always “ManualEditing” when creating manually)  
![Adding a new user](/img/users_and_groups/add-user.png)


###  Add user to groups
1. Open the **Groups** tab.  
2. Click **Add to Group**.  
3. Select one or more groups and click **Add**.  
4. To remove a user from a group, select the group and click **Remove**.  
5. Click **Set as default** to choose the user’s default group (used in reporting).  
6. Check **Show Disabled** to view disabled groups.  
7. Use **Search** to filter the group list.
![Adding user to a group](/img/users_and_groups/add-user-to-group.png)

### Manage email aliases
Email aliases link multiple email addresses to a user.
1. Open the **Email Aliases** tab.  
2. Click **Add alias**.  
   - Select an existing alias, or  
   - Enter a new alias and click **Add**.  
3. To detach an alias, select it and click **Remove**.

### Manage user aliases
User aliases merge related user accounts under a primary user.
1. Open the **User Aliases** tab.  
2. Click **Attach alias**.  
   - Select one or more existing users to attach as child aliases.  
3. To detach an alias, select it and click **Remove**.

### Edit an existing user
1. In the Users panel, click the **Edit** (pencil) icon on the desired row.  
2. Update any field using the same options described in **Add a new user**.  
3. Click **Save** to apply changes.
