# License Parser

License Parser は、難解な FlexLM ライセンスファイルを人間に読みやすいレポートに変換します。ライセンスサーバーに渡す前にライセンスファイルを確認したり、想定どおりの機能が含まれているかを検証したり、ライセンステキストを直接扱わない関係者と整理されたサマリーを共有したりするために使用します。

## License Parser でできること

- FlexLM ライセンスファイルをアップロードまたは指定する。
- ベンダー、機能、有効期限、数量、ホストやユーザーの制約を構造化された形で表示する。
- 解析されたレポートを、購入内容を確認したい技術者以外の関係者と共有する。

## プラットフォーム上の場所

OpenLM Cloud アプリランチャーを開き、**Licenses and Features → License Parser** を選択します。

## 前提条件

- [Products](./openlm-administration/products) で **License Parser** を有効化した OpenLM Platform アカウント。
- 確認したい FlexLM ライセンスファイルへのアクセス。
