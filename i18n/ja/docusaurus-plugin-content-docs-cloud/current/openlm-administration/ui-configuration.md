このガイドでは、UI の設定とカスタマイズ方法を説明します。要件に合わせてインターフェースを調整してください。

## 設定可能な項目

- Time zone（タイムゾーン）
- Date format（日付形式）
- Decimal symbol（小数点記号）
- Thousands separator（桁区切り記号）
- Number of records per page（1 ページ当たりの表示件数）
