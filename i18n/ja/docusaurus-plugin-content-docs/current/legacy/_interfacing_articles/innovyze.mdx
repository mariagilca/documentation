# Innovyze

This integration enables OpenLM to monitor Innovyze for license usage, denials, and borrowed license reporting.

## Requirements

1. OpenLM Server v4.7 or higher installed on a central network server.
2. OpenLM Broker v4.14.0 or higher installed on the same machine as Innovyze.

## Monitoring capabilities and features

| Feature | Resolution | License totals | License usage | Denials reporting | Borrowed license reporting | Expiration date reporting | Multiple server redundancy |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Support | By second | ✔ | ✔ | ✔ | ✔ | ❌ | ❌ |

Additionally, using OpenLM Broker allows for buffered communication and the ability to remotely start or stop the Innovyze service.

## OpenLM Broker configuration

![Diagram of how OpenLM interfaces with Innovyze](https://www.openlm.com/wp-content/uploads/2021/07/word-image.png)
*Diagram of how OpenLM interfaces with Innovyze.*

OpenLM Broker reads the Innovyze `LicenseMonitor` log file, compiles the data, and sends it to OpenLM Server for processing.

:::note
You must have OpenLM Broker installed and reporting to OpenLM Server before starting this configuration.
:::

### Automatic configuration

1. In the OpenLM Broker configuration tool, click **Detect** in the bottom-right corner.
2. If the Innovyze process or service is running, Broker automatically creates a port node with the required settings.
3. Click **Apply**.
4. Click **Restart Broker** to send changes to OpenLM Server.
5. To verify, go to **Commands → data_query** and click **Execute**.

### Manual configuration

1. Click **Add Port**.
2. Enter the Innovyze port number (e.g., `20230`).
3. Set **License Manager Type** to **Innovyze** and click **Apply**.
4. Under **Vendors**, select “Vendor Name to Be Filled,” enter **Innovyze**, and click **Apply**.
5. Select the **Log Files** node and click **Add Log File**.
6. Select the newly created **log** node, click **[…]**, and browse to the CSV log file location (typically `C:\ProgramData\Innovyze<LM>#.#\Usage` where `#.#` is the version, e.g., `6.0`).
7. Click **Advanced**, then check **Watch Files by Pattern**.
8. Click **Apply**.
9. Click **Restart Broker**.

## OpenLM Server configuration

### Automatic configuration via EasyAdmin

1. Open EasyAdmin via browser (`http://<OpenLM Server IP>:7019/EasyAdmin2/`) or **Windows Start → OpenLM → OpenLM EasyAdmin User Interface**, or log in to **Cloud.OpenLM.com**.
2. In **License Servers**, click the message showing pending approvals.
3. Enter a display name (e.g., Innovyze).
4. Click **Approve**.

![](https://www.openlm.com/wp-content/uploads/2021/07/word-image-3.png)
![](https://www.openlm.com/wp-content/uploads/2021/07/word-image-4.png)

### Manual configuration

1. Open the OpenLM Server configuration tool (**Windows Start → OpenLM → OpenLM Server**).
2. Select the **License Servers** tab.
3. Click **Add**.
4. From **Type**, select **OpenLM Generic**.
5. Enter a description (e.g., Innovyze).
6. Set the correct **Time Zone** for the server.
7. Enter the **Hostname** and **Port** matching the Broker configuration.
8. Leave **Is Triad Configuration** unchecked.
9. Check **Use Broker**.
10. Click **Apply** and close the tool.

## How to verify configuration

1. Open EasyAdmin.
2. Go to **Start → Widgets → License Servers**.
3. Verify that Innovyze appears with a green status indicator.

![](https://www.openlm.com/wp-content/uploads/2021/07/word-image-5.png)

:::note
It may take up to 3 minutes for a new connection to appear as active in EasyAdmin.
:::
