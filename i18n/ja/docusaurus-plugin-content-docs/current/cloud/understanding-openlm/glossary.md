用語集
この用語集では、OpenLMのドキュメント全体で使用される主要な用語、頭字語、およびフレーズを定義します。

用語	定義
Alerts	OpenLMのアラートを使用すると、ライセンス管理者は条件を定義し、その条件が満たされたときに通知を受け取ることができます。これにより、ライセンスシステムの安定性が確保されます。
Annapurna	OpenLMプラットフォームの最新バージョンで、ライセンス管理および監視機能が強化されています。
API	Application Programming Interface (アプリケーション・プログラミング・インターフェース) の略。
Broker	OpenLMとライセンスマネージャー間の通信を促進する仲介ソフトウェアコンポーネントで、ライセンス使用データを標準化された形式に変換します。
Component (OpenLM)	機能拡張のためにOpenLMコアプラットフォームとは別にデプロイされるソフトウェアモジュールです。例として、OpenLM License Server Broker、Workstation Agent、Directory Sync Agentなどがあります。
Concurrent usage	ある瞬間に使用されているライセンスの数。
Denied usage	利用可能なすべてのライセンスが使用中のため、ライセンスへのアクセスがブロックされたインスタンス。
Feature	OpenLMによって追跡される、ライセンスソフトウェアアプリケーションの特定の機能、モジュール、またはコンポーネント。
Historical reports	過去の期間のライセンス使用状況を分析するレポートで、傾向の特定や需要の予測に役立ちます。
Idle time	ライセンスがチェックアウトされているが、アクティブに使用されていない時間。
License file	ライセンス数、アクティブ化された機能、有効期限、使用制限などのライセンス情報を含むデジタルドキュメント。
License manager	ライセンスの配布と使用を制御し、制限を超えないようにするソフトウェアです。例: FlexNet, IBM LUM, Sentinel RMS。
License server	ライセンスマネージャーソフトウェアをホストし、ネットワーク全体のライセンス配布と認証を処理するサーバーです。
License utilization	利用可能なライセンスのうち、時間の経過とともにどれだけが使用されているかを示す指標で、ソフトウェアの使用効率を評価するのに役立ちます。
Microservice	特定のタスクを実行する独立したソフトウェアサービスで、多くの場合、より大きなマイクロサービスベースのアーキテクチャの一部を形成します。
On-premises	物理的なまたはプライベートクラウドの、組織自身のインフラストラクチャでホストされるOpenLMソフトウェアを指します。
OpenLM Platform	Engineering Licensing、SAM、SaaS管理のためのOpenLMのサービスと製品を網羅するコアシステム。
OpenLM token	OpenLMトークンは、OpenLMソフトウェアライセンス管理システム内で使用されるライセンス資格の一種です。特定のOpenLM機能や機能をアクセス・利用するための、柔軟で再利用可能な測定単位として機能します。
Platform	マイクロサービス上に構築された、OpenLMスイート内のライセンス管理と監視のための中央プラットフォーム。
Options file	ユーザーやグループの制限、借り出し設定など、ライセンスアクセスポリシーを制御するために使用されるFlexNetの設定ファイル。
Perpetual licensing	ソフトウェアを無期限に使用するためのモデルで、通常は前払い料金と年間保守料が発生します。オンプレミスでのデプロイメントでのみ利用可能です。
Product (OpenLM)	OpenLMの個別の製品で、コア製品またはオプション製品のいずれかで、有効化するとシステムリソースを消費する場合があります。例：Dongle Monitoring、Software License Management。
Project	OpenLMにおける、チーム、部門、またはプロジェクトごとにライセンス使用データを整理し、追跡およびレポートを行うための分類方法。
Real-time reports	現在のライセンス使用状況、利用可能性、拒否に関する最新のビューを提供するレポート。
Role	OpenLMシステム内のユーザーに割り当てられる権限とアクセスレベルを定義します。
Session	ユーザーによるソフトウェア使用のアクティブなインスタンスで、開始/終了時刻、アプリケーション、ワークステーションなどの詳細がOpenLMによって追跡されます。
User	OpenLMによって追跡される、ライセンスアプリケーションを使用する個人です。名前、チーム、ワークステーションなどの属性が記録されます。
Usage monitoring	ライセンス消費を分析および最適化するために、ソフトウェアの使用状況を追跡・記録するプロセス。
Workstation	ユーザーがライセンスソフトウェアにアクセスするコンピューターまたはデバイスで、組織全体のライセンス使用状況をマッピングするためにOpenLMによって追跡されます。
Workstation Agent	エンドユーザーのワークステーションにインストールされる小型のソフトウェアプログラムで、ソフトウェアライセンスの使用データを収集し、Agents Hubを介してOpenLMプラットフォームに送信します。
