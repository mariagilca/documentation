OpenLM Workstation Agentの役割
OpenLM Workstation Agentは、ソフトウェアライセンスの使用状況を監視し、最適化するためにエンドユーザーのマシンにインストールされます。これにより、ライセンスサーバーがレポートする情報に加え、ライセンスされたソフトウェアが「どのように、いつ、使用されているか」をリアルタイムでエンドポイントレベルで可視化できます。

このガイドでは、Agentが以下の点でどのように役立つかを説明します。

遊休ライセンスの検出と再利用

高度な管理ポリシーの適用

ユーザーへの透明性と管理権の付与

遊休ライセンス
ライセンスはチェックアウトされていても、アクティブに使用されていないことがよくあります。例えば、ユーザーがAutoCADを開いたまま離席すると、ライセンスが占有されたままになります。この状態は以下のような問題を引き起こします。

アクセスの妨害: 他のユーザーがソフトウェアにアクセスできなくなります。

誤った需要: 高いチェックアウト率が、過剰な購入につながります。

予算の無駄: 遊休ライセンスが、価値を提供することなくリソースを消費します。

遊休時間の監視と未使用ライセンスの再利用
遊休時間の追跡
遊休時間とは、ライセンスされたアプリケーションが開いているものの、アクティブに使用されていない（そのアプリに対してキーボードやマウスの入力がない）状態を指します。Workstation Agentは遊休時間を追跡し、OpenLMに送信します。

セッションが遊休時間の閾値を超えると、OpenLMはそれを遊休状態としてマークし、以下を表示します。

実行中のすべてのソフトウェアセッション

各アプリケーションの遊休時間

アクティビティと非アクティビティを示すセッションタイムライン

遊休ライセンスの自動再利用
ライセンスハーベスティングは、遊休セッションからライセンスを再利用し、他のユーザーが利用できるようにプールに戻します。

ハーベスティング方法の選択
OpenLMは、アプリケーションとライセンスの種類に応じて、いくつかのハーベスティング戦略をサポートしています。

保存＆終了: ユーザーの作業を保存し、アプリを閉じます。OpenLM拡張機能が必要です。以下のアプリケーションで一般的です。

ArcGIS / ArcGIS Pro

AutoCAD

SOLIDWORKS

MATLAB

CATIA

一時停止＆再開: アプリを一時停止します（FlexLMに最適）。ユーザーは個人のダッシュボードから再開できます。

強制終了: 保存せずにアプリを強制的に終了します。他のオプションが利用できない場合にのみ使用してください。

セッションの制御、ポリシーの定義
プロセスマネージャーを使用して監視ルールを定義
プロセスマネージャーでは、Agentが各アプリケーションをどのように処理するかを設定できます。

プロセスの設定
「プロセス」タブで設定します。

名前: 正確な実行ファイル名を入力します（大文字小文字を区別）。

ライセンスサーバートグル:

オン: プロセスをライセンス機能にリンクします。

オフ: スタンドアロンアプリ用です。

遊休時の動作を定義
「ライセンスリリース」タブで設定します。

リリース方法: 保存＆終了、一時停止＆再開、カスタムプロシージャ、またはなしから選択します。

リリース条件: 遊休時間の閾値（例: 60分）を設定したり、使用率が一定のレベル（例: 90%）に達した場合のみリリースするように設定したりします。

高度な検出: CPU、I/O、またはアクティビティレベルに基づいて詳細を調整します。

エージェントプロシージャ: カスタムアクションを定義します（例: Agent Kill、Agent Save&Close）。

シャドウライセンスポリシーを適用
「シャドウライセンス」タブを使用して、ライセンスマネージャーのないアプリケーションを管理します。

消費ルールを定義
ポリシータタイプ:

プロセス: 実行中のインスタンスごとに1ライセンス。

ワークステーション: マシンごとに1ライセンス。

ワークステーションのユーザー: ユーザー/マシンコンボごとに1ライセンス。

指名ユーザーの制限: 同じユーザーが複数のマシンでアプリを使用するのを防ぎます。

同時実行とバージョン管理: 複数のバージョンをブロックしたり、同時使用を制限したりします。

リリースルールを定義
リリース遅延: 猶予期間を設定します（例: 10分）。

バケット期間:

DAY: ライセンスは深夜0時にリリースされます。

HOUR: 時間のトップでリリースされます。

NONE: 遅延後すぐにリリースされます。

プロセスセッションレポートを確認
プロセスセッションレポートは、ライセンスのチェックアウト以外の、ユーザーのマシンで何が起こったかを記録します。

データには以下が含まれます。

プロセス名、ユーザー、ホスト

セッションの開始時間と終了時間

合計遊休時間

シャットダウン理由（例: ユーザーまたはエージェントによって終了）

:::note
過去のセッションの遊休時間を確認するには、ライセンスサーバーのデータではなく、プロセスセッションレポートを使用します。
:::

個人ダッシュボードを使用してセルフサービスをサポート
個人ダッシュボードは、ユーザーが自身のライセンス使用状況を理解し、管理するのに役立ちます。

主な機能:

ライセンスの利用可能性: リアルタイムの状況を確認し、誰が各ライセンスを保持しているかを確認できます。

最近終了したアプリ: OpenLMによって終了されたアプリが表示され、再開するための「再開」ボタンがあります。

プロジェクト: レポートのために、使用状況を特定のプロジェクトに紐づけることができます。

ライブフィード: ローカルのAgentからの診断ログを表示します。
