OpenLM とは?
OpenLM ドキュメントへようこそ。

OpenLM は、エンジニアリング、科学、その他技術的な環境に特化したソフトウェアライセンス管理およびソフトウェア資産管理 (SAM) ソリューションです。オンプレミス、ハイブリッド、クラウドのインフラストラクチャにおけるソフトウェアライセンスの使用状況を監視、最適化、制御するのに役立ちます。

OpenLM は、FlexNet、DSLS、Sentinel RMS、Reprise、LM-X を含む 100 以上のライセンスマネージャーに対応しています。また、Autodesk Cloud のようなクラウドベースのライセンスプラットフォームを管理するための専用ツールも含まれています。

主な機能
コンプライアンスと監査への対応
  ベンダー準拠のレポートを生成し、使用ポリシーを適用し、不正なアクティビティを検出することで、監査に備えることができます。

クラウドライセンス管理
  専用ツールを使用して、SaaS およびトークンベースのライセンスモデルを監視および制御します。

高度な使用状況分析
  ユーザー、機能、またはワークステーションごとのリアルタイムおよび履歴の使用状況データを表示して、傾向やアイドル消費を特定します。

ポリシー適用とアクセス制御
  設定可能な割り当てルールにより、ライセンスの解放を自動化し、アクセス制限を適用し、拒否を減らします。

エンタープライズ統合
  LDAP、SAML、ITSM プラットフォーム、レポートツール、および内部システムに接続します。

マルチ環境対応
  分散、仮想化、クラウドホスト環境にわたるライセンスを、統合されたインターフェースから管理します。

セットアップ、構成、および高度な機能を開始するにはドキュメントをご覧ください。
