# OpenLM とは？

OpenLM ドキュメントへようこそ。

OpenLM は、エンジニアリング、科学、その他の技術分野向けに特化したソフトウェアライセンス管理およびソフトウェア資産管理（SAM）ソリューションです。オンプレミス、ハイブリッド、クラウド環境にわたり、ソフトウェアライセンスの使用状況を監視・最適化・制御するのに役立ちます。

OpenLM は FlexNet、DSLS、Sentinel RMS、Reprise、LM-X を含む 100 以上のライセンスマネージャーをサポートしています。さらに、Autodesk Cloud などのクラウドベースのライセンスプラットフォームを管理するための専用ツールも含まれています。

## 主な機能

- コンプライアンスと監査対応  
  ベンダー準拠のレポートを生成し、利用ポリシーを適用し、不正なアクティビティを検出して監査に備えることができます。

- クラウドライセンス管理  
  SaaS やトークンベースのライセンスモデルを専用ツールで監視・管理します。

- 高度な使用状況分析  
  ユーザー、機能、ワークステーション別にリアルタイムおよび履歴データを表示し、利用傾向や遊休消費を把握できます。

- ポリシー適用とアクセス制御  
  ライセンス解放を自動化し、アクセス制限を適用し、割り当てルールの設定によって利用拒否を減らします。

- エンタープライズ統合  
  LDAP、SAML、ITSM プラットフォーム、レポートツール、社内システムと接続できます。

- 複数環境対応  
  分散型、仮想化、クラウドホスティング環境にわたり、統合インターフェースからライセンスを管理できます。

ドキュメントを参照して、セットアップ、構成、そして高度な機能の利用を開始してください。
