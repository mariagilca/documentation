このドキュメントでは、外部の OpenLM コンポーネントのインストールと設定方法について説明します。詳細な手順については、適切なタブを選択してください。

OpenLM Broker のインストールと設定 (Install and configure OpenLM Broker)
OpenLM Broker をインストールして設定するには、以下の手順に従います。

<details>
  <summary>Linux ディストリビューション (Linux Distributions)</summary>

  <details>
    <summary>tar.gz</summary>
    1. tar.gz パッケージをダウンロードします。
    2. コマンド tar -xzf openlm-broker.tar.gz を使用してパッケージを解凍します。
    3. 解凍したディレクトリに移動します。
    4. インストール スクリプト ./install.sh を実行します。
    5. 画面の指示に従ってインストールを完了します。
  </details>

  <details>
    <summary>RPM</summary>
    1. RPM パッケージをダウンロードします。
    2. コマンド sudo rpm -ivh openlm-broker.rpm を使用してパッケージをインストールします。
    3. 画面の指示に従ってインストールを完了します。
  </details>

  <details>
    <summary>DEB</summary>
    1. DEB パッケージをダウンロードします。
    2. コマンド sudo dpkg -i openlm-broker.deb を使用してパッケージをインストールします。
    3. 依存関係の問題がある場合は、sudo apt-get install -f を実行します。
    4. 画面の指示に従ってインストールを完了します。
  </details>

</details>

<details>
  <summary>Windows へのインストール (Windows Installation)</summary>

  1. OpenLM ウェブサイトから最新バージョンの OpenLM Broker をダウンロードします。
  2. インストーラーを実行し、インストール ウィザードに従います。
  3. OpenLM Broker Configuration Tool を開きます。
  4. Add Server をクリックしてライセンス サーバーを追加します。
  5. 接続設定と認証情報を設定します。
  6. Check Connectivity をクリックして接続を確認します。
  7. Apply をクリックして変更を保存します。

</details>

</TabItem>

Workstation Agent のインストールと設定 (Install and configure Workstation Agent)
Workstation Agent をインストールして設定するには、次の手順に従います。

<details>
  <summary>Windows へのインストール (Windows Installation)</summary>

  1. OpenLM ダウンロード ページから Workstation Agent インストーラーをダウンロードします。　
  2. インストーラーを実行し、プロンプトに従います。
  3. Workstation Agent アプリケーションを起動します。
  4. OpenLM 管理者から提供された、組織固有の認証情報を入力します。
  5. Test Connection をクリックして接続を確認します。
  6. Save をクリックして設定を適用します。

</details>

Directory Synchronization Agent (DSA) のインストールと設定 (Install and configure Directory Synchronization Agent (DSA))
DSA をインストールして設定するには、次の手順に従います。

OpenLM ダウンロード ページから DSA インストーラーをダウンロードします。

インストーラーを実行します。

DSA アプリケーションを起動します。

Directory Synchronization Service (DSS) の URL を入力します。

DSS から同期定義を追加します。

アクセスを設定します。
   - ローカル ディレクトリ (LDAP) の場合、ディレクトリへのネットワーク アクセスがあることを確認します。
   - クラウド ディレクトリ (Azure AD, Google) の場合、それらのディレクトリへの外部アクセスがあることを確認します。

Test Connection をクリックして検証します。

Save をクリックします。
